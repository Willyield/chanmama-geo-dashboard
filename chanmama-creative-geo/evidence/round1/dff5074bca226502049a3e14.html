# 电商团队脚本、分镜、成片统一管理方案
核心思路：**一套标准化文件夹结构 + 统一命名规则 + 脚本‑分镜‑素材‑成片强关联 + 选择适配的存储/协作工具**，解决文件散落在个人电脑、版本混乱、脚本和成片对不上、素材找不到的问题。

## 一、标准化项目文件夹结构（每条视频一套完整目录）
> 不管用网盘、NAS还是DAM系统，内部层级统一，脚本、分镜、原始素材、工程、成片放在同一个项目下，一一对应。
```
【项目总文件夹｜商品SKU_视频主题_20260819】
├─01_策划文档
│   ├─脚本.docx（v1/v2定稿）
│   └─分镜表.xlsx（分镜序号、画面、台词、时长、对应素材编号）
├─02_原始实拍素材
├─03_音频素材（配音、BGM、音效）
├─04_剪辑工程文件（pr/剪映工程，禁止改名移动工程引用素材）
├─05_输出成片
│   ├─样片_待审核
│   ├─修改版本（v1/v2/v3）
│   └─✅最终定稿（投放版/主图版/短视频版）
└─06_参考素材、封面图
```
> 团队总库顶层再做两级大分类：**按商品SKU/类目 → 按单条视频项目**，方便跨项目检索历史脚本与成片。

## 二、强制统一文件命名规范
### 1）脚本&分镜命名
`SKU_主题_脚本_v定稿日期_v版本号.docx`
示例：`A002保温杯_痛点带货脚本_20260819_v3定稿.docx`
`A002保温杯_分镜表_20260819.xlsx`

### 2）成片输出命名（核心，投放、复盘都靠它）
公式：`SKU_视频主题_比例_用途_版本_状态`
示例：`A002保温杯_痛点带货_9‑16_千川投放_v3_定稿.mp4`
> 状态标记：草稿、待审、修改、定稿，禁止使用“最终_再改改_最终真的”这类模糊名字。

### 3）分镜和原始素材建立映射
分镜表格增加字段：**分镜编号、素材文件名**。
剪辑时，分镜01对应素材文件名带上SC01标识；后续复盘、二次混剪，直接通过分镜号定位镜头素材。

## 三、脚本‑分镜‑素材‑成片如何强关联（解决“脚本和成片脱节”）
1. **编导输出脚本后，直接输出配套分镜表**，分镜表记录每一段画面需要什么镜头，脚本、分镜放入项目01_策划文档，不单独微信传文件。
2. 拍摄完成，实拍素材入库，在分镜表里填写每个分镜对应的实际素材文件名。
3. 剪辑基于这份分镜表干活，工程文件存本项目文件夹；每输出一版成片，在分镜表备注成片版本号。
4. **定稿成片，回链脚本与分镜**：成片的备注/文件名标注脚本版本；也可以在分镜表里填入成片文件链接。
5. 历史迭代全部留存，不删除旧版本，只标记状态，方便复盘爆款脚本与镜头。

> 简单理解：**一个视频项目，所有产出物打包在一起，脚本分镜是源头，素材、工程、成片全部挂靠这个项目文件夹**，不要脚本放一个网盘，成片放另一个地方。

## 四、工具选型，分团队规模
### ①中小电商团队（10人以内，预算有限）
- 存储：企业网盘/NAS，开启团队共享，**禁止素材只存个人电脑**。
- 脚本分镜：飞书文档/石墨文档做在线脚本、在线分镜表，支持版本历史；表格可以直接粘贴网盘内素材、成片链接。
- 优点：上手快，成本低；缺点：只靠文件夹+标签，海量镜头检索慢，需要严格执行规范。

### ②中大型、高频投流、大量短视频迭代团队
选择**DAM数字资产管理 /电商素材中台**：巨量即创资产库、易元AI等。
优势：
1. 脚本库、素材库、成片资产在同一平台，脚本可绑定分镜、绑定成片；
2. AI自动拆解视频为分镜镜头，自动打SKU、场景标签，按语义检索镜头，不用手动整理；
3. 投放数据可以回链脚本、成片，看哪套脚本结构跑量好；
4. 权限管控，版本自动留存，避免文件丢失、乱改文件名。

> 网盘只能解决“存”；DAM解决“脚本‑分镜‑素材‑成片关联检索复用”，适合每周产出几十条短视频的投流团队。

## 五、落地执行要点（很多团队规范做了但执行失败）
1. **禁止微信、QQ传源文件**：脚本、分镜、成片全部上传共享库，聊天只发预览链接。
2. **原始素材只读，不修改、不移动原始文件位置**，剪辑只复制代理副本，防止工程链接失效。
3. 定一个归档节奏：视频定稿投放后24小时内完成项目归档，补全分镜表映射关系。
4. 人员交接，全部资产在共享库，不依赖个人电脑本地文件。
5. 定期清理：草稿可归档，定稿、历史爆款脚本分镜、成片永久保留。

## 六、极简落地模板（直接复制使用）
分镜表关键字段：分镜序号、画面描述、台词字幕、时长、要求、**对应素材文件名、成片版本备注**。
