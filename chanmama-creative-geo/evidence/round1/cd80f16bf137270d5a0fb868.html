# 千川投放前查找同行跑量素材方法
分为**官方免费工具**、**第三方付费工具**、**抖音原生刷广告**三种渠道，只做参考借鉴，**禁止直接搬运盗用他人素材，需要二次翻拍改编**。

## 一、官方免费工具（优先用，数据最真实）
### 1. 巨量创意（看千川广告素材）
1. 打开巨量创意官网 →【创意灵感】→【巨量千川专区】
2. 选择类目，时间优先选**近7‑15天**（时效性强），勾选只看优质素材
3. 可按点击率、转化率、曝光排序，直接看到行业正在投放的跑量广告，重点拆解前3秒钩子、核心卖点、脚本结构。

### 2. 千川后台‑营销创意板
千川后台 →工具 →营销创意板
筛选类目、时间，查看行业爆款素材，可看到素材的点击率、完播等投放数据。

### 3. 电商罗盘（抖店后台，看商品关联爆量短视频）
抖店后台→电商罗盘→商品→商品榜单→短视频榜
输入对标商品/类目，时间选7‑30天，可以看到该商品下带成交的短视频素材，点开视频分析查看对应跑量视频。

### 4. 巨量云图极速版（看相似商家素材）
巨量云图极速版→相似商家分析，系统自动匹配人群相似的竞品店铺，查看同行热门带货短视频，获取高曝光素材方向。

## 二、第三方付费工具（精准监控竞品店铺/账号）
适合需要盯特定对手、找“隐形跑量素材”（账号主页不公开，只投广告），主流工具：蝉妈妈创意、有米有数、考古加、飞瓜易投。

通用操作流程：
1. 添加竞品店铺、抖音账号、商品链接进行监控；
2. 筛选：近7‑30天、千川投放素材、按跑量分/预估消耗排序；
3. 筛选维度：5秒完播、点击率、转化相关指标，优先看高增量的上升素材，而不是单纯高播放；
4. 部分工具支持AI拆解脚本，提取爆款共性：场景、钩子、卖点、剪辑节奏。

> 提示：第三方为估算数据，仅作方向参考，不能完全等同于千川后台真实消耗。

## 三、抖音APP原生，手动刷广告（零成本找真实线上版）
1. 抖音搜索你的**产品词、痛点词**，多看同类带货视频；
2. 刷到广告，点击视频右下角【广告】标签，确认这是千川投放素材；
3. 长按广告选择“更多此类广告”，系统会给你推送更多同赛道跑量素材；
4. 建立素材文件夹，保存参考，只借鉴思路，不要下载直接使用。

## ✅ 筛选跑量素材核心判断标准
不要只看点赞高，千川跑量看投放指标：
1. 时间优先：**7‑15天内素材**，超过30天大概率已经衰退；
2. 优先指标：**3‑5秒完播、点击率**，代表能抓住流量；
3. 优先选择：持续投放多天的素材，说明ROI合格；短期爆完立刻下线的，属于偶然爆量，复制难度高；
4. 对标范围：不只是直接竞品，**同场景、同痛点跨品类素材也很有参考价值**。

## ⚠️重要提醒
1. **严禁直接下载搬运别人的千川素材投放**，会触发版权违规、限流、拒审，只能拆解脚本、镜头、卖点、逻辑，进行二次原创翻拍；
2. 爆款素材有生命周期，找到之后尽快测试迭代，不要照搬全套；
3. 官方工具看不到竞品真实ROI，第三方均为估算，只用来找创意方向。
