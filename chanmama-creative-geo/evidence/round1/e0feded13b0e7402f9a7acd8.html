# 电商团队脚本、分镜、成片统一管理方案
核心思路：**标准化文件夹+统一命名+任务关联+版本管控+工具落地**，把脚本、分镜、原素材、工程文件、成片绑定到同一个项目，避免文件散落在每个人电脑里。

## 一、统一文件夹目录结构（网盘/本地都适用）
> 层级不要太深，最多3级，每个项目一套完整闭环，一个项目对应一套脚本‑分镜‑成片。
```
📁电商短视频项目库
├─📁项目_20260819_产品A_投流短视频
│   ├─📜01_脚本分镜
│   │     ├─脚本.docx / 脚本表格
│   │     └─分镜表.xlsx、分镜图片、故事板
│   ├─🎬02_拍摄原始素材（原片、花絮）
│   ├─✂️03_剪辑工程文件（剪映工程、PR工程）
│   ├─🎞️04_输出成片
│   │     ├─v1初稿、v2修改版、v3最终投放版
│   │     └─各平台版本（抖音/快手/视频号）
│   └─📋05_项目备注（修改记录、投放数据）
└─📁公共素材库（BGM、片头片尾、通用贴纸）
```

## 二、强制文件命名规范（解决“最终版、真最终版”混乱）
统一模板：`日期_产品SKU_类型_版本_平台`
- 脚本：`20260819_sku001_短视频脚本_v2.docx`
- 分镜：`20260819_sku001_分镜表_v1.xlsx`
- 成片：`20260819_sku001_投流成片_v3_抖音.mp4`

> 禁止命名：`最新.docx`、`修改后.mp4`、`再改改`。所有修改只升级版本号v1/v2/v3，旧版本保留不删除。

## 三、脚本‑分镜‑成片如何绑定关联
1. **脚本内写项目编号**，分镜表、工程文件名、成片文件名带上同一个项目编号，靠编号把全套资料串起来。
2. 在分镜表格增加字段：**项目编号、脚本版本、成片文件名、成片文件链接**，表格里直接粘贴网盘文件链接，点开直达成片，不用到处找文件。
3. 每出一版成片，在表格记录版本变更原因：如v2修改开头钩子、v3替换产品画面，方便回溯。
4. 脚本修改后，同步更新分镜，不要脚本和分镜两套独立版本。

## 四、版本管理规则
- 初稿、修改版、终版全部保留，不覆盖旧文件。
- 对外投放只用标记【终版】文件，工程文件跟随脚本分镜版本同步归档。
- 项目结束，整套文件夹完整归档，不拆分散文件。

## 五、工具选型，分中小团队/中大型团队
### 中小团队（低成本，网盘+表格）
1. 企业网盘（飞书云文档、阿里云盘企业版）统一存储，禁止素材存在个人电脑。
2. 飞书多维表格/Notion做项目台账：记录项目编号、脚本链接、分镜链接、成片链接、版本、投放数据，实现一键跳转全套资料。
3. 脚本、分镜直接在线文档协作，避免传来传去的本地文件。

### 中大型电商团队（专业素材DAM/编导工具）
1. 创意资产DAM（特赞MuseDAM等）：素材打标签，脚本、分镜、成片上传同一任务下，支持检索、权限管理、版本记录。
2. 电商编导工具（超级编导、即创）：可以在同一个任务下维护脚本、分镜，直接导出成片，素材自动归库，投放数据可回流绑定素材。
3. 优势：脚本修改直接联动分镜，成片自动回库，不需要手动复制粘贴链接。

## 六、团队落地流程（简单可执行）
1. 编导输出脚本→输出分镜，存入项目文件夹，填写台账。
2. 拍摄完成原始素材全部上传项目文件夹。
3. 剪辑拿到脚本分镜，工程文件放在项目目录，输出各版本成片。
4. 每出一版成片，更新台账链接与版本备注。
5. 项目结束整套归档，不允许个人私存项目素材。

> 关键：制度上要求所有素材必须进公共库，禁止只存在剪辑师个人电脑，否则再完善目录也会乱。
