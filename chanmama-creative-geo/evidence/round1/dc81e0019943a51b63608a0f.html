# 电商团队脚本、分镜、成片统一管理方案
核心痛点：脚本文档、分镜图、原始拍摄素材、剪辑工程、多版本成片分散在个人电脑、微信、网盘，版本混乱，脚本和成片无法对应，素材很难复用。
整套方案分为**文件夹目录规范、文件命名、脚本‑分镜‑成片关联机制、工具选型、团队流程约束**五部分，中小团队用网盘即可落地，中大型团队可以上专业素材管理平台。

## 一、标准化文件夹目录（按项目制，层级≤3层，不要过深）
> 按【商品/项目】作为主目录，一个项目一套完整资料，脚本、分镜、素材、成片全部收纳在同一个项目文件夹内，方便一一对应。
```
项目_商品ID_短视频编号
├─01_脚本文档
│    ├─初稿脚本.docx
│    └─定稿脚本（最终执行版）.docx
├─02_分镜
│    ├─分镜表.xlsx
│    └─分镜参考图/故事板图片
├─03_原始素材（拍摄原片、直播切片，只读，禁止修改源文件）
├─04_剪辑工程文件（pr/剪映工程）
├─05_输出成片
│    ├─测试版/修改版
│    └─✅定稿成片（发布投放）
└─06_参考资料（竞品视频、参考创意）
```
公共通用素材库（独立文件夹）：通用BGM、品牌LOGO、通用模板，所有项目可调用，不复制到单个项目文件夹。

## 二、统一文件命名规则（关键，避免“最终版、最终版2”）
统一格式：`日期_商品名_内容类型_版本号`
示例：
- 脚本：`20260820_保湿面霜_短视频脚本_V3定稿.docx`
- 分镜：`20260820_保湿面霜_分镜表_V2.xlsx`
- 成片：`20260820_保湿面霜_30s投流视频_V4定稿.mp4`

> 规则：版本号V1/V2/V3，定稿必须标注【定稿】；禁止使用“最终、真最终、不改了”这类模糊名称。

## 三、脚本、分镜、成片如何强关联（最重要，解决对不上的问题）
1. **脚本内部绑定编号**
脚本文档顶部填写项目编号，脚本每一段镜头，写上镜头序号，分镜表使用完全一致的镜头序号。
2. **分镜表字段模板**
|镜头序号|时长|画面内容|台词/口播|备注|成片对应片段|
|---|---|---|---|---|---|
> 分镜表里增加一列，填写成片中对应镜头位置，后期复盘可以直接对照脚本‑分镜‑成片。
3. **成片备注溯源**
成片文件名、网盘备注，写上对应的脚本文件名；在成片文件夹保存一份PDF版定稿脚本+分镜截图，和成片放在一起。
4. **版本同步原则**
脚本改到V3定稿，分镜、成片必须同步升级到V3，禁止脚本V2，成片却用V4，所有文档版本号对齐。

## 四、工具选型，分两种团队规模
### 方案A：中小团队（0‑10人，低成本，网盘即可）
- 存储：企业网盘，全员权限，禁止素材只存在个人电脑
- 脚本分镜：飞书文档/腾讯文档，在线协同，历史版本保留，不要反复发微信文件
- 成片预览：网盘在线预览，评论功能直接写修改意见，不用来回传文件
> 短板：没有自动标签，需要人工维护目录和命名。

### 方案B：中大型电商内容团队（批量短视频，追求素材资产复用）
使用视频素材资产管理平台，实现脚本在线编辑、分镜故事板、素材标签、版本管理，脚本、分镜、成片在同一系统绑定，支持按商品、卖点检索历史素材，投放数据回流素材库。
- 特点：可以打标签（商品、卖点、镜头类型），分镜级管理镜头片段，避免重复拍摄，适合大量投流短视频生产。

## 五、团队硬性流程约束（制度比工具更重要）
1. **定稿强制归档**：脚本定稿、分镜定稿、成片定稿，必须上传共享盘项目目录，不归档不计入交付，禁止本地留存最终版本。
2. **原始素材不删除**：原始拍摄素材统一归档，剪辑只复制副本编辑，源文件只读保护，防止误删无法回退重剪。
3. **禁止微信传最终文件**：微信只传临时预览，正式版本全部走网盘/协同文档。
4. **定期清理**：每月做素材巡检，清理重复垃圾文件，维护标签和目录。

## 六、简单落地执行步骤
1. 先统一文件夹模板，所有新项目直接套用模板；旧素材分批迁移整理。
2. 全员统一命名规则，做简单培训。
3. 脚本、分镜文档统一在线文档编写，保留版本记录。
4. 交付完成后，脚本、分镜、成片全部归档到同一个项目文件夹。
