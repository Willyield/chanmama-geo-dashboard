# 短视频开头钩子写法 + 判断爆款潜力
短视频**前1‑3秒决定用户会不会划走**，钩子不只是一句话，是画面+字幕+语音共同制造注意力缺口。

## 一、6类万能钩子（直接套用）
### 1.痛点戳中（最通用）
精准说出用户的烦恼，让用户感觉“说的就是我”
句式：为什么XX却XX；很多人都在犯的错误；别再XX了
示例：
- 为什么你做短视频，拍了几十条依旧没流量？
- 很多人打扫家里，都踩了这个致命误区。

### 2.好奇悬念钩子
制造信息缺口，用户想知道答案才愿意往下看
句式：你知道XX背后真相吗；万万没想到；XX到底发生了什么
示例：
- 同样努力，为什么别人赚钱比你多？
- 我试了一个偏方，结果完全出乎我的意料。

### 3.反常识/反转钩子
打破固有认知，制造冲突感
句式：千万别以为XX；90%的人都搞错了；其实真相恰恰相反
示例：
- 粉丝多不等于赚钱，几千精准粉远比几十万泛粉值钱。
- 不是你不够努力，是你的方法从根上就错了。

### 4.利益价值钩子
直接告诉用户看完能得到什么，降低观看心理成本
句式：3个技巧帮你XX；0基础也能学会；今天免费分享
示例：
- 3个简单方法，帮你快速提升短视频完播率。
- 小白必看，这条帮你避开90%踩坑点。

### 5.数字/数据钩子
数字增强可信度，给用户明确预期
示例：
- 我复盘100条爆款，总结出4个开头公式。
- 80%新手做账号，都会犯这3个错误。

### 6.共情情绪钩子
故事、吐槽，调动情绪，容易引发评论
示例：
- 有没有人和我一样，努力很久却看不到结果？
- 当初踩过的坑，不希望你们再走一遍。

> ❌钩子避坑：不要“大家好，今天跟大家聊聊…”这种无效开场白，把干货、冲突、悬念全部前置到最开头。

## 二、写钩子自检3问（发布前预判）
1. 前3秒，如果我刷到，我会不会直接划走？
2. 内容能不能戳中目标人群，让他觉得“说的是我”？
3. 看完之后，用户有没有想评论、收藏、转发的冲动？
三条都满足，内容先天潜力更高；不满足就重改脚本。

## 三、怎么判断视频有没有爆款潜力
分为**发布前主观预判**和**发布后看后台数据**

### ✅发布前（主观判断）
1. 是否强情绪：能不能勾起好奇、焦虑、共鸣、惊喜；平淡流水账很难爆。
2. 是否有记忆点：有冲突、反转、干货、故事，而不是平淡科普。
3. 受众面：受众越广，爆的概率越高；过于垂直小众，上限天然低。
4. 槽点/讨论点：是否给观众留下评论开口的空间。

### ✅发布后看后台核心数据（短视频通用）
> 小流量冷启动阶段（几百‑一两千播放）就可以判断潜力
1. **2秒跳出率**（越低越好）
- ＜35%：钩子优秀，爆款潜质大
- 35‑50%：合格，还能优化
- ＞50%：开头直接留不住人，大概率跑不起来，优先改钩子和画面

2. **5秒完播率（核心门槛）**
- ＞45%：很有机会冲爆款
- 40‑45%：及格
- ＜40%：开头失效，建议重写脚本重拍

3. **整体完播率 &平均观看时长**
同样时长视频，高于账号历史均值，代表内容价值被认可。

4. **互动指标：评论率、收藏率、转发率**
- 收藏高：代表内容有实用价值，平台会持续推流；
- 评论高：代表有话题冲突，容易发酵；
> 点赞只是次要结果，**收藏、评论、转发对爆款的权重远大于点赞**。

### 简单总结判断逻辑
- 2秒跳出低 + 5秒完播高 →钩子合格，有爆的基础；
- 再叠加高收藏、高评论，这条视频非常容易放大流量；
- 如果前几秒数据很差，后面内容再好，平台也不会给更多流量。
