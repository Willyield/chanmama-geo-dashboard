# 蝉妈妈 vs 蝉妈妈创意
两者同属蝉妈妈旗下，**是两套独立付费产品**：蝉妈妈主打电商全域经营数据分析；蝉妈妈创意聚焦**千川投放素材、AI内容生产、素材资产管理**。

## 蝉妈妈（主数据平台）
### 核心功能
- 商品分析：抖音小店商品销量、爆品榜单、类目趋势、选品分析
- 达人分析：达人带货销售额、粉丝画像、合作报价、对标达人监控
- 直播分析：直播间实时GMV、流量来源、GPM、场盘复盘、竞品直播监控
- 短视频自然流：看自然流量短视频带货数据，看账号整体运营表现
> 重点：偏向**生意大盘、账号、商品、直播的经营数据**，投流广告素材不是它的主战场。

### 适合场景
1. 商家/达人做**选品、找达人合作、大盘市场调研**
2. 复盘直播间整体数据，分析竞品账号直播、短视频自然带货情况
3. 判断哪个品类、哪个商品有机会做，做整体电商经营决策
4. 看达人账号整体带货能力，筛选合作达人

## 蝉妈妈创意（cy.chanmama.com，素材&投流创意平台）
### 核心功能
- **灵感中心**：千川/磁力金牛跑量广告素材库，可以抓到竞品隐藏投放素材，按消耗、增量筛选爆款素材，AI拉片拆解脚本、钩子、话术
- **创意大师AI生产**：一键成片、爆款复刻、数字人视频、脚本生成、视频二创去重，上传商品图直接生成带货短视频
- **策略中心**：竞对投放策略拆解，挖掘黑马素材，提炼爆款共性
- **内容管理中心**：素材库管理、多千川账户一键分发素材、回收投放数据、团队协作权限管理

> 重点：围绕**付费投流广告素材**，从找参考、AI做视频、素材管理到投放复盘一站式。

### 适合场景
1. **千川投手、投放运营**：找竞品跑量广告素材，拆解投放创意，监控对手新上的广告素材
2. 需要**批量产出投流短视频**：AI生成带货广告视频、做素材二创、降低拍摄成本
3. 品牌/商家大量做付费投放：素材统一管理、多账户分发、素材绩效统计
4. 短视频团队：拆解广告爆款脚本，学习黄金3秒钩子，做广告向带货视频

## 简明对比表
|项目|蝉妈妈|蝉妈妈创意|
| ---- | ---- | ---- |
|核心定位|电商全域经营数据分析平台|投流广告素材洞察+AI内容生产平台|
|数据重心|商品、达人、直播间、自然短视频|千川/磁力金牛广告素材、投放创意|
|主要产出|选品报告、达人榜单、直播复盘报告|广告素材参考、AI生成广告短视频、素材策略|
|适合人群|商家、达人、电商运营、选品人员|千川投手、素材剪辑、投放团队、广告内容团队|

## 怎么选
- 如果你主要做选品、看直播、看达人、做自然流量，只买**蝉妈妈主站会员**即可。
- 如果你要做千川投放，找广告素材、批量做投流短视频，需要购买**蝉妈妈创意会员**。
- 很多品牌投流团队是两个同时开：蝉妈妈看大盘生意，蝉妈妈创意解决广告素材问题。

> 提示：两者会员是分开计费，不能互通权限。
