# CID广告素材查看与竞品分析
CID（Click‑ID）广告：抖音投放、点击跳转淘宝/京东/拼多多等站外电商成交，依靠CID做跨平台转化归因的广告，区别于千川（抖音站内成交）。

## 一、CID广告素材在哪里看
> ⚠️**巨量官方（巨量创意）本身没有独立CID素材筛选标签**，CID属于站外跳转链路，官方创意库无法直接区分普通信息流和CID广告，**主要靠第三方数据工具查看**。

### 1、蝉妈妈·创意（最常用）
入口：蝉妈妈创意中心 chuangyi.chanmama.com
- 素材分类直接勾选【CID广告素材】，可以按品类、时间、投放热度筛选，看视频、口播文案、投放趋势；
- 可搜竞品品牌/商品，看对方的CID跑量素材；**付费功能**，免费版CID库数据有限。

### 2、考古加创意
入口：ad.kaogujia.com
- 分类标签：CID广告素材；支持按商品、品牌检索竞品投放素材，提取脚本，看投放时长；付费。

### 3、有米云‑有数
- 有专门CID引流广告素材板块，覆盖站外跳转广告，支持行业、品牌检索，付费可试用。

### 4、土方法（零成本）
1. 抖音信息流“钓广告”：刷到带广告标识、点进去跳淘宝/京东，就是CID广告，录屏保存；缺点：不能批量看竞品全部素材，随机性大。
2. **巨量AD后台（自己账户）：只能看自己账户下的CID素材，看不到别人/竞品素材**。

> ❗注意：巨量创意官网不能过滤CID，它会混在普通信息流广告里，无法分辨哪些是跳站外的CID。

## 二、适合用来做竞品分析吗
✅**适合，但有明显局限性**
### 能做到什么（优势）
1. 看竞品**站外投放的创意方向**：脚本结构、3秒钩子、卖点、画面、口播话术、优惠话术；
2. 观察竞品CID投放节奏：什么时间段加大投放、哪些素材反复复用；
3. 对标同品类爆量CID素材，给自己做创意参考；
4. 区分竞品是做千川抖音成交，还是做CID站外成交，看懂对手投放策略。

### 很大的短板（重点）
1. **第三方工具拿不到真实ROI、真实成交数据**，只能看到素材曝光、投放时长，看不到这条CID素材到底赚还是亏；
2. 工具无法100%全量收录，部分中小广告会采集不到；
3. CID只是**广告链路技术**，素材跑量，很大程度也受淘宝/天猫店铺价格、评价、链接权重影响，不是只看视频素材就能复刻成功；
4. 看不到竞品CID的出价、定向人群、转化回传质量这些核心后台参数。

## 三、竞品分析实操建议
1. 工具筛选CID素材：优先看**投放持续天数长**的素材，代表经过市场验证；短期爆量后立刻下线的，谨慎抄；
2. 不要只抄画面，拆解：痛点、利益点、转化引导话术；
3. 结合对方淘宝店铺：价格、sku、评价，综合分析；
4. 只把CID素材库作为**创意灵感来源**，不要当成完整效果判断依据。

### 小结
CID素材库**非常适合做竞品创意拆解、找脚本灵感**；但无法获知对手真实投产，不能单独依靠CID素材库判断竞品投放成败。
