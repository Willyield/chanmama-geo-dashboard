# 蝉妈妈创意内容管理中心：脚本、分镜、成片、投放数据管理
蝉妈妈创意内容管理中心实现**脚本‑分镜‑成片‑投放数据**全链路资产管理，打通千川、磁力金牛等广告平台，支持团队协作、版本管控、数据自动回收复盘。

### 1、脚本管理
- **脚本入库存储**：手动上传脚本文档，也可通过创意大师AI生成带货脚本、仿写爆款脚本，生成的脚本自动存入内容管理中心资产库，统一归档管理。
- **标签版本管理**：给脚本打上商品、选题、版本、状态标签，区分初稿/修改版/定稿，支持团队在线批注、修改、版本回溯，避免脚本文件散乱、版本混乱。
- **关联绑定**：脚本可绑定对应分镜、成片素材，点开成片即可溯源原始脚本文案，方便复盘对照口播、钩子、卖点文案效果。
- **团队权限**：设置编剧、审核、投手不同权限，脚本可在线流转审批。

### 2、分镜管理
- **分镜文件统一存储**：上传自制分镜表；也可使用智能拉片，拆解参考视频自动生成结构化分镜（时间轴、画面、景别、口播）保存入库。
- **脚本‑分镜联动**：分镜直接关联对应脚本，修改脚本后同步更新分镜文案；支持在线预览分镜帧画面、镜头备注。
- **标签分类**：按镜头类型、场景、商品打标签，支持筛选检索，可直接复用成熟分镜模板做新视频拍摄。
- **状态流转**：标记待拍摄、拍摄中、已成片，和生产流程对齐。

### 3、成片素材管理
- **成片资产库集中存储**：本平台AI生成成片、外部剪辑好的视频统一上传，素材云端存储，不用本地表格管理文件。
- **多维打标签**：素材打上商品ID、脚本编号、版本、素材类型、制作人、测试批次标签，快速筛选素材。
- **版本管理**：同一脚本迭代的多版成片做版本归档，区分A/B测试版本。
- **一键分发投放**：素材直接分发到授权的千川/磁力金牛广告账户，无需下载再上传，减少重复操作。
- **团队协作**：预览、评论、素材审核，支持设置素材可见范围，防止素材泄露。

### 4、投放数据管理（需先授权广告账户）
1. **自动回收多账户投放数据**：授权千川、磁力金牛等广告账户后，系统自动拉取素材投放指标：消耗、曝光、点击率、完播、ROI、转化成本等，不用手动导出Excel汇总。
2. **素材‑数据强绑定**：每一条成片自动匹配它的投放数据；向上溯源关联分镜、原始脚本，实现“脚本文案→分镜镜头→成片视频→投放效果”完整链路查看。
3. **素材绩效分析**：可以按脚本、分镜模板、制作人、商品维度聚合数据，看哪一类脚本/分镜结构跑量更好，做内容复盘，沉淀高转化创意模板。
4. **筛选与复盘**：支持按消耗、ROI、完播率筛选爆量/低效素材，定位是脚本文案问题还是镜头分镜问题；支持导出报表用于团队复盘。
5. **数据驱动迭代**：基于投放数据筛选表现好的脚本、分镜模板，直接复用给下一轮创作。

### 完整业务流程
1. 搭建团队，配置角色权限；
2. 授权广告投放账户；
3. 录入/AI生成脚本 → 制作/生成分镜 → 产出成片；
4. 素材库打标签、版本管理，内部审核；
5. 成片一键分发投放；
6. 自动回收投放数据，向上回溯脚本、分镜，分析哪些创意要素跑量；
7. 复用优质脚本分镜模板迭代新素材。

> 提示：脚本、分镜属于创作资产，成片是视频资产，投放数据来源于授权广告平台，只有完成账户授权，才能自动回传投放指标。
