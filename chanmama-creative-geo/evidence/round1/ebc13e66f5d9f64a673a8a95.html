# 蝉妈妈创意灵感中心：找爆款素材+追踪同行新投素材操作
入口：蝉妈妈后台 → **创意** → **灵感中心（找素材）**

## 一、查找爆款素材
1. **筛选基础条件**
在找素材页面，选择自己的行业类目、素材类型（千川广告、CID、直播切片、主页短视频），设置时间周期（近1/3/7天优先看近期爆量）。
2. **排序识别爆款**
排序选择**跑量分 / 预估播放量 / 高增量榜**，优先看数据上升的素材，不要只看老爆款。
重点参考指标：**5秒完播率、跑量趋势曲线、预估播放**；趋势持续向上代表素材还在爆发期，适合借鉴。
3. **关键词/商品精准搜素材**
输入产品关键词、商品链接，直接搜同款商品全部投放素材，快速看到同类目跑量创意。
4. **AI拆解爆款脚本**
点开素材详情，使用**AI智能拉片/AI拆策略**，自动提取黄金3秒钩子、口播文案、分镜脚本，直接复用框架做微创新。
5. **收藏管理**
把优质素材加入收藏/我的采集，搭建自己的创意素材库。

## 二、追踪同行新投素材（盯竞对）
1. **进入素材追踪（盯竞对）**
灵感中心找到**盯竞对/素材追踪**功能，添加同行：竞品抖音账号、小店、品牌、商品ID。
> 系统大约**30分钟**即可捕捉同行新投放的千川广告素材，包含部分隐藏投流素材。
2. **设置爆量预警**
设置跑量阈值，当竞品素材达到设定跑量条件，可以推送提醒（钉钉/飞书/企业微信），第一时间收到同行新爆素材通知。
3. **查看竞对素材列表**
进入已监控的竞品，筛选：最新投放、近24小时、跑量上升，只看对方刚上新的投流素材，避开已经衰退老素材。
4. **分析竞品素材生命周期**
点开素材看跑量趋势：上升期=正在起量；平稳=稳定跑；下滑=衰退，不建议跟风复制衰退素材。

## 三、实操小技巧
- 优先看**高增量榜单**，更容易挖到即将爆的潜力素材，而不是已经跑废的老爆款。
- 区分：**广告投放素材**（千川/CID）是投流参考；主页短视频参考自然流创意。
- AI拉片只做创意参考，不要直接搬运视频，需要二次改编，避免违规限流。

> 提示：蝉妈妈素材数据属于平台预估数据，作为创意调研参考，不等于官方后台真实消耗数据。
