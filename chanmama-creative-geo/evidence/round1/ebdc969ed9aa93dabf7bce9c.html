# 蝉妈妈创意：发现千川隐藏素材+素材异动提醒
>千川隐藏素材：商家千川后台本地上传、**不对外发布到抖音主页**，仅用于广告投放的视频素材。该功能需要蝉妈妈创意版本权限。

## 一、发现千川隐藏素材两种方式
### 方式1：素材追踪（定向盯竞品，推荐）
1. 进入蝉妈妈后台 → 顶部菜单【创意】→【素材追踪】
2. 添加监控对象：输入竞品**抖音号、小店ID、品牌关键词**
3. 开启追踪任务，系统约30分钟抓取一次，自动捕捉竞品新上的千川隐藏素材（直播间引流、商品广告等）
4. 进入竞品详情页，切换「千川投放素材」标签，即可查看该账号全部抓取到的隐藏投放素材，可查看投放时长、预估消耗等数据。

### 方式2：找素材页面全局筛选隐藏千川素材
1.【创意】→【找素材】
2. 筛选条件：勾选「千川投放素材」，可勾选「新发素材」，时间选择近1小时/近6小时；再筛选类目
3. 列表中出现的部分素材即为没有在账号主页公开的千川隐藏素材。

>提示：工具只能抓取到已经产生投放曝光的隐藏素材，完全零曝光的千川上传素材第三方工具无法获取。

## 二、素材异动/爆量提醒设置（爆量监测）
作用：素材消耗突然暴涨、竞品新出爆量隐藏素材时自动推送通知。
1.【创意】→【爆量监测】
2. 添加监控：选择监控对象（抖音号、店铺、关键词）
3. **设置异动阈值**：设置预估消耗增量、跑量门槛，达到阈值即触发提醒
4. 配置通知渠道：绑定钉钉/飞书机器人，消息会自动推送；也支持平台内消息提醒
5. 保存开启任务，7×24小时监测，一旦素材（含隐藏千川素材）出现爆量异动，立刻收到告警通知。

## 三、补充实操要点
1. 素材追踪负责抓**新出隐藏素材**；爆量监测负责**素材数据异动告警**，两个功能搭配使用效果最好。
2. 点开任意素材详情页，可以使用**AI智能拉片**，拆解脚本、分镜、5秒完播等数据，分析竞品创意逻辑。
3. 第三方数据为预估数据，和千川后台真实消耗会存在偏差，仅作参考。
