# 电商团队脚本、分镜、成片统一管理方案
核心思路：**一个项目一套编号，脚本‑分镜‑原始素材‑工程‑成片全部绑定同一编号，统一存储+标准化命名+版本管控，杜绝散落在个人电脑**。分为文件夹架构、命名规则、关联逻辑、工具选型、团队流程规范五部分。

## 一、标准文件夹目录结构（网盘/共享盘通用，层级≤3层）
> 按【项目/商品SKU】为核心，每个视频项目独立文件夹，脚本、分镜、素材、工程、成片全部收拢在此目录下。
```
├─01_项目归档库
   └─20260819_SKU001_洗面奶投流视频【项目唯一编号：P0086】
       ├─01_脚本文档          # word/飞书文档：脚本、brief、需求
       ├─02_分镜故事版        # PDF/图片：分镜表、镜头清单
       ├─03_原始素材          # 拍摄原片、产品素材、BGM，只读不修改
       ├─04_剪辑工程文件      # 剪映工程、PR工程
       ├─05_成片输出
       │   ├─01_待审核版本
       │   ├─02_最终定稿版本
       │   └─03_多平台衍生版本（抖音/快手/小红书）
       └─06_项目备注          # 修改记录、审片意见、投放数据截图
├─02_公共素材库               # 品牌logo、固定BGM、字幕模板、空镜
└─03_历史归档                 # 已下线旧项目
```

## 二、统一文件命名规则（脚本、分镜、成片强关联）
模板：`日期_项目编号_SKU_内容类型_版本号`
- 脚本示例：`20260819_P0086_洗面奶_脚本_V1.2.docx`
- 分镜示例：`20260819_P0086_洗面奶_分镜故事版_V1.0.pdf`
- 成片示例：`20260819_P0086_洗面奶_成片_抖音9:16_V2.3.mp4`

> 版本号规则：V1.0初稿；V1.1小修改；V2.0大改版；最终定稿固定为V_FINAL，禁止出现“最终版、最终版2、真最终”。

## 三、脚本‑分镜‑成片如何绑定关联
1. **脚本内标注项目编号Pxxxx**，脚本每一条镜头，写上对应分镜序号；分镜表引用脚本段落，做到脚本行号=分镜编号。
2. 分镜表格增加两列：**对应素材文件名、成片时间轴位置**，剪辑完成回填，后续改片可以直接定位镜头。
3. 成片文件夹内保留一张对照表（excel）：项目编号｜脚本链接｜分镜链接｜工程文件路径｜定稿成片路径｜投放链接。
4. 禁止复制另存为新文件改编号；迭代只升级版本号，旧版本不删除，保留历史版本。

> 小团队可以用飞书多维表格/Airtable做索引台账，一条记录绑定脚本链接、分镜、素材路径、成片地址，一键跳转所有文件。

## 四、工具选型（分中小团队、中大型团队）
### 中小电商团队（低成本）
- 存储：企业网盘/阿里云盘企业版，全员共享，禁止存个人电脑
- 脚本&分镜：飞书文档/石墨文档；分镜用表格或PPT绘制
- 剪辑：剪映企业版，工程文件同步网盘
- 索引台账：飞书多维表格做素材资产台账，记录项目、SKU、脚本、分镜、成片链接

### 中大型投放电商团队（专业素材管理）
- DAM数字资产管理系统：柚柚兔、易元AI、即创（巨量），支持脚本库、分镜管理、素材标签、成片版本管理，审片批注，投放数据回流绑定素材资产。
- 优势：脚本线上写、在线分镜故事板、素材标签检索，脚本‑分镜‑成片系统内直接关联，不用手动维护表格，适合大量投流短视频批量生产。

## 五、团队落地流程规范（最重要，否则工具搭好依旧乱）
1. **立项即分配项目编号**，编导写完脚本、输出分镜时，就带上编号，所有后续产出全部沿用这个编号。
2. **产出物强制入共享盘**：脚本、分镜、原始素材、工程、成片完成后必须上传共享目录，不允许只存在剪辑师个人电脑。
3. 修改流程：修改脚本→更新版本号；修改分镜→更新版本号；剪辑输出新版本成片，旧版本保留不删除。
4. 公共素材统一放在公共库，不要复制拷贝到各个项目文件夹，直接引用，减少重复文件。
5. 定期清理归档：项目结束，移入历史归档文件夹，活跃项目留在外层目录。

## 六、常见坑提醒
1. 不要文件夹层级太深，超过3层查找成本暴涨。
2. 禁止中文特殊符号、空格，文件名用下划线分隔。
3. 原始素材文件夹**只存原件，不做修改**，修改后的素材放工程目录，避免源文件被覆盖丢失。
4. 所有脚本、分镜不要只存在本地，文档要生成共享链接写入台账。
