# 竞品商品素材竞争态势分析
核心目的：看清类目素材整体格局，拆解对手素材策略，找到**行业共性、对手优势、素材缺口、差异化机会**，不是单纯抄图，而是输出可落地的素材制作方向。整体流程：筛选竞品→多维度拆解素材→态势归纳→SWOT机会挖掘→输出行动方案。

## 一、筛选对标竞品样本
分3类，建议选取5‑8个竞品，优先拿流量、转化靠前的链接
1. **直接竞品（核心70%精力）**：同价位、同功能、同一目标人群，直接抢流量的商品
2. **标杆竞品**：销量头部、素材表现力强，不一定价格一致，学习成熟素材打法
3. **潜力竞品**：新品起量快，素材创新度高，预判未来素材趋势

> 采集对象：商品主图组、详情页、SKU图、短视频/投放素材、标题文案、评价晒图。

## 二、素材多维度拆解（表格化记录）
### 1）视觉素材维度
- **主图组**：每张主图承担什么信息；背景风格；构图；卖点文案；是否做对比图、场景图、细节图；有没有痛点钩子；商品占比、配色风格
- **详情页**：页面叙事逻辑；模块顺序（痛点‑卖点‑参数‑场景‑售后）；信息图占比；场景实拍/渲染图比例；证据素材（检测报告、买家实拍）
- **SKU图**：不同规格如何表达，是否用图文降低选择成本
- **短视频/投放素材**：开头钩子；前3秒画面；叙事结构；重点展示卖点；使用场景；节奏；字幕文案

### 2）文案信息维度
- 标题、主图文案、详情大标题反复强调的**核心卖点集合**
- 痛点表达：在讲什么用户问题
- 价值主张：主打性价比/性能/颜值/安全/便捷
- 信任背书：用什么证据（证书、实测、用户反馈）

### 3）素材‑数据联动分析（竞争态势关键）
不能只看图片，要结合流量转化数据判断素材有效性
- 该商品流量结构：搜索流量、推荐流量、付费流量占比；如果推荐流量高，说明主图/封面点击率能力强
- 评价反馈：用户高频吐槽、高频夸赞，看竞品素材是否覆盖用户真实痛点；有没有用户关心，但素材完全不提的点（素材缺口）
- 竞品素材迭代：是否频繁更换主图、短视频；判断对手正在测试什么方向

## 三、归纳类目素材竞争态势
把多个竞品拆解结果汇总，看清市场格局，输出4个结论：
1. **行业共性**：类目大部分商家统一在用什么素材风格、统一主打哪几个卖点；这是市场基线，不做就容易脱离用户认知。
2. **头部优势**：头部竞品靠什么素材实现高点击率、高转化；哪些素材手段已经被验证有效。
3. **普遍短板（素材缺口）**
    - 用户高频关心，但几乎没有竞品素材表达；
    - 竞品素材表达很浅、信息单薄；
    - 竞品只讲A卖点，大量用户反馈B痛点无人承接。
4. **竞争激烈程度**：
    - 红海：几乎所有竞品素材角度、画面、卖点高度趋同，正面内卷严重；需要强差异化。
    - 蓝海：卖点分散，有大量用户需求没有被素材覆盖，可以卡位切入。

## 四、素材层面SWOT分析
- **优势S**：我方产品可突出，竞品素材没有充分表达的点
- **劣势W**：我方短板，竞品素材重点放大的优势，需要规避正面硬刚
- **机会O**：类目素材缺口、用户痛点盲区，是我们素材创新突破口
- **威胁T**：头部竞品持续迭代素材，付费素材疯狂投放，需要预判对手下一步素材方向

## 五、输出落地行动结论（最重要，避免只做调研不输出方案）
1. **基线要对齐**：行业通用的必要信息、图片类型，不能缺失，保证用户基础认知。
2. **差异化要做**：避开内卷严重的同质化卖点，抢占素材缺口，把用户真实痛点做成画面表达。
3. **避坑**：竞品素材中被评价打脸的宣传点，我方素材不要照搬。
4. **测试方向清单**：列出3‑5组素材创意方向，用于后续拍摄作图测试。

| ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- |
|竞品A|场景主图，强对比|耐用、性价比|痛点‑参数‑场景|效果对比开头|点击率高|缺少真实使用细节|增加真实实测画面|
|竞品B|白底产品图|功能强|参数堆砌|功能演示开头|专业感强|缺少用户痛点共情|增加用户场景痛点|

>小提示：态势分析不是一次性工作，类目竞品会持续更新素材，建议定期复盘，跟进竞争变化。
