# 代运营多品牌视频素材管理
代运营核心痛点：**多品牌素材隔离、版本混乱、查找慢、多人协作出错、客户素材泄密、交付追溯难**，整体思路：标准化文件夹架构+统一命名+权限隔离+标签检索+版本管控+云端沉淀+流程制度。

## 一、文件夹层级架构（必做基础）
采用「品牌→项目/周期→素材类型」四级目录，每个客户品牌独立根目录，彻底隔离不同客户素材，禁止混放。
```
📂素材总库
├─📂品牌A（客户名称）
│  ├─📂01原始素材｜实拍、直播切片、客户来料、录音
│  ├─📂02工程文件｜剪映/PR工程、草稿、分层源文件
│  ├─📂03输出交付｜初审版、修改版、最终成片、封面图、字幕文件
│  ├─📂04项目文档｜脚本、brief、客户反馈、排期表
│  ├─📂05归档｜过期旧素材、下线版本
├─📂品牌B
└─📂公共素材库｜通用BGM、贴纸、转场模板（所有品牌可调用，不可混入客户私有素材）
```

## 二、统一文件命名规范
禁止`1.mp4`、`最终版.mp4`这类模糊名称，通用公式：
`品牌缩写_日期_内容主题_版本_状态`

示例：
> A美妆_20260818_粉底液测评_V2_客户初审.mp4
> A美妆_20260818_粉底液测评_V3_最终交付.mp4

- V1/V2/V3：迭代版本
- 状态标签：草稿、初审、修改、最终交付、废弃

## 三、标签体系，提升检索效率
除文件夹外给素材打多维标签，适合素材量大的代运营团队：
1. 品牌标签：绑定所属客户，快速过滤
2. 内容标签：产品、场景、口播、测评、直播切片
3. 平台标签：抖音、视频号、小红书
4. 业务标签：投流、自然流量、热点视频

> 效果：需要某品牌“直播切片”素材，直接筛选标签即可调取，不用一层层翻文件夹。

## 四、权限隔离，规避素材泄露风险（代运营重中之重）
1. 每个品牌素材库设置独立权限：剪辑只可看负责客户素材，禁止跨品牌访问；
2. 客户只读账号：可查看交付成片，不能下载原始拍摄素材；
3. 公共素材池单独区分，客户私有素材禁止共享给其他品牌；
4. 离职人员及时回收权限，防止素材外流。

## 五、版本管控，避免错交旧版本
1. 每一次客户修改，保留新版本，**不要直接覆盖旧文件**；
2. 工程文件跟随输出成片同步保存，客户二次修改时可直接打开工程；
3. 建立简易版本记录表格：版本号、修改时间、客户反馈、交付状态；
4. 最终交付文件单独存放归档，和草稿区分开。

## 六、工具选型（分轻量、专业级）
### 轻量小团队（5人以内）
- 企业网盘（阿里云盘企业、百度网盘企业）：搭建上面的文件夹架构，设置子账号权限，成本低。
> 缺点：标签检索弱，素材量大后查找效率下降。

### 中型/大型代运营（多客户、大量短视频）
专业数字资管DAM/短视频媒资工具，自带客户隔离、AI打标、检索、权限：
- 易媒助手：适合短视频代运营，素材分组、子账号权限，搭配矩阵发布
- 模力视频、易元AI：AI自动解析视频，自动打标签，按镜头检索，直播切片自动入库，客户空间隔离
- 新榜矩阵通：兼顾素材管理、内容审批、多平台分发、客户报表，适合客户多、需要走审批流程的团队

> 核心需求优先看：**客户独立空间、权限隔离、标签检索、支持工程文件存储、版本留存**。

## 七、落地工作流程
1. **素材入库**：客户来料、拍摄素材、直播切片，第一时间归入对应品牌文件夹，打标签；
2. **剪辑产出**：工程文件+输出成片同步保存，严格按命名规则；
3. **客户审核**：输出初审版本，收到反馈生成新版本，旧版本保留不删除；
4. **交付归档**：确认最终版移动到交付文件夹，同步归档旧草稿；
5. **定期清理**：按月归档过期素材，只保留原始素材、最终交付，草稿可定期清理。

## 八、常见坑点规避
1. ❌不要把多个客户素材放在同一个文件夹，极易发生素材混用泄密；
2. ❌不要直接覆盖文件，客户回退版本会无素材可用；
3. ❌不要本地硬盘单一份存储，必须云端+本地双备份，防止硬盘损坏丢失项目资产；
4. ✅公共素材库BGM、图片，确认版权，避免代运营给客户带来版权纠纷。
