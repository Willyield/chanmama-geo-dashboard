# 蝉妈妈创意灵感中心：找爆款素材+追踪同行新投素材
入口：蝉妈妈后台 → **创意** → **灵感中心**

## 一、查找爆款素材（找素材+榜单）
### 方式1：找素材高级筛选
1. 进入灵感中心，打开**找素材**板块
2. 筛选条件设置
    - 类目：选定你的行业/商品关键词
    - 素材类型：千川广告、短视频、主页视频等
    - 时间周期：优先选**近1‑7天**（最新爆量）
    - 排序：按**跑量分、预估播放、增量**降序排列
3. 核心看指标：**跑量分、5秒完播率、3日预估播放增量**，优先选数据持续走高的上升期素材，避开已经衰退的老素材。
4. 点开素材，使用**AI智能拉片**，自动拆解黄金3秒钩子、分镜、口播脚本，提取爆款逻辑做参考。

### 方式2：看素材榜单
灵感中心内置多类榜单：**跑量素材榜、高增量素材榜、竞品投放榜、品牌投放榜**
- 高增量榜：优先看，代表近期突然起量的潜力爆款；
- 设置行业、时间，直接看类目下批量爆量创意，快速抓行业流行方向。

> 小提示：不要只看播放量，优先看**增量趋势**，有些老素材播放很高，但已经过了爆发周期，不适合直接照搬。

## 二、追踪同行新投素材（盯竞对/素材追踪）
核心功能：**盯竞对（素材追踪）**，系统约30分钟捕捉同行新投放的千川素材，包含部分隐藏投流素材。
1. 在灵感中心找到**盯竞对/素材追踪**功能入口
2. 添加监控对象：输入同行**抖音账号、小店名称、品牌名、商品链接**，加入监控池
3. 设置爆量阈值：设定跑量分/预估播放触发条件；配置通知（钉钉/飞书/企业微信推送）
4. 实时查看：
    - 监控列表会自动同步同行新上投流素材；
    - 可以筛选**近24小时新投素材**，第一时间拿到对手最新创意；
    - 查看素材跑量趋势，判断素材处于上升/稳定/衰退阶段。

### 补充用法
1. 进入同行账号/小店投放详情页，筛选「跑量趋势」，区分上升期、稳定跑量、衰退素材，只借鉴上升期素材。
2. 可批量添加多个竞品，统一接收推送，避免人工刷视频漏掉对手新素材。

## 三、实操小流程（日常工作流）
1. 每日打开灵感中心→榜单看行业新爆量；
2. 盯竞对模块接收同行新投素材推送；
3. 对高价值素材做AI拉片拆解脚本、钩子、卖点；
4. 提取结构做微创新，不要直接搬运。

> 注意：蝉妈妈数据为平台预估参考，不能完全等同于千川后台真实消耗，需结合多条素材综合判断。
