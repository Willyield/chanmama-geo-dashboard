# AI生成带货视频能否用于广告投放
**可以投放，但不是直接拿来就投，商家承担全部广告主体责任，AI不能免责**。需要满足工具商用授权、国家AI生成标识、平台广告审核、广告法合规，才允许作为千川、信息流等广告素材投放；不满足会出现拒审、下架、限流、罚款、侵权赔偿等后果。

## 电商团队需要重点注意事项
### 一、版权与工具授权风险
1. 核对AI工具协议：免费版大多仅限个人使用，**商业广告投放优先企业版授权**，确认协议明确允许广告商用，留存工具授权截图、提示词、工程文件，方便举证。
2. 视频内全部素材（背景音乐、字体、贴图）都要有商用授权，AI生成也不会自动获得第三方素材版权。
3. 禁止AI生成酷似明星、网红、普通人的人脸、声音，即便没有直接输入参考图，只要公众可以识别到对应人物，就构成肖像侵权，不要碰AI换脸、声音克隆，无书面授权一律禁用。

### 二、AI生成强制标识（监管硬性要求）
1. 视频画面**显著位置（前5秒，字体清晰，不能放在角落极小字号）标注：本广告由AI生成/本内容为AI深度合成**，不能折叠、淡化处理。
2. 同时必须标注**“广告”标识**，区分普通内容和商业推广，测评、体验类带货视频两项标识缺一不可。
3. 平台端按要求勾选AI生成选项，不可删除、篡改AI元数据标识。

### 三、广告内容与虚假宣传红线（最高发违规）
1. AI虚拟数字人不要用“亲测、亲身体验、我使用之后”这类第一人称体验话术，虚拟人没有真实使用经历，改为客观描述参数、功能，避免虚假宣传判定。
2. AI生成画面不要过度美化产品：比如护肤品瞬间祛斑、家电夸张效果；AI生成的理想化效果图，要标注「效果仅供演示，以实物为准」，主图核心展示建议用实拍素材，避免实物与画面不符被下架扣分。
3. 文案人工排查广告法违禁词：“最、第一、100%、根治、特效”等绝对化用语；禁止AI虚构销量、好评、专家证言、检测报告、获奖背书，所有数据、资质要有真实凭证可核验。
4. 食品、保健品、美妆、医疗器械等类目，严禁AI生成医疗功效、治病、防病类描述，严格遵守行业广告限制。

### 四、平台投放实操注意
1. AI素材审核会比真人素材更严格，批量产出后必须**人工全量审核**，不能完全依赖AI输出直接上计划。
2. 不要全部素材都使用AI视频，混合实拍真人素材，降低低质素材判定，避免账户整体权重受损。
3. 留存全套审核记录：脚本、提示词、授权文件、标识版本，遇到平台申诉、监管核查可作为证据。
4. 投放监控：AI素材容易出现画面逻辑错误、参数矛盾，投放后盯转化、退货率、投诉，出现差评、退货飙升及时关停素材。

### 五、法律责任认知
> AI只是创作工具，**广告违规的责任全部归属电商商家（广告主）**，不能以“视频是AI生成”作为抗辩理由，违规会面临广告下架、平台扣分罚款、市场监管处罚、民事侵权赔偿。

## 快速自查清单（投放前必过）
- [ ] AI工具具备广告商用权限，留存授权记录
- [ ] 无仿冒他人肖像、声音，无未授权IP
- [ ] 画面显著标注「AI生成」+「广告」
- [ ] 无极限词、无虚构体验/数据/背书
- [ ] 产品效果图做演示提示，关键信息与实物一致
- [ ] 文案画面完成人工复核
