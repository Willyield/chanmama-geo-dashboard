# 代运营公司多品牌视频素材管理
代运营同时服务多个品牌，核心痛点：**素材混淆、版本混乱、客户素材泄露、查找慢、交付追溯难**，整套管理围绕「文件夹架构+命名规范+权限隔离+版本管控+标签检索+流程制度」落地。

## 一、标准化文件夹目录结构（云端存储）
每个品牌独立主目录，做到客户素材物理隔离，防止混用。
```
📂全部客户
 ┣ 📂品牌A（客户编码）
 ┃  ┣ 📂01_原始素材：实拍原片、直播切片、图片、音频BGM
 ┃  ┣ 📂02_剪辑工程：剪映工程、PR工程文件、草稿版本
 ┃  ┣ 📂03_输出成品：分平台（抖音/视频号/小红书）成片、封面、字幕
 ┃  ┣ 📂04_交付客户：发给客户审核、最终定稿文件
 ┃  ┣ 📂05_归档：过期活动、废弃版本、历史旧素材
 ┃  ┗ 📂06_品牌规范：logo、色值、口播规范、禁用词
 ┣ 📂品牌B（客户编码）
 ┗ 📂公共素材库：无版权BGM、通用空镜、模板（所有品牌共用）
```
> 网盘、DAM数字资产管理系统都可以套用这套目录。

## 二、统一文件命名规则
不用打开文件就能识别信息，格式：
`客户编码_日期_项目_素材类型_版本号.后缀`
示例：`PP01_20260820_新品活动_短视频成片_V3.mp4`
- V1初稿、V2修改版、V3客户定稿；定稿后标记FINAL
- 素材类型区分：raw原片、draft草稿、cover封面、final成片

## 三、权限隔离，保障客户素材安全
多品牌最重要就是**素材隔离，防止A品牌素材给到B客户**。
1. 按品牌设置独立权限分组：编导、剪辑只开放自己负责品牌文件夹，看不到其他客户素材。
2. 区分角色权限：
    - 剪辑：上传、编辑，不可删除归档素材
    - 运营：查看下载成品，不能改动原始素材
    - 客户：仅可查看交付文件夹，禁止下载原始原片
3. 对外给客户审核：使用带时效的分享链接，设置密码，到期自动失效，禁止直接发送完整素材库。
4. 开启操作日志，记录上传、下载、修改记录，出现问题可以追溯。

## 四、版本管理，避免多版本片乱
1. 工程文件、成片禁止直接覆盖旧文件，每次修改生成新版本，保留全部历史版本。
2. 定稿版本单独放到【交付客户】文件夹，打上FINAL标记，剪辑只允许拿这个版本对外输出。
3. 使用DAM/协同工具，支持版本回退、在线批注，客户反馈直接写在素材上，不用来回传文件。

## 五、标签体系，快速检索素材
素材量大只靠文件夹不够，需要打标签，实现快速搜索调取：
- 基础标签：品牌、平台、日期、活动名称
- 内容标签：产品SKU、镜头类型（产品特写/场景/口播）、卖点、视频时长
- 业务标签：爆款/测试素材、已发布/未发布、投流素材/自然流量素材

> 简单方案：网盘+表格记录标签；高效方案：DAM素材中台支持AI自动打标，直播切片自动拆分子镜头素材。

## 六、素材流转工作流程
1. **素材入库**：拍摄/直播切片完成，立刻上传对应品牌的原始素材文件夹，打标签，不允许存个人电脑。
2. **剪辑制作**：读取原始素材，工程文件存入对应品牌工程目录，输出多个版本。
3. **客户审核**：把待审核版本放到交付文件夹，生成分享链接收集修改意见。
4. **定稿归档**：客户确认后，将最终版标记FINAL；旧草稿不要删除，移入归档文件夹。
5. **复用管理**：爆款镜头可以复制到公共素材库，标记来源品牌，禁止跨品牌直接挪用客户专属实拍素材。

## 七、工具选型参考
1. **轻量小团队（3‑10人）**：飞书云文档网盘、阿里云盘企业版，搭建文件夹+权限，成本低；缺点AI打标弱，需要人工维护标签。
2. **中型代运营（10‑30人）**：数字资产管理DAM系统，支持品牌隔离、版本控制、AI打标、操作日志，适合客户数量多，素材量大的团队，如MuseDAM、火山智能创作云。
3. **短视频投放为主代运营**：短视频中台工具，素材库和剪辑、发布、投放打通，支持直播切片自动入库，按品牌分区隔离。

## 八、制度规范（容易被忽略）
1. 禁止把客户原始素材下载保存到个人电脑，防止素材泄露丢失。
2. 离职人员立刻收回全部素材权限。
3. 定期清理：归档文件夹定期备份，原始素材保留合同约定周期，到期按合同处理。
4. 版权管控：公共BGM、素材确认版权，每个品牌素材区分自有实拍和授权素材，避免侵权风险。
