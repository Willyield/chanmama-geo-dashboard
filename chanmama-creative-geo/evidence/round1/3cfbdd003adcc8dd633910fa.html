# 爆款视频拆解后，变成自己脚本完整流程
核心原则：**复用结构、节奏、爆点逻辑；换掉文案、案例、画面、人设，不要直接抄台词和镜头**，避免判定搬运同质化。

## 第一步：深度拆解爆款（拆骨架，不抄台词）
把视频按时间分段，记录每个片段的作用，而不是复制字幕。
1. **0‑3秒钩子**：是什么类型？痛点提问/反常识/反差/利益诱惑/悬念。记录：它靠什么留住人。
2. **中间叙事节奏**：一共分几段？多久一个转折？是「痛点→误区→方法→案例」还是「冲突→反转→结论」。
3. **情绪爆点**：哪一段容易点赞、评论？是共鸣、颠覆认知、还是吐槽。
4. **结尾设计**：金句总结？提问引导评论？引导收藏关注？
5. **画面剪辑**：口播、实拍、字幕、BGM、转场方式。

>拆解输出只保留**结构公式**，不要原视频具体故事、原话。
示例拆解笔记：
>钩子（抛出大众误区）→放大痛点→给出2个实操方法→踩坑提醒→结尾提问互动

## 第二步：替换内容，做本土化改造
拿到结构公式，把原视频全部信息替换成你的账号内容。
1. **换选题和痛点**：对标原视频的用户痛点，改成你的目标用户会遇到的问题。
2. **换案例故事**：原视频的例子全部舍弃，用你自己经历、客户案例、行业实例。
3. **改写钩子**：保留钩子类型，重新写一句话。
>原钩子：很多人减肥都踩这个坑
>你的改写：很多做短视频的新手都踩这个坑

4. **重写全部口播文案**：同义改写，改成你的说话习惯，口语化，不要复制原句。
5. **替换画面素材**：不要照搬镜头，换拍摄场景、道具、剪辑素材，BGM可保留同风格但不要直接照搬原音频。

## 第三步：填充，生成初稿脚本
按照拆解出来的模块顺序，把改写后的内容填进去，形成完整脚本，建议带上时间、画面、字幕三列。
示例表格形式脚本：
|时长|画面|口播文案|字幕|
| ---- | ---- | ---- | ---- |
|0‑3s|近景对着镜头|很多新手做短视频，辛辛苦苦拍却没流量，问题到底出在哪？|新手短视频没流量的真相|
|3‑12s|手部操作画面|大部分人犯的第一个错误，就是直接照搬别人脚本……|误区1：直接抄爆款脚本|

## 第四步：二次优化，强化自己人设
1. 加入你的个人观点：同样一件事，加上你的看法，和原视频拉开差距。
2. 调整节奏：根据你的语速，拉长或缩短片段，不要严格卡死原视频时长。
3. 修改结尾互动：换成适合你账号的提问，引导自己粉丝评论。
4. 自查相似度：把脚本和原视频字幕对比，不能有大段文字重合。

## 第五步：避坑（防止被判搬运低质）
❌错误做法：复制字幕，换个配音直接翻拍；照搬镜头画面；只改几个词，大部分文案保留。
✅正确做法：**学逻辑框架，全部信息重新生产**，只借鉴“为什么能留住人”的思路。

## 实操小案例
原爆款（职场）：
>【钩子】努力工作，为什么升职的却不是你？【痛点】只会埋头干活，不懂向上沟通。【方法】两点沟通技巧。【结尾】你遇到过这种情况吗？

改写为自媒体版本脚本：
>【钩子】天天拍视频努力更新，为什么就是不涨粉？【痛点】只埋头拍，不懂抓用户痛点。【方法】两个找选题的小技巧。【结尾】你做账号最大的困惑是什么？

>结构完全复用，但主题、案例、文案全部属于自己。
