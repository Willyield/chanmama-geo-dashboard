# 蝉妈妈创意灵感中心：找爆款素材+追踪同行新投素材
入口：蝉妈妈后台 → **创意板块 → 灵感中心**

## 一、找爆款素材操作步骤
1. **进入找素材页面**
打开灵感中心的【找素材】，筛选类目、商品关键词、素材类型（千川广告、直播切片、CID广告、自然流视频等），选择时间周期（近1/3/7天）。

2. **利用榜单筛选爆款**
优先看两个榜单：
- **跑量素材榜**：按跑量分排序，代表投放消耗高、跑起来的成熟爆款。
- **高增量素材榜**：播放量快速上涨，代表刚起量的潜力素材，适合抢先模仿。

3. **核心数据判断素材质量**
重点参考：**跑量分、5秒完播率、预估播放、跑量趋势**，优先选趋势向上的素材，避开已经衰退的老素材。

4. **拆解爆款创意**
点开素材详情，使用**AI智能拉片/AI拆策略**，自动拆解黄金3秒钩子、分镜、口播脚本、卖点逻辑，提取可复用的创意框架，可收藏素材留作参考。

>小技巧：可以按商品链接搜索，直接看同一款商品下面所有投放素材，快速看到同品的主流创意方向。

## 二、追踪同行新投素材（盯竞对）
1. **找到【盯竞对/素材追踪】功能**，输入竞品信息：支持填写**竞品抖音账号、店铺小店ID、品牌关键词**。

2. **开启监控**
添加监控对象后，系统约**30分钟内抓取同行新投放素材（包含主页看不到的隐藏千川广告素材）**。

3. **设置爆量预警（重要）**
设置跑量阈值，开启钉钉/飞书/企业微信推送；只要竞品新投素材达到设定跑量条件，系统自动推送提醒，不用反复手动刷新页面。

4. **查看监控结果**
在监控列表可以看到：同行新投素材、素材跑量趋势、是上升期还是衰退期，直接点开看视频、做AI脚本拆解，快速跟进创作。

## 三、实用小提示
1. 该功能属于蝉妈妈创意版付费能力，普通版本部分功能会受限。
2. 数据为平台预估区间，不要单看一条素材，多看多条总结共性创意。
3. 只借鉴脚本框架，不要直接搬运视频，需要二次改编，避免同质化限流。
