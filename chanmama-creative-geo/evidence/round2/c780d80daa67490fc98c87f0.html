# 电商短视频：脚本/分镜/成片统一管理方案（中小电商团队直接落地）
核心思路：**按【项目单条视频】为核心打包，一条视频的脚本、分镜、原片、工程、成片全部归集在一起；再配套统一命名+版本规则+标签库，用一张总表做索引**，解决文件散落在微信、个人电脑、不同网盘、版本叫“最终版_final真最终”的痛点。

## 一、统一目录结构（云盘/飞书云文档/企业网盘都能用）
```
📁素材总库
├─📁01_项目生产库（正在做的视频，按产品+日期建项目文件夹）
│  └─📁20261012_产品A_痛点口播_01【唯一项目ID：V26101201】
│     ├─📄00_项目信息卡（表格：项目ID、产品、卖点、平台、负责人、状态、投放数据链接）
│     ├─📝01_脚本 文档（在线文档，可协同）
│     ├─🎨02_分镜（PDF/图片，分镜表，和脚本一一对应）
│     ├─🎥03_原始拍摄素材（RAW原片，只读，禁止直接修改覆盖）
│     ├─✂️04_剪辑工程文件（剪映工程/PR工程）
│     ├─🎬05_迭代成片版本 v01/v02/v03
│     └─✅06_终版成片（审核通过、可投放）
├─📁02_公共资产库（可复用，跨项目调用）
│   ├─脚本模板库｜爆款脚本拆解库
│   ├─分镜模板库（口播、产品展示、对比测评模板）
│   ├─空镜素材｜产品Broll｜BGM音效｜字幕模板
│   └─品牌规范（LOGO、色值、字体、包装规范）
└─📁03_归档库（投放结束，沉淀历史素材，保留数据）
```

> 关键规则：**原始素材目录只读，任何人不能覆盖原文件；修改只新增版本号，不覆盖旧文件**

## 二、强制统一文件命名（根治final_final乱象）
命名模板：`【项目ID】_类型_名称_v版本号`
- 项目ID：V26101201（V+年月日+流水号，一条视频唯一ID，贯穿脚本、分镜、成片）
- 类型简写：脚本、分镜、RAW、工程、成片
示例：
- V26101201_脚本_产品A痛点口播_v02.docx
- V26101201_分镜_产品A演示_v01.pdf
- V26101201_成片_抖音竖屏_v03.mp4

> 版本规则：v01初稿、v02修改稿、v03终审定稿；**定稿不再继续覆盖，新修改直接升版本号**

## 三、脚本、分镜、成片如何强关联绑定（最重要）
1. **脚本模板标准化**
脚本里固定字段：项目ID、产品、核心卖点、时长、平台、镜头序号、台词、画面描述、时长、备注。
脚本里每一行镜头编号，**和分镜表镜头编号完全一致**。

2. **分镜表必须和脚本同序号**
分镜表列：镜头号、画面截图/草图、景别、时长、画面内容、台词、参考素材ID。
> 好处：编导、拍摄、剪辑、投手，所有人看同一份编号，不会理解偏差。

3. **成片和脚本分镜绑定**
成片文件命名带同一个项目ID；成片审片批注（分秒帧/飞书批注）直接在视频上打点，**批注可以关联回脚本镜头号**，修改时直接定位脚本、分镜哪一镜要调整，不用来回翻聊天记录。

4. **一张总索引表（多维表格/飞书多维/Notion/Excel）**
每一行=一条视频项目，字段：
项目ID｜产品名称｜脚本链接｜分镜链接｜成片链接｜版本｜状态（初稿/拍摄中/剪辑中/待审核/已投放/归档）｜投放数据（消耗、ROI、完播）｜标签
👉 所有物料放在线链接，一点直达，不用翻文件夹。

## 四、标签体系（方便检索复用素材）
给每条项目/片段素材打标签，多维筛选：
- 产品标签：洁面仪、保温杯
- 内容类型：痛点口播、场景演示、对比测评、效果展示
- 平台标签：抖音千川、小红书、视频号
- 效果标签：爆款素材、高完播、低效素材、待迭代
- 素材类型：脚本、分镜、成片、Broll空镜

> 目标：后续想找“保温杯+痛点口播+抖音爆款脚本”，直接筛选标签就能调出历史全套脚本+分镜+成片，不用重做

## 五、工具选型，分3档
### 小团队（5人以内，低成本）
- 存储：企业网盘/飞书云盘
- 文档&脚本：飞书文档/腾讯文档（在线协同脚本）
- 索引：飞书多维表格 / Excel
- 审片批注：分秒帧（视频打点批注，直接在成片上提修改意见）
优点：上手快，不用额外买软件

### 中型电商素材团队（10人左右，大量素材迭代）
创意云、分秒帧、飞书全套；支持素材预览、标签管理、版本对比、权限控制，投手可以直接查看成片和脚本，打通投放数据。

### 大团队素材中台
专业媒体资产管理MAM系统，支持素材智能标签、素材权限、素材使用统计，适合日产出几十条素材的团队

## 六、生产SOP流程（保证所有人遵守）
1. 编导新建项目 → 分配唯一项目ID，在多维表新建一行
2. 写脚本 → 同步出对应编号分镜，提交评审
3. 拍摄：原始素材上传到项目RAW文件夹，**禁止个人电脑存唯一一份**
4. 剪辑：工程放项目文件夹，导出成片带版本号上传
5. 审片：在成片上打点批注，修改后升版本号
6. 审核通过，标记终版，录入投放链接与数据
7. 投放结束，项目移入归档库，打上效果标签，供后续复用

### 权限划分（避免误删）
- 编导：读写脚本、分镜
- 剪辑：读写工程、成片；只读原始素材
- 投手/运营：只读全部物料，看索引和成片，不可修改
- 素材管理员：定期清理、归档、维护公共素材库

## 七、日常维护规则（防止用一段时间又乱掉）
1. 拍摄当天，素材必须上传云端，不允许素材只留在相机/剪辑电脑
2. 每周一次素材巡检：清理废弃草稿、无效版本，归档已投放项目
3. 每月复盘：把高ROI爆款的脚本、分镜提取到公共模板库，直接复用框架
4. 废弃素材不要直接删除，先打标签归档，保留溯源

## 八、常见坑提醒
❌ 不要只按产品文件夹存放，不做单视频项目打包：后期脚本成片对不上
❌ 不要用微信传脚本成片：版本丢失、无归档
❌ 不要直接覆盖成片：一旦要回溯旧版本直接找不到
✅ 最小落地动作：先统一命名规则+建一张多维索引表，不用一次性全改造，新项目先按新规则跑，旧素材分批整理
