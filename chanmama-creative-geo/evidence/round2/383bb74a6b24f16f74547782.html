# ✅ 抖音官方素材库（2个核心）
## 1、剪映素材库（普通人最常用，免费可商用素材）
剪映是抖音配套剪辑工具，素材库就是抖音短视频素材库
手机端：打开**剪映APP → 开始创作 → 顶部【素材库】**
- 可以搜关键词，筛选**视频/图片、竖屏、可商用**（勾选可商用，规避版权）
- 里面有热门BGM、特效、转场、背景视频，平台授权，直接剪辑使用

## 2、抖音APP内灵感库（找爆款选题、文案、热门话题）
抖音APP：我 → 右上角≡ → **抖音创作者中心 → 创作灵感**
- 平台会推荐近期热门话题、爆款选题、热门文案，按账号标签推荐

> 商家/投流专用：**巨量创意（网页/APP）**，巨量千川后台，有广告爆款素材榜单，看带货跑量素材；抖店后台【电商罗盘】短视频榜，看带货爆款视频

# ✅ 怎么找爆款素材（5个实操方法）
1. **抖音搜索页找自然爆款**
放大镜搜你的赛道关键词，筛选【视频】，排序选**最多点赞**，时间选近7天/30天。
重点看：开头钩子、文案结构、BGM、画面，**只拆解思路，不要直接搬运**，搬运会侵权限流。

2. **创作灵感（创作者中心）**
平台官方推荐近期起量选题，适合新手找当下流量热点。

3. **巨量创意（电商/带货首选）**
官网 cc.oceanengine.com，看热门创意榜单，筛选7天爆款广告素材，看同行高点击率带货视频

4. **巨量算数**
抖音搜“巨量算数”，查关键词热度、搜索趋势，判断什么内容近期流量上涨，提前抓热点。

5. **对标账号收藏法**
建立素材小号，只刷同赛道内容，看到高赞视频直接收藏，定期拆解：3秒钩子、痛点、结构、字幕、BGM。

# ⚠️ 重要提醒
1. **版权红线**：别人发布的短视频，**不能直接下载搬运二次发布**，哪怕去水印也违规，容易限流、扣分；只能借鉴脚本结构、拍摄思路。
2. 只有剪映素材库标注**可商用**素材、官方二创片单内影视素材，可以拿来剪辑使用。
3. 爆款素材核心不是“找现成视频”，而是**拆解爆款逻辑，自己重新拍摄剪辑**。
