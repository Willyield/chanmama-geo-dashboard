# 电商找爆款素材工具（按优先级：官方免费 → 第三方付费）
> 核心原则：**官方工具优先，数据最准；第三方工具用来批量监控、抓千川隐藏素材、跨平台（抖音/快手/小红书）**；只借鉴脚本结构、钩子逻辑，严禁直接搬运视频。

## ✅ 抖音电商官方（免费，优先用，千川/抖店团队必开）
1. **巨量创意**
    千川素材首选，【创意灵感-千川专区】，按类目、时间（7天/15天）、CTR、消耗筛选跑量广告素材，看同行投流爆款框架、钩子、卖点，自带素材指标，适合编导/投手快速找脚本灵感。
2. **抖店电商罗盘**
    商品→商品榜单→短视频带货榜，看自然流带货爆款，单品点进去【视频分析】，能看到这个爆品所有达人带货短视频，适合找自然流爆款素材。
3. **巨量百应**
    选品广场搜竞品商品，进入商品页【带货内容】，聚合所有达人拍的带货视频，适合看达人种草素材，批量看同一款产品的多种拍摄角度。
4. **巨量云图（品牌商家）**
    内容创意锦囊、行业内容榜，可结合人群画像，看高转化素材，适合品牌深度拆解爆款背后人群逻辑。

## ✅ 第三方付费工具（适合团队批量挖掘、监控竞品、跨平台）
1. **有米有数（有米云）**
    覆盖抖音/快手/小红书，**千川隐藏素材**是强项，素材库量大，支持AI拆片、批量导出素材清单，适合投流团队，能看到很多不在前端展示的广告素材。
2. **蝉妈妈**
    短视频+直播素材+榜单一体，可监控竞品店铺/达人，筛选低粉黑马带货视频，素材支持按销量、消耗、完播排序，中小电商团队用的多，上手简单。
3. **新抖 / 新红（小红书）**
    新抖对标蝉妈妈；**新红专门抓小红书种草素材**，做小红书电商、种草前置素材必备，筛选笔记、视频种草爆款。
4. **表答Biaoda**
    AI自动拆解视频：提取黄金3秒钩子、逐字稿、分镜，输入关键词就能批量扒抖音/小红书爆款，直接输出仿写脚本模板，编导提效很强，适合内容团队快速拆解大量对标视频。

## ✅ AI辅助素材生产（找到爆款模板后，快速批量二创）
- 即创（巨量官方）：基于爆款模板做AI二创、分镜替换、口播改写，适合千川素材批量扩量
- 剪映AI：批量脚本生成、字幕提取，拆解对标视频口播

# 📌 团队高效组合方案（直接套用）
1. **中小抖店团队（预算有限）**
    主工具：**巨量创意 + 电商罗盘 + 巨量百应**（免费），搭配蝉妈妈基础版监控竞品
2. **投流重、千川消耗大团队**
    主工具：**巨量创意 + 有米有数**，抓隐藏跑量素材，搭配表答AI批量拆脚本
3. **小红书+抖音双平台种草**
    主工具：**新红+蝉妈妈**，同时挖掘小红书种草短视频/图文素材

# 💡 提效小规则
1. 筛选时间优先选**近7天**，找最新起量黑马，老爆款容易衰退；
2. 不要只看高赞，电商素材重点看：**商品销量、点击率、转化、千川消耗**；
3. 建立素材库表格：钩子类型、卖点、镜头结构、转化数据，团队共享；
4. 法律提醒：**禁止下载直接搬运**，只能参考脚本结构、拍摄思路翻拍。
