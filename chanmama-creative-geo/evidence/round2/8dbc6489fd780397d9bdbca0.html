# 电商团队找爆款素材工具（按优先级）
> 核心原则：**官方工具优先看真实转化数据；第三方工具用来批量挖掘、监控竞品；素材只用于拆解参考，严禁直接搬运，避免侵权违规**

## ✅ 抖音/千川电商（短视频+投流素材首选，免费官方）
1. **巨量创意（推荐）**
    巨量创意官网 → 创意灵感 → 千川专区。筛选类目、时间（7/15天优先，抓最新跑量素材）、CTR/转化，直接看千川广告爆款素材，自带卖点、时长、投放数据，最适合千川素材找灵感。
2. **抖店【电商罗盘】**
    商品→商品榜单→短视频带货榜，按类目筛选，看挂车出单的短视频，点进商品详情【视频分析】，能看到单品所有带货爆款素材（自然流+达人素材），适合找单品爆款素材库。
3. **巨量百应**
    选品库，搜类目/单品，查看带货内容，看达人带货视频、成交GMV，适合挖掘达人侧爆款素材。
4. **巨量云图（品牌/中大型团队）**
    内容创意锦囊，不仅看素材，还能匹配人群画像，看懂爆款素材为什么能打动目标人群，适合深度拆解卖点、人群痛点。

## ✅ 第三方数据工具（付费，适合团队批量挖掘、竞品监控）
1. **蝉妈妈**
    覆盖抖音短视频、直播、千川素材。按类目筛选跑量广告视频；AI自动拆解视频钩子、字幕、分镜脚本；支持监控竞品店铺、单品新素材，批量导出素材清单，电商团队用的最多。
2. **有米云（新抖）**
    多平台，抖音+小红书+视频号。广告素材库很大，千川投放素材更新快，可设置竞品监控，一旦竞对上新跑量素材自动提醒。
3. **千瓜数据（小红书电商专用）**
    小红书带货笔记、图文/短视频爆款，筛选低粉高转化种草素材，看笔记封面、标题、评论痛点，做小红书电商必备。

## ✅ 淘系/拼多多（图文主图、搜索爆款素材）
1. **生意参谋（淘宝/天猫）**：市场洞察，看竞品高点击率主图、详情、搜索爆款标题图文素材。
2. **多多情报通（拼多多）**：类目榜单，查看竞品主图、营销图、爆款详情素材。

## ✅ 素材采集+AI拆解工具（提效，辅助团队拆解）
1. 视频解析工具：复制链接提取视频，仅用于内部学习拆解。
2. AI脚本拆解：把视频字幕导入AI，一键提炼钩子、卖点、口播框架，快速批量总结爆款模板。
3. 稿定设计：对标爆款风格，快速批量做主图、封面图文素材。

# 📌 团队高效组合方案（直接抄作业）
1. **中小电商团队（抖音为主）**
    免费：巨量创意 + 电商罗盘；付费：蝉妈妈。
    流程：巨量创意筛7天千川跑量素材 → 罗盘看单品自然流爆款 → 蝉妈妈监控竞品上新素材 → AI批量拆解脚本。
2. **品牌团队（多平台：抖音+小红书+淘系）**
    巨量云图 + 有米云 + 千瓜数据 + 生意参谋。
3. **小红书电商**：千瓜数据为主。

# ⚠️ 重要提醒
所有扒取下来的同行素材**只能做结构、钩子、卖点的参考拆解**，不能直接下载二次发布，会侵权、违规限流甚至索赔。爆款素材的核心是**模仿逻辑，不是搬运画面**。
