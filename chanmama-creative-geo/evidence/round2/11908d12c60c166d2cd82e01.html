# 电商编导拆解爆款脚本：优先看这6大维度（写脚本直接复用）
核心思路：**先看数据归因，再拆叙事结构，然后逐秒拆视听，最后看转化闭环与人群，不是单纯抄文案**。拆解目标：搞懂「这条视频为什么能留住人、为什么能下单」，提炼可复制脚本模板。

## 1. 数据与人群基线（先看，决定这个爆款值不值得拆）
> 先排除：纯泛流量高播放、但是CVR极低的“虚爆款”，电商编导优先拆**高消耗+高转化**素材，而不是只看点赞。
- 核心指标：3s留存、5s留存、完播率、点击率、商品点击CVR；看流失节点（用户在哪一秒大量划走）
- 目标人群：这条视频在对谁说？精准人群画像，钩子在**筛选谁、过滤谁**（泛流量还是精准购买人群）
- 评论区挖掘：高频提问、痛点、顾虑、种草关键词。评论就是用户真实诉求，直接放进脚本痛点/答疑部分

## 2. 叙事脚本骨架（最重要，直接用来写脚本框架）
通用电商带货骨架：**0-3s钩子 → 痛点放大/冲突 → 产品出场 → 核心卖点（≤3个） → 信任佐证 → 价格机制+打消顾虑 → CTA行动指令**
逐段拆解：
1. **前3秒钩子（重中之重）**：钩子类型（痛点提问/反差打脸/结果前置/价格冲击/悬念）；第一句话+首帧画面，**有没有直接抛出用户问题，不是自我介绍**
2. 中段逻辑：痛点怎么放大；卖点不是堆参数，而是**功能→优势→用户利益（FAB）**；卖点是怎么可视化展示（实验、前后对比、实测）；每隔8~15s有没有新的信息锚点，防止中途流失
3. 信任背书：用什么建立信任——真人实测、对比实验、用户反馈、检测、场景真实感、避坑科普
4. 转化收口：价格锚点（原价vs现价）、赠品、稀缺、售后；**打消核心购买顾虑**；结尾CTA（明确引导小黄车/直播间，一句话指令，不要模糊）

> 重点区分：这条爆款是**流量型素材（拉曝光）**，还是**转化型素材（高CVR）**，写脚本时定位完全不一样。

## 3. 口播文案与情绪话术（脚本台词层）
- 逐句提取：金句、反问句、情绪词；哪些句子是制造冲突、引发评论的
- 话术特点：口语化程度，有没有长难句；卖点是否翻译成生活化类比，避免干巴巴参数
- 节奏：哪里停顿、哪里加重、哪里反问；情绪曲线：焦虑→看到希望→安心→冲动下单

## 4. 镜头/视听节奏（脚本分镜层，编导最容易忽略）
把视频拖进剪辑软件，按秒拆镜头：
- 镜头：景别切换（特写/中景）、机位、运镜；每个镜头停留时长；**多久切一次镜头**
- 画面：首帧画面、对比画面、产品特写、场景置景、道具；字幕（大字重点词什么时候弹出）
- 音频：BGM风格、卡点位置、音效；人声大小；什么时候静音只留画面演示
> 电商短视频关键：**卖点必须有画面同步佐证，不能只靠嘴说**

## 5. 场景与人设（人货场，脚本场景设定）
- 使用场景：产品放在什么真实场景下演示（居家/通勤/厨房），用户能不能代入“我也会遇到这个场景”
- 人设：主播身份（素人/测评师/过来人），人设带来的信任成本；说话语气，是科普、吐槽、真诚分享还是强逼单
- 人货匹配：人设、场景、产品是否统一；广告感强不强

## 6. 合规与风险（编导写脚本必看）
- 看对方哪些词、哪些演示方式是平台允许；有没有极限词、功效夸大、违规承诺
- 效果展示：是真实演示，还是暗示效果；避免直接抄袭素材画面带来查重问题

# 简易拆解工作流（团队落地）
1. 筛选样本：优先**近7~14天、同赛道、高消耗高转化**素材，不要拆很久之前过时爆款
2. 建表格：每条爆款记录：数据、人群、钩子类型、完整脚本分段、镜头节奏、核心转化点、可复用公式、不可复制点（达人专属人设、独家素材）
3. 归因判断：这个爆款爆是**钩子强？场景共鸣？价格机制？主播表现力？** 只复制可控的部分，不要复制不可控的（达人个人魅力）
4. 提炼模板：把共性抽成脚本模板，后续写脚本直接套用，每次只改单一变量做A/B测试

# 避坑提醒
❌ 不要只抄文案台词，忽略**3秒首帧画面、镜头节奏、人群筛选逻辑**；很多爆款的核心爆点是画面，不是台词
❌ 不要把高点赞低转化视频当成电商脚本模板，这种只能做内容种草，不能带货
✅ 拆解目的：提炼**可复用的脚本结构+钩子公式+卖点可视化方法**，不是翻拍一模一样视频
