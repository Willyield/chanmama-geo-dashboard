# 核心思路：AI做粗稿+批量裂变，人工做决策、卡点、合规、钩子优化
一句话分工：**AI负责80%重复机械工作，人负责20%决定转化效果的关键环节**；不要指望AI直接导出就能投流，AI的价值是快速出多个初稿版本，人工做筛选与精修，把单条制作时间压缩。

## 一、分工边界（谁干什么）
### ✅ AI一键成片负责
1. 批量套模板生成初稿：输入产品图、卖点文案，自动拼镜头、配BGM、自动字幕、AI配音、基础转场；同脚本一键多变体（换BGM、换音色、换镜头顺序），快速一次产出3~5版备选。
2. 素材粗剪：实拍长素材自动切片、按口播分割片段、图片动态运镜。
3. 多平台格式输出：9:16短视频、1:1商品主图视频，自动适配画幅。
4. 文案辅助：基于产品卖点生成多版口播脚本、标题、话题标签。

### ✅ 人工剪辑/编导负责（核心价值区）
1. **前置：固定爆款模板库**。人工先沉淀经过投放验证的分镜框架（3秒钩子→卖点演示→痛点→CTA下单），AI只在固定框架里替换产品素材，避免AI自由发挥乱做分镜。
2. 审片+产品真实性校验：检查产品颜色、细节、logo有没有AI变形错误；修正字幕错别字、数字读错、口播不通顺。
3. 优化前三秒钩子：替换开头镜头、重剪节奏，这是电商素材完播率核心；调整卡点、删减冗余片段。
4. 合规审核：排查极限词、违规功效宣传，避免素材直接投放被下架。
5. 品牌统一：固定品牌调色、logo停留时长、字幕样式、片尾引导，保证全素材视觉统一。
6. 数据复盘：拿投放数据反哺模板，淘汰低转化框架，更新AI提示词库。

> 素材配比建议：**AI素材40% + 实拍核心镜头60%**。产品特写、功能演示、手部操作、模特口播这类决定信任感的镜头尽量实拍；AI用来做背景、场景过渡、图文动画，减少AI失真带来的低转化问题。

## 二、完整流水线SOP（批量生产最优流程）
1. **前置准备（一次性沉淀，反复复用）**
    人工整理：爆款分镜模板库、品牌规范包（字幕/配色/logo位置）、标准化提示词、实拍素材库（产品特写、开箱、细节镜头）。
2. **AI批量出粗稿**
    导入产品素材+选定模板，AI一键成片，一次性生成多版本变体，**不直接发布**，全部导出为工程文件，进入人工筛选池。
3. **人工快速筛选（初筛，30秒/条）**
    快速剔除产品穿模、画面错误、钩子很差的废稿；保留20%-40%可用初稿。
4. **人工精修剪辑**
    在AI工程上微调：重排镜头顺序、改口播文案、修正字幕、调整BGM音量、替换关键实拍镜头、卡点微调、添加品牌元素。
5. **终审合规**：检查广告词、产品画面、标识合规。
6. **导出+投放+复盘**
    投流后看点击率、完播、转化；把高数据素材拆解，更新模板库，反向优化AI成片的提示词，持续拉高AI初稿良品率。

## 三、两种素材类型，搭配策略不一样
1. **大批量测试素材（千川测素材、信息流测试，追求数量）**
    AI成片为主，人工轻审核+少量微调，每条人工耗时控制在1~3分钟。目标：快速堆素材量测爆款，不追求极致质感。
2. **精品素材（商品主图视频、高预算广告片、直播间引流精品片）**
    AI只做分镜草稿、素材拼接、字幕配音；人工深度剪辑、调色、精细卡点、实拍素材重组，重点打磨钩子和卖点节奏。

## 四、提效关键技巧 & 避坑
1. **不要从零生成**：AI成片一定要套人工验证后的固定脚本模板，自由生成的AI视频大概率卖点混乱、前三秒留不住人。
2. **素材库前置**：提前拍好标准化实拍片段，AI生成初稿后，人工直接替换掉AI失真的产品镜头，提升真实感。
3. **建立问题库**：记录AI高频错误（颜色失真、数字读错、字幕错字），写进提示词，持续提升AI初稿良品率，减少后期修改量。
4. **人力配比参考**：1个剪辑可以同时跑AI批量任务，一天产出几十条粗稿，人工只做筛选+精修，而不是从零剪辑。
5. 避坑：完全依赖AI一键成片直接投放，很容易出现产品失真、AI感过重、合规翻车，素材点击率普遍偏低。

## 五、团队角色简化方案（小团队适用）
- 运营/编导：定模板、卖点、审片、数据复盘（做决策）
- AI工具：批量生成初稿、自动字幕配音
- 剪辑：精修、替换实拍镜头、调色、合规检查

这套搭配的本质，是把剪辑人员从重复拼接、字幕、转场这种机械劳动释放出来，把精力放在**影响转化的创意、钩子、卖点节奏**上，实现素材数量和质量平衡。
