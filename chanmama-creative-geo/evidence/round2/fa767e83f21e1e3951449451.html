# 一句话总结
**蝉妈妈（蝉妈妈数据）：电商大盘生意分析工具，看销量、达人、直播间、商品大盘；蝉妈妈创意：千川投流素材专项工具，找广告素材、拆解爆款创意、AI批量做带货短视频**。两者同属一家公司，是两套独立产品，会员分开购买。

## 一、蝉妈妈（主站 / 蝉妈妈数据）
### 核心能力
定位**直播电商全域数据平台**，看“生意结果数据”：
1. **商品大盘**：爆品榜单、销量、价格带、品类趋势，哪个品卖了多少、哪些达人在带货；
2. **达人分析**：达人带货GMV、粉丝画像、历史直播业绩、评估达人合作价值；
3. **直播分析**：直播间预估销售额、流量结构、直播回放、竞品直播间监控；
4. **小店/品牌分析**：竞品店铺整体销量、品牌大盘、渠道结构；
5. 自然流短视频数据，看自然爆款视频的点赞、转化。

### ✅适合场景
1. 选品、测赛道，判断这个类目能不能做；
2. 找达人、筛选达人、评估达人合作报价；
3. 监控竞品直播间、竞品店铺整体销售情况；
4. 直播运营复盘，看整场直播流量、转化；
5. 做自然流短视频带货，看自然爆款账号。

> 适合人群：直播操盘手、选品专员、达人商务、店铺运营、MCN负责人。

## 二、蝉妈妈·创意（cy.chanmama.com）
### 核心能力
定位**爆量广告创意素材平台**，重点看**千川付费投流素材**：
1. 海量千川跑量短视频素材库，可筛选投放广告素材（很多在抖音自然页刷不到）；
2. 素材跑量分、增量榜，追踪竞品正在投放的广告视频；
3. AI智能拉片：自动拆解视频脚本、话术、黄金3秒、爆款要素；
4. AI创意大师：一键成片、数字人带货、脚本仿写、批量生成带货短视频；
5. 定向监控竞品品牌/小店的投放素材更新，看对方最近上新哪些广告素材。

### ✅适合场景
1. 千川投流团队，找跑量广告素材灵感，学习竞品投流创意；
2. 短视频素材编导，批量拆解爆款脚本、仿写带货视频；
3. 素材团队批量产出投流短视频，AI辅助快速成片；
4. 监控竞品广告创意迭代，看对方近期在投放什么素材。

> 适合人群：千川投放、短视频编导、素材剪辑团队、品牌内容创意负责人。

## 三、简单对比表
|项目|蝉妈妈（主站）|蝉妈妈创意|
|---|---|---|
|核心视角|**生意结果：销量、GMV、达人、直播、商品**|**广告素材：千川投放视频、创意脚本**|
|重点数据|直播间、商品销量、达人业绩、店铺大盘|素材跑量、广告曝光、视频创意拆解|
|强项|选品、达人挖掘、直播数据分析|千川素材检索、AI拆片、AI生成带货视频|
|短板|广告投流素材库较弱，AI成片能力弱|大盘销量、达人直播数据不如主站|

## 四、怎么选
1. **只做直播、选品、找达人、自然流带货 → 买蝉妈妈主站即可**
2. **主要投千川、大量做付费短视频素材，需要找广告素材、AI批量做视频 → 买蝉妈妈创意**
3. **品牌团队，既要监控竞品生意，又要大量产出千川素材 → 两个都开**
