# 一句话总结
**蝉妈妈（蝉妈妈数据）：全域电商大盘数据工具，核心看销量、GMV、达人、直播、商品大盘；蝉妈妈创意：广告素材/千川投流素材专项工具，核心找跑量广告素材、AI拆素材、做创意生产**，两个是蝉妈妈旗下独立产品，会员分开购买。

## 一、蝉妈妈（主站，蝉妈妈数据）
### 核心定位
**直播电商大盘数据分析平台，看“生意结果”**，看账号、直播间、商品、达人的成交数据，做选品、达人对接、直播复盘、赛道调研。
### 核心功能
1. 商品榜单：看全品类销量、爆品、潜力品，商品历史销量、哪些达人在带货
2. 达人分析：查达人带货GMV、粉丝画像、场均销量、合作报价参考，筛选达人合作
3. 直播分析：监控直播间预估GMV、在线人数、流量结构、商品转化、直播回放
4. 账号&小店分析：对标店铺、品牌整体销售趋势，自然流短视频带货数据
5. 行业大盘：赛道趋势、价格带、市场竞争度

### ✅适合场景
- 达人/商家**选品、找爆品、评估赛道**
- 商务BD，筛选带货达人、评估达人价值
- 直播运营：监控竞品直播间、复盘直播成交数据
- 品牌调研：看竞品抖店整体销量、品类大盘行情
- 做自然流短视频带货，看自然流爆款视频、账号数据

## 二、蝉妈妈创意（cy.chanmama.com）
### 核心定位
**千川/磁力金牛广告素材洞察+创意生产平台，看“投放素材”**，专门找付费投流跑量素材，素材拆解、AI批量做带货短视频脚本和成片。
### 核心功能
1. 投流素材库：海量千川广告短视频、直播切片素材；可按投放时长、跑量分、完播、消耗筛选，很多是**付费广告素材（蝉妈妈主站看不到）**
2. 竞品投放追踪：定向盯竞品品牌/小店正在投放的广告素材，看对方素材迭代节奏
3. AI素材拆解：智能拉片，提取视频文案、卖点、黄金3秒结构，自动分析爆款要素
4. AI创意大师：AI生成带货脚本、数字人视频、一键成片、仿写爆款素材，素材团队协作管理
5. 策略中心：分析竞品投放策略，挖掘黑马素材

### ✅适合场景
- 千川投手、短视频投放团队：找跑量广告素材，对标同行投流创意
- 短视频素材编导：批量拆解广告素材，快速仿写、生成新带货视频
- 品牌付费投放：监控竞品广告素材，了解对手投放打法
- 素材团队：素材资产管理、多人协作产出投放素材

# 三、快速对比表
| 项目 | 蝉妈妈（数据版） | 蝉妈妈创意 |
|---|---|---|
| 侧重点 | 成交、销量、达人、直播大盘数据 | 付费广告素材、创意内容生产 |
| 数据对象 | 直播间、商品、达人账号、抖店自然+带货数据 | 千川/金牛投放广告短视频素材 |
| 核心产出 | 选品清单、达人名单、直播成交报表 | 素材灵感、脚本、AI成片、素材拆解报告 |
| 人群 | 商家、直播运营、达人BD、选品 | 投手、短视频编导、素材团队 |

# 四、怎么搭配选择
1. **只做自然流直播、选品、找达人** → 只用蝉妈妈（数据版）即可
2. **主要做千川付费投流，大量产出短视频广告素材** → 重点买蝉妈妈创意
3. **品牌，自然流+付费投流一起做** → 两个都开，蝉妈妈看大盘生意，蝉妈妈创意盯投放素材

> 提示：两个会员独立，不是开通一个就自动拥有另一个全部权限。
