# AI虚拟影棚 / 素材影棚 生成场景化商品视频
> 两类：**素材型AI虚拟影棚（网页SaaS，电商最常用，上传产品白底图，调用预制场景素材库，一键生成）**；**3D虚拟影棚（引擎/3D预演型，自由度更高，可自定义机位、光影、道具）**。
核心逻辑：**锁定商品主体 → 搭建/选择场景环境、灯光、镜头运动 → AI把产品和场景做光影融合、生成动态视频 → 后期剪辑拼接**，最大难点是**防止产品变形、穿模、材质跑偏**。

## 一、完整标准工作流（电商通用）
### 1. 准备商品基准素材（最重要）
优先准备**高清白底产品图**，多拍正/侧/顶三视图，保证产品轮廓、logo、纹理准确；
- 简单商品：1张高清白底图即可；
- 高要求：可做产品3D模型，AI识别几何体，旋转、多角度展示更稳定；
> 原则：**全程用这张基准图做参考，不要每次都用随手拍原图，否则产品会不断变形**。

### 2. 选择场景（两种模式）
#### 模式A：素材影棚（模板库，新手首选，Photoroom、酷家乐电商棚拍、筷子AI影棚）
1. 进入工具，在素材库挑选预制场景：厨房、卧室、极简水泥影棚、大理石台面、户外阳台等；
2. 选择预设灯光方案：柔光、侧逆光、硬影棚光；
3. 摆放商品位置、大小、透视，添加配套道具（杯子、书本、绿植等素材）；
4. 选择镜头动画模板：缓慢推镜、环绕旋转、平移、产品360°转盘、细节特写；
5. 上传白底产品图，AI自动抠图+**光影匹配**，把产品融入场景，直接生成短视频（9:16竖版电商短视频为主）。

#### 模式B：3D虚拟影棚（高阶，3D-BOX、UE引擎+AI视频）
1. 文字描述或直接搭建3D虚拟空间，放置场景模型、道具；
2. 在虚拟空间设置摄像机，手绘镜头运动轨迹，做分镜预演动画（预览视频）；
3. 放入产品3D资产，调整全局光照、环境反光，让场景的光真实打在产品表面；
4. 将预演参考视频+产品参考图送入AI视频模型，生成最终画面，镜头运动严格跟随预演，可控性更强。

### 3. 写提示词/配置镜头指令（控制画面稳定）
核心三要素：场景环境 + 产品光影 + 镜头运动。
示例：
> 极简轻奢浴室，柔和自然光，浅景深，高清商业摄影，白色陶瓷洁面仪放在大理石台面上，缓慢向右平移镜头，聚焦产品曲面光泽，产品形状不变，不扭曲，8K，写实，电影级布光。

> 技巧：加上约束词：**保持产品外观、logo不变，无变形，无穿模，光影统一**，大幅降低产品崩坏概率。

### 4. 分段生成视频片段（不要一次性生成长视频）
AI长视频容易漂移，行业做法：**4–6秒一个镜头片段**，分别生成：全景、产品特写、旋转展示、细节镜头；
每一段都绑定同一张基准产品图，保证产品统一。

### 5. 后期合成
把多个AI片段导入剪映/达芬奇：拼接、调色统一色调、加字幕、BGM、口播；
做画面修复，修正轻微闪烁、产品抖动，输出成片。

## 二、两种影棚的区别
### ✅ AI素材影棚（模板型）
- 特点：海量现成场景素材库，不用懂3D，上传产品图直接套模板；
- 优点：上手快、成本低、几分钟出片，适合电商主图视频、短视频带货；
- 局限：场景自由度有限，镜头只能选预设动画，复杂创意受限。

### ✅ 3D虚拟影棚（引擎虚拟制片）
- 特点：自由搭建3D空间，自定义机位、道具、光线、镜头轨迹；
- 优点：镜头运镜完全可控，真实光影反射，适合品牌广告片；
- 局限：门槛更高，需要理解基础3D，制作周期更长。

## 三、常见踩坑与避坑
1. **产品变形、logo乱改**：必须固定一张基准白底图，开启图片参考/图生图强度，不要纯文字生成；
2. **光影割裂，产品像贴上去**：场景、产品光源方向统一，提示词写明环境反光、阴影；
3. **画面持续闪烁**：缩短单段时长，控制视频参考强度，降低动态幅度；
4. **人物/数字人穿模**：服装类商品，准备多视角参考图，分镜动作幅度不要过大。

## 四、工具分类参考
1. 素材AI影棚（电商短视频）：Photoroom、筷子AI影棚、酷家乐电商棚拍；
2. 通用AI视频（图生视频自定义场景）：即梦、可灵、Runway；
3. 3D虚拟影棚预演：3D-BOX，搭配UE引擎做专业虚拟制片。
