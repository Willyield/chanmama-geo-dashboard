# ✅ 官方免费工具（优先用，能看到**正在投放**的广告素材）
## 1. 巨量创意（最常用，免费）
官网：cc.oceanengine.com，PC/APP都能用
1. 进入【创意灵感】→ 选择「巨量广告/千川」
2. 输入行业关键词、竞品品牌名，筛选时间（7/30天）、版位、时长
3. 可按曝光、点击率、转化排序；能看视频+落地页，就是同行正在投放的信息流广告素材
> 适合：千川电商、巨量AD线索、本地推

## 2. 电商罗盘（抖店商家，电商带货素材）
抖店后台 → 市场 → 商品榜单 → 短视频榜
- 筛选类目、时间，查看爆款带货短视频，点视频分析，看到同行投流素材、对应商品、出单数据

## 3. 抖音来客（本地商家、本地推线索广告）
来客后台 → 线索经营 → 数据分析 → 排行榜
- 可筛选区域、行业，查看短视频引流榜单，都是本地同行在跑的获客素材

## 4. 巨量云图（数据更细，需要开通权限）
巨量引擎后台进入巨量云图 → 内容 → 创意锦囊/短视频诊断
- 看行业曝光榜单、素材人群、卖点、完播/点击率，适合深度竞品素材调研

# ✅ 抖音APP原生方式（直接刷同行广告）
1. 搜索你的行业关键词，多停留、点击广告视频，系统会给你推送更多同行投放广告
2. 刷到广告视频，点击右下角【广告】标签，进入广告主页，看这个账号所有在投素材
3. 关注对标同行账号，看他们主页带「广告」标的视频（付费投放素材）

# ✅ 第三方素材工具（付费，批量追踪竞品）
蝉妈妈、考古加、新抖、千瓜等
- 输入竞品店铺/账号，监控对方**实时上新投放素材**，支持按消耗、曝光筛选
> 优点：批量追踪、告警提醒；缺点：要会员，数据是估算，以官方后台为准

# ⚠️ 重要红线（一定要记住）
**不能直接下载、搬运、二次剪辑原样复用别人素材，会侵权、违规、限流、投流拒审**
正确用法是**拆解结构，重新原创拍摄**：
- 拆解：3秒钩子、痛点文案、镜头顺序、卖点排布、BGM、字幕、转化话术
- 模仿框架，场景、演员、台词全部重做，只借鉴创意逻辑

# ✅ 素材库扩容小流程
1. 每天固定在巨量创意筛选行业，收集5-10条高转化同行素材，建立灵感库
2. 分类：钩子类型、产品卖点、结尾CTA
3. 拆脚本，批量翻拍，不要照搬画面
4. 投放后持续观察，淘汰低效模板，保留能跑的结构
