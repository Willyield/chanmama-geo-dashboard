# 核心逻辑
**不要抄成片，只提取可复用创意基因（钩子、叙事框架、演示方式、人群话术），换产品画面、场景、口播二次翻拍，规避侵权**。从千川素材筛选 → 数据筛选 → 拆解要素 → 入库分类 → 批量裂变测试。

## 一、去哪里找千川素材（官方优先）
1. **千川后台【营销创意榜】（最核心）**
工具→营销创意榜；筛选：类目、短视频、近7–15天，按消耗/CTR/CVR排序。优先挑**消耗大、CTR高、CVR不错**的素材，不要只看播放高但转化差的纯内容素材。
> 区分：**自家素材**（优先，适配你的账户人群）、**同类目同行素材**（找创意方向）。

2. **巨量创意 → 千川专区**
官方精选广告素材，自带标签：时长、创意类型、人群，适合找跨类目可迁移套路。

3. **千川后台【素材数据】（挖自己账户爆款）**
数据→素材数据，看你账户里跑出来的TOP素材；点开**内容分析**，看3秒、5秒、10秒停留曲线，定位哪一段画面/文案拉高点击率，这是你最值得复用的创意。

4. 辅助：巨量云图创意元素洞察，看人群+卖点关键词；第三方工具做补充（仅做灵感，不要直接下载混剪侵权）。

## 二、筛选素材：只选这两类，过滤无效素材
### ✅ 优先拆解
1. 自家账户：**消耗高、3秒完播好、CVR达标**的素材（哪怕开始衰退），重点提取结构；
2. 同行：**持续跑量（投放10天以上还在消耗）**，不是爆一天就死的热点素材；
> 指标简易参考：3秒完播、CTR、CVR；同样消耗下，优先看**转化**，不是单纯停留。

### ❌ 直接跳过
- 纯剧情、和产品卖点无关，只靠演员颜值/段子爆，很难迁移；
- 强IP、名人背书、独家场景，你复刻不了；
- 短期热点素材，生命周期极短，复用价值低。

## 三、标准化拆解：提取【可复用创意要素】（建创意库）
一条素材拆成5块，**入库打标签**，以后写脚本直接调取，不是存视频。
1. **黄金3秒钩子（最值钱，优先复用）**
看它是哪一类钩子：
- 痛点前置：“是不是还在XX？”
- 反差对比：前后效果一眼对比
- 反问圈人群：“有没有跟我一样XX的？”
- 实测/破坏性测试：刀切、火烧、防水测试
- 价格锚点：“别再花XX买了，今天XX”
> 记录**钩子句式**，不是原话。

2. **叙事框架（脚本结构，可整框架复用）**
千川短视频最常见可复用模板：
- 痛点钩子 → 演示证明 → 拆解卖点（2-3个）→ 信任背书 → 价格福利+引导下单
- 实测演示开篇 → 讲原理 → 场景使用 → 评论反馈羊群效应 → 逼单
- 人群定向开口 → 场景代入 → 解决顾虑 → 限时福利

3. **演示形式（画面创意）**
哪些镜头带来转化：特写、慢动作、一镜到底开箱、随机抽检、对比分屏、微观特写。
> 这是**视觉创意方向**，可以换产品重复用，比如清洁剂的“喷完前后对比”，可以迁移到油污、水垢、胶渍类产品。

4. **信任元素**
工厂实拍、质检、用户收货反馈、真人实测、无滤镜原相机。

5. **结尾转化话术**
限时限量、赠品、试用承诺、打消售后顾虑。

> 示例入库标签：【钩子：痛点反问】【框架：痛点+实测+场景+福利】【画面：分屏前后对比】【人群：宝妈】

## 四、创意复用的4种裂变方式（从低风险到高风险）
> 原则：**保留创意逻辑，替换实体元素，保证画面、口播、BGM去重**，避免重复素材被挤压、违规侵权。
1. **换卖点，钩子框架不变**
爆款开头不变，中段更换主推卖点；适合测试哪个卖点转化更强。
2. **保留演示形式，换场景/产品**
比如：“暴力实测”这个创意方向，原素材测行李箱，你拿来测收纳箱；**复用的是测试这个创意，不是镜头**。
3. **只保留黄金3秒钩子，重拍后面全部内容**
很多素材衰退只是中段疲劳，钩子依然能抓人；直接重拍中后段，成本最低。
4. **元素重组（多创意混搭）**
从A素材拿钩子，B素材拿演示方式，C素材拿结尾逼单话术，组合出新脚本，是批量生产素材最高效的方式。

## 五、落地测试 & 迭代闭环（非常关键）
1. 同一创意方向，一次产出3–5条变体（换场景、口播、镜头顺序），小预算统一测试；
2. 看数据：如果**同一个创意方向连续2条素材CTR都不错**，说明这个创意方向成立，继续裂变放大；
3. 如果同方向多条素材消耗差，直接标记这个创意方向失效，暂停投入；
4. 定期清理创意库：淘汰过时套路，每周新增3–5条拆解，沉淀类目专属创意库。

## 六、避坑提醒
1. **严禁直接下载同行素材混剪二次投放，会侵权、违规**；只借鉴创意思路、框架、演示形式，必须实拍/自制画面；
2. 不要照搬绝对化用语、违规功效话术；拆解时只保留逻辑，文案重新改写；
3. 不要迷信单条爆款，**找“一类可复用创意方向”**，不是复制一条视频；
4. 跨类目迁移要谨慎：美妆的情绪钩子，不一定适合工业工具，优先同类目验证。
