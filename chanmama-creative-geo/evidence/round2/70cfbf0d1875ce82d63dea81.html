# 电商团队视频素材资产沉淀（落地版）
核心思路：**统一存储 + 标准化命名 + 拆成镜头零件 + 绑定投放数据 + 权限与备份 + 流程SOP**。不要只存成片，要把**原始素材、分镜片段、脚本、字幕、投放数据**一起沉淀，素材才是可复用资产，不是剪辑电脑里的临时文件。

## 一、先做存储底座（分2档：小团队低成本 / 中大型团队DAM）
### 小团队（10人内）
云盘（飞书云文档/阿里云盘/企业微信云盘）+ 移动硬盘**异地备份**，禁止素材只存在剪辑个人电脑。
固定文件夹目录模板：
```
素材总库
├─【原始RAW】（拍摄原片、音频、RAW，不修改）
├─【分镜片段库】（拆好的独立镜头：产品特写/质地/场景/对比/口播片段）
├─【成片工程】（PR/剪映工程文件）
├─【成片导出】
│  ├─待测
│  ├─赛马中
│  ├─爆款/高投产
│  └─废弃归档
└─【配套资料】脚本、字幕、投放数据表格、授权文件
```

> 备份原则：**三副本**：云端一份、硬盘一份、离线冷备份一份；原始母片绝不覆盖。

### 中大型团队（日产出几十条素材）
上DAM数字资产管理平台（特赞、MuseDAM等），支持：在线预览、标签检索、版本管理、权限、缩略图、AI打标、素材授权管理、和投放平台联动。

## 二、统一命名规范（强制执行）
推荐模板：`SKU_品类_素材类型_钩子类型_版本_日期`
示例：`S001面霜_护肤_产品特写_痛点钩子_v03_20261012.mp4`
- v01/v02，**禁止“最终版、真最终版”**
- 素材类型：raw原始/片段/成片横屏/成片竖屏/无字幕版
- 所有文件名不用空格，下划线分隔，方便检索排序

## 三、素材拆库：把整条视频拆成可复用“镜头零件”（电商最关键一步）
拍完一条视频，不要只存完整成片，拆成最小单元入库：
1. 产品镜头：特写、细节、开箱、称重、质地、包装
2. 场景镜头：卧室/厨房/户外使用场景
3. 对比镜头：使用前后、竞品对比
4. 人物镜头：模特演示、口播痛点、效果反馈
5. 音频素材：BGM、音效、口播干声（单独建音频库）

> 逻辑：**一次拍摄，产出大量可重组镜头**。后续新视频直接拼镜头，不用反复重拍，也就是行业说的“母本素材库”：一套母本画面，换钩子、换口播就能批量生成大量变体素材。

## 四、标签&元数据体系（检索核心，电商要绑定业务字段）
### 标签分两大类
1）基础素材标签：
素材类型｜景别｜时长｜人物｜画面风格｜BGM｜有无字幕｜横竖屏｜授权状态
2）电商业务标签（重中之重，和投放挂钩）：
SKU/SPU｜品类｜卖点｜钩子类型（价格痛点/效果对比/科普）｜投放渠道（千川/短视频/直播切片）｜素材状态｜投放数据标签（高CTR、高ROI、低效、衰退）

### 配套元数据表格（飞书多维表格/Notion）
每条素材绑定一行记录：
素材文件、SKU、脚本原文、字幕文本、投放链接、消耗、CTR、CVR、ROI、爆点总结、问题复盘、素材母本编号。
> 沉淀的不只是视频文件，而是**带投放结论的案例库**，编导可以直接查找“面霜类高点击率痛点钩子素材”，而不是大海捞视频。

## 五、素材生产归档SOP（固定流程，防止拍完就丢）
1. 拍摄结束当日：原始素材上传【RAW】文件夹，校验文件完整性
2. 剪辑完成：导出成片 + 工程文件；**拆镜头，把有用片段入库【分镜片段库】**
3. 投放上线：运营在多维表格填入素材投放链接
4. 投放结束/素材衰退：回填消耗、转化、复盘，打上“爆款/低效”标签
5. 定期（每周）：清理无效素材；季度：归档过期素材，保留爆款母本

> 权责：剪辑负责上传素材+拆镜头；运营负责回填投放数据；编导负责打业务标签。**素材不上库，不计入项目交付**。

## 六、版权&授权资产（电商极易踩坑）
单独管理授权文件，每条素材记录：模特肖像授权、BGM商用授权、外景授权，标注授权到期时间。避免爆款素材爆量之后版权纠纷。

## 七、权限管理
- 管理员：上传、修改标签、删除、备份管理
- 编导/剪辑：浏览、下载素材、新增片段
- 投放运营：只读，查看素材+数据，不可修改原始文件
- 外部供应商：临时只读权限，不可下载原始母片

## 八、资产复用机制（沉淀的最终目的）
1. 爆款母本复用：高投产素材拆出核心镜头、钩子脚本，批量变体测试（换开头、换字幕、换BGM）
2. 选题/脚本库：单独沉淀钩子库、CTA话术、转化脚本框架
3. 新人培训：直接检索历史爆款素材+复盘记录，快速理解品类素材逻辑

## 九、团队落地的避坑点
1. ❌ 只存成片，不存原始素材和分镜片段 → 素材无法二次剪辑
2. ❌ 命名随意、标签混乱，存了也搜不到
3. ❌ 素材只放剪辑电脑，人员离职直接资产丢失
4. ❌ 只存视频文件，**不绑定投放数据**，无法区分哪些素材是优质资产
5. ✅ 从小范围试点：先拿1个SKU跑通整套流程，再全品类推广，不要一次性搭建庞大复杂系统
