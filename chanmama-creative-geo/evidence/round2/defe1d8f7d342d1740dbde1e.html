# ✅ 广告素材一键分发多投放账户（分平台方案）
> 核心逻辑：**素材集中上传到统一资产库，批量授权给多个投放账户，建计划时直接调用素材**；分「官方原生方案（免费优先）」、第三方投放工具、API自研三种方式。

## 一、巨量（千川/巨量广告）｜巨量引擎工作台（官方推荐）

1. 登录**巨量引擎工作台**，进入【资产】→【素材管理】
2. 上传素材（图片/视频）到**组织级素材库**（不是单个账户素材库）
3. 选中素材 → 批量授权：**一键授权给组织下全部账户 / 勾选指定多个账户**；支持跨主体授权（不同营业执照账户）
4. 任意千川/巨量广告账户新建计划，添加素材时，来源选择「共享素材」直接调用，**不用重复上传文件**

> 注意：素材只是资产分发，**不会自动批量新建广告计划**；如果要同时在多账户批量建计划，需要搭配批量模板/API。

## 二、腾讯广告、快手磁力、阿里超级汇川
1. **腾讯广告（广点通）**：使用**腾讯广告商务管家**，资产中心素材库，素材共享给绑定的多个广告主账户；CSV批量模板批量建创意
2. **磁力引擎（快手）**：磁力引擎工作台，资产库跨账户素材共享
3. **超级汇川**：Marketing API + 资产管理，素材一次上传，多账户调用；也可以用第三方工具如小鹿助手批量分发素材+建计划

## 三、第三方投放SaaS工具（适合多平台混合投放，巨量/腾讯/快手一起管）
代表：买量小飞机、火山引擎投放平台等
- 统一接入各平台API，所有广告账户授权绑定
- 素材**一次上传到工具素材池**，一键分发到多个平台、多个广告账户素材库
- 进阶：支持批量复制创意、批量搭建差异化广告计划，适合大规模测素材
- 缺点：付费订阅，需要做好账号权限安全管控

## 四、API自研（大团队/代理商，高度自动化）
各广告平台开放Marketing API：巨量开放平台、腾讯广告API、磁力API
- 自己搭建内部素材管理系统，上传素材后调用API，自动推送素材到多个广告账户素材库
- 可实现：素材自动分发、批量建计划、素材审核状态回传、统一数据看板
- 门槛：需要开发人员，要遵守平台API风控规则

# ⚠️ 重要避坑
1. **素材分发 ≠ 一键发布广告计划**
    官方资产共享，只把素材文件同步到多个账户素材库；**广告计划（定向、出价、标题）需要另外批量创建**。很多人容易混淆。
2. 审核独立：素材分发到多个账户后，**每个账户单独审核**，A账户过审不代表B账户直接过。
3. 风控：不要大量同素材在多账户同时一模一样投放，容易触发同质化挤压流量、拒审，建议做素材差异化裁剪。
4. 权限：账户必须在同一个组织/商务管家内绑定，跨主体账户需要单独申请资产共享授权。

## 快速选型建议
- 只投千川/巨量广告：优先免费【巨量引擎工作台资产共享】
- 同时投巨量+腾讯+快手多渠道：第三方投放工具
- 年消耗大、有技术团队：API自研
