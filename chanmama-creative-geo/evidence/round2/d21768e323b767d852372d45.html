# ✅ 千川PC素材库（创意管理-视频库）
**入口：千川PC后台 → 工具 → 创意管理 → 视频库**
> 这里存放**你本账户上传/创建的自有素材**（不是别人的素材）

## 可以看到哪些素材
- 视频素材、图片素材、图文素材（轮播图）
- 来源：本地上传、即创生成、抖音主页视频授权导入
- 可预览素材、查看素材ID、素材状态（审核通过/审核中/驳回）、素材标签、是否标记【优质素材】

## 投放数据怎么看（素材数据不在视频库，在素材分析）
入口：**数据 → 素材分析 → 视频素材**
可查看单素材投放指标：
展现、点击、点击率、消耗、成交金额、ROI、完播率、转化率等；点击素材「分析」，可看该素材下关联计划的推广明细，优质素材还能查看激励增量数据。

> 简单区分：
> - **视频库（创意管理）：素材仓库，管素材文件本身，基础素材信息，不带完整投放报表**
> - **素材分析：素材投放数据报表，看素材跑量、转化**

# 📌 另外两个相关素材创意入口（看行业爆款参考，不是你账户素材库）
1. **营销创意榜**：千川PC后台 → 工具 → 营销创意榜，看类目爆款素材参考，带行业投放数据参考，**不能直接下载他人素材**
2. **巨量创意官网**：创意灵感 → 千川专区，行业创意榜单，用于找创意灵感，仅参考创意框架

# 📱 移动端（小店随心推）
移动端没有独立完整素材库页面，新建计划添加创意时，可选择账号下已上传/抖音主页视频，素材详细投放数据建议在千川PC素材分析查看。

如果你有操作异常（找不到入口），可以咨询巨量千川官方客服：巨量千川PC端进入 https://qianchuan.jinritemai.com/ 后点击右下角【智投星】；抖音APP端搜索“巨量千川客服”，或通过【我】-右上角【三】-【更多功能】-【小店随心推】-【我的】-【帮助与客服】联系客服。
