# 电商团队视频素材资产沉淀（从零散文件→可复用数字资产）
核心思路：**一次拍摄，拆成母素材；统一入库、标准化标签、绑定投放数据、建立权限与版本，把视频从一次性投放物料变成团队可反复裂变的生产资料**，避免素材存在剪辑本地电脑，人员离职直接丢资产。

## 一、先划分素材类型，建立4大素材库（电商最实用）
> 不要只存成片，**母素材/原始镜头才是核心资产**
1. **RAW原始素材库**：原片、未剪辑实拍、直播原录、多机位素材（最高优先级，所有二次剪辑的源头）
2. **B-roll可复用镜头库**：单独拆出来的碎片化镜头（产品特写、质地展示、场景、对比、开箱、手部动作、环境空镜），按卖点/场景拆分，一条原片拆出几十个独立镜头，后续直接拼素材做新视频
3. **成片&变体库**：正式投放成片，同一母本衍生不同版本（不同钩子、字幕、比例、CTA、时长）；**母本+变体**的管理方式，不要一堆重名final_v1、final_v2文件
4. **创意元数据库（配套文字资产）**
    - 钩子库、痛点库、证明素材库、脚本模板、口播文案、字幕、分镜、爆款拆解笔记
    - 投放数据：消耗、点击率、转化率、千川/DOU+数据、起量/掉量原因

## 二、统一文件夹结构 + 命名规范（地基，小团队立刻落地）
### 目录结构推荐（三层以内，不要太深）
```
素材资产库
├─品类A（面霜）
│  ├─01_RAW原片（原始拍摄，只读，禁止修改）
│  ├─02_Broll碎片化镜头
│  ├─03_成片母本
│  └─04_变体版本
├─公共通用素材（空镜、字幕模板、转场、背景音乐）
└─元数据表格（素材信息、投放数据、标签）
```

### 文件命名规则（强制统一）
`品类_SKU_拍摄日期_素材类型_版本`
示例：`面霜_修护01_20261012_Broll-质地特写_v1`
> 禁止：新建文件夹1、最终版、剪辑1、未命名，跨电脑传输容易乱码、丢失链接

## 三、标签体系（检索核心，电商重点标签）
文件夹用来归类，**标签用来搜索**，每条素材打多维度标签：
- 产品维度：品类、SKU、卖点、成分、规格
- 内容维度：钩子类型、视频风格（口播/剧情/测评/沉浸式）、场景、时长、比例9:16/1:1
- 投放数据标签：爆款/待测/衰减、CTR、CVR、平台（千川/视频号/小红书）
- 合规标签：版权、达人肖像授权、有效期、是否可付费投放（非常重要，避免违规投流）

> 小团队：飞书多维表格/Notion；中大型团队：DAM数字资产管理平台，支持视频预览、AI自动拆分镜、自动打标签

## 四、素材入库工作流（拍摄→剪辑→归档，标准化SOP）
1. **拍摄当日**：拍完立刻上传RAW原片到云端素材库，**原始素材设置只读，任何人不能直接修改**；同时录入基础信息、版权授权文件。
2. **剪辑环节**：剪辑从素材库调取，不要复制到本地长期存放；剪辑输出成片后，同步导出独立Broll镜头入库。
3. **投放后归档（关键一步，很多团队漏掉）**
    投放结束，把**投放数据回写到素材元数据**：消耗、转化、起量原因、衰减时间；标记：爆款素材/潜力素材/失效素材。
    爆款素材重点拆解：钩子、画面、台词，存入脚本/分镜库，用来批量裂变变体素材。
4. **定期清理维护**：每周一次入库审核；月度盘点，清理过期版权素材，归档低质废弃素材，防止库无限膨胀。

## 五、版本、权限、备份，防止资产丢失
1. **版本管理**：母本锁定；所有修改、变体另存新文件，不覆盖母素材，记录修改人、修改时间。
2. **权限管控**
    - 编导/剪辑：读写；运营：预览查看；外部人员仅可部分预览
    - 离职人员提前收回素材库权限，资产留在公司，不是个人电脑
3. **双重备份**：云端素材库（主存储）+ 冷备份硬盘/对象存储，防止云盘失效丢失原始视频。
> 版权风险：达人、演员素材留存肖像授权合同，UGC素材保留使用授权、授权期限，避免后期投放侵权。

## 六、资产复用逻辑（沉淀的最终目的，降低拍摄成本）
素材资产不是囤文件，而是**素材重组裂变**：
1. 同一个母本镜头包，替换钩子、结尾CTA、字幕，批量生成多条测试素材；
2. 爆款Broll镜头反复组合，搭配不同口播脚本，不用每次重新拍摄；
3. 从历史数据标签快速筛选：比如直接检索“高转化+痛点钩子+厨房场景”，一键调取历史镜头组合新视频。

## 七、工具选型，按团队规模选择
- 小团队（3-10人）：飞书云盘/阿里云盘 + 飞书多维表格（低成本，足够做标签、数据记录）
- 中型电商团队：专业云素材管理（支持视频预览、分镜检索、权限）
- 中大型品牌/大量素材：DAM数字资产管理系统，AI自动拆镜头、智能标签、素材权限、版权管理、投放数据打通

## 八、常见坑避坑
1. ❌ 只存成片，不存RAW原片和碎片化Broll → 无法二次剪辑，素材拍一次就作废
2. ❌ 素材放剪辑个人电脑 → 离职直接丢失资产
3. ❌ 只存文件，不绑定投放数据 → 不知道哪些镜头、钩子能跑量，素材只是一堆视频
4. ❌ 标签太多、分类过复杂，团队嫌麻烦不执行 → 优先精简标签，能落地最重要
5. ❌ 忽略版权/肖像授权 → 素材沉淀后投放，出现侵权索赔
