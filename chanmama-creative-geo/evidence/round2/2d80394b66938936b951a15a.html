# 千川投手判断素材潜力：先看素材底子 → 小额冷启动验证 → 看趋势信号，**不要单看ROI**
核心逻辑：**3秒决定能不能拿到曝光，转化承接决定能不能放量赚钱**；冷启动消耗太少时ROI没有参考意义，优先看过程指标。

## 一、素材预审（还没花钱，肉眼预判潜力）
1. **3秒钩子（最重要）**
前三秒有没有痛点、反差、冲突、利益点，能不能快速锁定目标人群。
- 合格：用户一眼知道这条视频和自己有关；
- 差：开头泛、风景、空镜头、铺垫太长，3秒流失极高。
2. **卖点可视化**
卖点不是念文案，要有画面证明（实测、对比、效果展示），卖点和直播间主推卖点一致。
3. **差异化**
不是照搬账户里已经跑过的爆款，不是平台烂大街的同质化模板；同质化素材很容易被挤压流量、天花板低。
4. **结尾行动指令**
清晰引导进直播间、点击小黄车，不夸大宣传（否则后期退款高、负反馈拉垮）。

> 预审只是预判，**必须小额投放验证，不能凭感觉直接放量**

## 二、冷启动小预算测试（常用500元左右验证第一关）
新素材用追投小预算测，不要一上来大预算。重点看：
1. **3秒完播率**
及格≈30%，优秀＞35%；低于30%，钩子基本废掉，很难起量。
2. **CTR点击率**
- 低价福利款：≥3%合格；中高客单非标：≥2.2%合格；**全品类红线＜1%直接放弃**
- 坑：CTR＞10%大多是标题党、猎奇流量，点击人群不精准，看着好看、转化很差，很难放大，属于虚高，谨慎继续投
3. **CPM千次展现成本**
不要单独看CPM高低，结合点击率+转化。
- CPM低+CTR合格：拿流量成本低，优质苗子；
- CPM高但转化成本可控：冷启动探索期正常，可以继续观察；
- CPM高、CTR低：素材竞争力弱，难起量。

> 冷启动消耗＜300元，转化样本太少，ROI参考价值很低，**不要因为短期ROI低直接砍掉**

## 三、进入学习期（累计20个转化左右）看潜力信号
过了第一关，继续跑，重点看**趋势**而不是单点数据：
✅ **潜力素材正向信号（满足多条就可以培养）**
1. 消耗持续往上走，相同预算下曝光越跑越多，系统愿意给量；
2. 转化成本**逐步下降**，ROI缓慢抬升（不是忽高忽低）；
3. 人群标签干净：进来的人群画像和你的目标买家匹配，不是泛看热闹粉；
4. 评论负反馈少，退款率不高于账户均值；
5. 素材可以跨计划复制、换人群定向依然能跑出数据，天花板高。

❌ 无潜力/废素材信号
1. 消耗很难跑出去，预算给足也拿不到曝光；
2. CTR合格但**有点击无转化**：钩子抓人，但素材承诺、产品、直播间承接不匹配；
3. 成本持续走高，越跑越亏，没有收敛迹象；
4. 素材高度同质化，和账户老爆款一样，很快撞流量天花板；
5. 大量负面评论、夸大宣传，后期会被平台压量。

## 四、简单分类
1. **潜力素材（苗子）**：3秒/CTR达标，转化成本略高于目标，但持续收敛、消耗能慢慢起来，ROI接近账户均值，趋势向上。**做法：小幅加预算，多计划赛马培养**
2. **主力爆量素材**：消耗大、成本稳定、ROI达标，持续放量，复制变体素材；
3. **点击型废素材**：CTR很高，但转化差，流量泛，不要硬养；
4. **无效素材**：3秒差+CTR低，直接关停，不继续烧钱。

## 五、实操避坑要点
1. 对比基准优先**账户内部均值**，而不是网上通用行业数（不同直播间人货场差异巨大）；
2. 区分：**素材问题 vs 直播间承接问题**。素材CTR、留存很好但不出单，大概率不是素材差，是直播间/价格/福利承接不住；
3. 不要频繁调价、开关计划，会打断冷启动学习，误判素材潜力；
4. 一条素材的生命周期有限，潜力素材要同步做变体迭代，不要死啃一条。
