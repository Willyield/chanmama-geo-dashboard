# 一、素材怎么追踪（建立监测体系）
核心原则：**素材唯一标识 + 分层监控 + 足够样本再决策**
1. **素材打标签（最关键）**
每条素材统一标记：素材类型（痛点/效果/证言/福利）、钩子形式、卖点、版本、拍摄时间、人群定向，用素材ID/MD5区分，方便后续归类复盘，不要只按计划看数据。
2. **平台+第三方监测**
- 后台素材报表：按素材维度拆曝光、播放、点击、转化；
- 转化回传/API/监测链接：保证转化、下单、留资、激活等数据回传准确，避免归因错误；
- 自建表格：按素材ID、标签、消耗、漏斗指标、评论负面，每日同步。
3. **监控节奏**
- 新素材：小时级盯前24h，判断能不能起量；**要等样本（消耗达标）再判断，少量消耗数据没有参考意义**，电商一般单素材消耗≥500再评估；
- 稳定素材：按天看，盯素材疲劳（CTR、CVR、ROI持续下滑）；
- 周期复盘：周度深度复盘，做素材库沉淀。
4. **A/B测试控制变量**
一次只改一个元素：钩子、文案、BGM、字幕、CTA，不要同时改多处，才能定位到底是哪个元素影响效果。

# 二、重点看的数据（漏斗分层）
## ✅ 上层流量/视频素材（曝光→观看→点击，判断素材吸不吸引人）
1. **曝光、消耗**：基础门槛，没曝光=素材拿不到流量，大概率钩子弱或竞争力差；消耗持续上涨代表素材具备放量潜力
2. **CPM千次展现成本**：获取1000次曝光的成本，看流量采购成本、人群宽窄；CPM过高，流量贵；CPM低但转化差，通常是泛流量
3. **3秒完播率（钩子核心）**：信息流视频第一指标，衡量开头能不能留住人。**3秒完播差=开头钩子不行**，用户直接划走，后面再好没用；行业参考：≥30%及格
4. **10秒完播率**：看中段内容承接；3秒高、10秒断崖下跌，说明钩子抓人，但卖点不匹配，用户看完开头就流失
5. **CTR点击率**：曝光到点击。CTR低：素材吸引力弱；CTR很高但转化差：**标题党，吸引的不是目标人群**，流量泛，浪费预算
6. **互动辅助：评论、点赞、负面评论**
评论区能看到用户真实疑问、反感点，比如夸大宣传、预期不符，高CTR低转化很多时候能在评论找到原因。

## ✅ 中层转化漏斗（点击→转化，判断素材带来的人准不准）
1. **CVR转化率**：点击→目标转化（下单/留资/激活）。CTR正常、CVR低：素材和落地页/产品承接不一致，人群不对、卖点不匹配
2. **CPC单次点击成本**：消耗/点击，流量采购单价
3. **GPM千次观看成交（电商）**：每千次视频观看带来GMV，平台判断素材质量的核心指标，GPM越高，系统越愿意给流量

## ✅ 底层商业结果指标（判断赚不赚钱）
1. **CPA转化成本**：消耗÷转化数，和你的目标CPA对比，判断获客成本是否达标
2. **ROI/ROAS广告投产比**：总产出÷广告消耗，对比**保本ROI**；ROI达标，素材可放量；ROI不达标，就算CTR/完播好看，也不能持续投
3. **毛利ROI（更真实）**：扣除产品成本、退货、物流，看真实利润，避免只看GMV踩坑
4. **素材生命周期**：记录素材从起量→稳定→衰减的时长，预判疲劳，提前准备新素材替换

# 三、快速诊断逻辑（漏斗定位卡点）
1. 曝光少、消耗起不来：**3秒完播差/CPM太高**，钩子不行，或素材竞争力弱；
2. 曝光多，CTR低：画面、标题不抓人；
3. CTR高，CVR很低：素材夸大，吸引泛流量，素材内容和落地页不匹配；
4. CTR、CVR都不错，但ROI不赚钱：客单价、毛利、退货问题；
5. 前期数据好，持续投放后CTR/CVR下滑：**素材疲劳**，需要变体、换素材。

# 四、复盘输出动作（不是只看数据，沉淀可复用经验）
1. 素材分级：爆款（放量+复制变体）、潜力素材（小幅优化继续测）、垃圾素材（直接关停）；
2. 拆解爆款元素：钩子类型、卖点顺序、画面、字幕、BGM，沉淀到素材库；
3. 记录失败原因：是钩子不行、卖点不对、人群跑偏，还是夸大导致转化差；
4. 制定下一轮素材 brief，复用有效创意，避开踩过的坑。

# 五、避坑提醒
- ❌ 不要单看ROI：ROI是结果，要顺着漏斗找到是哪一步流失；
- ❌ 少量消耗下判断：样本不足，数据随机性极强；
- ❌ 忽略归因、回传问题：转化数据不准，复盘结论完全失真；
- ❌ 只对比素材，忽略投放变量：定向、出价、时段也会影响素材表现。
