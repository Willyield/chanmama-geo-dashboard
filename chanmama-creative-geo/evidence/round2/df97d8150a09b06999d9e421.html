# 电商团队视频素材资产沉淀（核心一句话：**不要只存成片，要存原素材+分镜零件+投放数据，标准化归档+标签检索，把一次性视频变成可反复裂变的资产**）
## 一、先做素材分层：四类资产分开存
> 电商素材最大误区：只存发布后的MP4成片，原始素材、工程文件丢在剪辑电脑，人员离职资产直接流失
1. **原始母素材（底层资产，最重要）**
    拍摄RAW原片、直播回放、产品特写、质地镜头、场景空镜、口播原素材、BGM/字体/LOGO源文件。**这是可无限二次剪辑的零件**。
2. **工程源文件**
    PR/剪映工程、项目工程文件，方便后续改钩子、换字幕、裁剪尺寸。
3. **成片+变体**
    同母本衍生多条变体（不同钩子、不同时长、不同平台比例：9:16/1:1/16:9）
4. **配套数据资产（电商独有）**
    脚本、口播文案、字幕、投放数据（消耗、点击率、转化、ROI）、爆款原因拆解、平台、SKU、投放状态。

## 二、统一目录结构 + 命名规范（直接落地）
### 推荐文件夹结构（按SKU/产品维度）
```
【品牌】-【SKU名称】
├─01_RAW原素材（拍摄原片、直播回放）
├─02_BROLL可复用镜头（拆好的零件：产品特写、对比、使用场景）
├─03_Project工程文件
├─04_Export成片
│  ├─待测
│  ├─投放中
│  ├─爆款/优质归档
│  └─淘汰
├─05_Docs配套文档（脚本、口播、投放数据、拆解报告）
└─06_Archive历史归档（下架、旧版素材）
```

### 文件命名规则（固定模板，方便检索排序）
`YYYYMMDD_SKU_素材类型_钩子类型_版本Vxx_平台`
示例：`20260910_修护面霜_特写镜头_质地展示_V01_千川`
> 禁止命名：final、最终版、新版.mp4，避免版本混乱

## 三、素材拆解+多维标签（让素材可检索、可复用）
拍完/剪完一条视频，**拆成最小镜头单元，而不是整条视频**，这是电商素材裂变的关键
### 标签体系（分基础标签 + 电商业务标签，放在多维表格/素材库）
- 基础标签：镜头类型（特写/中景/第一视角）、时长、画面风格、人物/无人物、比例
- 电商业务标签：SKU、品类、卖点（保湿/抗皱）、钩子类型（痛点/效果对比/价格）、视频类型（口播/沉浸式/剧情/UGC）、投放渠道（千川/短视频/小红书）、投放结果（爆款/有效/低效）、母本编号

> 母本概念：同一套拍摄骨架（场景+产品）=1个母本；基于母本改钩子、改文案生成多条变体，全部关联回母本，方便批量复用

### 配套台账（飞书多维表格/Notion/简道云）
每条素材一条记录：素材链接、文件地址、SKU、标签、脚本、消耗、CTR、转化、复盘结论。
**核心：把素材和投放数据绑定，不是单纯存视频文件。**

## 四、存储、备份与权限（防止丢素材）
1. **存储架构**
    - 共享云端素材库（主库，团队统一访问：可选用企业网盘、专业DAM数字资产管理系统）
    - 本地高速盘：剪辑临时工程
    - 异地备份：重要原始素材做双备份（云+独立硬盘），防止硬盘损坏
2. **权限管理**
    - 编导/剪辑：上传、编辑、打标签
    - 投放：只读，查看素材+数据
    - 新人：只读，学习爆款素材
3. **版权合规标记**
    UGC素材、达人素材、背景音乐，必须标注授权范围、使用期限，避免侵权风险。

## 五、全流程SOP：拍摄→剪辑→归档→复用闭环
1. **拍摄前**：确认素材采集清单，固定拍摄BROLL镜头库（产品特写、细节、对比镜头，每次拍摄统一拍一套通用镜头）
2. **剪辑完成后（24小时内必须归档）**
    - 上传原素材、工程、成片到共享库
    - 拆分BROLL可复用镜头，打上标签
    - 多维表格录入素材信息+投放链接
3. **投放结束后复盘**
    按ROI标记素材等级：爆款/有效/低效；写简短拆解：爆点在哪，哪些镜头、钩子可以复用；低效素材标注问题，沉淀避坑经验
4. **定期维护**
    - 每周：素材入库、状态更新（待测→投放→爆款/淘汰）
    - 每月：素材盘点，清理无效素材、检查备份
    - 每季度：提炼爆款母本模板，用于下一轮拍摄脚本参考

## 六、工具选型（按团队规模）
- 小团队（≤5人）：企业网盘 + 飞书多维表格/石墨表格，低成本落地
- 中型团队（5–20人）：专业DAM素材管理工具，支持视频预览、标签检索、权限管理
- 投流大团队：电商素材资产管理平台，自动关联千川/抖店投放数据，AI打标签

## 七、常见坑
1. ❌ 素材存剪辑个人电脑，人离职直接丢失 → ✅ 规定所有素材必须进共享库才算交付
2. ❌ 只存成片，不拆镜头、不存原素材 → ✅ 强制拆BROLL镜头库
3. ❌ 只存视频，不绑定投放数据，不知道素材好坏 → ✅ 素材资产必须带数据标签
4. ❌ 标签太多、太复杂，团队不愿意填写 → ✅ 精简标签，3~8个核心标签即可，优先自动化

## 八、最小落地启动方案（立刻就能做）
1. 先定文件夹结构+命名规则文档
2. 建一张多维表格，先把历史爆款素材批量入库打标签
3. 规定：**新素材上线必须入库归档，否则不允许投放**
4. 指定1名素材管理员（编导/运营兼职），负责每周审核素材入库质量
