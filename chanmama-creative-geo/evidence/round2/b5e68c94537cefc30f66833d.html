# 蝉妈妈创意：发现千川隐藏素材 + 素材异动提醒
> 千川隐藏素材 = 商家**本地上传千川投放**，不发布到抖音主页，主页看不到，只有付费广告曝光的素材。
> 核心模块：**素材追踪（盯竞对）**抓隐藏素材；**爆量监测**做异动告警。

## ✅ 一、怎么发现千川隐藏素材（素材追踪/盯竞对）
1. 登录蝉妈妈创意，进入 **灵感中心 → 素材追踪（盯竞对）**
2. 添加监控对象：**竞品抖音号 / 抖店店铺ID / 品牌关键词**
3. 保存监控任务，系统**约30分钟**轮询抓取广告曝光素材，即使主页作品为0，也能抓到千川本地上传隐藏素材
4. 查看：进入该竞品详情页，切换【千川投放素材】标签，就能看到所有捕捉到的隐藏素材，附带投放天数、跑量分、预估消耗、完播等数据
5. 补充大盘挖掘：灵感中心【找素材】，筛选广告素材、高增量素材榜，按类目、商品检索全网隐藏跑量素材，不用只盯单个竞品

> 原理：蝉妈妈创意采集全网广告曝光的视频信号，**不是读取千川后台**，是通过广告曝光链路识别付费投放素材，所以能抓到主页不公开的本地上传素材。
> 注意：该功能需要蝉妈妈创意会员权限。

## ✅ 二、素材异动/爆量提醒怎么设置（爆量监测）
1. 创意 → 灵感中心 → **爆量监测**
2. 添加监控对象：可以直接导入上面素材追踪里的竞品账号、小店，或者添加商品关键词、类目词
3. **自定义异动阈值**（关键）
    - 可选：跑量分飙升、预估消耗上涨、播放增量、素材上新（新增素材提醒）
    - 例：设置“素材近24小时跑量分上涨＞XX”就触发告警
4. **开启推送渠道**：钉钉、飞书、企业微信，告警消息直接推送到群/个人消息
5. 收到提醒：消息自带素材卡片，点进去直接看视频+AI智能拉片，拆解脚本、黄金3秒、卖点结构

## ✅ 三、推荐搭配使用流程（实战闭环）
1. 素材追踪：批量添加竞品小店/账号，持续抓取**新上隐藏千川素材**，上新即提醒
2. 爆量监测：对这批竞品设置跑量异动阈值，一旦素材突然起量爆量，触发IM告警
3. 收到告警 → AI拉片拆解创意 → 分析卖点、脚本、人群，快速仿写迭代
4. 定期在灵感中心高增量素材榜，补充行业大盘黑马隐藏素材

## ⚠️ 限制与注意
1. 不是100%全部素材都能捕获：素材投放曝光量极低、展示频次太少，无法被采集到；
2. 数据为第三方预估数据，**不等于巨量千川后台真实消耗**，只用于竞品创意参考；
3. 素材版权：抓取的素材仅用于创意分析参考，不要直接搬运二次投放，避免侵权违规；
4. 素材追踪和爆量监测属于蝉妈妈创意增值功能，免费版权限有限。
