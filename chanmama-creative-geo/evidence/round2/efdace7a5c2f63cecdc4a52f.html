# 一句话总结
**巨量千川素材库（官方）：管自己账户素材管理+投放真实数据，少量官方行业创意参考；第三方素材洞察工具（蝉妈妈/有米有数等）：看全平台同行/竞品千川跑量素材，做竞品素材调研，但数据是估算，不能用来直接投放**

## 一、巨量千川素材库（千川后台素材管理+营销创意榜）
### 核心定位
**自家素材的存储、管理、投放数据看板，官方原生**
1. **数据范围**：优先看**你自己账户上传的素材**，消耗、CTR、CVR、ROI、素材生命周期都是**平台真实原生数据**，分钟级更新，最准
    营销创意榜/巨量创意（官方创意灵感）可以看行业优质广告素材，但开放的维度有限，不会展示竞品完整消耗、真实ROI。
2. **用途**：上传素材、广审预检、素材打标签、清理低效素材、看自家素材衰减，**素材直接在这里创建广告计划投放**
3. **优点**
    ✅ 数据真实、权威，和千川投放打通，支持素材预审、首发素材识别
    ✅ 免费，千川开户就能用
    ✅ 可以判断自家素材衰退、复用优质素材
4. **缺点**
    ❗**不能深挖竞品完整投放数据**，看不到竞品每条素材真实花费、投产
    ❗竞品素材筛选、拆解、脚本提取能力弱

## 二、第三方素材洞察工具（蝉妈妈、有米有数、新抖等）
### 核心定位
**竞品广告素材爬虫洞察工具，主打行业/竞品调研**
1. **数据范围**：抓取全网公开千川广告素材，**跨品牌、跨单品、跨类目筛选同行在投素材**；消耗、ROI、投放趋势属于**估算值，非平台原生真实数据**
2. **用途**：找同行爆款素材、拆解脚本、分析卖点/钩子/场景、监控竞品上新素材、看单品素材矩阵
3. **优点**
    ✅ 竞品素材检索能力极强：按商品、品牌、类目、时长、发布时间筛选
    ✅ 附带AI拆解：提取台词、钩子、卖点、分镜，批量导出素材灵感
    ✅ 可监控竞品素材上新、起量趋势
4. **缺点**
    ❗数据是估算，和千川后台真实消耗有误差
    ❗**不能直接上传素材投千川**，只是调研参考
    ❗大多需要付费会员
    ❗存在素材收录延迟、部分素材抓取不到

# 对比简表
|维度|巨量千川素材库（官方）|第三方素材洞察工具|
| ---- | ---- | ---- |
|核心对象|**自己账户素材为主**|**全网竞品广告素材**|
|数据真实性|平台真实投放数据|爬虫估算数据，仅参考|
|核心能力|素材存储、管理、投放、素材诊断、广审预审|竞品素材检索、脚本拆解、卖点分析、监控竞品|
|能否直接投放素材|✅可以，千川广告直接选用|❌仅看素材，无法投放|
|费用|免费|大多付费订阅|
|局限|竞品数据开放有限|数据有误差，不能作为真实投产依据|

# 搭配使用建议
1. **第三方工具**：前期找灵感，看同行素材结构、钩子、卖点，做素材脚本方向
2. **千川官方素材库**：素材制作完成后上传、预审、投放，看真实CTR/ROI，判断素材好坏、淘汰衰退素材

> ⚠️注意：不管第三方看到多少同行素材，**不要直接搬运素材**，平台有素材指纹/首发素材机制，容易限流、审核驳回。只能借鉴结构和卖点思路。
