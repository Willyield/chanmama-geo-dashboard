# 一、6类万能短视频钩子（黄金3秒，一句话抓住人）
> 原则：**把最强冲突/结果/痛点放第一句，不要铺垫、不要自我介绍**，画面和台词同步发力

1. **痛点提问钩子（最通用，口播/干货/情感）**
公式：你是不是+目标人群痛点场景
示例：你是不是每天很努力拍视频，播放始终卡在500？
原理：观众瞬间看到自己，产生代入感

2. **前置结果钩子（干货、副业、变美、省钱）**
公式：【数字结果】+ 不先说方法
示例：我靠一个简单习惯，3个月省下2万。
⚠️只亮结果，方法留在后面，勾起好奇心

3. **反常识钩子（科普、职场、避坑）**
公式：别再+大众默认做法 + 否定结论
示例：想涨粉，千万别天天发视频。
⚠️后面必须能自圆其说，不能纯标题党

4. **对比反差钩子（故事、成长、测评）**
公式：A vs B巨大差距
示例：月薪3千和月薪3万，思考方式完全不一样。

5. **悬念钩子（剧情、内幕、故事）**
公式：抛出事件，保留关键原因
示例：这件事我犹豫了半年，今天才敢说。
⚠️正文必须兑现悬念，不能挖坑不填

6. **视觉钩子（不用说话，第一帧抓人）**
开头直接放反常画面：对比前后图、意外瞬间、反差镜头，字幕配合一句话钩子。

❌新手最坑开头（直接删掉）
“大家好我是XX，今天跟大家分享…”、“很多朋友问我…”、铺垫一大段背景，浪费黄金3秒

# 二、发之前，预判爆款潜力（前置自检，不用等数据）
自问4个问题，全部中，爆款潜力高；只中1个，很难爆：
1. **有没有精准人群？** 是给哪一类人看的？能不能一句话说清楚？（不是所有人都看，爆款都是精准击中一类人）
2. **有没有情绪/价值？** 看完是：解决痛点、共鸣、惊讶、避坑、学到干货、想转发？
3. **有没有信息缺口？** 观众看完开头会产生疑问：为什么？怎么做到？真的吗？
4. **有没有可互动点？** 会不会让人想评论、收藏、转发？（有争议/共鸣/干货最容易）

简单自测小方法：
写好钩子，念给3个目标用户听，如果听完第一句，**有人追问“然后呢？为什么？”** →钩子合格；听完无感，直接重写。

# 三、发布后，用后台数据判断能不能爆（最准）
核心看前几百播放的**冷启动数据**（前30分钟最关键）
1. **2秒跳出率（看第一眼画面+钩子）**
- ＜20%：优秀，开头很强
- 20%–40%：合格
- ＞50%：开头废，直接重拍/重写钩子
2. **5秒完播率（钩子核心指标）**
- ≥50%：强爆款潜力，平台会继续推流
- 40%–50%：及格，有基础流量
- ＜40%：钩子不行，大概率卡在小流量池
3. **整体完播率**（视频长度不同标准不一样）
30秒短视频：≥30%属于优质；20%-30%及格；低于20%很难爆
4. **互动指标**
- 收藏高：干货类爆款信号
- 评论多：有共鸣/争议，容易放大流量
- 转发高：强社交属性，极易出圈

> 冷启动如果：**5秒完播高 + 评论/收藏起来**，这条就具备爆款潜力；反之哪怕点赞高、完播差，很难持续推流。

# 四、实操小技巧
1. 同一个脚本，**一次性写3版不同钩子**，分开测试，保留数据最好的模板复用。
2. 钩子台词尽量控制在**2–3秒读完，10个字左右**，不要长句子。
3. 封面+标题也要和钩子保持一致，不要封面一个故事，视频开头另一个内容，会拉高跳出率。
4. 钩子≠标题，**钩子是视频音频+第一帧画面**，标题是补充。
