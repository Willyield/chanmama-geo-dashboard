# ✅ 千川投放前找同行跑量素材（官方免费优先，第三方付费补充）
> 核心原则：**优先看消耗/转化，不要只看点赞；找到是用来拆解脚本、结构、卖点，严禁直接搬运抄袭，会侵权+违规**

## 一、官方免费工具（首选，数据最准）
### 1. 巨量创意（最常用，广告素材库）
入口：巨量创意官网 → 创意灵感 → 巨量千川专区
- 筛选：类目、关键词、时间（优先**7天**，时效性强），按CTR、CVR排序
- 重点：筛选「广告素材」，能看到同行正在投放的短视频/图文素材，可直接看视频、落地页、卖点，适合快速找脚本模板

### 2. 千川后台【营销创意榜】
千川PC后台 → 工具 → 营销创意榜
- 选商品视频/直播间引流素材，输入产品词，筛选7~15天，按消耗、转化排序，直接看赛道内跑量素材，是千川原生广告素材池

### 3. 抖店电商罗盘
抖店后台 → 电商罗盘 → 商品 → 商品榜单 → 短视频榜
- 筛选类目、时间，看同行爆款带货短视频，可对标同价位竞品店铺素材，看商品卡+短视频引流素材

### 4. 巨量云图（品牌/有云图权限商家）
内容 → 带货短视频诊断 / 内容创意锦囊
- 看行业高转化素材、同行集中打的卖点、拍摄形式（口播/对比/场景），可以看到素材的创意元素洞察，适合做卖点拆解，门槛高需要开通权限

### 5. 抖音APP人工刷广告（低成本查漏）
抖音搜索产品词、痛点词，**视频左下角带「广告」标识**，才是千川付费素材（不带广告是自然流，不要混淆）。
- 长按广告视频，点「不感兴趣/隐藏广告」之外，持续刷同类广告，积累最新起量素材；适合抓刚起量、工具还没收录的新素材

## 二、第三方付费工具（适合深度监控竞品）
蝉妈妈创意、有米云、考古加等
优势：
1. 可以**添加竞品店铺/品牌，定向追踪该店铺所有千川跑量素材**
2. 支持按预估消耗、销售额、订单量筛选，还能导出素材清单、脚本
3. 素材更新快，能抓到很多官方工具不好检索的竞品素材
缺点：需要付费，数据是**估算值，不是平台真实后台数据**，仅做参考

## 三、筛选标准：怎么判断是不是真·跑量素材
❌ 不要看：点赞、评论、粉丝量（自然流数据，千川不看这个）
✅ 重点指标：
1. 时间：优先**近7天**，素材生命周期短，超过30天大多衰退
2. 指标：预估消耗高、高3s完播、高CTR、高CVR、有稳定出单
3. 形式：优先看**同客单价、同人群**竞品；不要跨价位乱对标
4. 稳定性：素材连续多天在投，不是只跑1天就停（一天爆的偶然性大）

## 四、找到素材之后：正确拆解（重点！）
1. 拆解前三秒钩子：痛点提问、对比反差、结果前置（千川素材成败核心）
2. 拆解脚本结构：钩子→痛点放大→产品展示→卖点证明→信任背书→行动指令
3. 拆解拍摄形式：口播/产品特写/前后对比/场景情景剧、字幕排版、BGM
4. 拆解卖点：同行集中打哪2~3个核心卖点，避开已经内卷严重的方向，做差异化

> ⚠️法律&投放红线：**不能直接下载、二次剪辑搬运同行原视频**，会侵犯著作权，千川审核会拒审、限流甚至处罚账号；正确做法是学习脚本框架，**重新实拍原创素材**

## 五、快速工作流（投放前素材调研SOP）
1. 确定对标竞品：3~5家同品类、同客单、千川稳定投放店铺
2. 巨量创意+千川营销创意榜，批量导出7天内跑量素材清单
3. 第三方工具（可选）定向监控竞品店铺，补充素材
4. 抖音APP刷广告，抓最新刚起量素材
5. 汇总拆解钩子、脚本、卖点，整理成自己的素材拍摄脚本池，开拍
