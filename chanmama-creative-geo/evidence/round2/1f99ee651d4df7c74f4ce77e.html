# ✅ 蝉妈妈创意：发现千川隐藏素材 + 素材异动提醒完整操作
> 千川隐藏素材：商家在千川直接上传投放、**不发布到抖音主页**的广告视频，抖音主页看不到，普通刷视频刷不到，只能靠第三方素材爬虫捕获

## 一、发现千川隐藏素材（素材追踪 / 盯竞对）
### 方式1：素材追踪（推荐，自动捕捉新隐藏素材）
1. 登录蝉妈妈创意（cy.chanmama.com），进入 **素材追踪（盯竞对）** 模块
2. 添加监控对象：**竞品抖音号 / 小店ID / 品牌关键词**
3. 保存监控任务，系统**约30分钟抓取一次**，自动抓到竞品新上的千川隐藏素材（主页不显示的投流视频）
4. 在监控列表里，进入竞品详情页，切换【千川投放素材】标签，就能看到全部素材，包含隐藏素材、投放时长、跑量分、消耗趋势
5. 素材详情页支持AI智能拉片，拆解脚本、黄金3秒、完播、转化相关数据

### 方式2：灵感中心｜找素材（批量检索行业隐藏素材）
1. 创意 → **灵感中心 / 找素材**
2. 筛选：广告素材、类目、投放时间、跑量分、视频比例
3. 榜单：竞品投放榜、跑量素材榜、高增量素材榜，这里会收录大量千川隐藏投放素材，不用逐个加账号监控，适合大盘扫素材

> 注意：素材追踪/隐藏素材功能需要蝉妈妈创意会员权限

## 二、素材异动提醒（爆量监测，设置阈值自动告警）
作用：监控素材消耗、跑量分、流量增速异动（素材突然爆量/掉量），触发条件自动推送通知
1. 蝉妈妈创意 → **爆量监测**
2. 新建监测任务：添加竞品账号/小店/商品关键词
3. **自定义异动阈值**（核心）：
    - 跑量分突增、24h消耗增量、素材新增数量、播放增速等
    - 例：设置「素材24小时跑量分上涨>200」触发告警
4. 开启消息推送通道：**钉钉 / 飞书 / 企业微信 / 站内消息**，绑定接收群/人
5. 保存任务，7×24小时自动巡检；一旦素材触发阈值，直接推送异动提醒，附带素材链接，点进去看视频+数据拆解

## 三、两个功能的区别
- **素材追踪（盯竞对）**：抓【**新上线隐藏素材**】，竞品新投视频，侧重发现素材本身
- **爆量监测**：抓【**已有素材数据异动**】，素材跑量突然暴涨/衰减，侧重数据波动预警

## 四、实操小技巧
1. 优先盯核心竞品小店，比单纯盯抖音号捕获隐藏素材更全；很多商家用小店投放，抖音账号主页不放视频
2. 素材抓到后，可以用AI拉片快速拆解卖点、文案结构，做创意参考
3. 阈值不要设置太灵敏，否则告警消息刷屏；重点监控高消耗品类竞品
4. 数据为第三方爬虫估算数据，仅作为创意参考，不能等同于千川后台真实消耗
