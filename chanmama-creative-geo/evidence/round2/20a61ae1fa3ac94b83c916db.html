# 核心思路：AI做「粗剪批量初稿」，人工做「决策+精修+品控+模板迭代」
一句话分工：**AI负责80%机械重复工作（拼接、字幕、配音、BGM、多版本裂变）；人工抓20%决定转化的关键部分（3秒钩子、卖点逻辑、产品准确性、节奏、品牌规范）**。不要指望AI直接出可投放爆款成片，它是高效初稿生成器。

## 一、分层使用：两类素材，不同搭配策略
### 1）铺量测试素材（信息流测款、长尾SKU、大促素材填充）——AI为主，人工轻审
适合：快速批量产出几十条变体，小预算测点击率、钩子、卖点。
流程：
1. 人工前置：建好标准化素材库+固定脚本模板（痛点开场/效果对比/卖点罗列，2~3套经过数据验证的脚本框架），准备实拍产品主图、细节图、实拍演示片段、卖点文案库。
> 重点：**产品主体必须实拍，AI只用来做氛围、转场B-roll，避免AI生成产品变形、颜色错误引发售后**
2. AI一键成片：批量导入素材+脚本模板，自动生成多版本变体（换字幕、换BGM、换镜头顺序、换配音），快速出初稿。
3. 人工快速审核（30秒/条）：只查4件事
    - 产品外观、颜色、logo有没有出错
    - 字幕错别字、口播有没有违规/夸大词
    - 前3秒钩子是否通顺
    - 有没有硬伤穿帮
4. 轻微微调：只修改问题片段，不重剪整条；合格直接导出投放测试。

> 价值：单条制作时间从几十分钟压缩到几分钟，一天批量几十条素材用于测款。

### 2）精品爆款素材（高预算主力计划、首页/详情页主视频、品牌片）——人工为主，AI辅助
适合：已经测出数据不错的方向，做高转化精品视频。
流程：
1. 人工写脚本、规划分镜、实拍核心演示片段、真人出镜片段。
2. AI辅助：长素材智能粗剪、自动字幕、提取高光片段、生成过渡B-roll、多语言配音、自动调色打底。
3. 人工深度精剪：重新调整叙事节奏、卡点、替换弱钩子、优化转场、统一品牌包装、调色、添加特效，打磨完播与转化。
4. AI二次裂变：精品定稿后，AI基于这条精品工程，批量改版本，继续铺量。

## 二、标准流水线（推荐团队落地）
**前置准备（一次性投入，长期复用）**
1. 素材库分类：产品实拍、细节特写、效果对比、氛围B-roll、品牌包装模板（角标、字幕样式、片尾CTA）
2. 脚本模板库：沉淀2-3套高转化脚本结构，固定变量：产品名、痛点、卖点、信任状、行动引导。不要每次从零写脚本
3. 审核SOP清单，统一质检标准，减少反复沟通。

**流水线：**
1. 人工 → 定义需求：选SKU、选脚本模板、选定卖点
2. AI一键成片 → 批量生成初稿（一次产出3~5个版本）
3. 初审（剪辑/运营）：快速筛掉严重错误，保留可用初稿
4. 人工精修分级：
    - 普通铺量素材：轻度修改，修复硬伤，直接出片
    - 潜力素材：深度剪辑，优化节奏、钩子、卖点表达
5. 投放测试，回收数据（CTR、完播、转化率）
6. 人工复盘：把跑爆的脚本/镜头结构，更新进AI模板库，持续提升下一轮AI初稿质量（闭环）

## 三、分工边界（避免踩坑）
✅ AI适合交给它：
- 长实拍素材自动粗剪、自动字幕、识别高光片段
- 批量生成同脚本多变体、换BGM、换配音、换画面顺序
- 生成氛围背景、转场素材、数字人口播
- 自动适配多平台尺寸9:16/1:1/16:9

✅ 人工必须把控：
- 脚本逻辑、黄金3秒钩子、核心卖点表达
- 产品真实性、合规（极限词、功效承诺）
- 镜头叙事节奏、情绪、品牌视觉规范
- 数据判断，筛选爆款方向，迭代模板

❌ 不要：全部丢给AI直接投放，极易出现产品失真、夸大宣传、同质化严重，投放数据下滑

## 四、团队人力搭配建议（小团队也适用）
- 1个运营/文案：负责脚本模板、卖点撰写、素材库维护、数据复盘、审核
- 1个剪辑：负责AI初稿筛选、分级精修、爆款素材打磨，同时管理AI成片工具
> 产能：日常一天可产出20~50条铺量素材 + 3~5条精品素材。

## 五、提效小技巧
1. 不要一条一条生成，**批量输入，一次生成多变体**，降低重复操作；
2. AI初稿分辨率可以先用720P快速生成筛选，定稿后再高清导出，节省算力和等待时间；
3. 同一条精品母版，AI批量裂变变体，减少重复创意工作；
4. 定期清理素材库，淘汰低质量实拍素材，素材质量直接决定AI成片上限。

## 六、常见坑
1. 素材杂乱无分类：AI会随机乱匹配画面，成片质量差；
2. 全部用AI生成产品本体图：产品颜色、结构出错，带来售后风险；
3. 长期只用同一个模板批量生成：素材同质化，平台流量衰减；
4. 缺少人工审核：出现违规词、字幕错误、产品穿帮，投放被拒。
