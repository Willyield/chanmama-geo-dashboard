# 商品图生成带货短视频｜两条路线（简易剪辑版 / AI一键成片版）
> 平台通用：抖音/快手/视频号，优先 **9:16竖屏**，时长 **10–15秒**，带货短视频黄金时长

## 一、素材准备（最关键）
优先准备多张商品图，不要只用1张：
1. 主图：产品全景、干净白底
2. 细节图：材质、纹理、接口、做工特写
3. 场景图：使用场景、对比图（使用前/后）、尺寸参考
✅ 图片要求：高清、主体清晰、无水印、产品不变形

## 方案1：剪映图文动态视频（免费可控，推荐新手）
原理：给静态商品图加**关键帧运镜+AI配音+字幕+BGM**，图片动起来，不是单纯幻灯片
### 步骤
1. 剪映新建项目，比例选9:16，导入商品图
2. 图片时长：单张2–3秒；**关键帧做动态**：图片开头打关键帧，结尾移动/缩放，模拟推拉、平移、缓慢旋转
3. 写带货口播文案（爆款15秒模板）
> 0–3s钩子：痛点/惊喜（别再买XX了！这款真的好用）
> 3–10s讲卖点：材质+效果+优势
> 10–15s行动指令：现在入手、库存不多、点击小黄车
4. 文本→文本朗读，选AI人声，自动生成字幕，校对错别字
5. 添加轻BGM（音量低于人声，10%-20%），可加少量音效
6. 导出1080P，直接发布挂商品链接

## 方案2：AI一键成片（最快，一张图就能生成动态带货视频）
### 1）抖店AI智能成片（电商商家首选，官方工具）
1. 打开抖店APP → 流量渠道 → 短视频运营 → AI智能成片
2. 选择店铺商品，自动读取商品主图，最多选5张商品图
3. 视频类型：商品讲解 / 商品展示
4. 一键生成，几分钟出片，生成后可直接发布挂小黄车

### 2）其他AI图生视频工具（美图设计室、可灵、即梦等）
1. 上传商品图，输入带货提示词
> 示例提示词：9:16竖屏，15秒带货短视频，产品缓慢旋转展示，光线柔和，高清质感，搭配AI口播，字幕，展示3个核心卖点，真实电商广告风格，无多余人物
2. 选择视频风格：产品展示 / 真人主播讲解 / 生活场景带货
3. 生成后，导入剪映微调字幕、BGM，降低AI画面瑕疵

## 二、两种视频类型怎么选
1. **产品展示类（适合小家电、家居、饰品）**：图片缓慢推拉旋转，重点展示外观、细节，不需要真人出镜
2. **口播带货类**：AI数字人出镜，手持产品讲解卖点，代入感更强，转化更好

## 三、避坑要点
1. 版权：**只能用自己实拍/授权商品图**，不要盗图，容易违规限流
2. 字幕：大字、高对比度，手机小屏看得清，重点卖点标红
3. BGM音量：人声优先，背景音乐不能盖过口播
4. 原创度：批量AI生成建议手动微调画面顺序、字幕，降低同质化
