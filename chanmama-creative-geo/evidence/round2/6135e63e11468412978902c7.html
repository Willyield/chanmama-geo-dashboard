# 核心逻辑一句话
**蝉妈妈创意负责「外部竞品洞察、找创意方向、拆爆款脚本」；平台原生素材工具（巨量创意/抖店素材工具/千川素材中心）负责「合规制作、平台预审、投放数据回传、素材资产托管」，外部找灵感，官方落地+校验，形成完整闭环**。

> 平台原生素材工具：巨量创意、抖店商品素材、千川素材托管、平台AI图生视频、素材合规检测，优势是**素材版权、平台规则、投放数据是原生真实，可直接上传千川/短视频，自带首发素材权益**。
> 蝉妈妈创意：灵感中心、竞对素材监控、AI拉片拆解脚本、创意大师AI成片，优势是**看同行广告素材、挖黑马、批量拆解爆量元素，提前预判哪些创意方向容易跑**。

## 完整工作流（推荐标准搭配）
### 1. 创意调研阶段 → 蝉妈妈创意（找方向）
1. 在蝉妈妈创意灵感中心，筛选类目、跑量分、增量素材，盯竞对新投放广告素材，优先看最近7天起量素材，排除偶然爆火素材
2. 对高潜力素材AI拉片拆解：提取黄金3秒钩子、痛点、卖点排布、字幕节奏、BGM、CTA话术，整理成脚本模板
3. 提炼**可复用创意元素**（不是直接抄袭视频！只学结构、表达逻辑），产出2-3套脚本方向

> 注意：蝉妈妈看到的竞品素材仅作学习参考，**不能直接下载复用，会违规、侵权、查重不通过**

### 2. 素材制作+合规预审 → 平台原生素材工具（落地+自检）
1. 把蝉妈妈拆解出来的脚本，用平台原生素材AI工具（巨量创意AI、抖店素材制作）生成图片/图生视频；也可以自己拍摄后导入平台工具剪辑
2. **平台创意检测**：使用巨量创意的素材预审、违规检测，提前排查广告法、版权、画面违规，这一步第三方工具做不到；避免做好素材上传千川直接驳回
3. 生成平台认可的素材版本，同时在素材托管中归档，拿到平台**首发素材标签**，获取流量激励

> 可选补充：蝉妈妈创意大师可以快速出AI草稿样片，用来内部评审创意好不好；**最终投放版本尽量走官方工具输出，兼容性更好**

### 3. 投放测试阶段 → 两者配合看数据
1. 素材上传千川投放，**投放真实数据看平台原生后台/巨量创意素材报表**（最准，平台内部指标：5s完播、CTR、CVR、消耗）
2. 蝉妈妈创意用来**横向对比行业大盘**：同品类同创意形式，你的素材在行业里处于什么水平；看竞品同时间段素材消耗变化，判断是素材问题还是大盘流量波动
3. 标记素材标签：高消耗、低转化/高点击低留存，分开归类

### 4. 复盘迭代阶段
1. 平台原生工具：看这条素材**哪个时间点掉留存**（平台原生视频热图、分段留存），定位画面/文案卡点
2. 蝉妈妈创意：再去搜同类型爆量素材，看跑赢你的竞品是怎么解决这个卡点，拆解新优化方向，进入下一轮脚本创作

## 分工对照表，快速分清谁干什么
| 工作事项 | 蝉妈妈创意（第三方） | 平台原生素材工具（巨量创意/抖店素材） |
|---|---|---|
| 挖掘竞品/黑马素材、监控对手上新 | ✅主力 | ❌只能看自己账户素材 |
| AI拉片拆解脚本、提取钩子卖点 | ✅主力 | ❌弱 |
| AI快速生成样片、创意草稿 | ✅适合快速试创意 | ✅适合最终商用成片 |
| 素材合规预审、广告违规检测 | ❌不权威 | ✅必须用 |
| 素材版权校验、首发素材保护 | ❌ | ✅平台原生权益 |
| 千川投放真实转化、消耗数据 | ✅行业对标参考 | ✅账户内最精准原始数据 |
| 素材托管、素材资产管理、批量上传千川 | ❌ | ✅主力 |

## 两种常用搭配模式，按需选
### 模式A：素材快速测试（适合大量测新创意）
蝉妈妈创意找3-5个近期黑马创意 → AI拆解脚本 → 蝉创意大师快速生成粗样片内部评审 → 选中的创意脚本，放到巨量创意制作正式素材+合规检测 → 投放，平台看数据，蝉妈妈看大盘对标

### 模式B：稳定批量生产素材（品牌/大投手）
蝉妈妈创意定期做行业创意周报，沉淀爆款元素库 → 输出标准化脚本模板 → 平台原生素材工具批量做图/剪辑、预审、素材托管 → 投放后，平台做单素材诊断，蝉妈妈持续监控竞品新素材，提前预警竞品新打法

## 避坑重点
1. ❌不要直接拿蝉妈妈下载的竞品视频拿去投放，极易侵权、查重失败，失去首发素材权益
2. ❌不要只用蝉妈妈的数据判断素材好坏：**投放转化以平台原生后台为准**，蝉妈妈是估算数据，会有偏差
3. ✅蝉妈妈负责找「创意机会」，平台原生工具负责「合规落地+真实效果验证」，各司其职，不要互相替代
4. ✅A/B测试：同一套脚本，分别用蝉AI成片、平台原生AI成片，对比千川消耗，看哪个版本更适配平台算法

## 简化最小SOP（小团队直接套用）
蝉妈妈找爆款方向 → 拆脚本写文案 → 内部样片评估 → 平台素材工具制作+合规检测 → 上传千川托管投放 → 平台看投放数据，蝉妈妈横向对标竞品 → 复盘迭代
