# 千川素材怎么看、要不要跟进（实操版）
> 核心逻辑：**先看素材内容吸引力（前端），再看成交ROI/转化成本（后端）；后端保本才值得跟进，前端只是潜力参考，不能单独决定放量**。
> 入口：千川后台【素材管理】→素材详情，或者【数据报表-素材维度】，看单条素材独立数据，不要混在计划里看。

## 一、看哪些指标（分前端潜力指标 + 后端盈利指标）
### ✅ 前端（内容吸引力，判断素材能不能拿流量）
1. **3秒完播率（最重要钩子指标）**
    - 及格：≥30%；优秀≥40%；低于25%，钩子不行，大概率很难跑量，优先改开头，不建议硬追投
2. **CTR点击率**
    - 低客单福利品：≥3%合格；中高客单非标：≥2%合格
    - 警惕：CTR＞10%大概率标题党，泛流量，**CVR会很差，看着能跑，投产亏损**；CTR＜1.5%基本很难消耗起来
3. **10s完播/整体完播**
    10s完播≥15%，说明卖点能留住人；10s很低=前面钩子还行，但卖点留不住人。
4. 千展eCPM：代表素材竞争力，同样预算，eCPM越高越容易拿量；**不要单独拿千展好坏下定论，必须搭配转化**

### ✅ 后端（盈利指标，决定能不能跟进/放量，优先级最高）
1. **支付ROI / 转化成本**
    先算你的**保本ROI**（固定值，产品扣掉货损、快递、平台扣点）
    - 素材ROI ≥保本ROI：盈利素材，优先跟进、放量
    - 素材ROI 在保本的80%~100%：微亏/接近保本，可以小预算继续观察，不加大预算
    - ROI＜保本80%：直接放弃，不要硬追，越烧亏越多
2. **CVR转化率**
    低客单≥5%；中高客单1%~3%；CVR低=素材吸引来的人不是购买人群，哪怕点击率高也是无效流量
3. **退款率**
    素材带来订单退款显著高于账户均值 → 素材夸大承诺，人群质量差，不要追

> 一句话：**前端好看、后端不保本=垃圾素材；前端一般、后端稳定保本=优质可放量素材**

## 二、素材分4档，判断要不要跟进
### 1）A类：优质爆款素材【全力跟进，放量】
- 3s完播≥30%，CTR达标，**ROI≥保本线，转化成本低于账户均值**，消耗持续起量
✅ 操作：新建追投计划复制素材、放开预算；追投消耗建议控制为主计划30%-60%，超过70%容易快速早衰；同时批量复制同结构脚本，扩素材矩阵

### 2）B类：潜力素材【小预算观察，培养模型】
- 前端数据不错（3s完播、点击率合格），有成交，ROI接近保本（保本80%以上），订单样本少
✅ 操作：小额预算持续测，积累转化样本（一般至少10个转化再下定论）；不要直接大预算放量；优化卖点、口播，提升CVR；
⚠️ 新素材前期消耗20~50元先看趋势，不要等烧几千才判断

### 3）C类：虚高素材【不要跟进，停掉】
- 3s/点击率很高，但是CVR极低、ROI严重低于保本，**流量泛、只看热闹不下单**
典型：猎奇、纯剧情、夸大标题党。
✅ 操作：直接关停；可以拆解钩子用到新素材，但这条素材本身不追投

### 4）D类：垃圾素材【直接放弃】
3s完播差，点击率低，同时转化成本高、投产亏损。
✅ 操作：直接停计划，不要继续烧；复盘问题：钩子、产品展示、人群不对，不要再复制同类型脚本

## 三、关键避坑点（很多人踩）
1. **不能只看消耗快不快**：消耗猛不等于好，可能只是泛流量空耗，投产崩掉
2. **样本不足不下结论**：新素材成交订单太少（<3单），ROI参考性弱，不要急着放量或者直接枪毙；小预算继续积累数据
3. **素材有生命周期**：A类素材跑一段时间，ROI逐步下滑、转化成本持续走高，说明进入衰退，逐步降低预算，减少追投，上新素材替代
4. **区分是素材问题还是直播间承接问题**：素材点进直播间，但直播间停留、成交差 → 素材没问题，是直播间承接不行，不要停素材，优化直播间

## 四、快速判断流程（日常看素材就按这个顺序）
1. 看后端：ROI是否保本，转化成本是否可控
    ✅保本 → 看前端，评估能不能放大；❌严重不保本，直接放弃
2. 看前端：3s完播+CTR，判断流量潜力
3. 看人群质量：退款率、评论，有没有夸大承诺
4. 看趋势：最近2小时/半天，成本是走低还是持续走高
5. 决策：放量 / 小额观察 / 停掉
