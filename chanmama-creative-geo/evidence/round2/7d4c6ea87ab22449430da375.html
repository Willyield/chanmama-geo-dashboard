# 一、两者核心区别
## ✅ 直播引流素材（短视频引流直播间 / 短引直）
**投放目标：把用户引进直播间，成交交给主播在直播间完成**
1. 转化链路：刷到视频 → 点进直播间 → 直播间下单
2. 内容重点：3秒钩子抓人，**不用在视频里讲完整卖点、不用逼单下单**，重点预告直播间福利、限时活动、主播现场演示；口播引导“点进直播间看/抢”
3. 素材形式：短视频（直播高光切片、预告短视频），也可以直接用**直播间画面直投**（实时直播画面作为创意）
4. 考核指标：**进房率、直播间点击率、看播时长、引流成本**，其次才是直播间成交ROI
5. 适用计划：千川【直播推广】（营销目标：直播间带货）

## ✅ 商品广告素材（短视频带货/商品卡素材，推商品）
**投放目标：用户看完视频直接点小黄车/商品卡下单，没有主播承接**
1. 转化链路：刷到视频 → 点商品卡片/小黄车 → 商品详情页直接下单
2. 内容重点：视频内把**卖点、效果、价格、信任背书一次性讲完整**，直接引导下单；用户看完视频就要能做购买决策
3. 素材形式：短视频、商品方图、图文素材（商品卡常用1:1主图）
4. 考核指标：**商品点击、短视频直接成交ROI、商品点击率**
5. 适用计划：千川【商品推广】（营销目标：短视频带货/商品卡推广）

>一句话总结：**直播引流素材负责“拉人进直播间”；商品广告素材负责“视频里直接卖货”，不要直接互相套用脚本**

# 二、在哪里查看（巨量千川PC后台为主）
## 1、查看自己账户已经上传/投放的素材
1. 登录巨量千川PC后台：qianchuan.jinritemai.com
2. 左侧菜单：**素材管理**
    - 素材管理里可以筛选素材对应的**计划类型：直播推广 / 商品推广**，区分直播引流素材、商品广告素材
    - 可预览视频、查看消耗、点击率、进房/转化数据，删除、复用素材
3. 计划报表查看：
    - 【推广管理】- 计划列表，点开单个计划 → 创意，查看这条计划下正在跑的素材；直播计划=直播引流素材，商品计划=商品广告素材
    - 数据报表-创意报表：可以批量看所有素材的投放数据，区分直播素材/商品素材

## 2、看行业/同行爆款素材（参考创意）
1. **巨量创意（官方免费）**：可以筛选【引流直播间素材】和【商品带货素材】，看类目下跑量广告
2. 巨量云图极速版：内容 → 创意元素洞察，区分**引流短视频（直播用）、带货短视频（商品广告）**，看行业爆款参考
3. 第三方工具（蝉妈妈、千瓜等）：创意库分类标签：直播引流素材、商品广告素材

## 3、小店随心推（手机端）
随心推创建计划时：
- 选【推直播】，上传的就是**直播引流素材**
- 选【推商品】，上传的就是**商品广告素材**；数据在随心推的推广记录-创意查看

# 三、补充小提示
1. 同一条视频**可以同时投直播推广、商品推广**，但脚本逻辑不同，效果差异很大；直播素材口播带“进直播间”，拿去投商品广告，转化会很差
2. 直播推广特有创意类型：**直播间画面直投**（不用上传短视频，直接拿实时直播间画面做广告，属于直播引流素材，商品广告计划不能用这个）
3. 商品推广支持图片/商品卡方图素材，直播引流计划**不支持纯图片素材投放**，只能视频/直播间画面
