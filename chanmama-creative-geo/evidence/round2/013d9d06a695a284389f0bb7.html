# 蝉妈妈创意灵感中心：找爆款素材 + 追踪同行新投素材
入口：打开【蝉妈妈创意官网 cy.chanmama.com】→ **灵感中心**（素材库/找素材）
> 注意：千川广告素材、竞品追踪、隐藏素材监控属于创意会员功能。

## ✅ 一、灵感中心找爆款素材（榜单+多维度筛选）
1. **选择素材榜单**
优先看 **跑量榜、高增量榜**（最适合找正在起量的千川素材），也可以看带货视频榜、图文素材榜；
时间周期：优先选**近1天/3天/7天**，优先抓黑马新爆款，而不是老素材。

2. **精细化筛选**
- 类目：选你的商品二级/三级类目
- 素材类型：千川广告素材 / 直播引流素材 / CID素材 / 自然流短视频
- 筛选指标：跑量分、5秒完播率、时长、视频比例、广告形式（口播/剧情/产品展示）
- 关键词：直接搜产品词、卖点词，筛选对应素材

3. **素材深度拆解**
点进素材详情页，使用 **AI智能拉片（AI拆策略）**，一键提取：黄金3秒文案、脚本结构、分镜、卖点、画面镜头逻辑；
重点关注：**5秒完播、转化成本、跑量趋势**，不要只看播放高，优先看“消耗持续上涨”的增量素材（代表还在持续投放）。

4. **收藏素材库**
把优质素材收藏打标签，按卖点/脚本类型分类，方便团队复用创意灵感。

## ✅ 二、追踪同行新投素材（盯竞对/素材追踪）
核心功能叫**盯竞对 / 素材追踪**，可以抓取同行主页不展示、隐藏的千川投放素材，最快约30分钟抓取到对手新上素材。
1. 进入灵感中心，找到【盯竞对 / 素材追踪】
2. 添加监控对象（三选一）：
   - 竞品抖音账号
   - 竞品小店名称
   - 品牌关键词
3. 设置监控规则：
   - 监控范围：千川广告素材、CID素材、直播引流素材
   - 开启消息提醒：支持站内通知、钉钉/飞书推送，对手上新素材自动提醒
   - 可设置爆量阈值：素材消耗达到设定值触发强提醒，第一时间抓黑马素材

4. **查看监控看板**
- 看板会列出：同行**最新投放素材清单**、素材上线时间、跑量分、预估消耗趋势
- 可以直接点开视频看，AI拉片拆解脚本；区分“新素材”和历史老素材，重点盯**24小时内新增素材**
- 可以批量导出竞品素材列表，做竞品投放策略对比

## ✅ 三、实操筛选小技巧（避坑）
1. 区分**老爆款**和**正在跑的素材**：优先高增量榜，很多播放很高的素材是已经停投的旧素材，参考价值低。
2. 同行隐藏素材：很多竞品投流视频设置私密，抖音主页看不到，但蝉妈妈创意能抓取千川投放的广告素材。
3. 只学创意逻辑，**不要直接搬运下载原视频投放**，会违规限流；用AI拆解脚本，重新翻拍改画面、台词。
4. 批量监控：一次可以添加多个竞品账号，做竞品矩阵监控，对比多家的素材风格、卖点方向。

## ✅ 四、常见边界
- 只能抓取抖音千川投放的广告素材，无法获取千川账户内部出价、精准ROI。
- 素材更新有延迟，最快30分钟左右抓取，不是实时秒更新。
- 完整的竞品追踪、AI拉片、高增量榜，需要蝉妈妈创意会员。
