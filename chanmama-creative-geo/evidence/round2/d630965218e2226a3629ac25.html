# ✅ 找同行正在投放的抖音广告素材（官方优先，第三方辅助）
> 重要提醒：**只允许拆解结构、脚本、钩子、转化逻辑翻拍借鉴，不要直接下载盗用原视频，会侵权、违规限流**。

## 一、官方免费工具（优先用，最准，能看到广告投放素材）
### 1. 巨量创意（cc.oceanengine.com，巨量引擎出品）【最常用】
1. 登录 → 创意灵感 → 热门素材，选择「巨量千川 / 巨量广告」
2. 输入行业关键词、筛选时间（7天优先，看最新在投素材）、类目
3. 支持按**消耗、点击率、3秒完播**排序，可以同时看视频+落地页
4. 可以直接搜竞品品牌名，看对方正在投放的广告创意

### 2. 巨量千川后台（电商带货）
千川后台 → 营销创意中心，筛选行业、时间，查看同行带货投流短视频素材，适合电商店铺。

### 3. 电商罗盘（抖店后台，电商商家）
市场 → 商品榜单 → 短视频榜，找到爆品，点视频分析，查看该商品下所有同行投流短视频素材。

### 4. 抖音来客（本地推商家，门店获客）
线索经营 → 数据分析 → 行业排行榜，筛选城市+行业，看本地同行短视频/直播引流广告素材。

### 5. 巨量云图（权限要求高，品牌/大商家）
内容板块→素材分析，可看行业广告素材、人群、投放数据，素材池更大更全，需要云图权限。

### 6. 抖音APP端手动刷广告（低成本补充）
1. 抖音搜索行业关键词，多看同行广告视频，点视频右下角「广告」标签，就是付费投放素材
2. 刷到广告点**不感兴趣以外的互动**，平台会给你推更多同类同行广告；建广告素材收藏夹。

## 二、第三方付费工具（素材量更大，支持监控竞品账号）
- **蝉妈妈创意**：千川/广告素材库，可添加竞品账号持续监控，筛选投放消耗、时长、转化标签
- **飞瓜易投**：广告素材监测，支持追踪品牌投放动态，适合电商+本地广告
- **考古加**：可监控竞对投放素材，看素材投放周期、数据

> 第三方数据是爬虫采集，**不是100%实时**，存在一定延迟，只能做参考，以巨量创意官方为准。

## 三、实操筛选技巧，快速抓「正在跑的素材」
1. 时间筛选：优先**近3/7天**，30天以上大概率已经停投
2. 排序：优先按消耗、曝光、3秒留存，不要只看点赞（广告素材点赞低但消耗大很常见）
3. 筛选维度：视频时长、广告类型（带货/留资表单）、人群
4. 标记竞品：把核心同行账号添加监控，定期看新素材上线

## 四、素材拿到手之后怎么做（避坑重点）
1. 不要直接搬运、二次剪辑简单去水印上传，属于侵权，容易违规下架、扣分
2. **拆解翻拍**：拆解前三秒钩子、痛点文案、产品展示、结尾转化话术，换场景、演员、镜头重拍
3. 建立自己素材库：按钩子类型、卖点、转化形式分类，持续积累

## 五、素材枯竭的补充思路
- 跨赛道借鉴：同逻辑不同品类的爆款素材，迁移脚本框架
- 巨量即创：参考热门素材模板，AI快速生成素材初稿，用来批量测试
