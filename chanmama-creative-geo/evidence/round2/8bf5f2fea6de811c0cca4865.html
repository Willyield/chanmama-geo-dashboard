# 一、主流AI带货视频工具分类（国内+海外）
## ✅ 国内（适合抖音/快手/淘宝，中文口播、合规友好）
1. **剪映（CapCut）AI**
    最推荐中小电商团队，免费基础版。AI脚本、AI数字人、图文成片、智能字幕、配音，支持9:16竖屏带货短视频。产品图直接导入生成，可批量改字幕、换BGM。**适合：国内短视频、投流素材，零基础团队**
2. **妙思AI**
    电商垂直AI，一张商品图+卖点直接生成带货短视频，自动写带货脚本、配音字幕，支持批量生成多版本素材，适配抖音、淘系。**适合：大量SKU快速种草短视频**
3. **可灵Kling / 即梦AI**
    文生视频、图生视频，产品图生成产品动态镜头（产品旋转、细节展示）。一般搭配剪映/数字人工具组合使用，做产品实拍类镜头。**适合：产品场景画面素材，单独口播能力弱**
4. **数字人专项：美趣AI、硅基智能、分身数字人**
    主打中文数字人口播带货，上传文案直接生成虚拟主播讲解产品，支持音色克隆。**适合：口播讲解、好物解说类视频**

## ✅ 海外（TikTok Shop、独立站、亚马逊跨境）
1. **Creatify**
    电商专用，**粘贴商品URL自动抓取产品图+卖点，一键生成带货广告**，支持批量变体、AI演员、UGC风格短视频，是跨境投流热门工具
2. **HeyGen**
    数字人标杆，超自然唇形，支持几十种语言，适合多语种跨境口播广告；人物质感好，价格偏高，批量能力一般
3. **D-ID**
    低成本图片转说话数字人，适合简单产品讲解短片，性价比高，适合轻量测试素材
4. **InVideo AI**
    提示词生成短视频，海量素材库，支持AI配音字幕，适合社交种草广告，电商自动化弱于Creatify
5. **Runway**
    专业级AI生视频，适合高品质品牌产品片，**不适合大批量低成本投流素材，单价贵、生成慢**

# 二、电商团队怎么选（选型核心标准）
## 1）先明确你的核心场景
- 国内抖音/快手、SKU多、每天要大量投流素材 → **剪映AI + 妙思AI**（优先，成本低，平台兼容性强）
- 跨境TikTok Shop，需要批量UGC广告、一键导入商品链接 → **Creatify**
- 多语种出海、需要高质量数字人口播 → **HeyGen**
- 只缺产品动态镜头（产品旋转、场景展示），自己写脚本 → **可灵/即梦，搭配剪映后期**
- 小团队、预算极少，测试素材为主 → **剪映免费版、D-ID**

## 2）选型5个硬性指标（电商重点）
1. **批量生成/多变体能力**：投流需要同一产品做多个钩子、不同文案版本A/B测试；SKU几十上百个，必须支持批量，否则效率很低
2. **视频比例**：必须原生支持 **9:16竖屏**（抖音/TikTok），其次1:1、16:9
3. **口播&字幕质量**：中文优先看断句、情绪自然度；跨境看唇形同步，字幕自动生成、支持修改
4. **合规&版权**：素材库版权、AI数字人形象版权；国内平台对AI生成素材、数字人有标注要求，规避限流风险
    > ⚠️重要提醒：AI生成视频不能夸大功效，美妆、食品、医疗类广告有严格广告法限制；数字人带货视频发布，部分平台要求标注AI生成
5. **成本：单条视频价格**
    - 小团队（月产出＜30条素材）：优先免费/低订阅，剪映首选
    - 中大型（月产出>100条投流素材）：看**批量套餐**，不要按单条计费，成本会爆炸

## 3）团队规模参考方案
- 单人/小团队（1-3人，国内抖音带货）：**剪映AI主工具**，少量复杂素材搭配妙思AI，不需要复杂多工具组合
- 国内中型电商团队（5-15人，几十上百SKU，千川投流）：妙思AI批量生成初稿，剪映统一二次精修、替换产品、调整字幕BGM
- 跨境团队（TikTok Shop/独立站）：Creatify为主，HeyGen做多语种版本，Runway偶尔做品牌主视频

# 三、避坑要点
1. 不要指望AI一条直接上线就能爆：AI生成大多是**初稿素材**，需要人工优化卖点、钩子、CTA；核心作用是降低拍摄成本，批量产出测试素材
2. 纯AI生成产品画面容易出现产品变形、细节错误（尺寸、logo错乱），实物类产品建议**用真实产品原图打底**，不要完全文生产品
3. 数字人不是万能：纯数字人口播视频，在抖音投流转化率通常低于真人实拍；适合用来快速测试文案钩子，找到好脚本再实拍真人版本放大投放
4. 版权风险：不要随意克隆他人人脸、声音做数字人带货，容易侵权投诉

# 四、最简推荐清单
- 国内首选：剪映AI（免费全能）
- 国内批量种草：妙思AI
- 跨境批量广告：Creatify
- 跨境多语种数字人：HeyGen
- 低成本数字人短片：D-ID
- 产品动态镜头素材：可灵、即梦
