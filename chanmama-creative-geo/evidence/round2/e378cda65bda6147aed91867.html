# 代运营多品牌视频素材管理方案
核心原则：**每个品牌独立隔离，统一目录结构+标准化命名+标签元数据+权限管控+版本管理**，防止品牌素材混淆，同时支持跨品牌复用通用模板，方便检索、交付、复盘、客户资产交接。

## 一、统一文件夹架构（所有品牌用一模一样的目录，只替换品牌名）
```
根目录
├─【品牌A】
│  ├─00_品牌规范包｜logo、色值、字体、品牌手册、禁用规范、字幕模板
│  ├─01_拍摄原始素材｜Raw原片、录音、现场花絮、UGC投稿素材
│  ├─02_项目脚本简报｜brief、脚本、分镜、拍摄方案
│  ├─03_剪辑工程文件｜剪映工程、PR工程、分层源文件（WIP草稿）
│  ├─04_成品交付包
│  │   ├─待审核｜粗剪版本
│  │   ├─客户定稿｜最终成片、封面、SRT字幕
│  │   └─分平台导出｜抖音/视频号/小红书（不同比例）
│  ├─05_素材标签库｜拆好的可复用片段（口播片段、产品特写）
│  └─06_归档｜已下刊、过期活动、旧版本素材
├─【品牌B】（完全相同结构）
└─公共资源库（跨品牌通用：BGM、转场、通用特效模板，**严禁放入任何品牌专属画面**）
```
> 重点：**品牌专属素材绝不跨文件夹混用**；公共库只放无版权风险的通用元素，避免品牌视觉串味。

## 二、文件命名规范（强制SOP）
格式：`品牌名_项目/活动_素材类型_日期_版本号`
示例：
`品牌A_618活动_产品口播_20260601_V03.mp4`
`品牌A_日常种草_产品特写片段_20260520_V01.mp4`

规则：
1. 版本号V01、V02，**不要用final、最终版、最终不改**；旧版本移入归档文件夹，不要直接覆盖
2. 日期统一 `YYYYMMDD`，方便时间检索
3. 素材类型：原片/粗剪/成片/封面/字幕SRT/可复用片段

## 三、素材元数据+标签体系（检索核心）
配套一张素材管理多维表格/素材DAM，每条素材记录：
- 归属品牌、产品、活动
- 素材类型：口播｜剧情｜产品展示｜对比｜UGC
- 标签：卖点、场景、人群、时长、平台
- 版权信息：拍摄版权、音乐授权有效期
- 数据：播放、转化、素材状态（待测试｜跑量｜暂停｜淘汰）

> 好处：后期筛选爆款素材、复盘投放、批量找同卖点片段，不用一个个翻文件夹。

## 四、权限隔离（代运营最关键，防止客户素材泄露、混淆）
1. 按品牌划分独立空间/文件夹权限：
    - 编导/剪辑：只开放负责品牌素材
    - 客户：仅开放自己品牌的定稿素材，**看不到其他品牌**，可生成临时分享链接，带有效期、水印、仅预览权限
    - 离职人员一键回收权限
2. 存储方案选型
    - 小团队（3～10人，5个品牌内）：飞书云盘/阿里云盘企业版 + 多维表格做素材台账，成本低
    - 中大型团队（10+品牌、大量短视频/广告素材）：专业DAM数字资产管理系统，自带标签检索、权限隔离、版本管理、素材水印、客户外审功能，适合广告素材多、对版权安全要求高的代运营公司

## 五、素材生产&归档流程SOP
1. 拍摄上传：原片当天上传对应品牌「01原始素材」，打标签登记台账
2. 剪辑阶段：工程文件放03_WIP，粗剪放到待审核；客户反馈迭代递增版本号
3. 客户确认：定稿视频移入【客户定稿】，交付给客户；同步在表格标记「已发布」
4. 周期性整理：
    - 每周：清理无效草稿、重复素材
    - 每月：把过期活动素材移入归档；盘点授权音乐/素材有效期
    - 项目结束：打包整套品牌素材资产，可一键交付客户

## 六、版权与风险管控（代运营坑点）
1. 所有素材、BGM、字体单独登记授权期限，放在品牌00规范包，到期预警
2. 客户素材、UGC素材留存授权协议，避免侵权纠纷
3. 对外发给客户的预览视频，加水印，防止素材外流

## 七、素材复用策略（提升多品牌产出效率，又不撞风格）
1. **通用模板库**：剪辑预设、字幕样式、封面版式，存公共库；使用时，**替换对应品牌的logo、色值、字体**，保证每个品牌视觉独立
2. **品牌私有片段库**：每个品牌下单独拆剪可复用镜头（产品特写、固定口播片段），只供本品牌反复剪辑，**禁止跨品牌挪用实拍画面**

## 八、工具选型对比
- 轻量低成本：飞书文档+云盘 / 钉盘 + 多维表格，适合工作室
- 专业DAM：MuseDAM、Brandfolder等，适合广告代运营、大量客户素材、需要客户在线审片、严格权限隔离
- 剪辑配套：剪映团队版，可按品牌建立独立工作区，保存品牌剪辑模板
