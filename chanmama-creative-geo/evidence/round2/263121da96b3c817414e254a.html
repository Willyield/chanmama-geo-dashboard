# 核心一句话
**从千川素材里找创意，不是抄视频，是提炼「经过投放验证的创意骨架」：钩子类型、叙事结构、信任方式、人群话术、画面表达。优先拆自己账户跑量素材，再对标同类目同行素材，然后做变量测试沉淀可复用方向**

## 一、去哪里筛选素材（官方渠道优先）
1. **千川后台 → 工具 → 营销创意榜**
筛选条件：类目、推广目标（短视频带货/直播间引流）、时间7~15天，按消耗、CTR、CVR排序；只看**广告素材**，排除DOU+自然内容
2. **巨量创意 → 千川专区**：大盘广告素材库，可按数据、时长筛选
3. **巨量云图 → 创意元素洞察**：看人群、卖点、视觉元素的大盘偏好，适合提炼共性创意方向
4. **自己账户素材库（最重要）**：筛选历史素材，保留**高消耗、高CVR**素材；区分两类：
    - 高CTR、CVR一般：**钩子强，但转化弱** → 复用开头钩子，中段卖点重做
    - CTR一般、CVR高：**转化逻辑强，留人弱** → 复用中段信任+卖点，重做3秒开头
> 淘汰样本：消耗低、ROI差的素材，不要从中提取创意

筛选原则：**优先同类目、客单价接近、目标人群一致**，跨类目爆款只能参考形式，不要直接套用

## 二、标准化拆解表格（提取可复用创意维度）
每条跑量素材填下面6项，拆5~10条同类爆款，找**共性公因式**（这就是可复用创意方向）：
1. **0-3s钩子（决定点击率，最值得复用）**
    常见可复用钩子类型：
    - 痛点提问：是不是XX烦恼？
    - 反差对比：别再买XX，这款才是
    - 实测冲击：直接展示前后效果特写
    - 人群锁定：家里有XX的注意了
    - 悬念承诺：没想到XX可以这么简单
> 记录：钩子是画面驱动还是口播驱动

2. **叙事结构（短视频通用黄金结构）**
`3秒钩子 → 场景痛点 → 产品实证展示 → 信任背书 → 价值/福利 → CTA下单`
拆解：卖点顺序、节奏快慢、字幕卡点位置。**结构框架可以复用，台词和画面必须换**

3. **卖点表达逻辑**
不是记录卖点文字，而是记录**表达方法**：
- 是场景化展示？数据量化？实测对比？口碑证言？
例：同样讲防滑，A素材是泼水踩上去实测，这个表达形式可复用

4. **信任手段（转化关键）**
真人实测、开箱抽检、用户评价、证书、工厂溯源、前后对比，记下素材用了哪一类信任方式

5. **画面/剪辑元素**
场景（厨房/卧室/工厂）、镜头（特写、微距、手持实拍）、字幕样式、BGM风格、色调；
> 这些是可复用的视觉风格方向，不是照搬画面

6. **结尾CTA逼单逻辑**
价格锚点、限时、赠品、场景闭环引导下单

## 三、归纳创意方向：找多条爆款的共性
拆完5-10条素材，横向对比，提炼**稳定跑量创意方向**，举例：
- 方向A：**痛点提问钩子 + 实物对比实测 + 用户证言**（适合家居清洁）
- 方向B：**人群定向开头 + 细节特写展示 + 工厂溯源**（适合服饰家纺）
- 方向C：**悬念反差开头 + 效果快剪 + 价格锚点逼单**（适合小百货）

> 原则：**抄骨架，不抄皮**。不要直接复制台词、画面、人物；只复用创意逻辑，产品、场景、话术全部替换成自己的

## 四、创意复用&裂变测试方法（控制变量）
拿到创意方向后，做素材裂变，每次**只改1个变量**，方便判断哪个创意有效：
1. 保留创意框架，只替换3秒钩子（验证钩子方向）
2. 钩子不变，替换中段实证画面（验证卖点展示方式）
3. 整套结构不变，换口播文案、场景、模特（同创意方向批量生产）

素材生命周期管理：
- 黄金期（<15天）：基于这个创意方向批量衍生素材放量
- 衰退期（15~30天）：保留创意框架，重做开头、换BGM和字幕再测
- 老化素材：创意框架如果多次测试持续失效，直接归档，放弃这个方向

## 五、素材库沉淀，形成自己的创意资产
建立表格库，分三类归档：
1. **钩子库**：按类型存放可复用开头模板
2. **创意框架库**：验证有效的完整短视频叙事公式
3. **视觉元素库**：镜头、场景、字幕、剪辑风格

每周复盘：看哪些创意方向产出的素材ROI稳定，标记为**主力创意方向**；哪些创意反复测试不起量，标记淘汰。

## 六、避坑重点
1. ❌ 不要直接下载同行素材剪辑混剪，侵权风险极高；只借鉴创意逻辑
2. ❌ 不要只看高播放、高点赞素材，千川看**消耗、CTR、CVR**，点赞参考价值很低
3. ❌ 不要一次同时修改钩子+画面+文案，无法判断创意哪个部分有效
4. ✅ 优先拆解自己账户的跑量素材，人群匹配度最高，复用成功率远高于同行素材
