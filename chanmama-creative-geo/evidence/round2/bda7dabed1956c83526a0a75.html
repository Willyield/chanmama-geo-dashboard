# 抖音电商素材判断框架（团队直接落地用）
一句话原则：**先过合规门槛 → 小额测数据看潜力 → 看素材可复制性 & 生命周期 → 结合商品/直播间承接综合决策；不单独看一个指标，优先和【账户均值、保本ROI、类目大盘】对比，不是固定绝对值**

## 一、前置筛查：一票否决项（先看，不满足直接不跟进）
1. **合规安全**：不违反广告法、平台电商内容规则，没有夸大功效、极限词、虚假对比；无版权/肖像风险，不被判定低质、同质化、标题党。评论区无大量差评、投诉、举报负反馈。
2. **商品匹配**：素材讲的卖点，商品详情、直播间、售后能兑现，不能素材吹A，货是B；素材人群和产品目标人群一致。
3. **声画基础**：画面清晰、收音正常，不是模糊混剪、录屏搬运。

> 只要踩红线，数据再好也不要长期放量，容易断流、扣保证金。

## 二、数据层：分2阶段判断（新素材小测试 → 放量验证）
> 实操方法：新素材小额测（很多团队用30–100元预算，拿到样本再评估，避免数据抖动），**必须等模型跑出足够曝光/转化样本，不能刚花几块钱下结论**

### 阶段1：潜力信号（内容吸引力，看能不能拿到流量）
- **3秒/5秒完播**：黄金钩子，看开头留人；3秒完播低于账户均值，基本很难跑量。看流失曲线：如果是前3秒断崖下滑=钩子废；中段集中流失=卖点不吸引人；尾部流失高=转化引导弱
- **CTR点击率**：代表封面+钩子吸引力；过高（>10%）大概率标题党，点进来不转化，虚流量；过低（＜1.5%）基本很难起量
- eCPM：系统预估竞争力，eCPM高于账户平均，代表素材更容易拿曝光

✅ 结论：**完播+CTR优于账户均值，但转化暂时没出来 → 属于潜力素材，可以迭代同脚本/同钩子变体继续测；不直接放量**

### 阶段2：商业转化（核心，判断能不能赚钱）
1. **ROI / 转化成本**：对比保本ROI。素材ROI≥保本线，转化成本低于目标成本 → 值得追投放量；
   略低于保本但流量大、新客占比高，可以小幅观察，不要猛加预算；远低于保本，直接停。
2. **CVR转化率、GPM**：看素材带来的流量能不能成交；点击率很好但CVR极低=流量泛、人群不对，不要继续加大预算。
3. **消耗能力**：能不能平稳花预算，不是一下子爆一下就断；持续稳定消耗才是主力素材；消耗不动，eCPM低，大概率素材竞争力弱。
4. **人群质量**：看新客占比、人群画像，是不是目标客群；老粉高ROI没有长期放量价值。

#### 素材4类分级（团队用来快速定动作）
1. **主力素材（重点跟进+放量）**
    完播、CTR、CVR、ROI全部优于账户均值；消耗稳定；负反馈低；生命周期还在上升期。动作：加预算、多计划复制，同时同框架批量衍生新素材。
2. **潜力素材（跟进迭代，不直接放量）**
    内容指标（3秒完播/CTR）不错，但转化/ROI略差；一般是钩子好、卖点或承接弱。动作：不改钩子，优化卖点、信任背书、下单引导，拍同框架变体继续测试。
3. **观察素材（少量预算维持，不追加）**
    各项接近账户均值，没有突出亮点，也没有明显短板。不投入大量人力拍衍生素材，跑不动就下线。
4. **淘汰素材（直接放弃，不再跟进）**
    3秒完播极差 / CTR过低；或者高点击但转化极低；违规/大量负反馈；持续空耗不出单。

## 三、内容底层：素材有没有复用价值（团队最容易忽略）
同样数据，有的素材爆一次就没，有的可以持续产出系列素材：
1. **卖点可复用**：是不是击中真实痛点，不是短期猎奇梗；痛点能持续被搜索/关注，生命周期更长。
2. **差异化**：和账户现有素材、同行素材有区分，不容易被平台判定同质化，不会互相抢流量。
3. **生产成本**：拍摄难度、出镜人、场景好不好复制；如果拍一次成本极高，很难批量产出，就算爆了也很难规模化。

> 比如：一个猎奇段子素材短期ROI好，但没法批量复制、生命周期很短 → 可以短期拿量，但不值得团队长期投入跟进、批量翻拍。

## 四、外部承接：素材好不好，不只是素材本身
素材再好，承接跟不上也不能放量：
- 短视频挂车：商品价格、sku、评价、主图能不能接住素材带来的流量
- 引流直播间素材：直播间停留、话术、主播承接、库存能不能接住素材涌入的流量
👉 素材数据不错，但直播间承接差：优先优化直播间，而不是继续大量追加素材预算。

## 五、团队决策简易判断清单（开会直接勾选）
- [ ] 合规无风险，无大量差评投诉
- [ ] 小额测试后，3秒完播/CTR ≥账户均值
- [ ] ROI≥保本ROI，转化成本可控
- [ ] 人群是目标用户，不是纯泛流量
- [ ] 素材卖点有持续性、可翻拍，非一次性热点梗
- [ ] 商品/直播间可以承接流量

✅ 满足大部分：**跟进，加预算+批量衍生素材**
⚠️ 内容指标好，但转化差：**跟进迭代，小预算测变体，不放大**
❌ 前两项不达标：**停止跟进，放弃，不要继续烧钱**

## 六、常见误区
1. 只看完播点赞，不看成交：高互动不代表能卖货，泛流量素材最坑钱
2. 只看单条ROI，不看新客：老粉回购ROI高，没有拉新价值，不能作为主力素材
3. 数据刚跑几十块就下判断：样本小波动极大，容易误判
4. 爆量素材无脑无限追加：素材有衰减周期，一旦千展上涨、ROI下滑就要收缩预算
