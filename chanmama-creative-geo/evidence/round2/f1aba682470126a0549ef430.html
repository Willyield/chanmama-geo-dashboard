# ✅ 有，而且新手优先用国内免费工具，直接出分镜脚本
## 一、推荐工具（按上手难度排序）
1. **豆包（推荐首选，我本身就可以写）**
直接生成短视频分镜脚本，支持口播、知识科普、带货、剧情短剧。你给主题、时长、平台，就能输出：时长+画面描述+台词/旁白+字幕，不满意可以反复修改、调整语气、仿写博主风格。

2. **剪映（自带AI脚本，写完直接进剪辑）**
剪映PC/APP里的「脚本成片」功能，输入选题，AI一次性产出多版脚本，脚本可以一键导入剪辑、自动配字幕和AI配音，**不用跨软件**，拍口播最方便。



3. **文心一言 / Kimi**
中文强，适合深度打磨脚本。Kimi还可以直接上传爆款视频文案，让AI拆解爆款结构，再仿写同类型脚本，适合做对标爆款内容。

4. **专业视频脚本工具：Updream**
专门做影视短视频，从故事大纲→剧本→人设→分镜草图一体化，适合剧情短片、短剧，适合想做精细化分镜的创作者。

> 海外工具：Scrip AI、BIGVU，适合TikTok/Reels，国内访问不方便，普通抖音快手博主不优先选。

## 二、直接复制的提示词模板（丢给AI就能用）
> 模板示例：
```
写一条60秒抖音竖屏短视频脚本，知识口播类，主题：XXX。
结构：0-5s钩子，5-30s痛点讲解，30-50s解决方案，50-60s结尾引导点赞评论。
严格表格输出：镜头序号｜时长｜画面描述｜旁白｜字幕关键词。
语言口语化，不要书面长句，开头一定要抓人。
```
带货版本：
```
写45秒带货短视频脚本，产品XXX，目标人群XX岁。开头痛点钩子，中间3个核心卖点，结尾引导下单。表格形式，标注拍摄画面和台词，加镜头运镜提示。
```

## 三、重要提醒
AI写的是**初稿**！拿到后一定要：
1. 朗读一遍，删掉生硬书面话；
2. 检查时长，口播语速一般220字/分钟；
3. 加入你自己的个人风格，不要直接原样发布；
4. 涉及产品宣传，注意广告合规。

## 四、简单工作流
选题 → AI生成脚本初稿 → 修改润色 → 复制到剪映，AI配音+剪辑 → 成片
