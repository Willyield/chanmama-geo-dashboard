# 一句话结论
**找爆款素材优先用【素材洞察工具】；素材库用来存、管理、复用你筛选出来后的素材，不能用来找爆款方向**，两者是上下游搭配关系，不是二选一。

## ✅ 素材洞察工具（找爆款、定创意方向）
代表工具：巨量创意、巨量云图创意洞察、蝉妈妈、有米有数、电商罗盘创意板块
**核心价值：带数据，帮你判断什么素材能跑**
1. 按类目/时间筛选同行千川/带货跑量素材，附带**曝光、5s完播、CTR、转化、消耗**指标，区分真爆款和高赞但不带货的视频
2. 聚类拆解爆款元素：黄金3s钩子、高频场景、口播卖点、画面结构，提炼可翻拍的脚本模板
3. 看趋势：识别近期新起量素材，避开已经衰退、内卷严重的老素材
4. 适用阶段：**素材调研、选题、脚本策划阶段**

缺点：只能看参考案例，不能直接拿来投放（版权风险；照搬容易同质化，失去首发素材权重）

## ✅ 素材库（素材存储管理，不是找灵感）
代表：抖店素材中心、团队自建素材库、巨千素材托管库
**核心价值：存放内部拍摄/剪辑成品，团队协同管理**
1. 上传、分类、打标签、云端存储自家视频图片，千川/店铺可直接引用
2. 版本管理、素材复用、审核归档，方便编导投手查找内部历史素材
3. 适用阶段：**素材生产完成之后**

缺点：**没有外部行业爆款数据**，看不到同行素材，无法帮你发现新爆款方向。

# 电商团队标准工作流（推荐）
1. **素材洞察工具**：看类目大盘，筛选近7/15天高转化跑量素材，拆解爆款套路 → 输出脚本方向
2. 拍摄/剪辑，产出原创素材
3. **素材库**：上传成品素材，打标签、版本归档，投放调用
4. 投放后，再回到洞察工具复盘：对比自家素材和行业爆款的数据差距，迭代创意

# 团队选型参考
- 小团队，预算有限：先用免费官方洞察工具 **巨量创意 + 电商罗盘**，自建云盘素材库即可
- 投流量大、素材团队多人协作：付费洞察工具（蝉妈妈/有米有数）+ 抖店官方素材库
- 只买素材库不买洞察：编导容易闭门造车，拍出来的素材大概率跑不动；
- 只用洞察、不建素材库：素材资产散乱，历史优质素材无法沉淀复用。

> ⚠️重要提醒：洞察工具里的同行素材**只做创意参考，不要直接下载混剪投放**，有版权风险，同时千川现在重视首发素材，纯搬运/低质混剪起量难度很高。
