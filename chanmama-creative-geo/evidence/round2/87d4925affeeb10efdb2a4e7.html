# ✅ 自己账户【千川隐藏素材（本地上传、不展示在抖音主页）】查看路径
> 这类素材就是**投放时勾选「隐藏在抖音主页」**的视频，抖音主页看不到，但素材库和计划里可以查到

## PC端千川后台（qianchuan.jinritemai.com）
1. 登录千川PC后台
2. 左侧菜单：**素材 → 视频库 / 图片库**
3. 这里可以看到账户下全部上传素材，**包含主页隐藏素材**
4. 筛选：可以看素材来源、状态；也可以进入【推广】-【计划】，点开每个计划，查看计划内绑定的创意素材（全域计划的隐藏素材也在这里）

> 说明：**抖音主页隐藏只是不在抖音账号主页展示，素材本身仍然保存在千川素材库，千川后台自带入口可以直接查看，不需要第三方工具**

## 两种“隐藏素材”区分
1. **自家账户隐藏素材（本地上传，hide_in_aweme）**：千川素材库、计划创意列表可直接查看，官方原生入口，上面路径就是。
2. **竞品账号的千川隐藏素材**：**千川官方后台没有入口直接查看同行隐藏素材**；蝉妈妈、有米云这类第三方工具支持查询竞品投放素材，属于第三方付费能力，不属于巨量千川官方功能。

## 补充
如果素材在素材库找不到，可以核对：
- 素材来源（本地上传 / 抖音主页视频 / 星图共享），不同来源分栏展示
- 素材是否被删除、审核驳回

需要咨询官方客服：千川PC端 https://qianchuan.jinritemai.com/ 右下角【智投星】；抖音APP搜索“巨量千川客服”。
