# 千川投前找同行跑量素材（官方免费优先，第三方做补充）
> 重点：**只借鉴脚本结构、钩子、卖点、镜头逻辑，不能直接搬运下载别人素材上传投放，会侵权、违规、限流**。

## ✅ 官方免费渠道（优先用，数据最准）
### 1. 千川后台｜营销创意榜
入口：巨量千川后台 → 顶部【工具】→【营销创意榜】
- 筛选：类目、时间优先选**近7天**、选择【商品短视频/直播间引流素材】
- 排序：按消耗、播放、CTR、成交GMV排序；优先看**正在持续消耗**的素材（不是老爆款）
- 适合：快速看同赛道正在花钱跑量的广告素材

### 2. 巨量创意（官网）
入口：巨量创意 → 创意灵感 → 千川专区
- 筛选类目、时间，勾选优质素材，可按点击率、转化排序
- 能看到素材完整脚本、画面结构、文案卖点，用来找钩子、话术模板

### 3. 抖店电商罗盘
入口：抖店后台 → 电商罗盘 → 商品榜单 → 短视频榜
- 搜你的产品词/类目，点进单品详情→视频分析，可以看到该商品下所有带货短视频（含千川投流素材），能看到单量、销售额
- 适合盯**单品竞品**的素材矩阵，看同行一条爆品配套了多少条素材

### 4. 巨量百应 创作中心-爆款视频
入口：巨量百应 → 创作 → 爆款视频
- 选类目，时间可设24h/7天，能看新增播放、销售额、出单量，抓最新起量素材

### 5. 巨量云图（极速版可用）
入口：巨量云图 → 内容 → 创意元素洞察/带货短视频诊断
- 看行业爆款素材、人群偏好、高频卖点，还能拆解爆款素材的元素（画面、文案、BGM），适合做投前策略参考

## ✅ 第三方付费工具（找隐藏广告素材，补官方盲区）
> 官方看不到同行隐藏广告（仅投放、不对外公开的素材），第三方工具可以监测
- 蝉妈妈创意、有米云（原新抖）、考古加
- 功能：输入竞品小店/账号/品牌名，添加竞对监控，抓取**正在投放的千川广告素材**；筛选消耗、起量时间，看素材CTR、转化预估；导出素材库批量拆解
- 适合：深度盯固定几个头部竞品，看对方上新素材节奏

## ✅ 手动刷广告（零成本，抓新鲜素材）
1. 抖音APP搜索产品词、痛点词，刷视频，刷到带「广告」标的视频就是千川投放素材
2. 操作技巧：多点击、停留、评论同类广告，系统会给你推更多同赛道广告；建立专门收藏夹
3. 缺点：效率低，数据看不到消耗，只能看画面文案

# 📌 筛选标准：怎么判断这条素材是真·跑量素材（不是虚高）
优先同时满足下面几点：
1. **时间新**：近3～7天起量，不是几个月前的老素材（老素材模型衰退，参考价值低）
2. **持续消耗**：不是爆一天就停，连续几天有增量播放/成交
3. **指标**：3秒完播高、点击率高，有真实成交（只高赞不出单的自然流视频≠千川跑量素材）
4. **素材复用数量**：同一个竞品，**多条素材用同一套钩子/脚本框架**，说明这套模板经过投放验证

# 📌 投前素材拆解流程（找到素材之后）
1. 提取**前3秒钩子**（千川成败核心：痛点、反差、结果前置）
2. 拆解结构：钩子→痛点→产品展示→卖点证明→信任背书→行动指令
3. 记录卖点、字幕、口播、镜头、BGM、场景
4. **二次原创翻拍**，不能直接下载混剪搬运，规避版权与广告审核风险

# ⚠️ 重要红线
1. 直接下载别人广告素材上传千川投放，属于侵权，会下架、扣分、赔偿
2. 广告素材还需要遵守广告法，不要照搬同行违规话术（极限词、虚假承诺）
3. 素材参考只是找方向，**人群、出价、落地页/商品本身**才决定最终ROI
