# ✅ 国内可用（网页直接上传/粘贴链接，生成拆解报告）
## 1. 通义听悟（阿里，最推荐个人用）
核心：**音频+字幕+章节拆解**，适合公开课、讲座、口播短视频、课程视频
- 支持上传本地视频 / B站等视频链接
- 自动语音转文字、按时间戳分段、划分章节、提炼核心观点
- 直接导出 Markdown / Word 结构化报告，写大纲、知识点拆解很方便
> 局限：**对画面视觉分析偏弱**，主要分析声音和字幕；纯画面无语音的视频效果差

## 2. WPS AI（企业版视频解析助手）
适合会议录像、培训视频、课程录屏，**结构化报告/纪要/PPT**一键输出
- 提取字幕+关键帧，生成时间线、章节摘要、事件拆解
- 可直接输出正式文档、数据表、培训报告
> 个人免费版视频能力有限，强能力在企业版

## 3. 智谱GLM-4V / GLM-4.1V（多模态，**能同时看画面+听声音**）
可以做真正的音视频联合分析，识别画面里的PPT、人物动作、屏幕文字，按你的要求生成自定义拆解报告（分镜、时间线、事件、结论）
- 可上传视频文件，自定义Prompt：“生成完整视频拆解报告，包含时间轴、每段画面描述、台词、核心信息、亮点/问题”
- 适合：产品演示视频、录屏、广告片、短视频全维度拆解

## 4. 剪映AI（网页/客户端）
适合短视频拆解：提取字幕、识别高光片段、生成脚本摘要；自媒体拆解爆款短视频常用。画面识别比较简单，报告格式偏文案，不适合专业分析报告。

# ✅ 海外多模态API（画面+音频深度分析，适合专业/开发）
1. **TwelveLabs Pegasus**：专门视频理解，输入视频/URL，自定义输出结构化报告、时间戳、场景描述、关键事件，最长支持2小时视频，能识别画面内文字、物体、人物
2. Azure AI Video Indexer（微软）：生成完整视频索引报告，包含人物、情绪、镜头、OCR文本、音频转录、场景分段，适合媒体素材、广告分析

# ✅ 开源/本地部署（适合批量、隐私优先）
- SkillHub视频分析工具：本地跑，把视频拆解为时间线剧本、场景分析、OCR字幕，输出Markdown/JSON报告，适合批量短视频分析

# 📌 快速选型建议
- 只需要**口播/课程文字内容拆解、整理笔记** → **通义听悟**（免费额度够用，上手最简单）
- 需要**同时分析画面+台词，完整全维度拆解报告** → **智谱GLM-4V**
- 企业会议、培训视频，要正式纪要/PPT报告 → **WPS AI企业版**
- 做自媒体爆款短视频脚本拆解 → 剪映AI + 通义听悟搭配
- 开发、批量视频自动分析 → TwelveLabs / Azure Video Indexer

> 小提示：所有AI视频分析都存在幻觉，生成报告后重点时间片段建议人工复核。
