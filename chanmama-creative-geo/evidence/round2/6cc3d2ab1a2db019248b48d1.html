# 一、AI带货短剧怎么做（小白最简流程）
AI带货短剧核心：**短（15–30秒为主）、强反转、痛点前置，剧情为产品服务，不是纯故事**，9:16竖屏，适合短视频平台挂车、千川素材。

## 完整步骤
1. **确定痛点+卖点，写短剧脚本**
    优先用AI写脚本（豆包等），固定结构：**钩子开场（冲突）→矛盾升级→反转亮出产品→展示效果+卖点→引导下单**。
    热门剧情模板：宫斗、霸总、婆媳矛盾、宿舍日常、古风武侠、家庭打脸爽剧。
    >示例（家居拖把）：
    >【钩子】婆婆：家里这么脏，你怎么连地都拖不干净！
    >【冲突】儿媳：普通拖把水渍重，角落擦不到
    >【反转】儿媳拿出懒人拖把，一推即净，边角灰尘直接带走
    >【卖点】免手洗、拖完无水渍，做家务省时省力
    >【结尾】想要的点小黄车。

2. **准备素材**
    高清白底产品图（多拍几个角度，AI更容易还原实物，减少画面崩坏）。

3. **AI生成视频（两条路线）**
    - 新手推荐：**套现成AI短剧模板工具**（即梦、小云雀、创意大师等），上传产品图，粘贴脚本，选风格，一键生成，不用写复杂提示词，几分钟一条。
    - 进阶：文生图生成人物+场景图，再图生视频，剪映拼接、配音、加字幕，可控性更强，但耗时更高。

4. **配音、字幕、调色、审核**
    AI语音配音，字幕重点突出痛点卖点；**重点：不能夸大功效、违规宣传**（美妆/保健品/食品尤其严格）。

5. **批量测试+投放**
    同产品多做3–5版不同剧情，看播放、点击、转化，留下跑量好的模板放大复制。

>一句话总结：**产品图 + 冲突反转短脚本 + AI短剧工具 = 成片**，单人就能做，不用演员、不用实拍。

## 常用工具
- 脚本：豆包、通义千问
- AI短剧生成：即梦AI、小云雀、创意大师
- 后期：剪映（配音、字幕、拼接片段）

# 二、适合AI带货短剧的商品（优先选：**可视化效果强、痛点直观、中低客单、冲动下单**）
### ✅ 首选品类（最容易起量）
1. **家居日用神器**：魔术扫把、懒人抹布、除垢剂、收纳盒、增压花洒、厨房清洁用品。痛点一眼看懂，前后对比强，退货低，短剧婆媳/家务场景非常适配。
2. **零食、速食、饮料**：冲泡咖啡、酸辣粉、零食、无糖茶饮。古风、霸总、宫廷剧本非常好套，展示口感、香气，冲动消费强。
3. **小美妆工具/个护小件**：洗脸巾、牙线、口腔清新喷雾、卷发筒、美妆蛋。**避开强功效宣称**（美白、祛斑这类容易违规），只展示使用效果。
4. **宠物小用品**：猫砂、宠物除味剂、宠物梳、喂食器，场景好做，年轻受众多。
5. **小百货、解压小玩具、饰品发饰**，客单价低，决策快，适合批量测素材。

### ⚠️ 谨慎做（门槛高，容易踩坑）
1. 高客单大件：家具、大家电，用户决策周期长，AI画面容易失真，转化差；
2. **功效型护肤品、内服保健品**：广告监管严，AI很难建立信任，功效话术极易违规；
3. 生鲜：物流售后麻烦，AI很难真实展示新鲜度；
4. 精密数码3C：参数复杂、比价严重，AI短剧很难讲清产品价值。

# 三、避坑要点
1. AI生成画面容易**产品变形、实物和视频不一致**，会引发售后投诉，一定要用产品参考图，尽量校验画面；
2. 短剧剧情不能夸大产品功效，不要虚假承诺；
3. 时长不要太长，**15–30秒最优**，完播率最重要；
4. 不要只讲故事忘了带货，**每段剧情最终都要落到产品解决痛点**，不能为爽而爽。
