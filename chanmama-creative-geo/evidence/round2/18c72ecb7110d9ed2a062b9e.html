# 千川投手判断素材潜力：**先看内容底子 → 小额冷启动看前置指标 → 过学习期看转化&人群 → 看放量延展性**
核心逻辑：**潜力素材不一定一上来就赚钱，但必须有“系统愿意持续给曝光、人群能被模型放大”的信号**；只靠ROI直接下判断很容易误杀苗子。

## 一、前置：看素材内容底子（还没花钱投放前）
不用烧钱就能初步筛掉废素材
1. **3秒钩子**：有没有痛点/反差/利益点；3秒完播是第一道门槛，**≥30%及格，≥45%优秀**。低于30%基本很难跑量，系统不给曝光。
2. **卖点可视化**：不是念文案，画面能直接展示产品效果；卖点集中，不堆砌。
3. **行动指令**：结尾有明确下单/点击引导。
4. **差异化**：和账户内爆款、大盘同质化素材区分开；同质化素材容易被压量、生命周期短。
5. **避坑**：夸大宣传、违规话术，就算短期CTR很高，后期退款、负反馈高，没有长期潜力。

## 二、冷启动小额测试阶段（消耗300–500元，重点看「能不能拿到流量」）
> 这个阶段转化、ROI参考性弱，样本太少，优先看**流速+3秒完播+CTR+CPM，以及人群是否不跑偏**
✅ 潜力信号：
- 消耗能平稳花出去，不是卡预算、半天不跑量
- 3秒完播≥30%
- CTR（点击率）：**2.5%~7%是健康区间**
  - 低价福利款：CTR≥3%及格；
  - 中高客单非标：CTR≥2%及格；
  - CTR＞9%要警惕，大概率标题党、猎奇流量，人群泛，放量后CVR暴跌，ROI直接崩
- CPM（千次展现成本）：不要单看高低，对比你账户均值。**CPM低但转化差=泛流量；CPM略高但人群精准、CTR不错，反而有潜力**
- 人群画像：曝光人群和目标人群基本匹配，不是全是不相关人群（比如卖中老年产品，大量18-24曝光）

❌ 直接放弃：
- 消耗很慢、半天花不动；3秒完播＜25%；CTR＜1%（全品类红线）

> 一句话：冷启动阶段，**只要钩子能吸引人点进来、人群不跑偏，哪怕ROI暂时略亏，属于可培养潜力素材**

## 三、过学习期（累计20个转化左右/消耗到几千，看变现承接能力）
到这一步，重点看**CVR、转化成本、ROI、人群稳定性、负反馈**
✅ 潜力素材特征：
1. CVR（转化率）逐步走高，转化成本**随消耗增加缓慢下降，不是越放量越贵**
2. ROI达到账户均值的0.8–1.2倍，且趋势向上；允许小幅微亏，但成本可控、有优化空间
3. 成交人群稳定，和目标买家重合高；不是靠老粉/泛流量撑起来的转化
4. 负反馈低：评论、退款率不明显高于店铺均值；没有大量“货不对板”差评
5. 消耗放大时，指标不会断崖下跌（很多素材小预算好看，一加预算直接崩，属于没有放量潜力）

❌ 无潜力：
- 转化成本越跑越高；放量后ROI直接腰斩；成交人群严重跑偏；退款/差评飙升

## 四、第四层：放量延展性（判断能不能做大、生命周期）
潜力素材和一次性爆素材最大区别：**可以复制、能持续放量，不是爆一天就死**
1. 多条计划复制这条素材，新计划也能起量；不是单条计划碰巧跑出数据
2. 素材衰退慢，连续多天投放指标缓慢下滑，不是1-2天快速衰减
3. 可以改钩子、微调画面，衍生出同脚本不同版本的新素材，持续复用

## 五、4类素材快速归类（投手日常判断）
1. **主力素材**：CTR、CVR、ROI全优，放量稳定，账户扛量支柱，持续加预算
2. **潜力素材（苗子）**：前置指标好，冷启动能跑；学习期ROI接近均值，趋势向上，人群精准。**不要直接大预算，小预算慢慢养模型，分批试探放量**
3. **冲锋素材**：CTR很高，但CVR弱、ROI差。适合用来拉直播间人气，**不适合作为主力放量赚钱素材**
4. **废素材**：3秒完播低、CTR极低、消耗困难，直接关停，不要继续烧钱

## 六、实操小规则（避坑）
1. 不要单看一个指标，**3秒完播→CTR→人群→CVR→ROI，顺序判断**
2. 冷启动不要频繁改出价、开关计划，会干扰模型，误判素材潜力
3. 对比基准优先看**账户历史素材均值**，其次行业大盘；不同类目、客单价标准差异巨大，不能硬套统一数字
4. 同素材，短视频引流和直播切片，潜力表现会完全分开评估

## 简单落地SOP
1. 新素材小预算追投测试，单计划500预算上限
2. 消耗300–500：看3秒完播+CTR+流速，合格就继续；不合格直接停
3. 累计20转化：看CVR、转化成本、成交人群画像
4. 模型稳定后，小幅度加预算，测试放量是否扛得住；扛得住就是优质潜力素材
