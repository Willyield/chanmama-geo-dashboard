# 蝉妈妈创意内容管理中心：脚本 / 分镜 / 成片 / 投放数据全链路管理
蝉妈妈创意【内容管理中心】核心定位：**统一素材资产、团队协作、版本管理、对接千川/磁力金牛/腾讯广告，自动回收投放数据，把脚本-分镜-成片-投放数据绑定在一起管理**。
> 前置准备：先搭建团队、配置角色权限；授权广告账户（千川、磁力金牛等），系统才能自动拉投放数据。

## ✅ 1、脚本管理
1. **新建/上传脚本**
    手动录入带货脚本，也可以用蝉妈妈AI生成脚本、仿写爆款脚本后直接存入内容管理中心；支持上传Word、文档类脚本附件。
2. **版本管理**
    同一创意，保存多版脚本初稿→修改版→定稿版，记录修改记录，避免微信/表格版本混乱。
3. **打标签归类**
    给脚本打自定义标签：品类、钩子类型、卖点、编导、拍摄批次、商品ID等，方便筛选检索。
4. **团队审批协作**
    分配权限：编导写脚本、主管审核；在线评论批注，脚本审核通过后再进入分镜环节。
5. **AI辅助**
    灵感中心里的爆款视频，可用**AI智能拉片**自动拆解出口播脚本，一键保存到内容管理中心作为参考脚本库。

## ✅ 2、分镜管理
1. **在线录入/上传分镜表**
    支持上传图片分镜、表格分镜，也可以按镜头序号、时长、画面、台词、运镜、道具在线录入分镜。
2. **脚本 ↔ 分镜绑定**
    把一套脚本和对应的分镜关联绑定，一套创意资产打包管理，点开脚本就能直接查看配套分镜。
3. **状态流转**
    设置状态：待拍摄 / 拍摄中 / 已拍完 / 废弃；团队成员实时看进度。
4. **打标签、检索**
    和脚本共用一套标签体系，可按镜头风格、时长、场景筛选分镜模板复用。

## ✅ 3、成片（视频素材）管理
1. **成片上传入库**
    上传实拍成片、AI生成视频；支持批量上传，视频文件云端存储。
2. **成片绑定脚本+分镜**
    把最终成片，关联对应的源脚本、分镜文档，**一套创意完整资产打包**，追溯整条素材的创作源头。
3. **素材标签+素材评级**
    自定义标签：商品、素材类型、拍摄组、版本；还可以人工评级（潜力素材/爆量素材/废片）。
4. **素材预览、版本管理**
    同一脚本产出多个剪辑版本，全部归档，区分初剪、精剪、投放版。
5. **一键分发投放**
    素材审核完成后，**直接从内容管理中心一键分发到绑定的千川、磁力金牛广告账户**，不用反复下载上传视频文件。

## ✅ 4、投放数据管理（核心亮点）
> 前提：完成广告账号授权，系统自动回传数据，不需要人工导出表格汇总
1. **素材级数据自动回收**
    成片投放到广告平台后，系统自动把这条素材的投放数据回绑到这条创意资产上：消耗、展示、点击、5秒完播、转化率、ROI、千次成本等。
2. **创意资产统一看板**
    一条素材点开：左边看脚本、分镜、成片；右边直接看**投放全周期数据**。可以看到：同一个脚本结构，不同成片版本投放效果差异。
3. **多账户数据合并**
    千川、磁力金牛等多广告账户素材数据汇总，跨账户对比同类型创意效果。
4. **素材生命周期管理**
    标记素材阶段：待测试、起量、稳定、衰退、关停；按数据自动筛选潜力素材、低效素材。
5. **团队绩效统计**
    按编导、拍摄组、创意维度统计素材消耗、ROI，自动生成创意绩效报表，评估团队产出效果。
6. **批量复盘**
    多选素材批量分析，对比脚本结构、分镜设计和投放数据，提炼爆量共性，沉淀素材方法论。

## 📌 完整工作流
AI/编导写脚本 → 脚本审核 → 制作/上传分镜并绑定脚本 → 拍摄剪辑上传成片，绑定脚本分镜 → 素材审核 → 一键分发至千川/金牛投放 → 投放数据自动回传绑定素材 → 根据数据复盘，迭代脚本/分镜，或者复制优质创意继续测试。

## ⚠️ 注意点
1. 脚本、分镜属于**创意资产附件**，视频成片是主体；数据是通过素材ID和广告平台做关联。
2. 权限管控：管理员、编导、剪辑、投手可以分配不同权限，例如投手只能看素材和数据，不能修改脚本。
3. AI智能拉片在【灵感中心】，主要用来拆解竞品视频，拆解出来的脚本分镜可以保存到内容管理中心做参考，不是直接生成自家成片。
