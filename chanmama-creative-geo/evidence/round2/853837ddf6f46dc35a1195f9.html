# 千川投放前找同行跑量素材（官方渠道优先，第三方辅助）
> 核心原则：**优先看消耗、转化、3秒完播，不要只看点赞；只能借鉴脚本结构、卖点、镜头逻辑，严禁直接下载盗用视频，会侵权、违规限流**

## ✅ 官方免费渠道（最靠谱，优先用）
### 1. 千川后台【营销创意榜】
入口：千川PC后台 → 工具 → **营销创意榜**
- 筛选：选择类目、时间（优先**近7天**，短周期代表当下能跑；长品可看15/30天）
- 排序：按消耗、CTR、CVR、3秒完播排序，直接看千川广告素材，是已经花钱跑起来的素材，不是自然流视频
- 适合：快速看同品类近期主流素材形式、卖点、时长

### 2. 巨量创意（官网）
入口：巨量创意 → 创意灵感 → **巨量千川专区**
- 筛选类目、时长、指标：点击率、转化热度、完播；可以搜产品关键词，大量同行千川广告素材
- 优势：官方广告素材库，能直接看视频+标题文案，适合拆解脚本框架

### 3. 巨量云图（需要开通）
入口：巨量云图 → 内容 → **带货短视频诊断 / 内容创意锦囊**
- 可以看行业优秀商家素材、行业主流卖点、人群标签；能看到同行素材宣传角度，知道这个品类用户吃什么痛点
- 推荐筛选行业前25%-50%商家素材，头部太强很难复刻，中段爆款参考价值最高

### 4. 抖店电商罗盘
入口：抖店后台 → 市场 → 商品榜单/内容榜单
- 找到同类爆品，点商品详情，查看**视频分析**，看到该商品下所有带货短视频（千川投流素材+达人素材），能看到成交数据

### 5. 抖音APP手动刷广告（零成本）
1. 抖音搜索：产品词、痛点词、场景词（比如：腰突护腰带、厨房去油污）
2. 刷到带「广告」标识的视频，就是千川在投素材；长按视频选择**不感兴趣以外的操作**，多刷同类，系统会推更多竞品广告
3. 收藏素材，重点记录：前三秒钩子、痛点、产品演示、结尾转化话术

## ✅ 第三方付费工具（快速定向监控竞品店铺）
蝉妈妈创意、有米云、考古加等
- 功能：输入竞品店铺/商品名，监控该店铺**正在投放、历史跑量**的千川素材；看预估消耗、出单、脚本，支持按时间筛选新素材
- 适合：重点盯2-5个核心竞对，看对方上新素材节奏；缺点是数据为估算值，不是官方真实后台数据

## ✅ 找到素材后，标准拆解步骤（投放前必做）
1. 筛掉老素材：优先保留**7天内新起量素材**，老爆款大概率衰退
2. 拆解4个核心：
   - 3秒钩子：用什么痛点/反差/效果抓住人
   - 卖点顺序：先讲什么、演示什么、佐证什么
   - 拍摄形式：口播、实景测评、对比实验、开箱、剧情
   - 转化引导：结尾怎么逼单、引导下单
3. 归类：把素材分成几个模板（测评类、痛点口播类、效果对比类），**翻拍原创，不要直接搬运**

## ⚠️ 重要红线（一定要注意）
1. **禁止直接下载同行素材上传千川**，侵犯著作权，会违规下架、扣分、索赔；只能借鉴思路翻拍
2. 区分：**广告素材（带广告标）才是千川跑量素材；高赞自然流视频不一定能投千川**，自然流逻辑和付费流量逻辑不一样
3. 不要盲目追头部素材：头部商家有账号权重、人群积累，中小商家优先参考同层级竞对

## ✅ 快速工作流推荐（新手）
巨量创意 → 千川营销创意榜 → 抖音刷广告收集 → 用蝉妈妈/考古加盯2-3个核心竞品 → 拆解脚本，批量翻拍测试
