# ✅ 抖音官方素材库入口（免费版权素材）
> 抖音APP本身没有内置素材库，**剪辑素材库在剪映**（抖音官方剪辑工具，素材可直接用于抖音发布）
1. **剪映手机端素材库（最常用）**
打开剪映 → 点【开始创作】→ 顶部找到**素材库**
里面有：视频片段、背景、转场、音效、BGM、图片；支持筛选竖屏/横屏、图片/视频，可直接搜索关键词，**大部分免费版权可商用**。

2. **抖音创作者中心｜创作灵感（找选题、爆款文案、热门话题）**
抖音主页右上角 ≡ → **抖音创作者中心** → **创作灵感**
看：热门选题、粉丝爱看、热门话题、爆款脚本思路，适合找内容灵感，不是视频素材文件。

3. **巨量创意（电脑网页，广告/带货爆款素材案例）**
官网：cc.oceanengine.com
适合做带货、投流，筛选行业、7/30天热门素材，看爆款广告案例，学习脚本框架，**不能直接搬运**。

4. **二创片单（影视剪辑专用）**
抖音搜索【抖音二创片单】，平台授权可二次剪辑的影视剧素材，仅限片单内作品，避免侵权。

5. **抖店素材库（电商商家）**
抖店后台 → 商品→商品素材→素材库，用于商品主图、详情、店铺装修素材管理。

# 🔥 怎么找爆款素材（4个方法）
> ⚠️重要提醒：**不要直接下载搬运别人视频！容易违规限流**，只学习脚本、镜头、节奏、文案结构，自己翻拍/二次创作。

## 方法1：抖音内搜索找自然流爆款（免费）
抖音顶部放大镜搜索：你的行业关键词，例如“居家收纳”
筛选：**视频，最多点赞，近7天**
重点看：3秒开头钩子、字幕、BGM、评论区痛点，保存对标视频收藏分析。

## 方法2：创作者中心 / 抖音指数看榜单
创作者中心 → 抖音指数，查看**热点榜、视频热榜**，看当下平台热门内容方向。

## 方法3：电商带货专用（商家）
- 电商罗盘：商品榜单→短视频榜，看同行带货爆款视频，看播放、成交数据
- 巨量创意/千川后台营销创意：看付费广告爆款素材，高点击率素材参考

## 方法4：第三方工具（付费，进阶）
蝉妈妈、新抖、有米云等，可以按类目筛选7/30天爆款视频，查看完播、点赞、转化数据，适合批量找对标。

# 📌 避坑要点
1. 剪映素材库的素材，**版权合规**，直接拿来剪辑发抖音没问题。
2. 别人发布的抖音视频，**没有授权不能直接下载使用**，会侵权、限流、下架。
3. 爆款核心不是素材画面，是**开头钩子+痛点文案+节奏**，模仿框架，画面尽量实拍或用剪映正版素材。
4. 巨量创意里面是**案例参考**，不是下载素材库。
