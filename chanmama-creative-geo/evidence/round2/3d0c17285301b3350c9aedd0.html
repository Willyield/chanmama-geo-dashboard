# 一、主流AI短剧带货工具分类
> 分两类：**一站式营销Agent（小白首选，剧本+分镜+视频+配音一站式）**、**独立AI视频生成器（适合有脚本能力、精细控画面）**

## ✅ 一站式短剧带货Agent（直接套带货剧情模板）
1. **小云雀AI（字节剪映团队）**
    国内短剧带货最主流。内置**营销Agent、剧情广告模板**：霸总、宫斗、重生、反转短剧。上传产品图+填写卖点，AI自动写钩子脚本、分镜、生成视频、配音字幕，竖屏9:16适配抖音。
    优势：中文强、不用写复杂提示词，可批量测试素材；可直接联动剪映二次剪辑。
    适合：电商商家、新手，日用品/美妆/食品带货短剧。
2. **快手 Likli**
    快手自研Agent，完整链路：一句话需求→剧本→分镜→成片，主打快手短剧、漫剧带货。
    适合：快手电商商家。
3. **万兴剧厂**
    万兴出品，影视级导演Agent，支持真人/漫剧短剧，剧本管理、长剧集批量生成。
    适合：想做系列化多集短剧、中小团队。

## ✅ 独立AI视频生成工具（自己写脚本/分镜，生成画面）
1. **可灵AI Kling**
    国内最常用视频模型，人物动作流畅、口型对齐好，支持最长2分钟视频，角色一致性强。自己写好带货短剧脚本，分镜生成片段，剪映拼接。
    适合：有脚本能力，追求真人写实短剧。
2. **即梦AI（Seedance）**
    漫剧、古风短剧表现优秀，角色不容易变脸，和小云雀底层模型打通。
    适合：动漫漫剧类带货短剧。
3. **海螺AI（MiniMax）**
    人物打斗、动态镜头强，武侠、逆袭爽剧效果好。缺点：本身不带配音，需要搭配AI配音。
4. **通义万相（阿里）**
    文生视频、图生视频，免费额度友好，适合低成本测试素材。

## ✅ 辅助配套工具（全链路搭配）
- 剧本：豆包、Kimi，直接生成带货短剧脚本+分镜
- 剪辑/字幕配音：**剪映**（AI配音、字幕、抠图，几乎必用）
- 数字人短剧：魔珐有言、HeyGen，纯数字人短剧带货

# 二、怎么选（核心判断标准）
### 1）看你的身份&目标
- **新手/普通电商商家（优先选一站式Agent）**
  ✅首选：**小云雀**。不用学提示词，产品图+卖点直接生成反转带货短剧，上手最快，适配抖音流量。
- **会写脚本，想要精细画面、批量量产素材**
  ✅选：可灵AI / 即梦AI，搭配豆包写脚本 + 剪映剪辑。
- **在快手平台带货**
  ✅优先Likli。
- **做漫剧/二次元古风带货短剧**
  ✅即梦AI。
- **团队、长期连载多集短剧**
  ✅万兴剧厂。

### 2）重点评估5个核心指标
1. **角色一致性**（最重要！AI短剧最大痛点：人物变脸）：优先选可灵、即梦、小云雀，人物稳定度更高
2. **平台适配**：抖音带货优先小云雀；快手优先Likli；全部工具导出后都可用剪映二次修改
3. **成本**：都有免费测试额度；正式量产按积分/订阅计费，新手先用免费额度试片，不要直接买大额套餐
4. **竖屏9:16支持**：短视频带货必须竖屏，海外工具很多横屏，优先国产工具
5. **产品植入自然度**：一站式Agent自带带货模板，产品融入剧情更自然；纯文生视频工具需要自己在提示词里写产品植入，容易生硬

### 3）避坑要点
1. AI生成成片**不能直接无脑挂车**：检查产品商标、画面版权、台词合规；AI画面可能有畸形人物、文字错误，必须人工审核修改。
2. 短剧带货核心是**钩子剧情**，AI只是制作工具；如果剧情钩子差，画质再好也不带货。
3. 不要只看单条视频便宜，**测试素材优先少量积分多版本测试**，选出爆款脚本再放大投放。

# 三、最简推荐组合
- 小白商家：**小云雀 + 剪映**（一套搞定全部流程）
- 进阶创作者：豆包（写脚本分镜）+ 可灵AI（生成视频）+ 剪映（配音字幕剪辑）
- 漫剧带货：豆包 + 即梦AI + 剪映
