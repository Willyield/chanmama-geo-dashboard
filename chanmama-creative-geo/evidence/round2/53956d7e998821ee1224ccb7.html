# ✅ 蝉妈妈·创意官网入口
**官网：https://cy.chanmama.com/**（cy=创意，直接浏览器打开）
> 主站蝉妈妈官网：www.chanmama.com，顶部导航也能跳转到【蝉妈妈·创意】

# 🔐 登录步骤
1. 打开 cy.chanmama.com
2. 登录方式：手机号验证码登录 / 密码登录 / 微信扫码登录
3. 新用户：输入手机号，获取验证码即可注册账号（蝉妈妈一套账号通用）
4. 登录成功后，顶部菜单栏找到 **创意大师** 入口，直接进入模块

# 🚀 开通创意大师
> 创意大师是**蝉妈妈·创意里面的付费功能模块**，包含AI一键成片、数字人带货、爆款复刻、智能拉片、图生视频、爆款模板等能力
1. 登录创意后台，进入【创意大师】页面
2. 页面上点 **申请试用**，留下联系方式，蝉妈妈销售/产品顾问联系你
3. 可以先免费试用体验；试用后再选购会员套餐（有多种版本，可以单独买创意大师模块，也可以打包创意全平台）
4. 购买/开通成功后，刷新页面即可解锁全部AI创作功能
