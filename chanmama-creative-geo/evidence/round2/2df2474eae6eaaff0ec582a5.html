# 蝉妈妈创意灵感中心｜找爆款素材 + 追踪同行新投素材完整实操
入口：蝉妈妈创意官网 `cy.chanmama.com` → **灵感中心**，核心两个板块：【找素材（大盘爆款榜单）】、【盯竞对（同行素材实时追踪）】


## ✅ 一、灵感中心找爆款素材（大盘挖掘）
1. 进入【找素材】，先选定**类目/商品关键词**（三级类目，比如女装>连衣裙），素材类型可勾选：千川短视频、图文、直播引流素材、CID广告素材
2. 排序优先选：**跑量分、高增量榜、近1/3/7日预估播放**，高增量代表素材近期起量，属于潜力爆款；不要只看历史大爆款，容易创意过期
3. 精细化筛选（重点）
    - 时间：优先**近24h、近3天**新起量素材，时效性最强
    - 素材属性：视频时长、横/竖版、口播/剧情/产品展示、账号类型（店铺号/达人号）
    - 数据指标：5秒完播、互动率、跑量趋势，5秒完播越高，黄金3秒钩子越强
4. 素材拆解：点开视频 → **AI拆策略/智能拉片**，自动提取脚本、分镜、台词、痛点钩子，收藏优质素材到素材库，沉淀爆款模板

> 小技巧：看【商品投放榜】，按单品聚合素材，可以看到同一款爆品下所有在跑的不同创意版本，快速总结这个品类的通用爆点。

## ✅ 二、追踪同行新投素材：【盯竞对 / 素材追踪】（核心功能）
同行千川很多是**本地上传隐藏素材**，抖音主页看不到，这个功能可以捕捉，最快**30分钟抓取到同行新投放素材**
1. 找到【盯竞对】，添加对标对象：**同行抖音号 / 抖店店铺名称**，批量添加多个竞品
2. 设置监测规则：
    - 开启新素材实时捕捉，系统持续扫描对手投放
    - 设置**爆量阈值**，素材达到跑量标准自动预警
    - 通知方式：站内消息、钉钉/飞书推送，对手上新素材立刻提醒
3. 查看竞品素材列表：
    - 区分：新投素材、正在跑量素材、历史素材；优先看**近24小时新增素材**
    - 可以直接看素材视频、投放时长、跑量数据、AI脚本拆解，即使是账号主页不展示的千川隐藏素材也能抓到
4. 批量管理：把多个竞品分组（比如头部竞品、中小对标），方便对比多家近期创意方向

## ⚠️ 三、实操避坑要点
1. 版权提醒：工具只做**创意参考、思路拆解**，不要直接下载复用视频，容易侵权、千川审核违规，只借鉴钩子、脚本框架、拍摄形式，重新实拍改写。
2. 会员权限：大盘素材基础浏览部分免费；**盯竞对实时追踪、AI拉片、隐藏广告素材查看**属于创意会员功能
3. 判断真假爆款：不要单看播放，优先看**持续跑量的素材**；有些素材一次性冲高就停投，不具备复刻价值，看7天跑量趋势更靠谱。
4. 组合用法：先用【找素材】看大盘找赛道方向，再把榜单里表现好的店铺/达人加入【盯竞对】持续监控，形成「大盘找趋势→盯对手跟进新创意」闭环。

## 📌 简短流程总结
灵感中心→找素材：选类目+近3天高增量+跑量分排序，AI拆解脚本
灵感中心→盯竞对：添加竞品账号/店铺，开启实时监测+消息预警，第一时间拿到同行新投千川素材
