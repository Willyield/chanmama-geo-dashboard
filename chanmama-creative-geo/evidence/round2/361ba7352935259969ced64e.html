# 一句话总结
**蝉妈妈（蝉妈妈数据）：全域电商大盘数据分析工具，看销量、GMV、达人、直播间、商品大盘；**
**蝉妈妈创意：千川投流素材专项平台，专门找广告跑量素材、拆解创意、AI批量做带货短视频**，同一家公司，但两个独立产品，会员分开购买。

## 一、蝉妈妈（蝉妈妈数据）核心能力
定位：**直播电商大盘数据洞察，做生意决策**
1. 达人分析：查带货达人GMV、粉丝画像、历史直播业绩，筛选达人合作
2. 商品&选品：商品销量榜、爆品趋势、看哪些达人在带这款货、品类大盘热度
3. 直播监控：竞品直播间预估GMV、在线人数、流量结构、直播回放、整场转化数据
4. 店铺/品牌分析：看竞品抖店、品牌整体带货体量
5. 自然流短视频：挂车短视频的自然流量、带货数据

✅ **适合场景**
- 达人/商家**选品、找达人合作、竞品直播间监控、大盘趋势调研**
- 做自然流直播、自然流短视频带货，看整体生意大盘
- 运营、商务、操盘手做选品、达人对接、直播复盘
> 适合：想知道**谁卖得多、什么品爆、直播间卖多少**

## 二、蝉妈妈创意核心能力
定位：**千川广告素材洞察+AI创意生产，专门服务付费投流**
1. 千川跑量素材库：抓取竞品正在投放的付费广告短视频（很多蝉妈妈主站看不到的投流素材），按跑量分、增量筛选
2. 素材拆解：AI智能拉片，提取爆款脚本、钩子、卖点、画面结构，分析爆款创意元素
3. AI创作工具：一键成片、脚本仿写、数字人带货、字幕处理、批量生成多版本带货素材
4. 竞品投放追踪：定向监控竞品品牌/小店的上新广告素材，看对方投流节奏

✅ **适合场景**
- 千川投流团队：找广告素材灵感、盯同行投放素材、持续迭代短视频素材
- 短视频素材编导、剪辑团队，批量生产带货广告片
- 品牌付费投放，做素材测试、创意迭代，解决素材枯竭问题
> 适合：想知道**同行正在投什么广告素材、怎么写脚本、快速产出投流视频**

## 三、快速对比
|项目|蝉妈妈（数据版）|蝉妈妈创意|
| ---- | ---- | ---- |
|核心重心|**大盘销售、直播、达人、商品数据**|**千川广告素材、创意拆解、AI视频制作**|
|数据侧重|自然流+直播带货GMV、销量、达人业绩|付费投放广告素材、素材跑量表现|
|产出物|数据报表、榜单、达人/商品分析报告|短视频广告灵感、脚本、AI成片|
|人群|直播操盘手、选品、商务、MCN达人运营|投流手、短视频编导、素材剪辑团队|

## 四、怎么选
1. **只做直播、自然流带货、选品、找达人** → 只买蝉妈妈（数据）即可
2. **主要投千川，缺短视频广告素材，大量拍投流视频** → 重点买蝉妈妈创意
3. **品牌同时做直播+千川投流，既要大盘数据又要素材** → 两个会员一起搭配使用（分开订阅）
