# ✅ 巨量千川官方素材库（4个核心入口）
## 1、千川后台【我的素材/视频库】（你账户自己上传的素材）
PC千川后台 → **工具 → 创意管理 → 视频库**
- 看自己账户所有图片/视频素材，自带**优质素材、首发素材标签**，能看素材状态、审核、关联的计划、衰减情况
- 数据→素材分析，也能看素材消耗、CTR、CVR等投放数据

## 2、千川后台【营销创意榜】（看同行千川跑量广告素材，官方灵感库）
PC千川后台 → **工具 → 营销创意榜**
- 筛选类目、时间、推广目标，看千川广告爆款素材，附带基础投放指标，适合找同赛道跑量脚本框架

## 3、巨量创意（独立网站，最常用的千川素材灵感库）
官网：巨量创意 → **创意灵感 → 热门素材 → 巨量千川专区**
- 筛选类目、时长、时间、热度，大量千川广告素材，支持素材预审，看广告创意、封面、文案参考

## 4、巨量云图（侧重人群+创意元素拆解）
巨量云图 → 内容 → **内容创意锦囊 / 创意元素洞察**
- 不止看视频，还能拆解爆款素材的卖点、镜头、话术，匹配目标人群画像，适合深度拆解创意逻辑

> 补充：巨量百应创意中心、抖店罗盘短视频带货榜，也可以看带货爆款素材，很多是自然流爆款，可转化成千川素材

# 📌 第三方工具（蝉妈妈、有米云、新抖等）能补充什么？
> 官方素材库局限：只能看巨量广告池里公开素材；数据维度偏少、跨平台弱、批量拆解弱。第三方付费工具做补充：
1. **更广的素材检索**
   同时抓**千川广告素材 + 抖音自然流挂车短视频 + 达人切片素材**，跨类目、跨店铺、跨时间检索，能挖到官方创意榜没有的素材。支持按商品ID、品牌、达人搜对标素材。

2. **深度素材拆解**
   自动提取视频**字幕、脚本、卖点、BGM、镜头时长**；识别封面文案、钩子类型，批量导出脚本表格，省去人工逐字转录。

3. **更细的投放数据维度**
   预估消耗、预估销量、评论词云、受众画像，判断素材是“短暂爆量”还是稳定长期跑量；还能追踪素材生命周期，看什么时候起量、什么时候衰减。

4. **素材监控与告警**
   监控竞品店铺/达人，**新上广告素材实时提醒**，第一时间抓到对手新起量素材；批量收藏、建立竞品素材库。

5. **素材生产辅助**
   AI混剪、AI生成脚本、素材查重（检测素材重复度，规避非首发、同质化）、预审参考、批量封面生成。

6. **跨平台素材参考**
   抓取快手、小红书等平台同类目爆款，拿来做创意灵感，官方工具只有抖音/千川体系内素材。

## ⚠️ 重要提醒
1. **素材仅作创意参考、学习框架，严禁直接下载盗用他人广告素材投放，会侵权、违规、限流**，只用来借鉴结构、钩子、卖点逻辑，必须翻拍重制。
2. 第三方数据是**估算数据**，不是巨量官方真实后台数据，只能做参考，不能替代千川后台真实投放数据。
3. 首发素材、优质素材标签，**以千川后台视频库为准，第三方无法识别官方首发判定**。
