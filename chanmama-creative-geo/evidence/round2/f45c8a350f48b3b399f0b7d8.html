# ✅ AI带货视频 新手完整做法 + 需要准备的素材
新手优先做**数字人口播带货**或者**产品画面混剪**，不用自己真人出镜、不用买样品，手机就能搞定，短视频平台统一用 **9:16竖屏**，时长推荐 **15–30秒**，完播最好。

## 一、需要准备的素材（4大类）
### 1. 产品素材（最重要）
- 白底产品图（正面、侧面、细节特写、使用效果图，优先商家详情页原图，画质越高越好）
- 产品卖点图：对比图、使用前后效果图、尺寸、功能细节截图
> 注意：尽量拿到商家授权，不要直接盗同行视频素材，避免侵权违规

### 2. 文案&脚本素材
带货短视频万能脚本模板（直接给AI）：
> 0–3秒钩子（痛点）→ 产品出场 → 2–3个核心卖点 → 效果展示 → 价格+下单引导

需要整理信息：
- 用户痛点（比如：抹布掉毛、保温杯不保温）
- 产品3个核心卖点（不要太多，新手控制3个以内）
- 规格、价格、优惠、适合人群
- 结尾引导话术（点击小黄车/左下角）

> 可以直接丢给AI，让AI生成口播文案+分镜脚本

### 3. 音频素材
1. 口播文案（AI配音用）
2. BGM背景音乐：选无版权商用轻音乐/带货BGM（剪映素材库免费可用）
3. 音效（可选：开箱声、水流声、咔嚓声，增加真实感）

### 4. 包装素材
- 字幕关键词贴纸（价格、卖点大字，比如“限时特价”）
- 箭头、高亮框、贴片素材（剪映自带）
- 数字人形象（工具内置，不用自己准备）

## 二、制作流程（新手最简版）
1. **写口播脚本**
把产品痛点、卖点发给AI，生成15–30秒口播文案，精简口语化，不要书面长句子。
2. **AI配音 / 数字人生成口播画面**
方案A（数字人口播）：打开数字人工具，选人物形象，粘贴文案，生成口播视频，导出视频+音频。
方案B（纯产品画面）：用产品图片，AI生成动态镜头（图生视频）。
3. **生成产品镜头素材**
白底图导入AI图生视频，生成：产品旋转特写、使用场景画面。
4. **剪映合成（核心后期）**
把数字人片段、产品动态镜头拼在一起；
自动字幕、加粗重点卖点；配上BGM，加转场、高亮文字；
调整音量：人声为主，背景音乐音量压低。
5. **预览+导出 9:16 1080P，发布挂商品链接**

## 三、新手推荐工具（低成本）
- 文案脚本：豆包，直接写带货口播、分镜、提示词
- 数字人：剪映数字人、各类AI数字人工具
- 图生视频：剪映AI、即梦等
- 剪辑：剪映（免费，新手首选）

## 四、新手避坑重点
1. 版权：**不要直接下载别人带货视频拿来混剪**，容易限流、侵权；优先商家原图，AI生成画面
2. AI画面容易畸形：产品特写尽量用原图，少完全文生产品，防止产品变形失真
3. 文案不要太长，语速控制自然，字幕重点词放大，提升转化
4. 不要全片只有数字人，**一定要穿插产品实拍/产品特写镜头**，转化率更高

## 五、极简示例脚本（卖垃圾袋，直接复制给AI）
> 【0-3s钩子】垃圾袋一拉就破，太闹心！
> 【3-12s卖点】这款加厚垃圾袋，承重强，不容易破，抽绳设计一提就走，不脏手。
> 【12-22s场景】厨房剩汤、果皮直接装，家用、卫生间都能用。
> 【22-30s引导】今天价格划算，点左下角小黄车直接带走！
