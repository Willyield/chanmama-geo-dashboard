# 商品图生成带货短视频2种方案（小白优先）
> 短视频平台默认 **9:16竖屏**，时长建议 **10–20秒**，核心逻辑：图片+运镜+带货脚本+AI配音+字幕+BGM

## ✅方案1：剪映（免费，最推荐，可控性强）
适合：多张商品主图/细节图，做图片滑动、推拉运镜，纯图文带货视频
1. **准备素材**
   商品图：主图、细节图、使用效果图、对比图，图片高清，主体清晰，尽量白底/干净背景；
2. **导入图片**
   打开剪映 → 开始创作，选中商品图，比例改成9:16；
3. **图片动起来（关键）**
   选中图片，添加**关键帧**：开头放大，结尾缓慢平移/推拉，模拟镜头缓缓扫产品；也可以直接用「图片动画」：放大、缓慢移动、渐显；
4. **写带货脚本（15秒模板）**
   - 0-3s钩子（痛点）：夏天出油多？这款控油洁面巨好用！
   - 3-10s讲卖点：泡沫绵密、温和不紧绷，洗完不拔干
   - 10-15s引导下单：现在入手划算，直接小黄车带走
5. **配音+字幕+BGM**
   文本→粘贴脚本→**文本朗读**，选带货人声；自动字幕识别，检查错别字；添加轻音量热门BGM（音量低于配音）
6. 导出1080P，挂车发布

## ✅方案2：AI一键成片（最快，抖店AI智能成片 / 美图设计室等）
适合：只有1张商品图，不想手动剪辑，批量快速产出
### 抖店AI智能成片（电商商家首选）
1. 抖店APP → 流量渠道 → 短视频运营 → AI智能成片
2. 选择商品，系统自动抓取商品图，最多上传5张
3. 选择视频类型：**商品讲解 / 商品展示**
4. 填写产品卖点，提交生成，几分钟出片，可直接一键发布挂车

### 其他AI工具（美图设计室、可灵等）
1. 上传商品图
2. 输入提示词示例：
> 9:16竖屏，15秒带货短视频，缓慢环绕展示产品，清晰展示外观细节，生活化干净背景，AI配音讲解卖点，带字幕，电商带货风格，画面真实自然
3. 生成后二次修改字幕、配音，导出

## 📌图片素材优化要点（直接影响视频效果）
1. 图片主体居中，产品不要被裁切；
2. 尽量多准备：主图、细节、使用场景、前后对比图，镜头更丰富；
3. 不要大量使用网图，避免版权违规，优先自己实拍原图；

## ⚠️避坑提醒
1. AI生成视频容易出现产品变形、颜色失真，生成完**一定要核对产品**；
2. 字幕不要挡住商品主体；
3. BGM音量调低，保证人声清晰；
4. 平台审核：不要夸大功效、极限词（最、第一、100%）
