# 千川投放前找同行跑量素材（官方免费工具优先，第三方辅助，核心看**消耗/跑量分**，不是点赞）
> 重要提醒：**只能借鉴脚本框架、卖点、镜头逻辑，不能直接搬运、翻拍一模一样视频，会侵权、违规限流**。

## ✅ 一、官方免费渠道（优先用，数据最真实）
### 1. 巨量创意（最推荐，千川专区）
进入官网，选择【千川广告素材专区】
筛选条件：你的类目、时间**7天/15天**（优先短期，代表还在持续消耗）、按消耗/CTR/CVR排序。
可以直接看同行正在投放的广告短视频、图文素材，看他们的前三秒钩子、卖点结构、转化话术。

### 2. 千川后台 → 营销创意板
千川后台工具板块，营销创意看板，筛选行业爆款素材，直接看素材的点击率、转化、消耗数据，是千川官方的素材库。

### 3. 电商罗盘（抖店后台）
电商罗盘 → 商品榜单 → 短视频榜，选择你的类目/对标商品，查看爆款带货短视频。
可以看到商品对应的引流素材、出单素材，找到竞品店铺跑量短视频。支持添加竞对店铺监控，追踪对手上新素材。

### 4. 巨量云图（有云图权限才可用）
内容→带货短视频诊断/创意元素洞察，选择行业，能看到同行素材高频卖点、拍摄场景、镜头模板，拆解行业爆款共性，适合提炼卖点和脚本结构。

### 5. 抖音APP原生刷广告（零成本）
1. 抖音搜索你的**产品词、痛点词**，比如“去黄牙膏”“厨房油污清洁剂”
2. 多看同类带货视频，刷到带【广告】标识的就是千川投放素材
3. 多停留、点击小黄车，算法会持续推同类竞品广告素材
> 缺点：无法看到消耗数据，只能肉眼判断素材形式。

## ✅ 二、第三方付费工具（快速盯竞对，适合深度调研）
蝉妈妈创意、有米云、考古加、新抖这类，核心功能：
1. 输入竞品店铺/账号，**监控竞对千川素材**，区分直播间引流素材、商品广告素材、商品卡素材
2. 有**跑量分、消耗趋势**，快速筛出持续花钱的素材（重点！高消耗才是真跑量，高赞自然流没用）
3. AI自动拆脚本、分镜、提炼卖点，批量导出对标素材库

> 适用场景：需要持续盯竞品、批量收集素材、找竞品隐藏广告素材；新手可以先用免费官方渠道。

## ✅ 三、筛选跑量素材的判断标准（避坑重点）
**不要看点赞、评论！千川广告素材很多点赞很低，但消耗很高。**
优先筛选：
1. 时间：**近7–15天**，持续在投（消耗曲线平稳/上涨），不要找几个月前的老素材
2. 指标：消耗、跑量分、CTR、CVR；优先**消耗持续稳定**的素材
3. 类型：区分短视频素材 / 商品卡图文素材 / 直播切片素材
4. 人群：对标和你客单价、受众接近的同行，不要直接抄头部大牌（预算、人群完全不同）

## ✅ 四、拿到素材后怎么做（拆解+二次原创）
拿到对标素材，做拆解，而不是下载直接翻拍：
1. 拆解**前3秒钩子**（痛点提问、效果对比、反差）
2. 拆解脚本结构：痛点→产品展示→效果证明→信任背书→行动引导
3. 提取核心卖点、场景、镜头语言
4. **全部要素重新实拍**：换拍摄场景、换演员、换镜头角度、换台词、换BGM，做原创翻拍，规避侵权

## ⚠️ 红线
1. 禁止直接下载别人视频混剪上传，会侵权投诉+千川审核驳回
2. 不要照搬品牌专属素材、专利展示画面、专属口播文案
3. 不要只看单一爆款，至少收集10–20条跑量素材，提炼共性，不要只抄一条

## ✅ 五、快速执行流程
1. 确定3–5个对标竞品店铺
2. 巨量创意+电商罗盘，拉取近7天跑量素材
3. 筛选高消耗素材，批量拆解脚本框架
4. 归纳爆款共性，产出自己素材脚本，开拍测素材
5. 投放后持续监控竞品，每周更新素材库
