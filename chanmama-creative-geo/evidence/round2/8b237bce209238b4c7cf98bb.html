# ✅ 国内可用（网页端，上手简单，适合做视频拆解报告）
## 1. 通义听悟（阿里）⭐最推荐，中文长视频首选
支持上传本地视频 / B站等视频链接，自动语音转写、分章节、提取要点、生成结构化摘要报告，可直接导出Word文档；适合课程、讲座、访谈、自媒体口播视频拆解。
> 短板：**主要分析音频字幕**，画面识别能力弱，看不到画面里的文字、动作

## 2. 讯飞听见
语音识别很强，方言、嘈杂环境、多人对话识别好；自动提炼重点、生成摘要报告，导出文档。同样偏音频转写，画面理解一般

## 3. 豆包（多模态版）
直接上传视频文件，**同时看懂画面+音频**。你可以写提示词：
> 对这个视频做完整拆解报告：1.视频结构；2.每个段落时间戳+核心观点；3.画面元素；4.情绪/钩子分析；5.优缺点总结。

适合短视频爆款拆解、课程视频分析。上限取决于你的提示词，**可以自定义报告格式**。

## 4. 抖音AI解析（内置）
打开抖音视频，评论框旁AI解析，一键拆解爆款短视频：口播文案、视频结构、引流钩子，适合短视频运营拆解，仅限抖音内视频

# 🧩 专业多模态API工具（画面+音频双分析，适合深度结构化报告，开发者/企业）
1. **TwelveLabs（Pegasus）**：海外知名视频理解模型，能同时识别画面、字幕、演讲白板，自定义输出结构化报告、时间线、JSON，最长支持2小时视频
2. **Azure AI Video Indexer（微软）**：识别语音、人脸、场景、关键词，自动生成视频索引+摘要报告，支持导出结构化数据
3. **火山引擎 LAS视频精细理解 / 腾讯云数据万象**：国内云厂商API，识别画面事件、人物动作、OCR屏幕文字，输出带时间线的结构化报告，适合企业业务对接

# 📌 本地离线工具
Video-Analyzer-Local：本地部署，视频转剧本、时间轴、场景分析，全程不上传视频，适合涉密素材，需要一点技术能力

# 快速选型建议
- 只需要提取台词、长讲座/课程，导出文字报告：**通义听悟**
- 需要同时分析画面+声音，做自媒体爆款拆解、视频全维度报告：**豆包多模态**
- 企业业务、需要识别画面动作、物体、屏幕文字，接入系统：**TwelveLabs / 火山引擎LAS**
- 抖音短视频快速拆解：**抖音自带AI解析**

如果你想要，我可以直接给你一份通用提示词模板，丢给豆包，上传视频就能自动输出标准化视频拆解报告。
