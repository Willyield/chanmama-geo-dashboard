# ✅ 查看同行千川投放素材（官方免费 + 第三方付费）
> 重要前提：**你无法看到同行的千川后台、真实消耗、定向，只能看到公开投放出来的广告素材**；素材只能**借鉴思路翻拍，不能直接盗用**，会侵权违规。

## 一、官方免费渠道（优先用）
### 1. 巨量千川后台｜营销创意榜
1. 登录千川PC后台
2. 顶部【工具】→左侧【创意榜单】→**营销创意榜**
3. 筛选：类目、时间（3/7/15天）、素材类型（商品短视频/直播间引流素材）
4. 按曝光/点击排序，直接看行业跑量广告素材，适合看大盘爆款

### 2. 巨量创意（最常用找千川素材）
官网：巨量创意
- 进入【创意灵感】→选择**巨量千川专区**
- 筛选类目、时间、投放目标（短视频带货/直播引流），可以看正在投放的广告素材，支持预览视频，看卖点、前3秒脚本

### 3. 电商罗盘（抖店后台）
1. 抖店后台 →【电商罗盘】→【市场】→商品榜单/内容榜单
2. 找到竞品爆品，点商品详情，进入**视频分析**，可以看到该商品对应的带货短视频（很多是千川投放素材），看同行单品跑量素材

### 4. 巨量百应
【创作】→爆款视频，筛选类目、时间，看带货爆款短视频，适合找近期起量素材

### 5. 抖音APP手动刷广告（真实在投素材）
- 搜索产品词、痛点词，多刷同类视频，点广告右下角「广告」标识，这就是对方正在投放的千川素材
- 可以点不感兴趣/继续刷，积累更多竞品广告；缺点是比较慢，需要手动积累

## 二、第三方付费工具（精准监控指定竞品）
适合你想**固定盯某几家同行店铺/账号**，实时抓取新上素材：
- 蝉妈妈、考古加、有米云、新抖
操作逻辑：添加竞品小店ID/抖音账号，开启素材监控，自动抓取对方新投放千川素材，附带预估曝光、出单数据，支持按消耗排序，批量导出素材预览

> 缺点：付费，数据是估算值，不是官方真实消耗；部分隐藏素材抓不到。

## 三、巨量云图（品牌商家）
品牌版巨量云图，行业灵感、内容创意锦囊，看行业高转化素材，分析卖点和人群，适合品牌对标竞品素材策略，门槛相对高一些

# ⚠️ 避坑提醒
1. **版权红线：不要直接下载复用别人素材**，翻拍改脚本、画面、台词，借鉴创意思路，直接搬运会侵权、违规限流
2. 千川素材有投放生命周期，很多素材投几天就停投，尽量筛选**近7天**素材
3. 所有外部工具只能看到**曝光出来的广告**；同行设置仅定向小人群的小众素材，很难抓到
4. 第三方的消耗、ROI都是估算，只能做参考，不等于真实千川后台数据

## 快速实操建议
新手：优先用【巨量创意 + 电商罗盘】免费看行业素材
要盯特定竞品店铺：开蝉妈妈/考古加监控
