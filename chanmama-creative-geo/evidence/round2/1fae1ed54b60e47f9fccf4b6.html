# 一、AI商品特效怎么做（两套工作流：小白模板版 / 专业分镜版）
> AI商品特效分两类：**静态图片特效（光影、粒子、水滴、烟雾、换场景）** + **动态视频特效（产品旋转、流体、粒子散开、材质流动、AR试穿）**

## ✅ 小白快速流程（推荐商家）
1. **准备白底产品图**：手机简单拍，AI抠图把商品主体分离，保证产品不变形（核心！AI最容易把产品改歪）
2. **套用电商特效模板**（可灵、即梦、LiblibAI、佐糖、剪映AI）
    - 美妆洗护：水滴、泡沫、冰霜、雾气、液体流动
    - 食品饮料：蒸汽、溅液、光泽、食材炸开
    - 珠宝手表：星光、柔光、金属反光、缓慢旋转
3. **图生视频**：上传处理好的商品图，设置运镜（缓慢环绕、轻微推拉）+ 叠加粒子/烟雾特效；提示词重点写：**保留产品原样，只动背景和特效，光影匹配产品**
4. **后期微调**：导出到剪映，加字幕、BGM、卖点文字，裁剪成9:16短视频/主图视频
5. 批量：同一款产品，一键批量换背景、换颜色、生成多版本特效素材

> 极简提示词模板：
> 参考上传图片，保留商品外形、logo不变，产品缓慢360°旋转，周围柔和水滴特效，柔光，4K，电商主图视频，无扭曲，写实摄影

## ✅ 专业高阶流程（广告质感）
1. 拆解分镜，生成多帧静态效果图（首帧、中间帧、尾帧）
2. 使用**首尾帧图生视频**，减少产品变形，做连贯流体、爆炸、重组特效
3. AI生成特效层（烟雾、粒子），再用剪辑软件和产品画面合成（比直接一键生成稳定性更高）
4. 批量API方案：白底图自动换场景+生成带特效短视频，适合大量SKU（适合品牌/大店铺）

## ⚠️ 避坑重点
- 一定要锁定**商品主体不变**，否则AI容易改包装、logo变形
- 金属、透明瓶、玻璃材质优先匹配光影，不然特效很假
- 主图不要特效太杂乱，**主图抓眼球，详情特效讲卖点**

# 二、适合哪些电商场景
### 1. 商品主图 / 主图短视频（最高频）
适合平台：淘宝、拼多多、抖音小店、京东、小红书商品卡片
- 美妆、护肤、香水：水雾、水滴、液体流淌、冰霜，体现补水、清爽、香氛扩散
- 酒水饮料：气泡、液体飞溅、蒸汽，强化口感
- 珠宝、手表、首饰：星光闪光、光影流动，凸显质感
> 作用：3秒抓住点击率，替代传统实拍广告片，大幅降低拍摄成本

### 2. 商品详情页素材
- 动态GIF/Live实况图：展示材质特性（面料光泽、膏体延展性）
- 多场景AI特效图：同一件产品，放在不同家居场景（家具、软装、小家电），让买家想象放到自己家里的效果

### 3. 短视频带货 / 信息流广告（抖音、快手、视频号）
适合：种草短视频、千川/DOU+广告素材
特效类型：产品悬浮、拆解重组、粒子汇聚、慢镜头流体效果
优势：批量快速生成多版本素材，方便测款，不用每次实景拍摄

### 4. 直播素材、直播间贴片特效
- 直播间背景动态商品短片、弹窗商品动效
- AI数字人手持商品+特效叠加

### 5. AR互动特效（高阶）
试妆、试戴、AI试衣、家具“放到我家”：客户上传自己照片/家里照片，实时叠加商品，降低退货率（眼镜、口红、服装、家具）

# 三、品类适配清单
✅ **非常适合AI商品特效**
- 美妆护肤、香氛、洗护（液体、膏体、水雾特效效果最好）
- 酒水、饮品、零食（蒸汽、飞溅、食材爆开）
- 珠宝、手表、饰品（星光、光影、缓慢旋转）
- 家居软装、灯具、小家电（场景氛围光影）

⚠️ **谨慎使用**
- 服装：尽量用AI模特+面料柔光特效，少做夸张粒子特效，重点展示版型
- 精密工业品、数码配件：特效不能掩盖真实尺寸、接口，避免误导买家

# 四、不适合的场景
1. 需要**精准尺寸、参数、实物细节**的工业产品，特效容易造成视觉误导
2. 食品需要严格真实实拍质检类素材（不能用AI特效夸大效果，避免违规）
3. 平台白底主图规范要求纯白底，不能叠加花哨特效的类目
