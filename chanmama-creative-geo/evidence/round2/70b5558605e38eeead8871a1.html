# 一、核心逻辑：卖点≠直接念，卖点=痛点的解决方案
> 用户痛点（麻烦、尴尬、难受、浪费钱）→ 现有方案缺陷 → 产品卖点（解决这个麻烦）→ 可视化效果
**不要：我们这款拖把，纤维棉头、脱水快、不掉毛。**
**要：拖地总是留水印、掉毛，刚拖完又沾灰（痛点），普通棉拖干得慢还掉毛（旧方案缺点），这款棉头高密度，一挤就干，拖地不留水印、不掉毛（卖点转化）**

> 原则：**一条视频只抓1个主痛点+对应1-2个核心卖点**，不要堆一堆卖点，30～45秒最合适

## 二、万能短视频脚本公式（痛点带货，直接套用）
**【3秒钩子：戳痛点，圈人群】→【放大痛点+旧方案踩坑】→【产品出场，卖点对应痛点】→【实拍/对比，可视化证明】→【效果+情绪价值】→【结尾行动指令】**

表格版脚本模板（拍摄直接用）
|时长|画面|台词（口播）|字幕|备注|
| ---- | ---- | ---- | ---- | ---- |
|0-3s（钩子）|场景实拍，痛点画面|（痛点问句/感叹）谁懂啊，每次xxx都烦死了！|xxx的痛苦谁懂|抓住停留，不要先出产品|
|3-12s|继续展示麻烦，旧产品翻车|之前用xx，要么…要么…越用越闹心|普通款缺点|共情，放大麻烦|
|12-22s|产品拿出来，特写|直到我换了这个，专门解决xxx问题|产品登场|引产品|
|22-32s|实测演示卖点（重点！）|它因为【卖点】，所以再也不会出现刚才的麻烦|卖点→解决痛点|**卖点一定要搭配画面演示，不能只说**|

|38-45s|人脸+产品，引导下单|有同样困扰的，直接点下方小黄车|点击小黄车|明确行动指令|

# 三、转化实操步骤（把你的卖点痛点填进去）
### 第1步：梳理清单，做配对
把痛点和卖点一一绑定，**卖点用来解决痛点**
示例（保温杯）
- 痛点1：水装进去没多久就凉，出门喝不上热水
- 对应卖点1：24小时长效保温
- 痛点2：杯盖缝隙藏污，很难洗，容易有味
- 对应卖点2：可拆卸全拆分杯盖，无死角清洗

> 一次视频只选一组为主线，剩下卖点可以做第二条视频

### 第2步：写钩子（3秒留人，3种常用写法）
1. 人群定向：经常出门喝水很快凉的人，别再乱买保温杯了
2. 共情吐槽：谁懂啊！保温杯看着好看，半天水就凉了
3. 反问痛点：是不是保温杯用一段时间，盖子一股异味？

### 第3步：卖点口语化翻译（重点）
❌ 原始卖点：304不锈钢，长效保温，可拆卸杯盖
✅ 转化台词：内胆是304不锈钢，装热水24小时还是热的；杯盖全部能拆开冲洗，再也不会藏污垢发臭。

> 口诀：**不说参数，说好处；不说特性，说能帮用户避开什么麻烦**

# 四、完整案例演示（保温杯，40秒口播脚本）
- 0-3s｜画面：喝一口温水，很快变凉皱眉
口播：保温杯踩坑的人，看过来！
字幕：保温杯别乱买！
- 3-12s｜画面：旧杯子拆开，缝隙发黑有污渍
口播：之前买的保温杯，看着好看，半天水就凉。杯盖缝洗不干净，放久一股怪味。
字幕：不保温+难清洗
- 12-22s｜画面：拿出新款保温杯，产品特写
口播：后来我换成这款，专门解决这两个问题。
字幕：这款保温杯
- 22-32s｜画面：拆开杯盖，展示内胆
口播：内胆304不锈钢，24小时保温；杯盖可以全部拆开，每个地方都能洗干净，不会藏细菌。
字幕：24h保温｜杯盖全拆好清洗
- 32-38s｜画面：出门随手拿杯子喝水，轻松惬意
口播：出门一整天随时喝热水，再也不用忍受异味。
字幕：出门随时喝热水
- 38-40s｜画面：手持产品对着镜头
口播：经常外出需要热水的，直接下方小黄车。
字幕：点击小黄车带走

# 五、3种不同风格变体脚本
1. **情景短剧版（适合强场景痛点）**：人物演一遍踩坑→拿出产品解决
2. **实测对比版（适合工具/家居）**：A旧产品翻车，B本产品实测演示，直观对比
3. **口播种草版（护肤、日用品）**：真人分享亲身踩坑经历，共情更强

# 六、避坑要点
1. 不要堆砌卖点，一条视频1个主痛点；多卖点就拍多条素材
2. 卖点**一定要配画面演示**，单纯念卖点完播很差
3. 口语化，不要说明书式文案；短句，停顿自然
4. 结尾一定要给明确行动指令（点小黄车、进直播间）
