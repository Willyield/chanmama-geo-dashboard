# 一、怎么拆解爆款3秒（拆对标）
核心：**3秒同时拆3个维度：画面、台词、字幕/音效**，不要只抄文案
> 平台算法看「3秒留存」：用户划屏0.5秒，前3秒只判断一件事：**这条跟我有关系吗？**

拆解步骤：
1. 静音播放看**画面**（最重要！很多人静音刷视频）
   - 0-3s画面是什么？是痛点场景？还是产品效果对比？还是特写炸裂效果？
   - 镜头：是特写、分屏前后对比，还是人物直视镜头？有没有快速切换？
2. 听**口播台词**：第一句话有没有直接锁定人群、痛点、结果、悬念、价格？
3. 看**字幕+音效**：大字字幕是不是一句话钩子；有没有音效放大冲突（滋滋、去污、撕开包装声）
4. 标记类型：把钩子归类（下面5大类），记录它筛选的是哪一类目标客户
5. 反向找流失原因：自己视频3秒流失高，常见问题：慢铺垫、自我介绍、空镜头、3秒还不知道卖啥

✅ 拆解检验标准：**静音状态下，只看前3秒画面+字幕，能不能看懂这条视频讲谁、解决什么问题**，看不懂就是钩子失败

# 二、黄金3秒5大钩子类型（直接套用公式+案例）
> 原则：**结果前置，不要铺垫；不要先打招呼“大家好”**

## 1. 痛点提问钩子（最稳，家居/美妆/服饰）
公式：**锁定人群 + 高频痛点 + 反问**
例：
- 微胖姐妹，是不是穿裤子总显胯宽？
- 厨房擦油污，越擦越花的举个手？
逻辑：用户下意识心里回答“是”，产生共鸣，留下来找解决方案

## 2. 效果反差前置钩子（强视觉，清洁、护肤、祛类产品首选）
公式：**使用后惊艳画面放开头 + 一句话**
例：直接放黑脏灶台→一喷立刻干净，字幕：别再费劲擦灶台了！
要点：画面冲击力优先，先给结果，再讲过程；前后对比分屏是爆款高频手法

## 3. 反常识/避坑预警钩子（拉高好奇心，美妆、日用品）
公式：**打破固有认知+警示**
例：
- 别再用热水洗内衣，90%的人都做错了
- 这种洗面奶再便宜也别买
用户产生疑惑：为什么？想继续看解释

## 4. 利益价格钩子（福利、囤货品：纸巾、零食）
公式：**人群+劲爆价格/福利前置**
例：
- 9.9到手4大提抽纸，别再超市原价买了
适合千川投流素材，直接筛选薅羊毛用户

## 5. 悬念好奇钩子（小众好物、新奇特）
公式：**制造信息缺口**
例：
- 这个小东西，90%的人不知道干嘛用
- 我本来以为是智商税，结果被惊艳到

# 三、3秒设计实操流程（写脚本+拍摄+剪辑）
## 1. 写脚本（0～3秒严格控制一句话，15个字以内最佳）
结构模板：
`【0-1s画面】` 强视觉（痛点/效果特写）
`【0-3s口播】` 钩子一句话
`【字幕】` 大字，同步口播（重点词加粗放大）
`【音效】` 搭配场景音增强冲击

❌ 禁止：
“大家好，今天给大家介绍一款产品”
铺垫背景、讲品牌历史、慢慢介绍自己

## 2. 拍摄要点
- 镜头尽量特写，不要远景空镜头
- 人物类：直视镜头，表情有情绪（烦恼、惊讶），像面对面对话
- 实物类：直接拍使用瞬间、对比画面，不要先拿产品慢慢展示

## 3. 剪辑要点
- 前3秒不做淡入、缓慢转场，直接硬切开场
- 字幕放大放屏幕中间，静音也能一眼看懂
- 音效卡点，强化视觉冲击
- 成片一定要**静音测试**

# 四、完整短视频结构配套（3秒钩子之后怎么接）
0～3s：钩子（留人）
3～8s：给出解决方案，引出产品
8～15s：演示+对比，证明效果，建立信任
15s结尾：价格+限时限量，引导下单

# 五、快速测试优化方法
1. 同一款产品，同时拍**2个不同钩子版本**（痛点版 vs 反差效果版）
2. 看数据：重点盯 **3秒留存率**，哪个高就放大这个钩子逻辑
3. 不要只改文案，优先优化前3秒画面，静音观看的流量占比很高
