# 一、CID广告素材在哪看
> CID（ClickID）：抖音/快手等媒体投放广告，跳转淘宝/拼多多/京东成交，把订单数据回传给广告平台的跨平台引流广告。**官方后台只能看自己账户的CID素材，看竞品CID素材要用第三方广告情报工具**

### ✅ 主流工具（可筛选CID广告素材）
1. **蝉妈妈创意**
入口：蝉妈妈创意平台 → 找素材，筛选条件勾选【CID广告】，可以按品类、时间、跑量分、5秒完播排序；支持按店铺/品牌搜索竞品CID素材，AI拉片拆解脚本、口播、钩子，还能持续监控竞品上新素材预警。
2. **有米有数（有米云）**
专门有CID素材板块，收录巨量、快手CID素材；可搜竞品店铺、商品，看竞品CID投放素材、投放趋势、预估消耗，历史素材库量大，适合大盘+竞品长期追踪。


> 其他：新抖、千瓜也有CID素材收录，但CID筛选标签没有上面两个工具完善。

### ❗官方侧限制
巨量引擎后台**看不到别人的CID素材**，只能查看你自己账户下投放的CID广告素材+投放数据，不能做竞品素材挖掘。

# 二、CID素材适合用来做竞品分析吗？
**适合，但有局限，只能做「前端创意分析」，拿不到真实后端ROI和成交。**
## ✅ 能分析什么（价值很高）
1. 竞品素材创意：前3秒钩子、脚本结构、卖点话术、字幕、画面风格、场景，看竞品哪类素材持续跑量；
2. 投放策略：竞品上新节奏、素材迭代方向、主推SKU、投放时段、素材类型（口播/剧情/对比演示）；
3. 人群与卖点：竞品主打什么痛点、人群话术，判断竞品在打哪类用户；
4. 大盘赛道：整个品类CID爆款创意趋势，挖掘空白创意方向。

## ⚠️ 核心短板（一定要清楚）
1. **只有预估数据，不是真实成交**：工具只能估算曝光、跑量分，**看不到竞品真实ROI、CPC、订单成本**。CID是跳转到淘宝/拼多多成交，第三方工具无法拿到竞品真实后端订单；
2. 素材会有延迟、漏收录：部分小消耗、短期测试素材抓不到；
3. 区分不开：CID素材和普通千川素材，有些素材两者都投，需要结合筛选标签判断；
4. 无法知道竞品出价、账户模型、服务商链路配置。

## ✅ 竞品分析使用建议
1. 优先筛选**持续跑量、投放时间长**的CID素材，短期爆一下就停的素材参考价值低；
2. 批量拆解：统计竞品高频使用的钩子、痛点、转化话术，做创意差异化，**不要直接搬运素材（侵权）**；
3. 搭配电商平台看竞品落地页、价格、评价，完整还原竞品整套CID链路（广告素材→跳转电商详情→成交）；
4. 把CID素材分析作为**创意层情报**，不要仅凭素材预估数据判断竞品盈利情况。

# 三、简单操作步骤（蝉妈妈/有米有数）
1. 进入素材库，筛选【CID广告】，选定品类+时间范围（7/30天）；
2. 输入竞品店铺名/商品关键词，锁定竞品投放素材；
3. 按跑量/曝光排序，导出Top素材，拆解脚本、钩子、卖点；
4. 持续监控：开启竞品素材上新提醒，跟踪竞品素材迭代。
