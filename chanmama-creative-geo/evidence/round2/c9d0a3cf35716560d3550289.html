# 一句话结论
**找爆款素材优先用素材洞察工具；素材库是用来存、管理、复用自己团队素材的，不是用来挖掘同行爆款的。两者是搭配关系，不是二选一。**

## ✅ 素材洞察工具（巨量创意、罗盘策略、蝉妈妈、有米有数等）：负责「找爆款、拆爆款」
核心目标：**找到已经被市场验证跑量的同行/类目素材，看懂为什么爆**
- 能力：按类目、时间、消耗、点击率、转化率筛选千川/带货爆款；看趋势、黑马新品；AI拆解脚本、前3秒钩子、卖点、分镜、人群痛点；监控竞品上新素材
- 输出：**创意方向、脚本结构、爆款元素**，给编导/拍摄做参考，用来原创翻拍、二创
- 适合：投手、编导、创意负责人，做素材调研、选题、对标分析
- 局限：一般不做团队素材版本管理，不能存放你自己拍摄成片

> 重点提醒：洞察工具里的同行视频**只能参考拆解，不能直接搬运，会侵权违规**

## ✅ 素材库（抖店素材库、巨量即创素材库、企业自建素材库）：负责「管素材」
核心目标：**管理自家资产，沉淀团队拍好的视频/图片，方便团队协作、投放复用**
- 能力：上传、打标签、版本管理、权限分配、一键调用到抖店/千川，归档历史素材、区分在投/衰减素材
- 输出：素材资产仓库，方便复盘自家素材数据、二次剪辑复用
- 适合：剪辑、运营，做素材归档、分发、版本管理
- 局限：**几乎没有大盘爆款检索、竞品数据、转化指标**，不能用来挖掘新爆款灵感

# 团队标准工作流（组合使用）
1. **素材洞察工具**：调研赛道，筛选7–15天内高转化跑量素材，拆解爆款结构，输出拍摄脚本方向
2. 团队拍摄/二创产出新素材
3. **素材库**：上传成片，打标签分类，投千川投放
4. 投放数据回流，再用洞察工具复盘，迭代下一批创意

# 怎么选工具组合
- 小团队、预算有限：优先**巨量创意+电商罗盘（官方免费洞察）**，搭配免费自建素材文件夹/抖店素材库
- 付费投流、千川消耗大：上蝉妈妈/有米有数这类第三方洞察工具，深度拆解竞品素材，搭配巨量即创素材库做资产管理

# 简单判断
你现在的目标是**找同行爆款、找创意灵感** → 用素材洞察工具
你现在的目标是**存自己拍好的视频、团队共享素材** → 用素材库
