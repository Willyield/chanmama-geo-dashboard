# 竞品商品素材竞争态势分析（完整SOP）
核心思路：**不是单纯截图抄卖点，而是分析素材在搜索/推荐场里的「点击能力、转化能力、心智占位」，找到市场共性、对手短板、我们的差异化机会**，输出可落地的素材策略。

## 一、第一步：锁定分析对象（选对竞品）
一般选5～10个，分三类：
1. **直接竞品**：同品类、同价格带、目标人群一致，搜索词和你重合，销量靠前爆款（核心分析对象）
2. **间接竞品**：替代型产品，解决同一个用户痛点
3. **标杆竞品**：头部品牌、素材做得好，不一定价格一样，参考视觉与表达策略

> 筛选标准：核心关键词下排名靠前、有稳定销量、评价样本足够大，避开短期冲量的非正常链接

## 二、第二步：素材信息采集，建对比表格
把所有竞品素材统一录入表格，字段如下：
> 素材类型：主图5张、短视频、标题、sku图、详情页、评价图、直播切片、种草素材

| 对比维度 | 竞品A | 竞品B | 竞品C |
|---|---|---|---|
| 标题 | 核心关键词、卖点顺序、钩子句式 | | |
| 首图（搜索图） | 主体构图、背景、大字卖点、信任标、痛点/效果展示 | | |
| 主图组逻辑 | 第2张卖点、第3张场景/对比、第4张参数、第5张售后 | | |
| 短视频 | 前3秒钩子、叙事结构、展示场景、字幕卖点 | | |
| 详情页 | 首屏价值主张、证据类型（实测/证书/对比图）、痛点排布 | | |
| 文案卖点库 | 高频词：功能、效果、材质、售后、场景 | | |
| 视觉风格 | 色调、模特、实拍/3D、简约/热闹 | | |
| 用户反馈 | 好评高频词、差评痛点、问大家关注点 | | |
| 素材背后策略 | 主打人群、主推卖点、价格/促销配合 | | |

### 采集要点
1. 批量保存：搜索结果首图（**重点，决定点击率**）、商品内所有素材、买家秀、追评图；
2. 区分：**搜索场素材（抓点击）、商品内素材（做转化）、内容种草素材（建立认知）**，三者目标不一样，不能混在一起分析。

## 三、第三步：多维度拆解竞争态势
### 1）卖点竞争态势：市场都在抢什么心智？
- 统计所有竞品素材**高频卖点词**，做词频统计，看类目共识卖点（大家都在说的）
- 区分：**基础卖点（所有人都有，说了不加分，不说减分）、差异化卖点（少数人主打）、缺失卖点（没人提，但用户痛点）**
- 交叉验证：去评价、问大家看用户真实关心点，**素材宣传卖点 vs 用户真实痛点有没有缺口**
> 机会点：竞品素材都在宣传A，但大量差评是B，B就是你的素材突破口

### 2）视觉竞争态势：搜索页视觉拥挤度
- 搜索页同屏对比：大家都用什么背景、色调、字体大小；是否同质化严重
  - 如果80%竞品都是白底大字，你用场景实拍就更容易脱颖而出
  - 如果全部都放效果对比图，你就要换更高级的证据形式（实测视频/证书）
- 风险：不要盲目跟风，要看**素材对应的人群**：同样一张图，A竞品主打年轻人群，不一定适合你的客群

### 3）素材结构与转化逻辑分析
拆解竞品素材叙事链路：
- 主图：第1张抓点击，后面几张逐步打消顾虑（痛点→效果→参数→信任→售后）
- 短视频：前3秒钩子，是痛点冲击？效果演示？场景代入？
- 详情页：先价值，再证据，再打消异议，还是堆砌参数？

### 4）素材+营销联动分析（很容易漏掉）
素材不是独立存在，要结合价格、促销、活动：
- 大促期素材：是否突出限时、赠品、降价；
- 日常素材：是否侧重产品价值、长期使用收益；
- 看素材是否配合SKU策略：主推哪个SKU，素材就展示哪个版本。

### 5）强弱矩阵：绘制竞品素材优劣势
- 优势：竞品素材成功点（高点击率卖点、视觉、证据形式）
- 劣势：素材短板
  - 卖点夸大、缺少证据；
  - 只讲功能，不讲用户场景；
  - 用户差评集中的问题，素材刻意回避；
  - 视觉同质化严重，搜索页辨识度差

## 四、第四步：市场态势总结 & 机会判断（输出结论）
输出3个核心结论：
1. **市场素材格局**：当前类目素材主流打法是什么，分几派（比如一派主打性价比大字图，一派主打场景质感）；
2. **竞争空白机会**：哪些用户痛点没有被竞品素材讲透；哪些视觉/表达赛道对手还没占领；哪些信任证据对手缺失；
3. **风险区**：哪些卖点已经内卷严重，再跟进很难突围；哪些宣传点容易踩合规风险。

> 做一个**素材差异化策略矩阵**
> - 跟随区：基础卖点，必须有，保证不落后；
> - 差异区：别人弱、我们强，作为主素材核心钩子；
> - 规避区：竞品内卷红海卖点，不正面硬刚。

## 五、第五步：落地输出（素材策略+测试建议）
分析最终要落地成素材brief，而不是一份调研报告：
1. 标题文案方向：核心关键词+差异化钩子；
2. 主图策略：首图视觉方案、主图组叙事顺序；
3. 短视频脚本方向：前3秒钩子、核心演示；
4. 详情页逻辑：优先展示什么证据，解决哪类用户异议；
5. 测试方案：做多版素材，小流量测点击率、转化率，验证分析结论。

## 六、常用工具参考
- 素材采集：平台截图、批量下载主图/视频
- 词频分析：把竞品标题、评价文本导出，做词云，提炼高频痛点卖点
- 数据：生意参谋/千牛、蝉妈妈、新抖等，辅助看竞品流量结构，判断素材效果的底层原因

## 七、避坑提醒
1. ❌ 不要只截图看好看不好看，**素材好不好，最终看点击率、转化率，不是审美**；
2. ❌ 不要直接照搬，竞品素材有效，可能依托它的品牌、价格、流量权重，照搬不一定起量；
3. ❌ 忽略合规：竞品素材有夸大宣传，不要直接学，评估广告法风险；
4. ✅ 定期迭代：素材竞争是动态的，爆款竞品会持续换图，建议每2～4周复盘一次。
