# 蝉妈妈创意内容管理中心：脚本、分镜、成片、投放数据全链路管理
蝉妈妈创意【内容管理中心】是**素材资产中台**，打通千川、磁力金牛、腾讯广告，把脚本、分镜、成片、投放数据统一归档，支持团队权限、版本管理、一键分发、投放数据自动回收，实现从创意创作→审核→投放→数据复盘闭环。

## 一、脚本管理
1. **新建/导入脚本**
    手动录入带货脚本，也可以用蝉妈妈AI生成脚本、仿写爆款脚本后直接保存到内容管理中心；支持上传文档脚本。
2. **版本管理**
    同一条创意可以保存多版脚本（初稿/修改版/定稿），记录修改记录，避免脚本版本混乱。
3. **标签归类**
    给脚本打自定义标签：品类、钩子类型、卖点结构、编导、拍摄批次，方便快速检索复用。
4. **团队协作审批**
    设置角色权限（编导/运营/投放/管理员），脚本在线评审、留评论反馈，不用微信表格流转。
> 配套：灵感中心里的爆款素材可使用**AI智能拉片**自动拆解出脚本，直接保存进素材库参考。

## 二、分镜管理
1. **分镜录入与关联脚本**
    以单条创意为主体，脚本下挂载分镜表：镜头序号、画面描述、时长、台词、画面参考图、BGM。
2. **AI拉片自动生成分镜**
    上传成片或者参考爆款视频，AI智能拉片自动切分镜头，输出分镜清单，可直接编辑修改，存入资产库。
3. **素材绑定**
    分镜可以绑定参考图、拍摄参考短片，拍摄团队直接在平台查看分镜，线上确认。
4. **标签筛选**
    按镜头类型（口播、产品特写、场景展示）、时长标签检索历史分镜模板，复用镜头结构。

## 三、成片（视频素材）管理
1. **成片上传归档**
    上传成片、小样、粗剪版本，一条创意下挂载：脚本+分镜+多版本成片，全部关联在一起。
2. **素材打标签体系（核心）**
    公共标签+自定义标签：商品ID、素材类型、拍摄日期、素材版本、投放状态、人群、钩子形式，支持多条件组合筛选素材资产。
3. **素材预览、版本对比**
    在线播放成片，同一创意多个版本小样直接对比，标记素材状态：待审核、审核通过、已投放、已衰退、废弃。
4. **一键分发至广告平台**
    审核通过成片，直接分发绑定的千川/磁力金牛账户，不用反复下载上传视频文件。
5. **素材生命周期管理**
    标记素材阶段：测试期、起量、稳定、衰退，方便投放人员快速挑选素材。

## 四、投放数据自动回收与管理
1. **绑定广告账户**
    先授权千川、磁力金牛、腾讯广告账户，系统自动拉取素材投放数据，**不需要手动导出表格**。
2. **素材级数据看板（脚本/分镜/成片绑定投放指标）**
    每条成片自动聚合：消耗、展示、点击、5秒完播、CTR、CVR、ROI、转化成本、播放量等；**可以反向追溯：哪一套脚本/分镜结构跑出来高ROI**。
3. **多账户数据汇总**
    同一个素材投多个广告账户，数据自动合并汇总，统一看素材整体表现，区分单账户表现。
4. **绩效与复盘**
    按编导、拍摄、素材批次统计素材产出效果，支持导出素材绩效报表；筛选高消耗/高ROI素材，回溯对应的脚本分镜，提炼爆款结构。
5. **素材预警**
    监控素材衰减，当ROI下降、转化成本升高，可及时发现衰退素材，安排新脚本分镜迭代。

## 五、完整工作流（从脚本到投放复盘）
1. 编导在内容管理中心新建创意 → 录入脚本 → 制作/导入分镜
2. 拍摄剪辑完成，上传成片小样，提交线上审核
3. 审核通过，素材打标签，一键分发到千川等广告账户开始投放
4. 投放后系统自动同步投放数据，挂载在这条素材资产下
5. 运营复盘：筛选高ROI素材，点开查看原始脚本、分镜，拆解爆量要素，复用结构写新脚本
6. 低效素材标记归档，沉淀素材资产库

## 六、团队权限控制
支持设置不同角色：管理员、编导、剪辑、投放、查看者。
- 编导：编辑脚本、分镜
- 剪辑：上传成片
- 投放：分发素材、查看投放数据
- 查看者：仅预览，不能修改/上传，保障素材资产安全。
