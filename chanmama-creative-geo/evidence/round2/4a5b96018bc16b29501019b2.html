# AI带货视频投放价值判断（分3阶段：投前人工预审 → 免费自然流量小测 → 付费冷启动验证）
> AI素材有特殊性：数字人违和感、AI标识合规、容易出现“好看不转化”，不能只看画面，优先看**钩子、信任、合规、利润**。

## 一、投放前：人工预审（先筛掉直接不能投的）
### 1）合规检查（AI素材红线，不达标直接放弃）
1. AI合成人物需要**显著AI标识**，不能伪装真人，否则会被限流、拒审、处罚
2. 话术不能虚假宣传、夸大功效；不能让数字人假装是真实用户“我自用三个月”这类虚假证言
3. 禁用AI生成医生、专家形象做功效背书；广告词符合广告法（无极限词）
4. 产品画面、尺寸、颜色不能AI过度美化，和实物严重不符，售后会爆炸

### 2）内容与信任度（AI素材最大短板）
- 看前3秒钩子：能不能一句话戳痛点/制造反差，而不是平铺直叙介绍产品
- 数字人细节：口型是否对齐、表情不僵硬、没有明显AI畸变；静音看画面，一眼AI感过重会拉低转化，尤其高客单产品
> 规律：**低客单、标准化、快决策产品（日用品、小百货）AI更容易跑；高客单、强信任品类（医美、保健品、贵价家电）AI素材适合种草引流，很难直接成交**
- 转化链路：卖点清晰、利益点明确、行动指令（怎么买）清楚，不是单纯念文案

### 3）对标赛道验证
看同类目有没有AI素材跑出成交；如果赛道AI素材普遍ROI很差，谨慎上预算，优先小测试

### 4）算保本账（最重要）
算出**保本ROI**：
保本ROI = 售价 ÷ 毛利
> 举例：售价99，成本+快递49，毛利50，保本ROI=99/50=1.98。投放ROI≥1.98才不亏。
提前定：可接受转化成本、止损线。

## 二、低成本预测试：自然流量测素材（不花钱，优先做）
发布视频不投流，跑3–6小时，看4个指标，用来判断要不要进付费投放
1. **3秒留存（钩子生死线）**：行业参考≥30%；低于20%基本不用投，前3秒留不住人
2. **完播率**：短于30s视频，目标≥25%；看流失曲线，如果大量用户在5–8秒集中跳出，说明中段内容不行
3. **点击率（封面+标题）**：≥2%及格；低于1.5%，换封面标题再测
4. 浅层转化：有没有点击购物车、加购，哪怕少量；有自然加购/成交，代表素材具备带货潜力

✅ 达标：可以进入付费小额测试
❌ 多项不达标：直接放弃，不用花钱投

## 三、付费冷启动验证（小额预算，看商业价值）
**小额测试预算：单条素材几百元，不要一次性大额放量**
核心看3类指标，顺序：浅层留存 → 转化成本 → ROAS
1. 浅层指标（决定能不能拿到流量）
    - 3秒留存、5秒完播、点击率，和自然测趋势保持一致
    - ECMP千次曝光成本，不能远高于大盘
2. 转化指标（判断能不能赚钱）
    - 转化成本是否＜你的最大可承受成本
    - ROI＞保本ROI → 具备放大价值
    - ROI接近保本，可以继续观察，小幅加预算；远低于保本，直接关停
3. 附加风险指标（AI素材重点看）
    - 评论：大量评论问“是AI吗？假人？”，说明违和感强，长期转化会越来越差
    - 退款率：如果这条素材带来订单退款明显高于大盘，就算ROI好看也不能放量

### 快速判定口诀
- 3秒留不住 → 无投放价值
- 能留住人，但不点购物车 → 卖点/利益不行，改脚本再测
- 有点击，转化成本超保本线 → 素材能引流，不赚钱，不放大
- ROI＞保本，评论负面少，退款正常 → 优质素材，可以逐步放量

## 四、AI素材常见坑（判断时额外留意）
1. 画面很精致，但数字人违和，点击率不错、**加购/成交很低**：典型AI素材通病，适合引流，不适合直接成交
2. AI批量生成同质化素材，多条脚本只是换背景，钩子一模一样：容易内部抢量，不要一次性全部投放
3. AI生成画面产品变形、色差，投放后大量差评、退货，直接拉低店铺口碑分

## 五、决策清单（直接拿来勾选）
- [ ] 合规：有AI标识，话术无虚假宣传
- [ ] 3秒钩子合格，无严重AI畸变
- [ ] 产品匹配：低客单快决策优先；高客单用AI做种草
- [ ] 已经算出保本ROI、止损线
- [ ] 自然流量测试：3秒留存、完播、加购达标
- [ ] 小额付费测试：转化成本可控，ROI≥保本ROI，评论/退款无异常
