# 蝉妈妈创意灵感中心实操：找爆款素材 + 追踪同行新投素材
入口：打开蝉妈妈创意官网 `cy.chanmama.com` → **灵感中心**（核心模块：找素材、看榜单、盯竞对）

## ✅ 一、找爆款素材（灵感中心-找素材/榜单）
### 1. 榜单快速抓爆量素材
优先看这几个榜单：
- **跑量素材榜**：长期稳定消耗的成熟爆款
- **高增量素材榜（黑马）**：近期流量快速拉升，潜力新素材（重点！抢先跟风）
- **商品投放榜**：绑定具体商品的千川广告素材，支持CID、直播切片素材查看

### 2. 多维筛选，缩小范围
筛选条件：
1. 类目：选你的产品所属二级/三级类目
2. 时间：近24h / 近3天 / 近7天（找新爆素材优先24h、3天）
3. 排序：**跑量分、预估播放、增量**（跑量分是蝉妈妈核心指标，代表素材投放爆发力）
4. 素材属性：视频/图文、时长、口播/剧情/产品展示、广告素材/自然流
5. 还可筛选：达人号/店铺自播号、投放地域、视频比例

也可以直接**搜索商品关键词**，批量看该品类下所有投放素材。

### 3. 素材深度拆解
点开素材详情页：
- 看5秒完播、互动、跑量趋势，判断是不是真爆款，避免虚高数据
- **AI智能拉片（AI拆策略）**：一键拆解脚本、分镜、黄金3秒、痛点话术，提取创意结构
- 收藏素材，归入素材库，方便后续对比复盘

> 重点思路：优先看**高增量榜**，这种刚起量的素材，竞争还没饱和，比已经爆很久的老素材更有参考价值。

## ✅ 二、追踪同行新投素材（盯竞对 / 素材追踪）


1. 进入灵感中心 → **盯竞对（素材追踪）**
2. 添加监控对象：**同行抖音号 / 抖音小店名称**（支持批量添加竞品）
3. 开启监控：系统会**分钟级捕捉同行新投放千川素材（含隐藏广告素材）**，一般30分钟内更新，同行刚上新投素材就能抓到
4. 设置**爆量阈值提醒**：当同行素材跑量达到你设定标准，自动推送通知（钉钉/飞书/站内消息），第一时间收到竞品新素材预警
5. 查看监控列表：直接看【新增素材】，区分：今日新增、近24h投放素材，看同行上新节奏、素材方向、素材类型变化

### 追踪小技巧
- 同时监控3–10家同赛道头部+腰部竞品，不要只盯1家
- 重点看同行**深夜上新素材**，很多投放团队会在夜间上新测素材
- 区分：同行**自然流视频** vs **千川付费广告素材**，广告素材才是投流参考重点

## ✅ 三、使用流程总结
1. 灵感中心 → 找素材/榜单，用类目+时间+跑量分筛选，挖掘行业爆款、黑马素材
2. AI拉片拆解脚本，收集创意方向
3. 切换到【盯竞对】，添加竞品店铺/抖音号，开启实时素材监控+消息提醒
4. 每日查看竞品新增素材，对比行业爆款，提取共性，做差异化创作（**严禁直接搬运素材，仅参考创意结构**）

## ⚠️ 重要提示
1. 素材仅用于**创意参考、脚本思路拆解**，直接盗用他人广告素材会侵权、违规限流
2. 素材监控、AI拉片、消息推送这些高级功能一般需要蝉妈妈创意会员权限
3. 工具数据是预估数据，作为投放参考，最终效果以千川后台真实消耗为准
