# 一、两者核心区别
## ✅ 直播引流素材（推直播计划）
**目标：把人引进直播间，成交在直播间完成**
- 转化链路：刷到短视频 → 点击进入直播间 → 主播讲解、逼单成交
- 内容逻辑：3秒钩子抓注意力，只讲痛点、效果、直播间福利预告；**不把价格、全部卖点一次性讲透**，把转化留给主播
- 素材形式：短视频（直播切片、预告短视频），也可以直接用**直播间画面（LiveHead）**当创意
- 优化指标：**直播间进入率、直播间点击率、看播时长**，最终看直播间ROI
- 投放计划类型：千川【推广直播间】计划

## ✅ 商品广告素材（推商品/短视频带货计划）
**目标：用户看完视频直接点小黄车/商品卡下单，不需要进直播间**
- 转化链路：刷视频 → 点购物车 → 商品详情页直接下单
- 内容逻辑：视频内一次性讲清**全部卖点、效果、价格、信任背书**，用户看完就要下决心下单，没有主播答疑
- 素材形式：短视频、图片、图文、商品主图（商品卡素材）
- 优化指标：**小黄车点击率、商品点击、直接成交ROI**
- 投放计划类型：千川【推广商品】短视频带货 / 商品卡计划

|对比项|直播引流素材|商品广告素材|
| ---- | ---- | ---- |
|核心目的|引流进直播间|短视频内直接卖货|
|转化发生地|直播间|商品详情页|
|内容重点|吸引点击进直播间，卖点留到直播间|视频讲完整卖点，促当场下单|
|素材类型|短视频、直播间实时画面|短视频、图片、图文、商品方图|
|核心指标|直播间进入率|商品点击、视频成交|

> 简单一句话：**直播引流素材负责“拉人进房”；商品广告素材负责“视频里直接卖货”**，素材不能直接混用，脚本逻辑完全不一样

# 二、在哪里查看素材（自己账户素材 + 同行参考素材）
## 1、千川PC后台（看自己账户素材）
1. 登录巨量千川PC后台：qianchuan.jinritemai.com
2. 入口1：**工具 → 素材管理**
    - 素材库：所有上传视频/图片，可筛选素材所属计划（推直播 / 推商品），查看消耗、点击率、转化数据
    - 素材评估：看高效/低效/首发素材标签
3. 入口2：**推广管理 → 计划列表**
    点开单个计划，查看创意，区分【直播推广计划创意】和【商品推广计划创意】

## 2、官方灵感素材库（看行业同行爆款参考）
1. **巨量创意 cc.oceanengine.com**
    千川专区，筛选：引流短视频（直播引流素材）、带货短视频（商品广告素材），看行业跑量样片
2. 电商罗盘/巨量云图极速版：内容→创意洞察，区分**引流短视频 / 带货短视频**筛选同行素材

## 3、小店随心推（移动端）
抖音APP → 我 → 右上角≡ → 更多功能 → 小店随心推，创建计划时上传/选择素材；也可在历史计划查看过往创意。

## 4、第三方工具（蝉妈妈、新抖等，付费）
创意素材库，可筛选广告类型：**直播引流素材 / 商品带货素材**，看同行正在投放的广告视频。
