# 一、在哪里看千川素材数据
千川后台 →【数据】→【素材数据】，可以按视频素材维度看，不是只看计划数据；
重点指标分组：**留存互动（前端吸引力）、流量指标、成交盈利指标**
> 前提原则：**素材要跑够样本再判断**，一般建议≥3000展现，或者消耗到能出几单，样本太少的数据没有参考意义，不要刚花几十块就下结论

## 1）前端内容指标（决定能不能拿到曝光）
- **3秒完播率（最重要）**：黄金3秒，代表钩子行不行。参考线：≥30%合格；低于20%，开头留不住人，基本很难起量
- 5s/10s完播：看视频中段流失，判断卖点节奏问题
- **CTR点击率**
  - 短视频素材：**2.5%~7%正常区间**；低于2%偏弱；＜1%基本直接放弃
  - 注意：CTR＞10%大概率是标题党、猎奇钩子，流量泛，转化差，不要盲目追投

## 2）流量效率指标
- **CPM千次展现成本**：同样预算，CPM越低越容易放量。**不能单独看CPM好坏，必须搭配ROI一起看**，CPM低但不转化也没用
- eCPM：系统预估竞争力，CTR、CVR越高eCPM越高，越容易拿到流量

## 3）成交盈利指标（最终判断要不要跟进的核心）
1. **ROI / 转化成本**：对比你的**保本ROI**，这是生死线
    - ROI ≥保本：优质，可以放量
    - ROI接近保本（保本的80%~99%）：潜力素材，可以小预算观察、迭代
    - ROI＜保本的60%：直接放弃，不要硬烧钱
2. CVR转化率：点击之后下单能力；低价品CVR更高，高客单会偏低，拿账户内同品类素材横向对比最准
3. GPM：千次曝光成交金额，衡量素材带货能力

# 二、四象限判断：素材要不要跟进
### ✅ 1. 高消耗+ROI≥保本：主力爆款，重点跟进
- 动作：复制新计划追投、扩预算、多计划分散放量；拆解这条素材钩子、卖点、话术，批量翻拍同模板素材；监控衰退，一旦ROI持续下滑就控预算
### ✅ 2. 低消耗+ROI≥保本：潜力素材，优先跟进
特点：盈利，但还没跑开，eCPM不错，只是预算/探索不足
- 动作：新建独立计划测试，小额起量，不要叠加在老计划；同脚本微调翻拍，放大这个创意方向；**这是最容易挖到新爆款的一类**
### ⚠️ 3. 高消耗+ROI低于保本：谨慎，不建议追
已经能拿到大量流量，但亏钱。
- 两种处理：
  - 直播间承接问题：优化直播间、落地页、价格，再观察；
  - 素材人群本身不成交：直接降预算或关停，不要继续烧
### ❌ 4. 低消耗+ROI差：直接放弃，不跟进
3秒完播/点击率双低，同时不赚钱，直接关停，释放预算给新素材

# 三、快速判断的简易标准（参考，以你账户保本ROI为准）
1. 3s完播＜20% + CTR＜2%：**直接淘汰**，钩子不行，很难跑量
2. 3s完播≥30%、CTR2.5~7%，但是**不出单/ROI远低于保本**：钩子抓人，但卖点、信任、价格不行，可尝试改卖点/价格，不行就放弃
3. 前端数据合格 + ROI≥保本：**值得跟进，复制放大**
4. 前端数据不错，ROI略低于保本：小预算观察，不要猛加预算

# 四、素材衰退识别（老素材判断）
- 消耗越来越难往上加
- CPM持续走高，ROI逐步下滑
- 相同出价，转化成本变贵
> 衰退素材：不要继续放量；可以降低预算，当辅助素材，同时大量拍同创意变体素材接力

# 五、常见踩坑提醒
1. **不要单看点击率**：高CTR低转化=泛流量，纯浪费钱
2. **不要样本不足下判断**：消耗很少、只有几百展现，数据波动极大，容易误杀潜力素材
3. **素材≠直播间**：素材数据好，但ROI差，有可能是直播间承接弱，不一定是素材本身问题，要分开定位
4. 素材追投不要一次性猛加预算，阶梯式放量，防止快速衰退

# 六、一句话实操流程
新素材小额测试 → 跑够3000展现看【3s完播+CTR】判断素材吸引力 → 看ROI对比保本线分四象限归类 → 优质素材复制追投、批量翻拍；差素材关停释放预算；衰退素材控预算，上新素材接力
