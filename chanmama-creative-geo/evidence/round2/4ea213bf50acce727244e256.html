# ✅ 抖音/剪映素材库入口（免费可商用素材）
抖音本身没有独立APP内“素材库”，**短视频剪辑素材库在剪映**（官方配套）
1. **剪映APP（手机）**
打开剪映 → 点【开始创作】→ 顶部点【素材库】，里面有视频、图片、音频、特效。
> 筛选：勾选**可商用**，避免版权风险；可搜关键词、选择竖屏/横屏。

2. **抖音创作者灵感（找选题、爆款文案）**
抖音主页右上角≡ → **抖音创作者中心** → **创作灵感**，看热门话题、选题、爆款文案、热门BGM，适合找内容方向，不是视频素材文件。

3. **巨量创意（找广告爆款素材，带货/投流必用）**
网页/APP：**巨量创意**，里面有海量跑量短视频案例、广告素材榜单，能看行业爆款视频、脚本参考，商家/带货号重点用。

4. **抖店商家素材中心**（开店用，存自己的商品图视频）
抖店后台 → 店铺 → **素材中心**，用来管理你自己上传的商品素材，不是公共素材库。

5. **抖音二创片单**（影视剪辑专用）
抖音搜索：**抖音二创片单**，平台授权可以二次剪辑的影视剧片库，仅限片单内影片二创，不能随便剪别的影视。

# 🔥 怎么找爆款素材（分2种：参考爆款案例 + 找素材片段）
> ⚠️重要提醒：**不要直接搬运下载别人的视频直接发布，侵权违规！只能拿来学习结构、钩子、脚本，重新翻拍/二次剪辑创作**

## 方法1：抖音APP内直接找对标爆款（普通人免费）
1. 搜索你的赛道关键词（如：家居收纳、美食教程）
2. 筛选：**最多点赞 / 最近7天**
👉优先看：**低粉爆款**（几千粉丝，播放几十万），这种更容易复刻；大博主爆款有粉丝基础，不好抄。
3. 收藏爆款，拆解：前3秒钩子、字幕、BGM、文案结构、画面镜头。

## 方法2：电商/带货专用（巨量创意、电商罗盘）
- 巨量创意：看行业素材榜单，筛选7/15天高消耗爆款广告素材，看点击率、转化数据
- 电商罗盘（抖店后台）：短视频榜单，看商品对应的爆款带货视频，分析同行卖点、镜头逻辑

## 方法3：第三方数据分析工具（蝉妈妈、考古加、热点宝，部分付费）
看行业热榜、爆款视频、热门BGM、选题，批量筛选同赛道爆款。

# ✅ 避坑重点
1. 剪映素材库标注【可商用】的素材，发布抖音没问题；没标的不要直接商用。
2. 别人发布的抖音视频，**未经授权下载搬运属于侵权**，会限流、下架、扣分。
3. 爆款核心不是找现成片段，是**学习爆款脚本逻辑，用合规素材自己重拍/剪辑**。
