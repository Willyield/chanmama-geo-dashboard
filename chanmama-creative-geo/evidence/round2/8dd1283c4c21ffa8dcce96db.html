# 一句话总结
**可灵AI、即梦AI、Vidu 是「AI视频生成引擎」，核心能力是文生/图生视频，靠提示词自由创作画面；蝉妈妈创意大师是「电商投放一体化创意平台」，把爆款数据分析、脚本、模板、AI视频生成打包在一起，主打批量做带货投流素材**，它底层甚至接入了即梦Seedance模型，但定位完全不一样。

## 一、可灵AI / 即梦AI / Vidu（纯AI视频生成工具）
### 核心定位
**视觉生成模型，创意自由创作引擎**，面向创作者、剪辑师、短剧/动画制作人，用来从零生成镜头画面。
1. **可灵AI（快手）**：写实、人物大动作、物理模拟强，支持较长片段、4K，适合广告片、短剧、影视概念镜头，擅长复杂运镜和大幅度动作画面
2. **即梦AI（字节Seedance）**：中文理解好，口型对齐，和剪映打通，适合短视频口播、漫剧，片段短、出片快
3. **Vidu（生数科技）**：二次元/动画强项，角色一致性强，适合AI动漫、系列短剧，锁定同一个角色持续出镜

### 特点
✅ 靠**提示词、参考图**自由创作画面，自由度高，风格不受限，电影感、特效、艺术短片都能做
✅ 核心产出：**视频画面素材**，脚本、投放策略、数据分析需要你自己另外搞定
❌ 需要你懂提示词、调参，有一定学习成本；本身不带竞品素材库、投流数据分析
✅ 适合：做创意短片、短剧、动画、广告Demo、艺术向视频

## 二、蝉妈妈创意大师
### 核心定位
**电商千川投放专用的创意生产平台（不是独立视频大模型）**，核心是**数据驱动批量产出带货短视频**，面向电商商家、投手、素材团队

### 核心能力
1. **爆款素材洞察库**：扒同行跑量短视频，AI拉片拆解爆款结构、黄金3秒、话术卖点，分析什么素材容易投爆，这是可灵/即梦/Vidu完全没有的能力
2. **AI智能编导**：粘贴商品/达人链接，AI自动仿写带货脚本，批量产出多套营销文案
3. **模板化一键成片**：大量电商带货预设模板，**不用写复杂提示词**，上传产品图直接生成商品展示视频；底层调用Seedance做画面生成
4. **数字人带货、素材复刻、字幕/剪辑工具**，产出可直接投千川的短视频素材，支持批量多版本测素材

### 特点
✅ 面向电商投流，**优先保证素材的带货属性、爆款结构**，不是追求艺术感
✅ 零提示词门槛，上传产品图即可成片，支持批量生成大量变体素材用来测款
❌ 画面创意自由度弱于可灵/即梦/Vidu，更适合带货短视频，不适合做独立短片、艺术动画

## 三、核心差异对比
|维度|可灵/即梦/Vidu|蝉妈妈创意大师|
| ---- | ---- | ---- |
|**本质**|AI视频生成模型（画面生成引擎）|电商创意一体化平台（内置AI视频能力）|
|**核心目标**|做出好看、有创意的镜头画面|批量产出**能投流、能带货**的短视频素材|
|**创作入口**|提示词、参考图，自由定制画面|爆款模板+商品图，AI自动生成带货脚本+视频|
|**独有能力**|运镜、角色锁定、长片段、艺术风格、特效画面|竞品素材库、爆款拆解、投流数据、批量脚本、素材管理|
|**适用人群**|视频创作者、短剧/动画、广告创意人|电商商家、千川投手、短视频素材运营团队|
|**创作门槛**|需要学习提示词调参|低门槛，几乎不用写提示词|

## 四、怎么搭配使用
1. **只想自由创作短片、短剧、动画、广告视觉片** → 直接用可灵 / 即梦 / Vidu
2. **电商做千川素材，需要参考竞品、批量生成多款带货视频测款** → 蝉妈妈创意大师
3. **组合玩法**：蝉妈妈分析爆款脚本，导出文案；再把脚本+参考图丢给可灵/即梦，自由定制更有创意的画面
