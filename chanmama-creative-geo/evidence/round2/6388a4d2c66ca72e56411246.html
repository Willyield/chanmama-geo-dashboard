# ✅ 抖音官方素材库（免费可商用素材）
>抖音本身没有APP内单独叫“素材库”的入口，**剪辑素材主要在剪映**；爆款创意/广告素材看【巨量创意】，选题灵感在创作者中心
1. **剪映素材库（最常用，抖音配套）**
手机剪映APP → 点【开始创作】→ 顶部【素材库】
✅ 里面有免费视频片段、图片、音效、背景音乐；支持筛选竖屏/横屏、热门素材，可直接加到视频里，平台授权可用于抖音发布

2. **巨量创意（找爆款广告素材，网页/APP）**
网址：cc.oceanengine.com
👉 适合带货、投流看爆款素材，筛选7/15/30天、行业、高点击率素材，都是抖音上跑起来的广告案例，**只能借鉴思路，不能直接搬运**

3. **抖音创作者中心｜创作灵感（找选题、热门话题）**
抖音APP主页右上角≡ → **抖音创作者中心** → **创作灵感**
会推荐你账号赛道的热门话题、爆款选题、热门BGM，找自然流爆款灵感

4. 电商商家专用
- 电商罗盘：看带货短视频榜单，同行爆款挂车视频
- 抖店后台【素材中心】：存放自己店铺图片视频，不是找外网爆款素材

# ✅ 怎么找爆款素材（实操方法）
## 方法1：抖音APP内搜自然流爆款（免费）
1. 搜索你的赛道关键词（例：居家收纳、早餐教程）
2. 筛选：**最多点赞 / 最近7天**
3. 优先看：完播高、评论多、发布时间1~7天的新爆款（老爆款容易过期）
>⚠️ 版权提醒：别人原创视频**不能直接下载搬运**，只分析脚本、镜头结构、开头钩子，翻拍重做。

## 方法2：巨量创意 看广告爆款（带货投流首选）
进入巨量创意 → 创意案例 → 选择行业，筛选：高消耗、高点击率、7天内素材，看爆款的开头、卖点话术、画面节奏

## 方法3：剪映找热门原生素材
剪映素材库搜赛道关键词，看【热门】标签素材，搭配热门BGM，适合混剪类内容，素材自带平台版权。

# ⚠️ 重要避坑
1. **不要直接下载别人的视频当素材发布，侵权违规，会限流下架**，只能学习框架翻拍；
2. 剪映素材库内标注【免费可商用】的素材，才能直接用；
3. 影视二创素材看官方**二创片单**，只有片单内的影视才能二次剪辑，其余影视剧不要随便剪，极易侵权。
