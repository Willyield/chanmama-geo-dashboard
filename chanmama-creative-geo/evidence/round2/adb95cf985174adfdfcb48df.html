# 蝉妈妈创意：查找千川隐藏素材 + 素材异动提醒完整操作
> 千川隐藏素材：商家不上传到抖音主页、仅直接上传千川后台投放，在抖音主页看不到，普通刷抖音刷不到的广告素材

## ✅ 一、发现千川隐藏素材（素材追踪/盯竞对）
**入口：蝉妈妈创意 → 素材追踪（盯竞对）**
1. 添加监控对象：输入**竞品抖音号 / 小店名称 / 品牌关键词**，添加到监控列表（素材追踪任务）
2. 系统自动抓取：开启任务后，**约30分钟**抓取一次，自动捕捉竞品新投放的千川隐藏素材（千川上传广告、CID素材、直播引流素材，主页不对外展示的视频）
3. 查看素材：进入竞品详情页，切换「千川投放素材」标签，就能看到该账号主页不显示的隐藏素材，附带**跑量分、预估消耗、播放、转化相关指标**；也可以在【灵感中心-找素材】，通过类目、商品关键词，全网检索千川广告隐藏素材池，筛选高增量素材榜/投放榜，批量挖掘行业隐藏跑量素材

> 原理：这类素材没有公开到账号作品列表，但在千川广告投放链路中曝光，蝉妈妈创意通过广告曝光数据捕获，不是读取对方千川后台。

## ✅ 二、素材异动提醒（爆量监测预警）
**入口：蝉妈妈创意 → 爆量监测**
1. 添加监控目标：添加竞品账号、小店、商品关键词，设置监测规则
2. **自定义异动阈值**（核心）
    - 素材跑量分飙升、预估消耗突增、播放快速上涨、新素材起量都可以设为触发条件；
    - 例：24小时跑量分上涨＞50、预估消耗突增，一旦命中即告警。
3. **配置消息推送渠道**：站内通知 + **钉钉 / 飞书 /企业微信**群消息推送，素材异动时自动推送通知，附带素材链接和数据概览
4. 收到告警：点通知直达素材详情页，支持AI智能拉片，一键拆解脚本、黄金3秒、分镜、文案，快速分析爆量逻辑

## ✅ 三、两个功能的区别（容易混淆）
1. **素材追踪（盯竞对）**：**发现新增隐藏素材**，只要竞品新投千川素材，系统抓到就入库，侧重「有没有上新素材」
2. **爆量监测**：**监测已有素材的数据异动**，素材投放后数据暴涨/爆量，触发预警，侧重「素材跑起来了」

## ✅ 四、补充要点
1. 权限：素材追踪、爆量监测属于蝉妈妈创意会员功能，免费版无法使用完整监控与告警
2. 局限性：属于第三方广告数据捕获，**不是100%抓取全部千川素材**，仅能捕获到已经对外广告曝光的素材；完全没有曝光的千川测试素材无法抓到
3. 推荐使用流程：
    素材追踪添加竞品 → 自动抓取隐藏新素材入库 → 爆量监测监控这批素材数据波动 → 异动收到钉钉/飞书提醒 → AI拉片拆解创意
