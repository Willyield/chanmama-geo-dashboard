# ✅ 一句话结论
**可以看同行素材，但只能看到公开广告素材，看不到同行账户内部隐私数据（单条真实消耗、定向、出价）**；分为**官方免费工具**（优先用）和**第三方付费素材监测工具**。

## 一、官方千川素材监测工具（免费，看同行素材灵感）
1. **巨量千川后台【营销创意榜】**
入口：千川PC后台 → 工具 → 营销创意榜
- 筛选类目、时间，看行业内正在跑量的千川广告素材，能看到预估曝光、点击率、转化相关指标，用于找同行爆款创意
- 自家素材监测：【数据-素材分析】，只看你账户下素材消耗、播放、转化，**不能看同行账户明细**

2. **巨量创意（官方创意灵感平台）**
入口：巨量创意官网 → 创意灵感 → 千川专区
- 筛选千川广告素材，按类目、热度排序，看同行投放短视频，适合找脚本、画面、卖点参考，免费基础版够用

3. **巨量云图（品牌/商家版）**
入口：巨量云图 → 内容 → 内容榜/素材分析
- 可以看行业优秀广告素材、相似竞店的热门素材，还能对比行业素材指标；**云图需要开通权限，极速版/品牌版能力不一样**

4. **巨量百应 / 电商罗盘（抖店后台）**
- 电商罗盘→市场→内容榜单/短视频榜：看商品维度的带货爆款视频，包含千川引流素材，看同行商品对应的爆量素材、销量、曝光数据

> ⚠️官方工具限制：**不展示同行真实千川消耗、出价、人群定向**，只有行业聚合/预估数据；部分素材商家选择隐藏就看不到。

## 二、第三方素材监测工具（付费，同行素材能力更强）
核心能力：全网抓取千川广告素材、CID素材，可监控指定店铺/品牌的跑量素材，附带预估消耗、完播、评论、脚本拆解
1. **蝉妈妈创意**：千川广告素材库，可监控竞店素材，AI拉片拆解脚本
2. **有米云（原有米素材）**：广告创意库，抖音千川素材检索、品牌追踪
3. **考古加**：竞对店铺追踪，监控店铺下千川引流短视频、直播切片素材
4. **新抖**：千川广告素材检索，按类目、商品筛选广告素材

> ⚠️第三方工具数据都是**估算值，不是平台真实后台数据**；只能用于创意参考，严禁直接下载盗用素材（侵权违规）。

## 三、重要提醒
1. **只能借鉴创意，不能直接搬运/二次剪辑盗用**，会触发版权违规、千川拒审、限流。
2. 任何工具**都无法获取同行千川账户真实消耗、计划定向、出价**，所有第三方标注消耗都是模型预估。
3. 同行素材如果设置隐私隐藏，不管官方还是第三方工具都抓取不到。
4. 自家素材监测（素材消耗、转化、关停预警）优先用千川后台素材分析；大量找同行爆款素材，巨量创意+电商罗盘组合免费够用，精细化竞对监控再考虑付费第三方。
