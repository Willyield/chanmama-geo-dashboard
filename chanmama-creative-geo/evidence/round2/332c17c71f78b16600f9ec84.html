# ✅ 找同行**正在投放**抖音广告素材（优先官方免费，再第三方付费）
> 重点区分：**广告投放素材（千川/AD/本地推）≠ 自然流短视频**，下面方法优先抓带消耗、正在跑的素材。
> ⚠️ 法律提醒：**不能直接下载照搬重投**，只用来拆解脚本、结构、前3秒钩子、卖点、剪辑节奏，重新翻拍，避免侵权、同质化限流。

## 一、官方免费工具（最稳，优先用）
### 1. 巨量创意（巨量引擎旗下，首选）
入口：巨量创意官网 / 巨量广告后台-创意灵感
- 筛选：创意灵感 → 选择「巨量千川 / 巨量AD / 本地推」
- 关键词搜类目、竞品品牌名；时间选**近3/7天**（找正在投放，不要选30天以上，很多已经停投）
- 可按**曝光、点击率、转化**排序，同时能看配套落地页，能看到素材投放状态标签

### 2. 巨量云图（适合品牌/有云图权限，素材量更大）
入口：巨量云图后台 → 内容 → 带货短视频诊断 / AD竞价搜索
- 筛选行业，看行业参考素材，看曝光数据，重点拆解前3-5秒钩子，适合看同行持续跑量素材

### 3. 抖店电商罗盘（电商千川商家）
入口：抖店后台 → 电商罗盘 → 商品榜单 → 短视频榜
- 筛选类目、近7天，看挂车出单的短视频，很多是千川投放素材，看商品关联的投流视频

### 4. 抖音来客后台（本地生活、本地推）
入口：来客后台 → 线索经营 → 数据分析 → 排行榜
- 分视频/直播/私信留资榜，可筛选地区、行业，看本地同行正在跑的线索类广告素材

### 5. 抖音APP手动刷广告（低成本，抓新鲜素材）
1. 抖音搜索你的产品关键词，多看同行广告，点广告右下角「广告」标识
2. 长按广告视频，选择**为什么看到这条广告**，系统会持续推送同类竞品广告（定向养号）
3. 遇到广告直接录屏，建立素材库。缺点：耗时间，无法看到消耗数据

## 二、第三方付费监测工具（适合批量监控竞品、实时追踪上新素材）
适合素材缺口大、需要**盯固定竞品店铺/账号**，实时抓取对方新上投放素材：
- **蝉妈妈创意**：千川素材库，可以搜店铺/品牌，看跑量分、增量素材，监控竞品上新广告视频
- **考古加、新抖、有米云**：同样支持千川/AD素材检索，可筛选投放消耗、投放时间，识别当前还在消耗的素材；线索信息流素材优先看有米云

> 第三方有延迟，部分素材抓取不全，数据仅作参考，不能完全替代官方工具。

## 三、怎么判断素材「还在投放」，不是过期老素材
1. 时间筛选：优先**近3天、7天**
2. 看指标：有**持续曝光、增量、消耗**，不是历史爆款
3. 交叉验证：同一个素材在巨量创意+蝉妈妈都能检索到，说明大概率还在跑
4. 排除纯自然流：只看标记「广告/千川投放」的视频，普通主页短视频不算投流素材

## 四、拿到素材之后怎么做（素材库扩充流程）
1. 拉片拆解：前3秒钩子、痛点、卖点顺序、字幕、BGM、镜头切换、CTA话术，**不要下载直接复用**
2. 归类：按痛点型、效果展示、测评、口播剧情等分类入库
3. 逆向测试：把多个同行爆款结构融合，拍摄自己版本，小预算A/B测试
4. 持续监控：固定2-3个核心竞品，每日/每周看有没有上新素材

## 五、避坑重点
1. ❌ 直接扒视频二次上传：侵权投诉、审核拒审、同质化压流量
2. ❌ 照搬落地页、文案、口播台词：知识产权风险
3. ❌ 只看历史爆款：很多爆过的素材已经衰退停投，参考价值低
4. ❌ 完全对标头部天花板素材：头部预算充足，中小商家很难复刻
