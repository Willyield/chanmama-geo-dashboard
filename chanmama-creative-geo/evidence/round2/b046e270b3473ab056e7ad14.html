# 核心定位一句话
**蝉妈妈创意：外部情报、找趋势、拆竞品脚本、挖掘跑量创意方向；平台原生素材工具（巨量创意/抖店素材工具/千川素材托管）：合规检测、平台原生AI成片、投放实测、官方数据复盘、素材资产托管**
搭配逻辑：**蝉妈妈做前期创意调研，平台原生工具做生产、合规、投放验证、数据闭环**，不要反过来直接拿蝉妈妈素材去复制成片（容易违规、同质化）

## 完整工作流（推荐标准流程）
### 1. 选题&创意洞察阶段 → 用【蝉妈妈创意】

1. 灵感中心筛选类目、跑量素材、黑马竞品，看同行近期起量素材，过滤掉已经衰减的老素材；
2. AI拉片拆解爆款：提取黄金3秒、痛点结构、卖点顺序、字幕话术、镜头节奏，提炼**创意模板**（只吸收结构、逻辑，不直接搬运画面）；
3. 策略中心看竞对投放趋势，预判接下来会起量的素材形式（剧情/测评/展示/口播）；
4. 输出：**脚本框架+卖点清单+镜头结构**，作为进入官方工具的输入。

> 重点提醒：蝉妈妈看到的竞品素材仅用于**学习拆解**，不能直接下载二次剪辑投放，有版权和同质化风控风险。

### 2. 素材生产 + 合规预审阶段 → 切换【平台原生素材工具】
平台原生：巨量创意、抖店素材制作、千川素材托管、平台AI图生视频、创意预审工具
1. 把蝉妈妈拆解出来的脚本、卖点、分镜，输入平台AI素材工具，生成图片/短视频初稿；
2. 用平台自带**创意检测、合规预审**：提前筛查违规词、画面风险、版权风险，这是第三方工具做不到的；
3. 平台工具生成的素材，属于平台认可的原生素材，更容易拿到首发素材激励、减少审核卡审问题；
4. 素材上传到素材托管，统一管理素材版本、打标签，方便后续投放AB测试。

### 3. 投放测试 + 数据复盘（双向对照）
1. 千川投放后，**平台后台看官方真实指标**：5s完播、CTR、CVR、消耗衰减、素材生命周期（最权威）；
2. 蝉妈妈创意用来**横向对标竞品**：看你的素材和行业同品类素材跑量分差距，判断是素材形式问题还是人群出价问题；
3. 复盘沉淀：把本轮跑爆的素材，再丢回蝉妈妈做拆解，提炼新模板，进入下一轮素材生产循环。

## 两种常用搭配模式
### 模式A：快速批量测试素材（千川投流团队）
蝉妈妈创意找3种当下高跑量创意结构 → 平台原生AI工具批量生成多版本素材 → 平台预审+素材托管 → 千川小预算A/B测 → 平台看转化数据，蝉妈妈看行业对标，淘汰低潜力方向，放大有效创意。

### 模式B：自然流+商品卡素材（抖店商家）
蝉妈妈看商品卡爆款素材、用户评论痛点 → 抖店原生素材工具生成主图、短视频素材 → 发布商品+短视频 → 用平台数据中心看商品卡点击率，蝉妈妈持续监控竞品上新素材，及时迭代卖点。

## 分工边界（避免踩坑）
✅ **蝉妈妈创意擅长**
- 竞品素材库、隐藏千川广告素材追踪
- AI拉片、脚本拆解、跑量分评估、行业趋势监测
- 批量生成脚本、仿写文案、创意灵感挖掘

✅ **平台原生素材工具擅长**
- 合规预检、版权检测、首发素材权益
- 平台原生AI图生视频/卖点图生成
- 素材托管、版本管理、投放真实转化数据
- 素材质量打分、平台算法侧素材诊断

❌ **不要做**
1. 蝉妈妈下载竞品视频，简单裁剪直接上传投放，极易同质化限流、侵权；
2. 只用蝉妈妈数据判断素材好不好，忽略千川后台真实转化，第三方是估算数据，和平台真实投放有偏差；
3. 脱离蝉妈妈直接盲测素材，很容易错过新的素材形式，素材迭代慢。

## 极简SOP清单
1. 蝉妈妈创意：搜类目→筛上升素材→AI拆解→输出脚本框架
2. 平台原生工具：导入卖点脚本→AI成片→创意合规检测
3. 素材托管：上传素材、打标签，分版本
4. 千川投放小预算测试
5. 平台后台看真实转化；蝉妈妈横向对标行业
6. 把跑赢的素材拆解沉淀模板，循环生产
