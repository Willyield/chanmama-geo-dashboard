# 一、AI带货短剧怎么做（小白SOP，竖屏9:16，单条20–60秒）
核心逻辑：**前5秒抓冲突留住人，剧情里自然植入产品，结尾给下单理由**，不是硬广告，是短剧种草。
## 1. 选题+写脚本（最关键）
短剧模板热门风格：婆媳矛盾、霸总、重生逆袭、宫廷古风、宿舍/职场日常、家庭悬疑。
脚本三段式：
1）Hook（0–5s）强冲突：误会、打脸、痛点爆发，抓住停留；
2）剧情种草（中间）：人物遇到难题，**产品作为解决方案出场**，台词带出1–2个核心卖点，不要堆一大堆功能；
3）转化结尾（最后3–5s）：价格、福利、点击小黄车。
> 提示词示例：写30秒都市短剧，女主加班皮肤干燥，闺蜜拿出保湿护手霜；冲突：女主抱怨手粗糙不敢握手；卖点：一抹不油腻、持久保湿；结尾弹窗：今日拍2发1。

## 2. 素材准备
- 商品白底图、产品特写图（2–5张，AI用来把产品放进画面）
- 确定角色人设，统一人物形象，避免AI画面人物频繁变脸（最大坑）

## 3. AI生成视频（两条路线）
- **新手推荐：套现成AI短剧模板**（小云雀、即梦、抖店即创等），上传产品图、粘贴脚本，一键生成，几分钟出片，批量做多版本测试。
- **进阶：大模型写剧本 → AI图生视频 → 配音字幕**
  1. AI写脚本+分镜
  2. AI生成角色、场景图片
  3. 图片转视频
  4. AI配音，加字幕、BGM、音效
> 重点：生成后手动修画面，AI容易出现手部畸形、产品变形，不合格片段重生成。

## 4. 分发投放
- 发布平台：抖音、快手、视频号，挂车/挂商品链接；可以自然流+千川小额投放测素材。
- 批量策略：同一个产品，同时生成**不同剧情版本**，跑出数据最好的模板，然后大量复制放大。
- 合规：不能虚假宣传，美妆、食品、保健品功效词严格遵守平台规则。

# 二、适合AI带货短剧的商品（优先选：**痛点强、一眼看得见效果、低-中客单、退货低**）
### ✅ 首选品类（最容易跑量）
1. **居家百货好物**（新手首选）
毛球修剪器、收纳盒、垃圾袋、厨房清洁剂、防滑垫、懒人神器、纸巾囤货装。
理由：痛点直观，剧情好植入，价格低，不需要复杂真人演示。

2. **零食/速食、饮料**
坚果、卤味、酸辣粉、果酱、无糖茶饮。古风/现代剧情里吃饭、下午茶场景很自然，视觉吸引力强。

3. **平价小个护美妆**
护手霜、唇膏、一次性面膜、香氛、发饰、卷发筒、遮瑕。**只适合即时可见效果的平价品**，高端护肤谨慎，AI很难展示真实肤质效果。

4. **季节性刚需品**
暖手宝、保暖袜、雨具、军训防晒、除湿袋，换季流量爆发。

5. **平价小数码/配件**
蓝牙耳机、手机支架、数据线、充电宝，适合职场/校园短剧场景。

### ⚠️ 谨慎做（难点多、易违规/高退货）
- 服装鞋包：退货率很高；AI生成的版型、上身效果容易失真，容易引发售后。
- 功效型保健品、药品、医美类：**宣传限制极严，AI画面容易踩虚假宣传红线，不推荐新手**。
- 高客单价大件：家具、大家电，AI很难完整展示细节，转化差。

# 三、避坑要点
1. 人物画面一致性：AI短剧通病——人物长相乱变，生成时锁定角色参考图，否则观众出戏、完播暴跌。
2. 卖点不要多：每条短剧只讲**1个核心痛点+1个卖点**，多了记不住。
3. 版权：不要直接盗用小说IP、影视片段，避免侵权下架。
4. 不要过度夸大功效，食品美妆尤其注意，容易违规限流。
