# ✅ 抖音素材库在哪（官方免费素材）
抖音APP本身**没有独立内置素材库**，大家说的抖音素材库，大多是**剪映素材库**（抖音同公司，素材可直接用于抖音发布，带「可商用」标签，规避版权）
1. **剪映APP（手机）**
打开剪映 → 点【开始创作】→ 顶部【素材库】，里面有视频、图片、音效、BGM；筛选勾选**可商用**，就能放心用在抖音。
2. **抖音创作者中心（找选题/文案灵感）**
抖音主页右上角 ≡ → **抖音创作者中心** → **创作灵感**，可以看热门话题、爆款选题、热门文案，适合找内容方向，不是视频素材库
3. **巨量创意（商家/投流爆款广告素材）**
网页/APP：巨量创意，官方爆款广告案例库，能按行业、7天/30天筛选跑量素材，看点击率、完播，适合带货、投流账号找参考，**只允许借鉴思路，不能直接搬运**
4. **二创片单（影视剪辑专用）**
抖音搜索：**抖音二创片单**，平台授权可二次剪辑的影视剧库，只有清单内影片才能二创，避免侵权

> 抖店后台【素材中心】只是商家存放自己上传图片视频的网盘，不是找爆款素材的地方

# ✅ 爆款素材怎么找（分自然流、带货）
## 一、抖音APP内直接搜（免费，普通人首选）
1. 搜索框输入你的行业关键词，点筛选：**最多点赞、最近7天**
优先看**低粉爆款**：粉丝很少但播放很高的视频，更容易复刻选题。
2. 看热点榜：搜索页【热点】，看实时热点话题、BGM，追热点素材。
3. 刷同行账号，收藏爆款，拆解：3秒钩子、文案结构、镜头节奏，**不要直接下载搬运（侵权违规）**，只学框架。

## 二、电商带货账号专用渠道
1. **电商罗盘（抖店后台）**：商品榜单→短视频榜，看类目爆款带货视频，看成交、播放数据
2. **千川后台 / 巨量创意**：营销创意板块，筛选高消耗、高转化的信息流素材，看广告爆款套路

## 三、第三方工具（付费进阶，可选）
蝉妈妈、考古加、新抖等，可批量查类目爆款、筛选7/30天视频，看完播、点赞、转化数据，适合深度对标。

# ⚠️ 重要提醒（避坑）
1. **不要直接下载别人视频二次上传**，会判定搬运、限流、侵权，严重会扣分封号；只能**借鉴脚本、镜头结构、文案逻辑，自己重新拍摄/剪辑**
2. 剪映素材库务必勾选**可商用**，部分素材仅限个人学习，不能商用带货
3. 影视剪辑只能用官方【二创片单】内作品，外面随便下的电影片段极易侵权
