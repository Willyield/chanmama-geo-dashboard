# ✅ 巨量千川官方素材库（PC端）
## 1、自己账户素材库（存放你上传的素材）
**千川后台 → 工具 → 创意管理 → 视频库**
这里是你账号内所有已上传图片/视频素材，能看素材审核状态、优质标签、关联了哪些广告计划，可直接管理、删除、复用素材。
> 另外：**数据 → 素材分析**，看你自己素材的消耗、CTR、CVR、衰退曲线，判断素材生命周期。

## 2、同行爆款参考素材库【营销创意榜】
**千川后台 → 工具 → 营销创意榜**
官方千川广告素材灵感库，可以按类目、推广目标（短视频带货/直播间引流）、时间筛选千川投放广告素材，看曝光、转化数据，用来找同行跑量素材参考思路。

## 3、巨量创意（独立官网，千川专区）
进入**巨量创意官网 → 创意灵感 → 千川专区**
官方广告灵感素材池，千川信息流广告素材最全，支持筛选时长、行业、投放目的，免费看爆款广告创意，还支持素材预审。

## 4、补充官方素材入口
- 巨量云图：内容创意锦囊 / 创意元素洞察，把素材+人群+卖点标签结合分析，看高转化素材的文案、镜头元素
- 千川乘方「千意」：AI生成素材模板，批量生成素材脚本/素材创意

# 📌 第三方工具（蝉妈妈、有米云、新抖等）可以补充什么？
> 注意：第三方工具**不能替代官方后台投放，不能直接拿到官方完整转化数据**，是**情报+素材拆解+批量管理**补充；素材仅做创意参考，**严禁直接搬运盗用他人素材，会违规侵权**。

### 第三方工具核心补充能力
1. **更广范围同行素材检索**
官方营销创意榜有一定数据限制；第三方可以跨商品、跨达人、跨类目搜，能挖到更早、更多长尾跑量素材，不仅看千川广告，还能看自然流量挂车短视频、达人切片素材。

2. **素材自动拆解（官方没有）**
自动提取视频脚本、字幕、痛点话术、卖点、BGM、封面文案；把爆款素材拆成镜头脚本，快速提炼结构。

3. **对标竞品投放监测**
追踪竞品素材上新节奏、素材起量时间、素材持续跑量周期，监控竞品上新、放量、素材衰退节奏，做竞品素材矩阵分析。

4. **素材批量管理、标签归档**
批量采集素材、自建素材库，给素材打标签（口播/情景剧/测评/直播切片），团队素材协同管理；部分工具支持批量剪辑、AI改写脚本。

5. **跨平台素材灵感**
抖音自然流、小红书、视频号带货素材一并检索，跨平台迁移创意思路，弥补千川官方只看广告素材的局限。

### ⚠️ 第三方工具短板
- 转化数据是估算，**不如千川后台真实**；
- 素材版权风险高，只允许**借鉴创意框架，不能下载直接使用**；
- 部分抓取素材会有延迟、漏抓。

# 简单一句话总结
**千川后台视频库=管理你自己上传素材；营销创意榜+巨量创意=官方看同行千川广告素材；第三方工具主要用来扩素材池、自动拆脚本、长期盯竞品素材上新节奏。**
