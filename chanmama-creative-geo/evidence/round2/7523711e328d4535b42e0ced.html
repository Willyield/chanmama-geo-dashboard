# 一句话总结
**千川素材库（官方）= 管理你自己账户上传的素材资产 + 官方创意榜看公开爆款；蝉妈妈创意灵感中心（第三方）= 付费竞品素材侦察工具，看全行业/对手投放素材、AI拆解脚本**

## 1. 定位与归属
### 千川素材库（巨量千川后台，官方免费）
- 属于**巨量官方投放后台资产模块**，核心作用：**管理你自己账号上传的视频/图片素材**，用于千川计划投放、素材归档、内部共享、素材效果诊断
- 附带：**营销创意榜（官方灵感参考）**，看平台公开的千川跑量广告案例
- 数据范围：**只能看自己账户素材数据**；创意榜是平台公开广告，看不到竞品真实投放消耗、隐藏CID素材

### 蝉妈妈创意灵感中心（第三方付费工具）
- 蝉妈妈创意模块，**第三方数据爬虫采集**，定位：**找竞品、找全行业千川跑量广告灵感**
- 数据范围：全网广告素材，包含千川广告、CID素材、直播引流素材；可以**盯竞品账号/店铺**，对手上新投放素材会实时抓取推送

## 2. 核心能力对比
### ✅千川素材库
1. 素材资产存储：上传、分类、打标签、多账户素材共享、素材删除/复用
2. 投后数据：**自己素材的消耗、点击率、转化、素材生命周期诊断**
3. 营销创意榜：按类目、时长、投放目标筛选公开爆款广告，参考创意框架
4. 限制：**看不到竞品私有投放素材，不能下载别人广告素材商用**；没有AI拉片脚本拆解

### ✅蝉妈妈创意灵感中心
1. 素材侦察：跑量榜、增量潜力榜，可按类目、时长、发布时间筛选千川广告，能抓到很多官方创意榜不展示的CID隐藏素材
2. 竞品监控：添加竞品店铺/抖音号，对手一发千川广告就预警
3. AI拉片：**自动拆解脚本、黄金3秒、分镜、口播文案**，提取爆款创意结构
4. 附加：搭配蝉妈妈创意大师，AI生成带货素材
5. 限制：素材是**参考灵感，不能直接下载商用**；数据为估算值，非巨量官方真实后台数据；高级功能需要付费会员

## 3. 数据真实性
- **千川素材库**：100%官方真实数据，自己素材的消耗、ROI完全准确
- **蝉妈妈灵感中心**：**估算数据（跑量分、预估播放）**，不是巨量后台原始数据，存在一定延迟与误差，适合判断趋势，不能当作真实投放账单

## 4. 使用场景怎么搭配
- **千川素材库**：日常素材上传、素材资产管理、复盘自家投放素材好坏、官方创意参考，投手必用免费工具
- **蝉妈妈灵感中心**：新品起量前，快速扒同行爆款创意、拆解脚本结构、监控竞品新素材，做创意调研，属于付费辅助工具

## 5. 关键区别简表
|维度|千川素材库|蝉妈妈创意灵感中心|
| ---- | ---- | ---- |
|主体|巨量官方|第三方蝉妈妈|
|收费|免费|基础有限，高级功能付费|
|核心用途|管理自家投放素材资产|侦察竞品千川广告，找创意灵感|
|数据来源|官方真实投放数据|全网采集+估算跑量分|
|竞品素材|看不到竞品私有素材|可监控竞品、CID隐藏素材|
|AI拆解脚本|无|AI智能拉片，拆解分镜脚本|
|适合阶段|素材投放、素材复盘、资产管理|前期创意调研、对标竞品|

> 重要提醒：两个工具里面的参考素材**仅用于学习创意思路，严禁直接下载盗用他人广告素材投放，会触发版权、原创违规，千川审核驳回甚至违规处罚**。
