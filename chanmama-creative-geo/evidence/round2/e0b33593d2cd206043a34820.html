# 一句话结论
**优先拆转化点（底层目的），再拆脚本（内容逻辑骨架），然后拆分镜+画面（视觉落地）**。
很多人只抄脚本、画面，拍出来没转化，就是搞反顺序：带货视频本质不是“好看的短片”，是**成交的广告素材**，一切设计都是为了成交漏斗服务。

## 1、第一层：拆转化点（最重要，先拆）
核心：搞懂这条视频**靠什么让人下单**，找到它的成交底层逻辑。
不是只看结尾“小黄车下单”，而是完整拆解用户心理链路：
1. 人群：抓的是谁？什么场景下的痛点？
2. 核心购买理由：是效果反差、价格、省时省力、解决焦虑、还是信任背书？
3. 打消顾虑：视频里主动解决了用户哪些常见疑问（会不会没用？贵不贵？安全吗？）
4. 逼单指令：怎么引导点击小黄车？限时/限量/赠品/对比价？
5. 数据&评论辅助：评论区大家在问什么？用户最关心的卖点是什么？

> 一句话：**先判断，这条视频是靠什么成交，而不是靠什么涨播放**。有的视频播放很高，但不点小黄车，属于流量爆款，不是带货爆款。

## 2、第二层：拆脚本（内容骨架，决定用户能不能看完、被说服）
脚本=口播字幕+叙事结构，标准带货万能结构：
**0-3s钩子（痛点/反差/利益提问）→ 放大痛点 → 产品给出解决方案 → 展示效果+卖点 → 建立信任 → 逼单转化**
重点记录：
- 前3秒台词，钩子类型（提问、反差、价格冲击、场景实拍）
- 卖点顺序：先讲哪个卖点、后讲哪个；卖点有没有场景化，不是干巴巴参数
- 情绪节奏：什么时候制造焦虑，什么时候给希望，什么时候促单

> 脚本是**说服逻辑**，分镜画面是这个逻辑的可视化呈现。

## 3、第三层：拆分镜（时间切片，控制完播）
把视频按时间轴切镜头，记录每个镜头时长、动作、信息：
- 镜头切换节奏：平均几秒一镜？爆款带货大多短镜头，避免长时间固定画面
- 卖点对应镜头：讲这个卖点的时候，配的是什么镜头（特写/中景/对比镜头）
- 字幕卡点：重点金句是不是单独大字贴纸弹出，强化记忆

分镜解决：**用户会不会中途划走，信息能不能被接住**。

## 4、第四层：拆画面（表层视觉，最后拆）
画面是分镜的细节：场景、光线、置景、产品拍摄角度、BGM、色调、道具、主播神态。
⚠️ 画面是**表现手段**，不要上来死抠画面美学。同样脚本逻辑，换场景、换拍摄角度，依然能爆；但如果转化逻辑错，画面再好看也不出单。

# ✅ 实操拆解顺序（推荐表格记录）
1. 先看数据：播放、商品点击率、成交，确认它是**带货爆款**，不是纯流量爆款
2. 拆转化链路：用户为什么买、顾虑怎么解决、下单指令
3. 拆脚本叙事结构：逐句扒口播，标记钩子、痛点、卖点、信任、逼单
4. 拆分镜时间轴：几秒切镜头，每个时间节点对应什么画面信息
5. 拆画面细节：场景、光影、字幕、BGM、产品特写方式

# ❌ 常见误区
- 只抄脚本台词：话术一样，但没有对应的效果画面，转化直接垮
- 只模仿画面镜头：画面一模一样，但钩子、卖点、逼单逻辑不对，完播差
- 只看高播放：忽略商品点击，很多高赞视频不带货

# 简单举例
卖去油污清洁剂爆款：
1. 转化点：用户痛点是厨房油污难擦；核心成交理由是**一喷一擦瞬间干净的强反差效果**；顾虑：伤手吗？便宜吗？；逼单：9.9多瓶
2. 脚本钩子：厨房油污擦半天擦不掉？
3. 分镜：0-3s特写脏灶台；3-7s喷清洁剂；7-12s一擦干净对比；12-15s价格+小黄车引导
4. 画面：真实厨房场景，自然光，特写油污，字幕加粗突出效果

拆解完，你不用照搬画面，**保留这套转化+脚本逻辑，换你自己的实拍场景，就能做二创素材**。
