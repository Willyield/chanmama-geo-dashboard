# ✅ 千川PC后台素材库（账户自有素材）
## 入口
1. **视频库（素材资产管理）**：千川PC后台 → **工具 → 创意管理 → 视频库**
> 这里就是你账户自己的素材库，存放本账户上传、投放过的视频素材；图片素材在创意管理对应图片管理模块。
2. **素材分析（看投放数据核心入口）**：千川PC后台 → **数据 → 素材分析 → 视频素材/图片素材**
> 侧重素材投放效果报表，既能看素材预览，也能看消耗转化数据。
3. 新建计划添加创意时：**创编计划 → 添加视频 → 我的视频**，也可以直接调取账户素材库内素材

## 能看到哪些素材
- 本千川账户上传的**短视频、图片、图文轮播素材**
- 从抖音主页同步过来的视频、达人素材
- 素材标签：优质素材标签、素材状态（审核通过/驳回/过期等）、素材预览、上传时间、素材ID
> ⚠️ 只能看**自己账户**素材，看不到其他商家账户内素材。如果想看行业爆款参考素材，去【工具→营销创意榜】或者巨量创意官网。

## 能看到的投放数据（素材分析模块）
**账户整体维度**：总消耗、展现、点击、点击率、成交金额、ROI、优质素材激励占比等汇总指标
**单素材粒度**：
- 消耗、曝光、点击、完播率、点赞、评论
- 成交金额、订单量、转化率、ROI
- 该素材关联了哪些计划、优质素材激励增量数据（优质素材专属）
支持按时间筛选，支持导出素材报表。

# 📌 补充：巨量创意（创意灵感/行业爆款参考库）
入口：巨量创意官网 → **创意灵感 → 热门素材 → 巨量千川专区**
- 作用：看行业公开爆款广告素材参考（**无他人账户详细消耗ROI，只展示公开参考指标**），不能直接看到别人账户隐私投放数据。

# 💡小提示
移动端千川后台素材管理能力相对精简，素材批量管理、详细素材报表建议在PC端操作。
如果页面入口找不到，可咨询巨量千川官方客服：千川PC端 https://qianchuan.jinritemai.com/ 右下角【智投星】；抖音APP搜索“巨量千川客服”。
