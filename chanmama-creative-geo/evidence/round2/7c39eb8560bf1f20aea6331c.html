# 短视频素材洞察工具清单（电商）
分为**官方免费工具（优先，数据最准）**、**第三方商业素材Spy工具（看竞品千川投流素材）**

## ✅ 官方工具（抖音电商，免费）
1. **巨量创意**
    核心：千川广告素材库，筛选类目、CTR、转化率、曝光时长，看付费跑量素材，找钩子、卖点、口播脚本，投流团队必用。
    适合：千川投手、素材策划，找付费爆款广告素材。
2. **电商罗盘（抖店后台）**
    商品-榜单-短视频榜，看单品带货短视频、看素材对应的销量，可筛选7/30天，看自然+带货短视频，看同行单品素材矩阵。
    适合：商家运营，看单品真实带货短视频。
3. **巨量云图（极速版）创意元素洞察**
    拆解行业爆款素材元素：镜头、卖点、人群、场景，区分带货短视频/直播间引流短视频，做大盘创意趋势分析，看素材人群匹配度。
    适合品牌，做人群+素材联动，找行业创意趋势。
4. **巨量百应**
    选品库-带货内容，看达人带货短视频，能看到视频对应的结算GMV，对标达人素材。

## ✅ 第三方国内工具（抖音/快手电商）
1. **蝉妈妈**
    抖音电商垂直工具；短视频榜单、商品素材库，**AI拆视频**，自动拆解黄金3秒、分镜、文案，监控竞品账号/单品素材；能看到大量千川素材。
    优势：AI拆解强，电商转化指标全；适合中小商家、MCN、短视频编导、投手。
2. **飞瓜数据**
    覆盖抖音+快手；达人、商品、短视频、广告素材一站式，飞瓜易投专门看千川广告素材，多平台对标。
    优势：跨平台，达人分析更强；同时做抖音+快手电商团队首选。
3. **有米有数（有米云）**
    主打**千川隐藏投流素材**，素材库体量很大，AI拆片、素材批量下载，支持CID素材，适合重度投流团队、品牌大商家，广告素材挖掘能力强。

## ✅ 跨境TikTok电商素材工具（如果做海外）
- BigSpy、Minea、AdSpy：TikTok/FB广告素材spy，看海外广告短视频、落地页、投放时长。

# 📌 电商团队怎么选型（核心判断标准）
### 1）先看团队规模&目标
- **小店新手/小团队（1-3人，预算有限）**
  优先：**巨量创意 + 电商罗盘（免费）**，足够找对标素材、看单品带货视频；不需要立刻买付费工具。
  需求：找爆款灵感、看同行短视频，少量素材拆解。

- **中小电商团队（有投流、编导，要大量千川素材）**
  选：**蝉妈妈**。性价比高，AI拆视频，编导可以直接拆脚本、黄金钩子，投手找千川素材，一个工具覆盖运营+投手+内容。

- **品牌/大投放团队（千川预算高，大量测素材，要挖掘隐藏广告素材）**
  选：**有米有数 或 飞瓜**。素材库更大，千川隐藏素材覆盖更强，支持批量素材监控、竞品品牌素材全周期追踪。

- **同时做抖音+快手双平台**
  优先**飞瓜数据**，双平台统一查看素材和商品数据。

### 2）选型5个关键评估维度
1. **素材来源**：能否区分「自然短视频」和**千川付费广告素材**（电商最重要！很多爆量素材是付费素材，自然榜看不到）
2. **拆解能力**：能不能AI自动拆视频：前3秒钩子、字幕、卖点、分镜、评论痛点，减少编导人工拆解时间
3. **数据指标**：素材不能只看点赞，要看**挂车销量、CTR、5秒完播、消耗、投放时长**（电商核心，不是内容号的播放）
4. **类目精度**：细分三级类目筛选能力，避免跨类目无效素材干扰
5. **价格&账号**：是否按席位收费、是否支持多子账号（编导/投手/运营分开登录）

### 3）推荐最简组合方案（最省钱高效）
- 基础组合：**电商罗盘 + 巨量创意（免费）**，所有电商团队必开，作为基础素材来源。
- 进阶组合：免费工具 + **蝉妈妈**，适合大多数国内抖音电商团队，内容+投流兼顾。
- 重度投流品牌：免费工具 + **有米有数**，主攻千川广告素材挖掘。

### ⚠️ 重要提醒
工具只用来**分析、拆解爆款结构、提炼卖点、学习镜头钩子**，**不能直接搬运下载素材发布**，会侵权、无首发、违规限流；工具的正确用法：拆底层逻辑，原创翻拍二创。
