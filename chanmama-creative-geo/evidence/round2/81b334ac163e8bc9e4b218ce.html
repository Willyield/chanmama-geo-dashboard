# 核心逻辑：**痛点是钩子，卖点是解决方案**
不要直接念卖点参数，把**产品卖点 → 解决哪个痛点 → 用户得到什么好处**一一对应。
> 卖点（产品有什么）→ 解决痛点（用户烦什么）→ 用户收益（得到什么体验）

## 一、先做转化表（写脚本前必做）
拿你的产品，列成三列：
| 用户痛点（场景化麻烦） | 产品卖点（硬参数） | 用户收益（感性好处） |
|---|---|---|
| 早上洗头下午就油、刘海贴脸 | 控油配方、长效控油 | 一天清爽，不用反复洗刘海 |
| 普通水杯漏水、笨重 | 食品级密封、轻量化 | 放包里不漏水，出门携带轻松 |

> 要点：痛点必须是**真实场景**，不要抽象。不说“体验差”，要说“放包里漏水弄湿手机”。

## 二、万能短视频脚本公式（30～45秒带货口播，最常用）
**3秒钩子（痛点场景）→ 放大困扰 → 产品出场 → 卖点对应痛点+可视化演示 → 前后对比 → 信任背书 → 行动指令**
1. **0-3s 钩子（痛点抓人，必须口语）**
直接抛出用户日常麻烦，精准圈人群。
例：是不是早上刚洗完头，到下午刘海就一绺一绺贴额头？
2. **3-12s 放大痛点，讲代价**
讲这个麻烦带来的尴尬、麻烦。
例：出门拍照不好看，半天就要去卫生间补洗刘海，特别麻烦。
3. **12-22s 产品登场，给出解决方案**
引出产品，不说参数，先说它能解决刚才的麻烦。
例：后来我一直在用这款洗发水，专门针对头油人群。
4. **22-32s 卖点落地+画面演示（重点！卖点可视化）**
**一个痛点对应一个卖点，边演示边讲**，不要堆卖点，一次只讲2-3个核心卖点。
例：它是控油配方，不是强行拔干头皮，洗完发根蓬松，不容易塌。（画面：洗头前后对比、发根特写）
5. **32-38s 降低顾虑，信任背书**
例：无硅油，敏感头皮也能用。
6. **38-45s 结尾引导下单**
例：容易头油、刘海塌的朋友，点下方小黄车试试。

## 三、脚本表格模板（直接复制使用）
|时长|画面|台词（口播）|字幕|
| ---- | ---- | ---- | ---- |
|0-3s|场景实拍：对着镜子摸油刘海|是不是早上刚洗头，下午刘海就贴脸上？|头油星人太懂了！|
|3-12s|皱眉、拿纸巾擦额头油|出门没多久就油腻，拍照巨显邋遢，还要频繁洗刘海|油头尴尬谁懂|

## 四、3种不同风格变体，批量产出多条素材
### 版本1：场景剧情版（适合故事感）
**痛点场景表演 → 旧方案踩坑 → 上新产品实测 → 效果对比 → 转化**
适合家居、收纳、母婴、厨房用品。

### 版本2：避坑劝退版（强转化，投流好用）
**别再买XX了！（痛点）→ 普通款缺点1/2/3 → 我们产品卖点刚好解决这些坑 → 实测效果**
> 例：别再买一坐就卷边的收腹裤！硬勒肚子还留红印。这款弹力面料，坐下不卷边，收肚子不勒人。

### 版本3：干货科普版（适合知识类、美妆护肤）
**很多人XX，其实是踩坑了（痛点）→ 根源原因 → 选品标准（对应卖点）→ 推荐产品**

## 五、避坑要点
1. 不要一次性堆5个以上卖点，短视频只讲**2～3个核心卖点**，多了记不住；
2. 卖点一定要**可视化**：讲防水就倒水测试，讲蓬松就拍发根特写，不要纯嘴讲；
3. 语言口语化，删掉专业术语，把“高密封性”改成“随便放包里，怎么晃都不漏水”；
4. 同一个产品，**换不同痛点单独拍多条视频**，用来测试流量。比如水杯可以拍漏水痛点、太重痛点、难清洗痛点，三条独立素材。

## 六、快速实操示例（保温杯）
痛点：保温杯半天就不保温、盖子难清洗、笨重。
卖点：24h保温、可拆卸杯盖、轻量化。
钩子：冬天带出门的保温杯，上午装热水下午就凉了？
中间：很多杯子保温差，杯盖缝隙藏污不好洗，还沉甸甸。这款24小时保温，杯盖可以全部拆开洗，重量很轻，放包里没负担。
结尾：想要长效保温又好清洗的保温杯，点小黄车。
