# 一、千川素材在哪看、看哪两类指标
入口：千川后台 → 【素材】→【素材分析】，可以按素材维度聚合数据，**不要只看计划数据，要把同一条素材下所有计划合并看**，避免单计划波动误判。

分两层：**内容质量指标（能不能抓住人）** + **成交结果指标（能不能赚钱）**
## 1）内容指标（先看，决定素材有没有潜力）
- **3秒完播率**：钩子核心，及格线≥30%；低于30%，基本是开头不行，后面卖点再好也很难救
- **完播率**：短视频素材基础，看整体内容吸引力
- **CTR点击率**：
  - 低价福利品参考≥3%；中高客单非标≥2%；**红线＜1%基本放弃**
  - CTR＞10%警惕：大概率标题党，泛流量多，看着点击高但转化差，不要盲目追投
- CPM千展：拿到1000次曝光的成本，**和你账户历史均值对比，不是硬套行业**，CPM持续走高=流量越来越贵，素材衰退信号

## 2）成交指标（最终判断能不能跟进，优先级最高）
- **支付ROI**：你的保本ROI是唯一标尺
  - ROI ≥保本线：优质，可以放量
  - ROI=保本线80%-100%：潜力素材，可以小预算培养，观察趋势
  - ROI＜保本线60%：直接放弃，不要硬烧
- **转化成本**：是否低于你的目标成本；成本持续下降=模型向好；持续上涨=衰退
- **消耗能力**：同等预算下能不能稳定跑出量；**有消耗≠好素材，必须结合ROI**
> 核心逻辑：eCPM由CTR、CVR决定，CTR负责拿流量，CVR负责把流量变成订单，两者缺一不可

# 二、测试流程：新素材怎么判断（非常关键，不要过早下结论）
新素材规则：**先跑够样本，再判断，不要烧几十块就杀素材**
实操标准：新素材给到小额测试预算，**跑满3000展现，消耗300~500元**再评估，给系统建模时间，一般观察2~24小时（短视频素材）

✅ **值得跟进/放量的素材（满足下面组合）**
1. 3秒完播≥30%，CTR在合理区间（不是虚高）
2. CVR/转化成本优于账户均值，ROI≥保本线
3. 消耗趋势：稳定消耗，CPM不持续上涨
4. 人群匹配：素材引来的访客，直播间承接正常，退款率无异常飙升

👉 这类素材动作：复制多条计划、逐步抬预算，**追高不追低，追新不追老**

⚠️ **可以小预算继续观察（潜力素材）**
内容数据不错（钩子、点击率好），但ROI略低于保本，≥保本80%，转化成本缓慢下降，还没跑出足够转化样本。
动作：保留少量预算继续测，不加大投放；同时复盘直播间承接、卖点话术问题。

❌ **直接放弃素材**（满足任意一条）
1. 3秒完播长期＜30%，CTR＜1%，钩子完全不行
2. 跑满3000展现，ROI低于保本60%，无好转趋势
3. 消耗很快，但零转化/转化极低（高点击低转化，泛流量）
4. 老素材：连续2天，消耗下滑、ROI持续跌破保本线，CPM明显抬升（素材衰退）

# 三、额外2个容易忽略的判断维度
1. **直播间承接**：素材再好，直播间留不住、转化差，投产照样崩。素材进来的流量，直播间30秒停留、购物车点击、成交转化要匹配。素材拉来的人群和直播间承接人群错位，不要继续放量素材，优先调直播间。
2. **素材生命周期**
- 新素材（0~3天）：重点赛马，抓爆量苗子
- 成熟期素材：ROI稳定，可以主力放量
- 衰退期：消耗逐步下滑、CPM上涨、ROI慢慢掉，**不要持续硬扛，逐步降预算，上新素材替代**

# 四、简单一句话判断口诀
**先看3秒抓不抓人，再看点击准不准；
投产对照保本线，成本趋势看升降；
有消耗不代表赚钱，衰退素材不要硬撑。**
