# 蝉妈妈创意：追踪抖音号/小店/品牌/关键词新投素材
核心功能：**素材定向追踪（素材追踪）**，可以一次性添加抖音账号、抖音小店、品牌词、产品关键词，系统定时抓取千川新投素材（含千川隐藏广告素材），支持消息预警；同时搭配「找素材」「灵感中心」手动检索补充。

## 一、素材追踪（自动实时监控，推荐）
1. 进入蝉妈妈创意平台 → 打开【素材追踪/素材定向追踪】
2. 新建监控任务，4类对象按需添加：
    - **抖音号**：输入竞品抖音昵称/ID，监控这个账号所有千川投放素材
    - **小店**：输入竞品抖音小店名称/ID，监控该小店关联所有投放素材（多个达人投这家店的素材都会抓到）
    - **品牌**：输入品牌名称（如XX护肤品），抓取素材标题、口播、商品名包含该品牌的广告素材
    - **关键词**：产品词、卖点词（比如“美白面膜”），匹配素材文案、商品标题含该词的投放素材
> 支持同时混合添加抖音号+小店+品牌+关键词，建立一个监控池
3. 设置监控规则：
    - 更新频率：约30分钟抓取一次新素材，捕捉刚上线的千川素材
    - **爆量阈值**：设置预估消耗/播放增量，素材达到条件触发告警
    - 通知渠道：绑定钉钉/飞书，有新素材、爆量素材自动推送提醒
4. 保存任务，等待系统采集；任务列表可以随时查看新增素材、看素材数据（投放天数、预估消耗、5s完播等），支持AI智能拉片拆解脚本分镜

> ✅优势：**自动持续监控**，不用反复搜索；能抓到千川后台本地上传、抖音主页看不到的广告隐藏素材。

## 二、找素材（手动检索，快速查最新素材）
创意模块 →【找素材】
- 检索入口切换：按达人（抖音号）、按小店、品牌、关键词搜索
- 筛选条件重点勾选：**新发素材**，时间范围选「近1小时/近6小时」，只看刚上线新投素材
- 附加筛选：类目、跑量分、预估消耗、素材形式（短视频/图文）、投放平台（千川/CID）
- 适合：临时快速查一波，适合一次性调研，不做长期持续监控

## 三、灵感中心榜单（大盘趋势补充）
【灵感中心】→高增量素材榜 / 跑量素材榜
可以按类目筛选，看全行业近期爆发素材；适合挖掘同赛道黑马品牌、小店，再把发现的竞品加到上面「素材追踪」长期盯。

## 四、使用小要点
1. 追踪范围：主要抓取**千川广告投放素材**，不是账号自然短视频；自然流视频不会被纳入投流素材监控
2. 素材判断：重点看「投放天数」，投放天数=1就是刚上新投素材；搭配跑量分、预估消耗判断潜力
3. AI拆解：抓到素材后点AI智能拉片，自动提取钩子、口播文案、画面结构，用于创意参考（**禁止直接搬运素材**）
4. 权限：素材追踪属于蝉妈妈创意会员功能，免费版无法使用完整监控预警能力

## 五、推荐工作流
1. 先用【找素材/灵感中心】批量挖掘竞品抖音号、小店、品牌词
2. 把目标批量添加进【素材追踪】任务，设置爆量阈值+钉钉预警
3. 收到新素材提醒 → AI拉片拆解 → 沉淀创意库
4. 定期复盘监控池，淘汰失效竞品，新增对标账号
