# 一、短视频开头钩子怎么写（黄金3秒，一句话+画面配合）
核心原则：**不要铺垫背景，直接上冲突/痛点/结果/反常识**，一句话控制在2～3秒说完，字幕、画面和台词同步发力。

## 6大类万能钩子模板，直接套用
### 1. 痛点提问钩（最稳，适合干货、生活、情感）
公式：戳中用户难题 + 提问，让观众对号入座
- 例子：减肥为什么吃得很少，体重还是不掉？
- 例子：为什么你很努力，却一直赚不到钱？

### 2. 结果前置钩（强吸引力，适合经验、改造、逆袭）
公式：【短时间】+【惊人结果】，再引出“怎么做”
- 例子：30天，我把负债从10万降到2万。
- 例子：0粉丝起号，半个月赚了5000。

### 3. 反常识/颠覆认知钩（制造好奇，拉高停留）
公式：大家都以为A，其实真相是B
- 例子：别再早睡了，很多人越早睡越累。
- 例子：粉丝多不代表赚钱，3000精准粉比30万粉更值钱。

### 4. 警告避雷钩（趋利避害心理，适合科普、避坑）
公式：90%的人都踩坑 / 千万别做这件事
- 例子：90%装修的人，都栽在这个坑上。
- 例子：这个习惯正在悄悄透支你的身体。

### 5. 点名精准人群钩（筛选精准流量，提升转化）
公式：专门对某一类人喊话
- 例子：月薪5000还存不下钱的人，认真看完。
- 例子：开店没客流的老板，这条视频救你。

### 6. 悬念留一半钩（故事类、剧情）
公式：讲一半，藏关键信息
- 例子：那天我做了一个决定，彻底改变我的生活。

> ❌ 千万别用的烂开头：大家好我是谁、今天跟大家聊聊XX、很久没更新了。全是无效铺垫，观众直接划走。

> ✅ 钩子写作小技巧：
1. 一条选题，**写3个不同版本钩子**，测试对比；
2. 台词口语化，短句，少长句；
3. 画面同步钩子：讲反差，首帧直接放对比图；讲痛点，首帧放对应场景；
4. 不要标题党：钩子承诺的内容，后面视频必须兑现，否则评论翻车、账号降权。

# 二、怎么判断视频有没有爆款潜力：分【发前预判】和【发后数据验证】
## ✅ 发之前，肉眼预判（提前筛选题和钩子），满足越多潜力越大
1. **强情绪**：能勾起好奇、焦虑、共鸣、惊讶、愤怒其中一种；平淡中立内容很难爆
2. **受众够大**：这个痛点/话题，很多人都遇到，不是极小圈子的内容
3. **有信息差**：观众看完能学到东西、刷新认知，不是大家早就知道的常识
4. **可讨论**：看完愿意在评论区说话（提问、反驳、分享自己经历）
5. **价值明确**：看完能获得：方法、避坑、情绪安慰、新认知

简单自测一句话：**刷到这个开头，你自己会不会停下，想继续看完？**
如果你的朋友听完钩子，第一反应是“然后呢？为什么？”，钩子合格；如果反应“哦，知道了”，钩子弱。

## ✅ 发布后，看核心数据（最准，1小时初判）
> 平台算法优先看**前几秒留存**，再看整体完播、互动

1. **2秒跳出率**（最直接看钩子）
- ＜20%：优秀，钩子很强
- 20%～30%：合格
- ＞30%：开头不行，钩子要重写

2. **5秒完播率（黄金指标）**
- ＞45%：爆款潜力很大
- 35%–45%：优质，可以继续推流
- ＜25%：开头失败，直接重拍/换钩子

3. **整体完播率**
- 干货口播：≥30% 爆款潜力；≥20%合格
- 剧情类：≥25%算优质

4. 互动指标：
- 互动率（点赞+评论+收藏+转发/播放）≥5%优质
- **收藏高**：代表内容实用，长尾流量强；**转发高**：自带社交传播属性，容易出圈；评论多，代表观点有争议、强共鸣

> 简单判断规则：发布1小时内，如果5秒完播达标，播放量持续上涨，评论自然增多，大概率会进入更大流量池；
> 发布1小时播放增长极慢，5秒完播很低，基本很难爆，不用硬投流，优先复盘钩子和选题。

# 三、快速实操流程
1. 选定选题，先写3版不同类型钩子；
2. 自测+找1-2个目标受众试听，选出最好的一版；
3. 拍摄，前三秒画面、字幕、台词对齐钩子；
4. 发布，重点盯**2秒跳出、5秒完播**；
5. 数据差：修改钩子重拍；数据好：积极回复评论放大推流。
