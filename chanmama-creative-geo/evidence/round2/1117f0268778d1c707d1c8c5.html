# ✅ AI商品特效怎么做（2套工作流：小白模板版 / 专业可控版）
AI商品特效主要分为**静态图片特效**（主图、场景、材质特效）和**动态视频特效**（旋转、粒子、水雾、爆炸、材质流动、镜头运镜），核心逻辑：**白底产品原图 → AI加特效/场景 → 生成图片/短视频 → 剪映微调**

## 一、小白快速流程（套模板，不用写复杂提示词，推荐新手）
1. **准备素材**：商品白底图，尽量产品轮廓干净、主体清晰（手机简单拍摄，AI自动抠图）
2. **选择电商特效模板**
    - 图片特效：换背景、水滴、冰霜、烟雾、光斑、光影、产品悬浮、多色换色、材质质感增强
    - 视频特效：产品360°旋转、粒子散开、液体流动、水雾、花瓣环绕、爆炸重组、镜头推拉运镜
3. **上传产品图，一键生成**，平台自动匹配光影，保证产品不变形，直接导出图片/短视频
4. **后期微调**：剪映简单加字幕、背景音乐、卖点文字，适配平台比例（9:16短视频，1:1主图）

> 常用工具：可灵AI、即梦、LiblibAI、美图设计室、剪映AI生视频；电商平台自带：京东Oxygen、淘宝AI商品图等，大量电商专用特效模板

## 二、专业可控流程（自定义特效，适合品牌广告片）
1. **准备参考图**：产品多角度白底图，固定产品主体（主体参考图，防止AI把产品改样、logo变形）
2. **写提示词** 公式：**产品主体+特效效果+镜头+光影+画质**
    示例：香水瓶，缓慢旋转，瓶身流动金色粒子，柔和柔光，浅灰色极简背景，电影质感，4K，电商广告，产品细节清晰，无扭曲
3. **图生视频/首尾帧生成**：用首帧+结束帧，控制特效变化过程（比如冰块融化、液体注入、烟雾缓缓散开）
4. **分镜头拼接**，AI生成多段特效短片，剪辑软件拼接、调色、加音效，输出完整广告片

> 重点避坑：一定要锁定产品主体，不然容易出现产品变形、logo文字错乱；特效不要太杂乱，优先突出产品卖点。

## 三、适合哪些电商场景
### 1. 商品主图/详情页（静态AI特效）
✅ 美妆护肤：水珠、水光、冰晶、泡沫、柔光氛围，展示保湿、清爽、修护卖点
✅ 香水香薰：烟雾、粒子、花瓣飘散，营造高级氛围感
✅ 家电、厨具：金属光泽、蒸汽、火焰特效，突出材质质感
✅ 家具软装：AI把产品放入客户家实景（AR/AI场景替换），看摆放效果
✅ 服饰鞋包：一键换色、AI模特试穿，一套图做多色SKU素材，大幅节省拍摄成本

### 2. 短视频带货、信息流广告（动态AI特效，抖音/视频号/小红书）
- 3秒钩子视频：产品登场特效（炸开、烟雾浮现、旋转亮相），提高完播
- 卖点可视化：保温杯冰水凝结水珠、洁面泡沫膨胀、护肤品精华流动，**把看不见的效果视觉化**
- 多SKU快速批量生成：同一款产品，批量生成不同场景、不同特效短视频，投信息流广告

### 3. 直播间素材
- 直播间背景短视频、贴片特效；AI数字人手持商品特效视频，循环播放
- AR实时试妆、试戴、试穿：口红、眼镜、首饰、衣服，用户直接在线预览上身效果，提升转化

### 4. 跨境电商（亚马逊、独立站、Temu）
批量生成白底图、生活场景图、产品动态展示短片，多风格、多场景素材，降低海外实拍成本

## 四、不推荐使用场景
- 强功能精密工业品、医疗器械：特效容易夸大功效，会违规；产品参数、结构要保证100%真实，AI特效仅做氛围，不能篡改产品本身
- 食品类：特效过度夸张（AI生成超夸张拉丝、爆汁）容易被判定虚假宣传

## 五、小技巧
1. 特效服务卖点，不要为炫特效而特效：保湿用水滴，冷感用冰霜，高级感用柔光粒子
2. 优先小批量测试，确认产品不变形再批量生成
3. 广告投放注意合规：AI特效不能夸大产品功效，素材要保留真实底图
