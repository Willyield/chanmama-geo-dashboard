# 一、素材效果怎么追踪（建立追踪机制）
> 核心原则：**素材单独标记，数据按素材粒度拆分，不要只看计划/账户**
1. **素材编码命名**
每条素材唯一ID：`类型_钩子方向_版本号`（例：短视频_痛点脱发_V3），图片/视频、封面、文案都绑定这个编号。
2. **后台埋点与数据口径**
- 渠道后台：巨量/腾讯/百度，拉【素材维度报表】，不是只看计划；
- 落地页/小程序：加素材参数（utm_creative），区分不同素材带来的转化；
- 统一口径：明确转化定义（表单/加购/成交），统一统计周期，避免跨报表数据打架。
3. **监测节奏**
- 小时级：新素材起量期，盯曝光、消耗、CTR，看能不能拿到流量；
- 日度：每日汇总素材表，记录指标，监控衰减；
- 稳定素材：按3/7天周期评估，**不要少量消耗就下结论**（一般素材需要积累足够样本，电商建议单素材≥500消耗再评估）。
4. **附加定性追踪**
评论区、私信、用户反馈、素材流失曲线，用来判断内容问题，弥补纯数字的不足。

# 二、重点看哪些数据（分3大类：拿量指标、转化指标、结果收益指标）
## ✅ 1、拿量&素材吸引力（决定素材能不能跑出去）
- **曝光、消耗**：基础门槛，0消耗=素材拿不到流量，检查钩子、出价、审核、定向；
- **CPM千次展现成本**：获取1000次曝光的成本。CPM高=买流量贵；CPM过低往往是泛流量，转化差；
- **CTR点击率（点击/曝光）**：封面+开头钩子好不好。点击率低：封面、标题、开头没吸引力；点击率虚高，容易人群跑偏，转化差；
- **3s/5s/10s完播率（短视频素材核心）**
  3秒完播=决定能不能拿到初始流量，代表钩子能力（行业常用参考：≥30%及格）；
  10秒完播：看第一段卖点能不能留住人；
  拉**流失曲线**，找到用户集中划走的时间点，定位内容卡点；

## ✅ 2、流量质量&转化承接（点进来之后能不能转化）
- **CVR转化率（转化/点击）**：素材承诺和落地页/商品匹配度。CTR高、CVR很低：素材“夸大钩子”，人群不精准；CTR正常CVR低：卖点、落地页、价格、信任背书问题；
- **CPC点击成本**：单次点击多少钱；
- **CPA转化成本**：获取1个目标转化的成本（表单、成交、留资），核心成本指标；
- **GPM千次观看成交（电商）**：每千次观看带来GMV，衡量流量精准度，平台判断素材潜力的关键指标；
- **加购/收藏率**：中间行为指标，看用户意向，提前预判转化潜力。

## ✅ 3、收益结果指标（最终判断素材值不值得投）
- **ROI投产比**：总收入÷消耗；对比你的保本ROI，判断盈利；
> 注意：ROI受商品、直播间影响，**不能单靠ROI否定素材**，要结合CTR、CVR一起看；
- **订单量、客单价**；
- **素材衰减曲线**：看素材生命周期，什么时候CTR/ROI下滑，提前准备新素材接替。

# 三、素材四象限分类复盘（最实用）
把素材按【消耗量级 × ROI/转化成本】分成四类，直接定动作：
1. **高消耗、正向ROI（爆款主力素材）**
✅ 动作：放量；拆解这条素材的钩子、场景、卖点、镜头逻辑，批量衍生同逻辑新素材；持续监控衰减。
2. **低消耗、正向ROI（潜力素材）**
✅ 动作：小幅提预算、放宽一点探索，测试能不能起量；保留继续观察。
3. **高消耗、负向ROI（流量大不赚钱）**
⚠️ 动作：重点排查：CTR高CVR低→钩子引流泛；看人群画像，曝光人群和成交人群是否不一致；可缩预算、或直接关停，不要持续空耗。
4. **低消耗、负向ROI**
❌ 动作：直接关停，复盘失败原因，避免继续踩同样脚本/钩子坑。

# 四、复盘分析逻辑（定位问题，一句话定位）
1. 没有曝光/消耗：3秒完播差、素材审核、出价低、定向太窄；
2. 有曝光，CTR很低：封面、前3秒钩子不行；
3. CTR不错，但CVR很低：素材承诺和落地页/商品不匹配、人群泛、卖点没说服力；
4. CTR、CVR都不错，但CPM很高：竞争激烈、人群窄，流量太贵，ROI打不平；
5. 前期好，后期逐步下滑：素材疲劳衰减，需要上新素材轮换。

# 五、复盘输出（形成闭环，沉淀素材库）
每次复盘记录：
1. 素材版本、脚本核心卖点、钩子类型；
2. 关键指标（3s完播、CTR、CVR、CPA、ROI）；
3. 结论：亮点 / 问题卡点；
4. 后续动作：放大、改封面、剪辑变体、废弃；
沉淀**素材标签库**：痛点型、对比型、剧情型、口播型，记录哪种钩子在本品类更容易跑出高ROI。

# 六、避坑提醒
1. 不要拿极小样本数据判断素材好坏；
2. 区分「素材问题」vs「落地页/商品/直播间问题」：素材负责引流，转化承接不全是素材锅；
3. 不同渠道素材指标基准不一样，不要跨渠道直接对比；
4. 关注人群维度：看曝光人群、点击人群、成交人群三者画像是否对齐，很多素材ROI差是人群跑偏，不是画面不好。
