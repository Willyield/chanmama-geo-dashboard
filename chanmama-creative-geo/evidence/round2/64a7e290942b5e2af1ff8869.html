电商团队素材太乱，脚本、分镜和成片怎么统一管理？

# 核心思路：**按「项目」为单位打包，脚本/分镜/素材/成片全部绑定到同一个项目，统一文件夹+统一命名+版本管控+标签库**，不再脚本在文档、成片在剪辑工程、原始素材散在每个人电脑、聊天记录里。
> 一句话原则：**一个项目一套资料，资料之间互相跳转关联；母素材单独沉淀公共素材库，方便跨项目复用**

## 一、固定文件夹目录（直接复制落地，云盘统一根目录）
根目录分两大块：**【项目库】（单次拍摄/单条视频） + 【公共资产库】（可复用镜头、BGM、参考脚本模板）**
```
/电商素材总库
├─【项目库】
│  └─SKU_产品名_拍摄批次号（例：洁面乳_20261012_01）
│     ├─00_脚本分镜 （核心文档）
│     │    ├─脚本文档v1/v2/v最终版
│     │    └─分镜表/分镜图（在线文档，每镜编号，和成片时间码一一对应）
│     ├─01_原始素材RAW（相机原片、原音，禁止删！）
│     ├─02_精选镜头Select（挑好可用片段，按镜头编号，对应分镜镜号）
│     ├─03_剪辑工程文件（剪映工程/PR工程）
│     ├─04_成片导出
│     │    ├─测试版v1、修改版v2、终审版v_final
│     │    └─多平台版本（抖音版/小红书版/千川投放版）
│     └─05_项目备注：审片批注、投放数据、修改记录
└─【公共资产库】
   ├─镜头资产（空镜、产品特写、对比镜头，打标签）
   ├─模板库（通用脚本模板、分镜模板、字幕模板）
   ├─BGM/音效库（版权标注）
   └─爆款拆解参考
```

## 二、强制统一命名规则（解决“最终版_final改不改v3”灾难）
### 文件名模板
`SKU_类型_卖点_日期_版本号`，用下划线，**不要空格、特殊符号**
示例：
洁面乳_脚本_去黑头_20261012_v2.docx
洁面乳_分镜图_去黑头_20261012_v1.png
洁面乳_成片_去黑头_千川_20261012_v_final.mp4
洁面乳_原素材_镜头03_泡沫特写.MP4

> 约定：**v_final=终审定稿，不再修改；所有修改都新建版本，禁止直接覆盖旧文件**。脚本和分镜里的镜号，必须和精选素材、成片时间码一一对应，剪辑拿到分镜，直接按镜号调取素材。

## 三、脚本&分镜标准化，和成片强绑定（最关键）
1. **统一脚本模板（在线文档：飞书文档/WPS）**
表格字段：镜号、时长、画面描述、台词、字幕、BGM、参考画面、备注。
> 镜号是唯一索引！脚本、分镜图、素材文件名、审片批注，全部共用同一个镜号，编导、拍摄、剪辑、投手看的是同一份文档，信息同源，不再各写各的。

2. **分镜两种方案按需选**
- 轻量电商短视频：直接在脚本表格插入参考图，不用手绘；
- 剧情/长素材：单独分镜画板，每镜标镜号，可导出图片放进00_脚本分镜文件夹。

3. **审片闭环**
用审片工具（分秒帧等）上传成片，**按时间码/镜号打点批注**，批注直接关联到对应脚本镜号；修改意见自动存档，不会散落在微信群聊天记录里。每次修改后生成新版本成片，写入版本记录。

## 四、工具选型（分低成本入门 / 专业素材管理两套）
### ✅ 小团队低成本（优先推荐，快速落地）
- 存储：企业云盘（飞书云盘/阿里云盘企业版），统一存储，本地电脑只放临时工程，**原始素材必须上云**，防止电脑丢文件
- 脚本分镜协同：飞书多维表格 / WPS在线文档，多人同时编辑、版本历史可回溯
- 审片批注：分秒帧，成片上传后帧级批注，不用来回发文件、截图传群

### ✅ 素材量大、多SKU、千川素材赛马（专业创意资产平台）
创量创意云、媒介资产管理平台：支持素材标签、投放数据绑定，一条成片直接关联脚本、分镜、母素材、消耗ROI，方便后续素材裂变复用

## 五、标签体系：素材从文件变成可检索资产
除文件夹外，给所有素材打标签，支持跨项目检索：
- 产品标签：SKU、品类
- 素材类型：口播/产品特写/对比测试/场景空镜
- 钩子类型：痛点开头、效果展示、价格冲击
- 投放状态：待测试、赛马中、爆量、废弃
- 数据标签：3秒完播、ROI（投放后回填）

> 好处：拍完一批素材，后续做混剪、变体素材，可以直接检索“洁面乳+对比镜头”，不用重复拍摄，最大化复用母素材

## 六、团队SOP（流程，避免执行走样）
1. 编导：新建项目文件夹 → 写脚本+分镜（带镜号）→ 提交评审
2. 拍摄：拍完立刻把RAW原始素材上传到项目01_RAW，精选镜头命名带上镜号放入02_Select
3. 剪辑：基于同项目脚本分镜、精选镜头出片，导出多版本成片
4. 审片：在审片工具批注，按镜号反馈；定稿标记v_final
5. 运营/投手：投放完成后，把投放数据回填到项目文件夹备注，更新素材标签（爆量/低效）
6. 每周固定维护：清理废弃素材、把优质镜头沉淀进【公共资产库】

## 七、避坑重点
1. ❌ 禁止：脚本放微信、成片放剪辑师个人电脑、原始素材只存本地、直接覆盖旧版本
2. ❌ 禁止：文件名随意：新建文档、视频最终版、123.MP4
3. ✅ 强制：**原始RAW素材永久保留不删除；只在云盘统一归档，本地仅临时工作**
4. ✅ 权限管控：编导可编辑脚本，剪辑上传成片，投手只读查看，防止误删

## 快速落地建议
不要一次性全量整理历史旧素材，**新产出素材立刻执行这套规范；历史素材分批迁移，优先迁移爆量素材**，一周就能跑通基础流程。
