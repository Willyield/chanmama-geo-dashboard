# ✅ 电商找爆款素材工具清单（按优先级）
> 核心原则：**官方工具优先（免费、数据真实），第三方付费工具做深度竞品挖掘，AI工具做素材拆解+仿写**；素材只能**借鉴框架、卖点、钩子**，严禁直接搬运侵权。

## 一、抖音电商官方（免费，优先用，最准）
1. **巨量创意（千川素材库）⭐⭐⭐⭐⭐**
    千川专区，筛选近7/15/30天，按**CTR、消耗、转化**排序，直接看跑量广告短视频，看钩子、口播、画面结构，适合投流素材灵感。
2. **抖店【电商罗盘】⭐⭐⭐⭐⭐**
    商品→商品榜单→短视频带货榜；筛选类目、时间，看单品对应的带货短视频、销量数据，找自然流爆款素材。
3. **巨量百应**
    选品广场，点开商品【带货内容】，查看达人发布的全部带货短视频，看达人素材打法，适合达人素材对标。
4. **巨量云图**
    内容创意锦囊，看高转化素材+人群、卖点标签，拆解哪类画面/话术更容易打动目标人群，适合品牌团队深度分析。

## 二、第三方付费数据工具（多平台素材挖掘，团队效率神器）
1. **蝉妈妈**
    覆盖抖音/视频号；素材库、竞品监控、榜单、AI拆视频脚本；可以挖到千川投放素材、黑马低粉爆款，适合团队批量找对标素材、盯竞品上新素材。
2. **有米有数（有米云）⭐⭐⭐⭐**
    抖音/快手/小红书素材库，可查看千川隐藏投流素材，AI自动拆片、提取卖点脚本，适合大规模素材收集，投流团队常用；素材库体量很大。
3. **新红（小红书专项）**
    专门挖小红书种草图文/短视频爆款，找小红书主图、种草文案、场景素材，做小红书电商必用。
4. **表答Biaoda.me**
    输入关键词/竞品链接，自动抓取抖音、小红书爆款，**AI自动拆视频钩子、逐字稿、分镜**，直接导出仿写脚本，适合内容团队快速拆解大量对标视频。

## 三、淘宝/天猫素材工具（淘系商家）
- **生意参谋**：市场洞察，看竞品高点击主图、详情、买家秀，找图片素材、文案卖点。
- **店侦探/店透视**：竞品主图、sku图、评价买家秀素材挖掘。

## 四、AI辅助提效（素材拆解+二次创作）
1. **即创（巨量官方AI）**：基于爆款素材做二创、换分镜、改写口播，批量生成素材版本，适合千川素材快速扩量。
2. **剪映AI**：批量提取字幕、拆镜头，快速把对标视频导出脚本。
3. 图片类：Canva可画、光厂，参考高点击率电商主图案例库。

# 📌 团队高效工作流（推荐）
1. 先用**电商罗盘+巨量创意**锁定赛道7天内爆款，过滤已经衰退老素材；
2. 不确定竞品隐藏投流素材 → 开**蝉妈妈/有米有数**批量检索；
3. 拿到一批视频后，**表答/剪映AI**自动拆钩子、口播、分镜，整理成爆款模板库；
4. 设计师/摄像基于模板翻拍，用即创批量产出多版本素材测试；
5. 建立素材台账：记录素材卖点、钩子、数据，沉淀团队自己的爆款库。

# ⚠️ 重要提醒
所有平台素材**版权受保护**，不能直接下载搬运发布；只做创意分析、拆解结构、学习卖点，翻拍必须重拍画面、重写文案。
