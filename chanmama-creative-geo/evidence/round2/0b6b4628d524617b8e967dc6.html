# 电商团队视频素材资产沉淀完整方案
核心思路：**原始素材分段留存 + 统一目录+命名+标签 + 绑定投放数据 + 入库流程化 + 权限与备份**。不要只存最终成片，要把**母素材、镜头片段、脚本、口播、音乐、投放数据**一起沉淀，才能反复剪辑裂变，避免人走素材丢。

## 一、素材分类与目录结构（文件夹标准）
分三大块：**原始源素材、可复用片段库、成品&项目归档**
```
素材总库
├─01_RAW原始拍摄源文件（摄像机原片、原始录音，不要压缩）
│  └─品类/产品/拍摄日期
├─02_CLIP可复用片段库【最重要，用来二次剪辑】
│  ├─产品特写镜头
│  ├─场景镜头
│  ├─口播片段
│  ├─对比测试镜头（使用前/后）
│  ├─细节证据镜头（质地、防水、承重等）
│  └─品牌固定资产：LOGO、片头片尾、BGM、转场、字幕模板
└─03_FINAL成品项目库
   ├─待投放、赛马中、爆款归档、废弃下线
   └─分平台版本：抖音竖版/快手/小红书/视频号
```
> 电商关键概念：**母本素材**。同一套场景+产品骨架算一个母本；基于母本换钩子、换文案、换开头，生成多条变体素材，全部关联到同一个母本下管理，大幅降低拍摄成本。

## 二、统一命名规范（强制，所有人遵守）
推荐模板：`品类_产品名_素材类型_卖点_日期_版本_画幅`
示例：
`面霜_修护面霜_特写镜头_上脸吸收_20261010_v1_916.mp4`
`垃圾袋_加厚垃圾袋_成品_承重测试_20261005_v2_916.mp4`

规则：
- 用下划线，**不要空格、特殊符号、不要写final、最终版**，只用v1/v2/v3
- 源素材、片段、成品文件命名体系保持一致

## 三、标签&元数据体系（用来快速检索，多维表格/DAM填写）
每条素材入库，必须录入元数据，推荐用多维表格（飞书/Notion/简道云）或者专业DAM素材管理系统：
1. 基础信息：产品、品类、拍摄日期、素材类型（口播/开箱/对比/场景）
2. 内容标签：核心卖点、钩子类型（痛点/价格反差/效果展示）、风格（真实测评/剧情/沉浸式）
3. 投放数据标签（电商最重要）：消耗、点击率CTR、转化率CVR、ROI、素材状态【待测/赛马中/爆款/废弃】
4. 版权信息：BGM授权、模特肖像授权，避免后续违规风险

> 核心：**把投放数据绑定素材**。沉淀的不只是视频文件，而是“什么镜头、什么卖点更容易出单”的经验资产。爆款素材单独打标，后续直接复用镜头、脚本框架做变体。

## 四、入库流程：拍完即归档，不要积压
1. 拍摄当天：剪辑导出源文件+拆有用的片段，**直接入库**，不要留在剪辑师电脑本地
2. 剪辑师：拆分可复用镜头，单独导出短片段，打上基础标签
3. 运营：投放后，把千川/DOU+后台数据回填到素材表格，更新素材状态标签
4. 审核：没有按规范命名、缺少授权文件的素材**不允许入库**

> 避坑：不要等项目结束再整理，批量回溯整理素材成本极高，很难坚持

## 五、存储、备份与权限
### 存储分层
1. 本地高速盘：剪辑临时工程文件
2. 云端共享存储（阿里云盘企业、夸克企业、DAM素材管理平台）：正式素材库，团队在线预览
3. 冷备份硬盘：原始RAW素材异地备份，防止误删、硬盘损坏

### 权限控制
- 编导/剪辑：上传、修改素材
- 运营：查看、填写投放数据，不可删除
- 普通成员：只读预览
**禁止随意删除素材，废弃素材做归档标记，不直接删除**

## 六、沉淀知识资产：不只存视频，还要拆脚本框架
素材资产分两层：**媒体文件资产 + 内容方法论资产**
1. 爆款视频拉片拆解：钩子、文案、分镜、CTA、爆点原因存入表格
2. 脚本模板库：开箱模板、测评模板、痛点口播模板，直接复用
3. 镜头库：固定爆款镜头包（比如产品挤压、拉丝、防水测试镜头），后续拍摄优先复用这类经过市场验证的镜头

> 一句话：只下载保存视频叫收藏；**拆卖点、绑定投放数据、可检索复用**，才叫资产沉淀。

## 七、工具选型（按团队规模）
- 小团队（3-8人）：企业云盘 + 飞书多维表格/石墨多维表，低成本落地
- 中大型电商团队：专业DAM数字资产管理平台，支持视频预览、AI自动打标签、检索、权限管理
- 剪辑工程：PR/剪映工程文件统一归档，方便二次修改

## 八、日常维护规则
1. 每周1次素材库巡检，清理重复文件、更新素材投放状态
2. 新成员入职，培训命名、标签、入库规范
3. 月度复盘：筛选高ROI母本素材，规划下个月素材裂变方向，减少无效拍摄
4. 版权管理：BGM、模特肖像授权文件和素材绑定归档，避免投流违规下架

## 九、落地顺序（由简到难，不要一次性上全套系统）
1. 先统一文件夹结构 + 文件命名规则
2. 搭建多维表格，记录素材基础信息+投放数据
3. 开始拆分可复用镜头片段库
4. 增加标签体系，实现检索
5. 团队流程固化，最后再考虑采购专业DAM系统
