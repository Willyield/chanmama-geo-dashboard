# 核心思路：**以项目为中心，脚本/分镜/成片双向绑定 + 统一命名+固定目录+在线协同表**
电商短视频最大痛点：脚本、分镜、成片散落在微信、个人电脑、不同网盘，版本混乱，不知道哪个脚本对应哪条成片，投放数据和原素材脱节。
一句话规则：**一条视频项目，全部资料放在同一个项目文件夹；脚本、分镜、成片共用同一个项目编号，全程溯源**

## 一、统一文件夹结构（云盘，全员共享，直接复制模板）
```
【根目录】
├─ 01_素材资产库（可复用，跨项目共用）
│   ├─ 品牌规范（logo、字体、色值、口播模板）
│   ├─ Broll空镜、产品特写、通用场景
│   ├─ 音效BGM（标注版权）
│   └─ 历史爆款成片+对应脚本分镜归档
└─ 02_项目生产文件夹（每一批/每条视频独立项目）
    └─ P20261014_洁面乳_痛点口播01【项目编号】
        ├─ 01_前期策划
        │   ├─ 脚本文档
        │   └─ 分镜图/分镜表
        ├─ 02_原始拍摄素材（原始原片，只读，禁止修改覆盖）
        ├─ 03_剪辑工程文件（剪映工程/PR工程）
        ├─ 04_成片版本
        │   ├─ v01初稿、v02修改版、v03终审版
        │   └─ 投放裁切版本（9:16/1:1）
        └─ 05_项目台账（链接：多维表格，记录状态、卖点、投放数据）
```

## 二、强制文件命名规范（杜绝“最终版、最终版2、真最终版”）
模板：`项目编号_内容类型_版本`
示例：
- P20261014_洁面乳01_脚本_v02.docx
- P20261014_洁面乳01_分镜_v01.pdf
- P20261014_洁面乳01_成片_v03_终审.mp4

> 规则：**不用中文空格，版本号v01、v02，终审标记写在文件名；原始素材不要重命名，保留机内文件名，在表格关联**

## 三、脚本、分镜、成片绑定台账（最关键！实现一键溯源）
用飞书多维表格/Notion/简道云建一张**项目总表**，一条一行，字段如下：
1. 项目编号（主键，脚本、分镜、成片全部使用这个编号）
2. 产品、视频类型（痛点/测评/展示）、核心卖点
3. 脚本文档链接、分镜链接
4. 成片云盘链接、版本、审核状态（待写脚本｜待拍摄｜剪辑中｜终审通过｜已投放｜废弃）
5. 拍摄日期、编导、剪辑
6. 投放数据（消耗、点击率、ROI）
7. 标签：#洁面乳 #口播 #3秒痛点，支持检索筛选

作用：点开一行，直接打开脚本、分镜、成片，反过来看到这条成片对应的原始创意，投放爆了可以快速复用脚本框架；素材出问题也能反向追溯来源

脚本建议标准化表格模板：序号、时长、画面描述、台词、字幕、对应分镜编号、备注。分镜可以是图片/表格，每一格标注镜头编号，脚本里写清楚对应镜头号，脚本和分镜一一对应。

## 四、工具选型（分小团队/中大型电商团队）
### 小团队（3–8人，低成本）
- 存储：阿里云盘/企业网盘，统一云盘，禁止本地单独存素材
- 文档协同：飞书文档/腾讯文档写脚本、分镜
- 台账：飞书多维表格
- 审片：分秒帧，直接在视频上打点批注，反馈留在成片上，不用来回传脚本和截图沟通

### 中大型电商素材量产团队（千川大量素材）
创意云平台（创量创意云、分秒帧素材中台），支持：脚本在线协同、素材标签化、成片版本管理、素材和投放打通，自动打标签，投手和编导共用素材库，沉淀爆款素材资产库

## 五、配套SOP流程（落地，避免规则形同虚设）
1. **立项**：编导新建项目，生成项目编号，在多维表格新建一行，创建项目文件夹，填写脚本和分镜
2. **拍摄**：拍完原始素材立刻上传02_原始素材文件夹，**原始素材只读，任何人不要修改**
3. **剪辑**：剪辑完成导出初稿，上传成片目录，在表格更新成片链接，发起审片
4. **审核迭代**：所有修改意见写在审片工具；新版本成片按v02、v03递增，**不覆盖旧版本**
5. **终审归档**：通过投放后，标记状态，打上卖点标签；投放结束后，把整套脚本+分镜+成片归档进素材资产库，方便后续复用混剪
6. **定期清理**：每月清理废弃素材，打废弃标签，不要直接删除；定期备份整套素材库

## 六、标签体系（方便检索，沉淀可复用镜头）
给成片、脚本、Broll素材统一打标签：
- 产品标签：洁面乳、保温杯
- 素材类型：口播、产品特写、对比测试、场景使用
- 卖点标签：去油、大容量、不伤肤
- 效果标签：高CTR、高ROI、低效素材

> 好处：后面混剪批量生产时，直接搜标签调取同卖点脚本、镜头，不用从零写脚本、重新拍摄

## 七、避坑要点
1. ❌ 禁止：脚本、成片单独发微信，微信文件不归档，很容易丢失、版本错乱
2. ❌ 禁止：覆盖旧成片，旧版本保留，版本号递增；不要只用“最终版”
3. ❌ 禁止：原始拍摄素材直接修改、裁剪，原始素材是母版，单独存放只读
4. ✅ 责任：指定素材管理员（兼职即可），每周检查命名、归档是否规范
