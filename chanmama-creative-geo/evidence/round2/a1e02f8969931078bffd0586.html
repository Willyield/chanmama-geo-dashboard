# 一句话总结
**蝉妈妈（蝉妈妈数据）：电商大盘经营数据平台，看生意、选品、达人、直播GMV；蝉妈妈创意：独立素材洞察平台，主打千川广告素材、找跑量创意、AI拆片+AI做素材**，两个产品同一家公司，但会员分开购买。

## 一、蝉妈妈（主站/蝉妈妈数据）
### 核心功能
1. **商品/大盘数据**：看商品销量、GMV、价格带、品类趋势、小店/品牌整体销售数据，分析竞品店铺整体生意情况
2. **达人分析**：筛选带货达人、看达人带货能力、粉丝画像、历史带货战绩，用于达人BD合作
3. **直播数据分析**：直播间预估GMV、销量、流量结构、直播回放、直播间商品转化，监控竞品直播、做直播复盘
4. **自然流短视频**：看账号主页自然爆款短视频（**不是千川广告素材为主**），账号整体作品数据

### ✅适合场景
- 做**选品、达人对接、直播运营、店铺大盘监控**
- 直播为主、自然流起号，重点看竞品直播间销量、达人带货情况
- 商家/运营：判断哪个品好卖、找达人合作、监控竞品店铺整体营收
- 做大盘调研、行业趋势、达人商务BD

## 二、蝉妈妈·创意（独立素材平台 cy.chanmama.com）
### 核心功能
1. **千川广告素材（强项）**：收录千川投放短视频、直播间投流素材，能查到**主页不公开的广告素材（投流隐藏素材）**，按跑量分、增量榜筛选正在花钱跑的素材
2. **素材拆解AI工具**：智能拉片，自动提取脚本、口播文案、黄金3秒结构，提炼爆款创意要素
3. **AI创意生产**：AI一键成片、爆款模板、数字人、脚本仿写，素材团队协作管理、素材云存储
4. **竞品投放监控**：定向监控竞品品牌/小店正在投放的广告创意，看对方投流节奏、素材迭代策略

### ✅适合场景
- **千川投流团队、短视频素材组、剪辑/编导**，核心痛点：缺投流素材灵感
- 付费流量为主，需要大量参考同行正在花钱跑的广告短视频
- 批量拆解竞品脚本、快速产出带货短视频素材
- 品牌投放团队，跟踪竞品广告创意迭代、分析投放策略

# 三、快速对比
|项目|蝉妈妈（数据）|蝉妈妈创意|
|---|---|---|
|定位|电商经营数据平台|千川爆量广告素材洞察+AI创意工具|
|侧重点|**生意结果：销量、GMV、达人、直播、商品大盘**|**广告素材：投流视频、脚本、创意灵感**|
|素材范围|账号主页自然短视频，**不擅长千川隐藏广告素材**|千川投放素材（含非主页广告素材）|
|会员|独立会员，和创意分开买|独立会员|

# 四、怎么选
1. **只做直播/选品/找达人、自然流为主** → 买【蝉妈妈数据】即可，创意可以不用
2. **做千川付费投放，每天要找、拆解大量带货短视频素材** → 买【蝉妈妈创意】
3. **品牌团队，既要监控竞品店铺销量+达人，又要大量千川素材参考** → 两个都开

> 小提示：蝉妈妈主站里面有简易素材板块，但**完整千川广告素材库、智能拉片、AI成片能力在蝉妈妈创意独立平台**
