# 千川投放前，找同行跑量素材（优先官方免费，第三方付费补监控）
> 核心原则：**优先看消耗/跑量分，不要看点赞**；只借鉴脚本框架、卖点、前3秒钩子，**严禁直接搬运下载原视频投放，会侵权、违规限流**

## ✅ 官方免费渠道（最靠谱，优先用）
### 1. 巨量创意（千川专区，推荐）
- 入口：巨量创意官网 → 创意灵感 → 选择【巨量千川】专区
- 筛选：类目、时间（**7天优先，找正在持续消耗的素材**）、广告类型（短视频/图文/直播切片），可按CTR、转化排序
- 价值：都是平台广告池里真实投流素材，能直接看到同行用什么钩子、卖点、视频结构

### 2. 千川后台【营销创意板】
千川后台→工具→营销创意板，筛选行业近7/15天跑量素材，自带CTR、转化数据，用来对标你的素材基准线

### 3. 巨量云图（有云图权限用）
内容→带货短视频诊断 / 创意元素洞察，选择你的类目、客单价区间，看行业头部素材、同行主打卖点、镜头形式（口播/场景对比/产品特写），适合挖掘**爆款创意元素**（痛点话术、画面对比手法）

### 4. 抖音APP手动刷广告（低成本人肉找）
1. 抖音搜索：产品词、痛点词（比如“腰粗裤子”）
2. 多刷同类带货视频，刷到带「广告」标签的就是千川广告素材
3. 点视频主页，持续刷，系统会持续推同品类广告；把对标账号/店铺记录下来
> 适合新品前期，快速感知同行钩子风格

## ✅ 第三方付费工具（适合批量监控竞对，看实时跑量）
蝉妈妈创意、有米云、考古加，功能大同小异：
1. 输入竞品**店铺ID/商品链接**，添加竞对监控
2. 筛选：千川广告素材、近7天、**跑量分/消耗排序**，过滤自然流视频
3. 优势：可以监控同行**新上素材**，同行上新广告几十分钟就能捕捉，支持AI拆解脚本、分镜、卖点
> 适合成熟品类、持续盯竞品素材迭代；预算有限可以先用免费渠道先收集一批素材框架

## ✅ 电商罗盘/巨量百应
电商罗盘商品榜单，找到同类爆品，点商品详情→视频分析，可以看到这个商品下面，同行用来千川引流的短视频素材，看哪条视频持续出单消耗大

# 📌 筛选标准：怎么判断是不是真跑量素材（重点）
1. 时间：优先**近3-7天**持续有曝光，不是30天前爆过现在停投的老素材
2. 指标：**消耗>点赞**，跑量分高；高点赞低消耗=自然流爆款，不一定适合千川投放
3. 稳定性：素材生命周期，看素材发布后是否持续放量，不是爆1天就断量
4. 匹配：客单价、人群、产品形态和你接近；不要直接抄高价/低价完全不同赛道的素材

# 📌 拿到素材之后怎么做（关键避坑）
1. 拆解，不是搬运：拆解**前3秒钩子、痛点顺序、证明卖点的镜头、结尾转化话术**，保留框架，全部重拍，换模特、场景、台词、镜头角度
2. 分类整理：把收集素材分成几类：痛点口播类、对比测评类、直播切片类、产品特写类，每类保留3-5个优秀框架，用来批量生产素材测试
3. 合规提醒：**不能直接下载原视频混剪投放，侵犯著作权，会出现审核拒审、赔付、限流**，只能作为创意参考

## ✅ 完整流程总结
1. 确定对标竞品（同类目、相近客单价、稳定千川消耗的店铺）
2. 巨量创意+巨量云图，批量拉行业跑量素材，建立素材灵感库
3. 第三方工具添加竞对监控，跟踪同行新素材
4. 拆解爆款结构，翻拍原创素材，放到千川计划里测CTR/CVR
5. 持续收集：千川素材迭代很快，每周都要更新对标素材库
