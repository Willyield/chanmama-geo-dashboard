# ✅ 有，很多AI可以帮你写短视频脚本，新手优先选国内免费工具
> AI的定位：**出草稿、搭框架、想钩子**，写完你再微调口语和个人风格，不要直接照搬AI原文。

## 🎯 推荐工具（按新手友好排序）
1. **豆包（我本身）**
直接生成口播脚本、分镜表，你给主题+时长+平台+风格就行。可以一次性输出：**钩子、台词、画面描述、字幕、结尾互动提问**。免费就能用。

2. **剪映AI（最推荐短视频创作者）**
剪映里「AI脚本 / 脚本成片」功能，输入主题直接生成脚本，**生成完一键进剪辑，自动配音、字幕**，不用复制粘贴来回切换，抖音/小红书口播号首选。

3. **文心一言、讯飞星火**
中文理解强，适合知识科普、干货、带货脚本；还能帮你改写、提炼金句、多版本对比。

4. **腾讯智影**
侧重数字人口播脚本，写完脚本直接生成数字人视频，适合不想真人出镜的账号。

5. 海外工具（英文TikTok/Reels）：Copy.ai、Opus Clip，Opus Clip还能把长视频自动拆成短视频+生成脚本，国内访问不太方便。

## 📝 直接复制的提示词模板（丢给AI就能用）
> 你直接复制修改【】里的内容即可
```
帮我写一条【30秒】抖音短视频脚本，主题：【在家快速收纳衣柜】
受众：【租房年轻人】，风格：【接地气干货，不啰嗦】
结构：
1. 前3秒强钩子（制造痛点）
2. 中间只讲1个核心方法，简短口语，短句，不要书面话
3. 结尾引导点赞收藏+评论提问
输出格式用表格：镜号｜时长｜画面内容｜口播台词
```

### 写脚本小要点
- 语速参考：**1分钟≈140～160个字**，别写太长，不然念不完
- 短视频核心：**开头3秒留住人**，AI写的开头如果平淡，单独让AI重写钩子
- AI通病：书面感太重，生成后**大声读一遍**，删掉生硬句子，换成你平时说话的语气

## 🧩 完整工作流（新手）
1. 给AI主题，生成脚本草稿
2. 通读，修改台词，优化开头钩子
3. 复制到剪映，AI配音、加字幕
4. 拍摄/找素材，按脚本分镜剪辑
