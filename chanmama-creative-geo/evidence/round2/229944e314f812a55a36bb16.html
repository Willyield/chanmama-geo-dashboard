# ✅ 千川直播引流素材 VS 商品广告素材
> 一句话核心区别：**直播引流素材目的是把人拉进直播间；商品广告素材（短视频带货素材）目的是看完视频直接下单**

## 一、详细对比
|项目|直播引流素材（短视频引流直播间）|商品广告素材（短视频带货/商品投放）|
| ---- | ---- | ---- |
|**营销目标**|营销目标：直播带货，落地页=直播间|营销目标：短视频带货，落地页=短视频小黄车商品页|
|**核心任务**|吸引用户点进直播间，**不把卖点讲完，留悬念**，由直播间主播承接转化|短视频内讲完整卖点、效果、价格，用户看完直接视频内下单|
|**内容逻辑**|3秒抓眼球，痛点/福利钩子，引导“来直播间看、直播间有福利”，不一次性讲透产品|完整种草，演示效果、对比、逼单，信息闭环，看完就能直接买|
|**常用素材形式**|短视频、直播间高光切片；也可以直接投直播间实时画面（直投）|短视频、图文、商品图，视频直接挂车|
|**考核指标**|CTR点击率、**进房率**、进房成本、直播间ROI|CTR、视频CVR（短视频直接下单转化率）、短视频ROI|
|**适合场景**|正在开播，直播间人货场稳定，需要持续拉人进直播间|不开播/非直播时段，短视频独立带货、商城短视频流量|

> 重点避坑：不要拿商品带货素材直接投直播间引流。视频把卖点全部讲完，用户看完就不需要进直播间，进房率会很差

## 二、在哪里看素材（自己账户素材 + 同行参考素材）
### 👉 千川PC后台（看自己投放素材）
1. 登录巨量千川PC：qianchuan.jinritemai.com
2. **投放管理 → 计划管理**
    - 营销目标选【直播带货】，里面创意就是**直播引流素材**
    - 营销目标选【短视频带货】，里面创意就是**商品广告素材**
3. 素材库：左侧【素材】，可以看到账户上传全部视频/图片素材，支持筛选、预览、看消耗数据

### 👉 官方参考素材（看同行爆款，免费）
1. **巨量创意官网**：千川创意专区，可以筛选【引流短视频】/【带货短视频】，看行业跑量素材
2. **巨量云图极速版 → 创意元素洞察**，区分：**引流短视频（直播用）、带货短视频（商品广告素材）**
3. 电商罗盘（抖店后台）：短视频分析，查看单品投放短视频素材

### 👉 小店随心推（移动端）
打开抖音→更多功能→小店随心推
- 推直播：直播引流素材
- 推商品：商品广告素材

### 👉 第三方工具（蝉妈妈、新抖、有米云）
创意库里面素材分类：**直播引流素材、商品带货素材**，可以筛选同行千川广告素材（大多付费）

## 三、投放小提示
- 直播引流素材：优化目标选【进入直播间】、【直播间成交】
- 商品广告素材：优化目标选【商品购买】，视频必须挂车
