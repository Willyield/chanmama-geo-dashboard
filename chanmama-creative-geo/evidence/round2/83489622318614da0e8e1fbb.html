# 一、6大类万能钩子（黄金3秒，一句话+画面配合）
> 核心原则：**前3秒直接给情绪/悬念/反差，不要铺垫背景；一句话控制在2～3秒念完，画面和台词同步，不要各说各的**

1. **痛点提问钩（共鸣最强，知识/生活/带货首选）**
公式：精准人群+正在遇到的麻烦
例子：“是不是你每天熬夜护肤，皮肤还是很差？”
要点：不要泛泛提问，要让用户一眼看到自己。

2. **结果前置钩子（数字量化，干货、逆袭类）**
公式：短时间+低成本+惊人结果，**只报结果，不说方法**
例子：“只用3招，我账号7天涨了1万粉。”

3. **反常识/打破认知钩（流量爆发力强）**
公式：大众以为A，真相其实不是A
例子：“你以为多喝水能排毒？其实喝多反而伤肾。”
⚠️ 注意：不能纯标题党，后面要能圆回来。

4. **点名人群钩子（精准筛选观众，提升留存）**
公式：“XX的人，这条一定要看完”
例子：“月薪5千想存钱的，千万别乱买理财。”

5. **悬念缺口钩子（剧情、故事类）**
公式：讲一半，留关键信息不说
例子：“我辞退了月薪2万的员工，原因不是能力差。”

6. **视觉钩子（不用说话，画面先抓人）**
画面第一帧直接放冲突/反差画面：烂脸对比、翻车现场、开箱惊喜、冲突瞬间，台词辅助。

> ✅ 写钩子自检一句话：**听完这句，观众是想继续看，还是觉得“哦，知道了”直接划走？**

# 二、怎么提前判断脚本有没有爆款潜力（发之前自测5问）
> 爆款不是猜，看「用户是否愿意停留+互动」，不是你觉得好不好看

### 1. 钩子能不能在3秒制造情绪？
能不能触发：好奇、焦虑、共鸣、惊讶、愤怒、爽感？
❌ 差钩子：“今天跟大家聊聊短视频怎么写钩子”（平淡，没有情绪）
✅ 好钩子：“90%的人写短视频开头，从第一句就错了。”

### 2. 内容和目标用户有关系吗？
问自己：这条视频是给谁看？他刷到会不会觉得“说的就是我”？
如果换任意博主讲这段话，都差不多，大概率难爆，属于通用废话。

### 3. 平台有没有同类爆款验证？
去搜索关键词，看同赛道有没有多条高赞视频。
- 有不少同类型爆款：选题被验证，概率更高；
- 搜出来几乎都是低赞：选题太冷，很难爆。
> 爆款本质是**已经被用户证明过的需求，换表达方式重做**

### 4. 全程节奏：每5～10秒有没有新信息/小反转？
钩子留住人之后，不能一直重复同一个观点。每隔几秒要有新观点、案例、反转、干货，不然中段大量跳出。

### 5. 有没有互动出口（评论/点赞/收藏理由）
看完能不能引发评论：认同、质疑、想@朋友、求教程、吐槽？
- 适合收藏：干货避坑
- 适合评论：争议、共鸣提问
- 适合转发：能发给别人参考

## 简易打分表（快速自测）
每项20分，总分≥70分，爆款潜力较高
1. 3秒钩子有情绪，不平淡（0-20）
2. 精准击中一类人的痛点/好奇（0-20）
3. 同赛道已有爆款佐证选题（0-20）
4. 视频中段持续有信息，不拖沓（0-20）
5. 看完愿意点赞/评论/收藏（0-20）

# 三、发布后，用数据二次判断潜力（最准）
1. **3秒留存（最重要）**：低于40%，钩子不行，直接改开头重拍；高于60%，钩子合格
2. **完播率**：短视频尽量达到行业基准以上；完播高才有机会推更大流量池
3. 评论、转发、收藏率，高则更容易持续推流

# 四、避坑提醒
❌ 不要开头铺垫一堆背景：“大家好我是谁，今天我来聊聊…”直接划走
❌ 不要过度夸大、纯标题党，开头吹很大，内容完全不兑现，会导致差评、低完播
❌ 钩子和正文脱节：开头讲存钱，后面讲美食，逻辑断裂
