# 代运营多品牌视频素材管理完整方案
核心原则：**品牌物理隔离 + 统一命名标签 + 权限分级 + 版本管控 + 版权台账**，防止不同品牌素材混淆、版本错乱、客户素材泄露，同时方便素材二次复用。

## 一、搭建标准化文件夹目录（模板直接套用）
顶层：按品牌独立建根文件夹，**品牌之间完全隔离**，禁止跨品牌混用素材文件夹
```
素材库
├─【品牌A】
│  ├─00_品牌规范（VI、字体、配色、logo规范、口播话术模板）
│  ├─01_原始素材（拍摄原片、达人交付、客户提供素材，只读，禁止修改覆盖）
│  ├─02_剪辑工程（剪映/PR工程文件、分镜、脚本）
│  ├─03_剪辑草稿（v1/v2/v3迭代版本）
│  ├─04_定稿成片（按平台区分：抖音/小红书/视频号）
│  ├─05_封面/字幕/音频
│  ├─06_归档（下线旧素材、废弃版本）
│  └─07_版权&授权文件（UGC达人授权、音乐授权、合同）
├─【品牌B】（同结构复制）
└─公共素材库（公司统一商用BGM、转场模板，**不属于任何客户**）
```

## 二、统一文件命名规范（强制落地）
命名公式：`品牌简称_内容类型_产品/主题_日期_版本_平台`
示例：
`品牌A_产品口播_洗面奶_20261014_v2_抖音.mp4`
- 禁止：`最终版.mp4`、`新建视频.mp4`、`最终改好真的.mp4`
- 版本号：v1初稿、v2修改、v3客户定稿；**不要覆盖旧文件**，每个版本另存，旧版移入归档文件夹

## 三、标签+元数据管理（检索提速，适合大量素材）
搭配多维表格 / DAM素材库，给每条素材打标签，支持快速筛选：
1. 基础标签：品牌、产品线、内容类型（口播/测评/剧情）
2. 生产标签：拍摄日期、素材状态（未剪辑/待审核/已发布/废弃）
3. 业务标签：平台、投放类型（自然流/千川）、数据表现（爆款/低效）
4. 版权标签：素材来源、授权期限、可用范围（仅限短视频/不可用于广告）

> 台账字段建议：素材ID、品牌、简介、文件链接、版权有效期、使用记录

## 四、权限管控（多品牌最重要：防素材泄露、串品牌）
按角色分配权限，每个品牌独立权限组：
1. 管理员：全部品牌素材读写、权限管理、备份
2. 项目编导/剪辑：仅负责品牌的素材读写，**看不到其他客户素材**
3. 客户对接（商务）：仅预览、分享，不可删除原始素材
4. 品牌方客户：外部访客权限，只能查看自己品牌待审核成片，看不到其他品牌，分享链接可设置有效期、密码，限制下载

## 五、版本管理+生产流程SOP
1. 原始素材一旦入库，**只读锁定**，剪辑只复制副本进行编辑，不改动原片，防止源文件损坏丢失
2. 审核流程：草稿→内部初审→客户确认→定稿入库；定稿文件单独存放，所有历史版本保留归档，不删除
3. 素材复用规则：**A品牌原始实拍素材，严禁直接给B品牌使用**；只有公司公共商用模板、BGM可以跨品牌复用
4. 定期清理：按月归档已下线素材；过期、无版权素材标记禁用，避免侵权风险

## 六、存储与工具选型（按团队规模选择）
### 小团队（3-10人，5个以内品牌）
- 网盘共享：阿里云盘/企业网盘 + NAS本地备份；多维表格（飞书多维/Notion）做素材台账
- 优点：低成本；缺点：标签、权限弱，素材量大后检索慢

### 中大型团队（10人+，10个以上品牌）
- DAM数字资产管理系统（MuseDAM、Filecamp等）：原生支持品牌隔离、标签检索、版本管理、客户外部门户、操作日志，适合大量视频素材，可直接分享给客户在线审片、批注反馈
- 存储方案：NAS本地高速存储（剪辑直接读取素材）+云端备份双备份，防止素材丢失

## 七、版权与风险管控（代运营高频踩坑点）
1. UGC达人素材、外购素材，授权合同、肖像权文件和素材放在同一品牌文件夹，记录授权到期时间，到期禁止继续使用
2. 商用音乐单独管理，区分免费商用/付费授权，禁止随意拿网络热门BGM商用
3. 离职人员：及时回收素材权限，所有客户素材资产留在公司库，不允许带走本地工程与原片

## 八、日常运维机制
1. 素材管理员/项目负责人：每次拍摄交付后24小时内完成上传、打标签、归档
2. 每周巡检：检查命名规范、权限是否泄露、过期版权素材
3. 每月备份：所有客户素材异地备份，防止硬盘损坏丢失素材
4. 新人培训：素材SOP、命名、权限红线，禁止跨品牌复制素材
