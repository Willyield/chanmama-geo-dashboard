# 一、核心逻辑：卖点≠直接念，卖点=痛点的解决方案
**转化原则：把产品特性 → 翻译成解决用户麻烦的价值**
> 错误：我们拖把吸水性强、不掉毛（纯卖点）
> 正确：拖完地全是水印、拖把掉毛粘一地头发（痛点）→ 这款拖把吸水快还不掉毛，拖完干得快，不用反复刮（卖点对应解决痛点）

**第一步：做配对表（先整理素材）**
| 用户痛点（麻烦、难受、损失） | 对应卖点（产品能力） | 用户得到的价值（情绪/结果） |
|---|---|---|
| 痛点1：早上赶时间，早餐又慢又难吃 | 卖点1：3分钟快速加热，口感松软 | 不用早起，吃上热早餐 |
| 痛点2：清洗麻烦，藏油污难刷 | 卖点2：可拆卸，全身可水洗 | 洗完一冲就干净，不藏细菌 |

> 规则：一条视频只抓**1个核心痛点+1~2个配套卖点**，不要堆一堆卖点，短视频记不住

# 二、万能短视频脚本公式（25～40秒电商口播最常用）
**3秒痛点钩子 → 放大痛点+共情 → 产品出场，卖点对应痛点演示 → 前后对比/效果证明 → 价值总结+行动指令**
1. **0～3秒钩子（留住人，疑问句/扎心陈述句）**
    直接戳场景痛点，不要铺垫
    例：是不是洗完地，地上全是水印，头发还粘在拖把上？
2. **3～12秒：放大痛点，共情**
    描述麻烦带来的糟心感受
    例：每次拖完还要蹲下来捡头发，干了之后脚印水印又出来，白忙活半天。
3. **12～25秒：产品亮相，卖点可视化（重点！不要干讲）**
    卖点**配合画面演示**，每讲一个卖点，对应解决前面的痛点
    例：换这个拖把就省事了（镜头：展示拖布），高密度纤维，一拖头发全部带走（演示拖地），吸水力强，拖完地面很快干，不留水印。
4. **25～33秒：效果佐证，降低顾虑**
    前后对比、实测、细节特写
5. **33～40秒：收尾+行动指令**
    圈人群+引导下单
    例：家里经常拖地嫌麻烦的，左下角直接带走。

# 四、3种不同风格脚本变体，同一个痛点卖点可以批量拍
## 版本1：口播种草（适合达人、个人IP）
公式：共情自述（我之前踩坑）→ 痛点难受 → 找到产品 → 卖点解决痛点 → 效果
> 台词：以前我拖地真的崩溃，拖布缠头发，地面干了全水印。试了好多拖把都不行。直到用这款，吸附毛发，吸水快，拖完不用二次清理，做家务省超多时间。

## 版本2：情景短剧（适合强场景，15-25秒）
公式：情景演出痛点画面 → 烦恼抱怨 → 拿出产品解决 → 展示效果
> 画面：女主拖地，看见满地毛发水印，叹气；男主递拖把；女主拖地，地面干净。
> 台词：又要捡头发？用这个拖把，头发水印一次搞定。

## 版本3：实测对比（投流素材，说服力最强）
公式：反面产品踩坑演示 → 暴露痛点 → 换自家产品实测 → 对比结果+卖点
> 台词：普通拖把，头发全缠上面，地面有水印。看我们这款，一拖毛发全带走，地面速干。

# 五、避坑要点
1. ❌ 不要罗列参数卖点，**卖点必须绑定痛点**，不要单独介绍产品参数
2. ❌ 不要一条视频塞3个以上痛点卖点，信息过载，用户划走
3. ✅ 卖点尽量**可视化**：能演示就不要只靠嘴说（吸水、防漏、耐磨，实拍比口播强很多）
4. ✅ 口语化，短句，去掉广告书面词；一句话控制在15字以内
5. ✅ 同一个产品，可以**换不同痛点**，批量产出多条素材去测试

# 六、快速实操示例（保温杯举例）
痛点：早上装热水，到中午就凉了；杯盖缝隙藏污渍难清洗
卖点：24小时保温；杯盖可拆卸，全拆开清洗
> 【脚本 30秒】
0-3s：（镜头摸已经凉掉的水杯）早上装的热水，中午就凉透了？
3-12s：想喝口热的太难，杯盖缝隙还藏污垢，刷都刷不到。
12-24s：这款保温杯，24小时长效保温，杯盖可以全部拆开冲洗，不留死角。
24-30s：随时喝热水，好清洗不藏脏，喜欢直接拍。
