# AI带货短剧怎么做 + 适合什么商品
一句话核心逻辑：**用短爽剧情留住人，产品嵌入剧情冲突，结尾带出卖点+购物车，不用真人出镜、不用实景拍摄，AI批量生成竖屏9:16短视频**，大多是15–60秒短剧片段，适合抖音、快手、视频号挂车。

## ✅ 一、完整制作流程（新手SOP）
### 1. 选品+提炼卖点（优先做这一步，剧本围绕产品写）
把产品浓缩**1-2个强痛点卖点**，不要堆参数。
> 例：魔术拖把——拖地边角去灰、免手洗；口气清新糖——吃完火锅立刻去异味

### 2. 写短剧脚本（AI直接生成）
爆款结构（非常好用）：
1. **5秒钩子**：制造冲突（婆媳矛盾、职场打脸、误会反转、宫斗、重生、家庭尴尬场景），留住用户
2. **剧情发展**：矛盾升级，主角遇到痛点
3. **产品出场**：痛点最高潮时拿出产品，解决问题（**产品必须是解决矛盾的关键道具**，不能硬植入广告）
4. **结尾转化**：展示效果、价格福利、引导点击小黄车

脚本提示词模板（直接丢给豆包）：
> 写30秒竖屏AI带货短剧，现代家庭题材，9:16，人物2个。开头冲突钩子，痛点，产品出场解决问题，结尾带货口播。产品：免手洗拖把，卖点：边角无死角、拖完无水渍。分镜写清楚画面+台词+时长。

题材模板：婆媳矛盾、职场逆袭、霸总、宫斗、宿舍日常、夫妻误会、家庭省钱小故事。

### 3. 生成画面、配音、字幕
两种路线：
- **新手一键流（推荐）**：小云雀、即创等AI剧情广告工具，上传产品图，粘贴卖点，直接选题材，AI一次性生成画面、配音、字幕，几分钟出片
- **精细自制流**：AI生成人物/场景图 → 分镜生成视频 → AI配音 → 剪映加字幕、BGM、产品特写、挂车贴纸

> 注意：保持人物长相统一，不然画面跳戏，影响完播。

### 4. 后期+发布
1. 剪辑微调：加产品特写、价格贴纸、小黄车引导文字
2. 合规检查：不能夸大功效、医疗宣传；食品/美妆不能违规宣称
3. 发布：挂商品橱窗，批量测试多版本脚本，看哪类题材跑量，放大复制

### 5. 工具清单
- 写脚本：豆包、Kimi
- AI短剧视频：小云雀、即创、Seedance
- 配音字幕：剪映AI配音

## ✅ 二、适合AI带货短剧的商品（核心标准：**痛点可视化、低客单、高佣金、场景强**）
### 优先推荐品类（跑单最多）
1. **家居日用百货**（最适配）
拖把、清洁湿巾、收纳盒、防滑垫、垃圾袋、厨房神器、除味剂。
理由：家庭矛盾剧情天然匹配，痛点一眼看得见，客单价9.9–39元，退货低。

2. **食品零食饮料**
速食面、无糖茶饮、小零食、坚果、冲泡咖啡/代餐。
适配剧情：加班、聚餐、宫廷美食、家庭聚餐场景。

3. **平价美妆/个护**
护手霜、唇膜、香氛、口气糖、洗脸巾、发饰。
适合：职场、约会、婆媳对比剧情。

4. **宠物小件**
宠物梳、猫砂除臭、宠物喂食小用品。

5. **小数码、小配件**
耳机、手机支架、数据线、充电宝。

### 选品硬性标准
- 售价：**9.9–59元最佳**，太高很难冲动下单
- 佣金：≥20%，才有投放和批量制作的利润空间
- 效果可视化：能在短剧里直观展示效果（去污、变干净、变好看）

## ❌ 不适合AI短剧带货的品类
1. 高客单价大件：家具、大家电、贵重珠宝、高端手表
2. 强体验类：需要真人试穿精细版型的高价女装（AI虚拟人物效果容易失真）
3. 医疗、药品、保健品（宣传限制极严，很容易违规限流）
4. 效果很难可视化的抽象产品、B端工业产品

## ⚠️ 重要避坑（很多人踩雷）
1. **版权风险**：不要直接盗用小说、影视IP剧情，AI生成人物素材要确认商用授权，避免侵权投诉、下架账号
2. **广告合规**：禁止虚假夸大，比如不能随便写“根治、100%除菌、治病”等词，美妆不能宣称医疗功效
3. **不要硬植入**：产品不能凭空出现，要融入剧情解决痛点，硬广完播直接崩盘
4. 批量发布：同一条视频不要直接重复发，改台词、镜头、人物风格，做多版本测试

## 💡简单案例参考
> 题材：婆媳矛盾，卖厨房去油湿巾
【钩子】婆婆嫌弃儿媳厨房油腻，吵架。
【痛点】油污怎么擦都擦不掉。
【产品出场】儿媳拿出去油湿巾，一擦就干净。
【结尾】“厨房油污难清理？这款去油湿巾，一张搞定，今天橱窗有优惠。”
